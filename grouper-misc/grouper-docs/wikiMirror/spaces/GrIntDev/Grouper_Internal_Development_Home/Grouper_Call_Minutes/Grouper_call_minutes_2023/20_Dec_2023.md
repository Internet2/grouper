- [GRP-5196 gsh template WS should be able to read and write arbitrary JSON](https://todos.internet2.edu/browse/GRP-5196)[Grouper programmatic JSON](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28547952/Grouper+programmatic+JSON)
  
  - - Relates to how to deal with JSON from Java
    - You can deal with a map, can use arrays or lists or collections
    - You can take JSON and marshall that into a map
    - JSON arrays go into collections in java
    - Can convert a map to a java bean
    - With GSH templates and web services
    - Previous way is awkward to deal with web services
    - The inputs are name value pair params
    - Like what the screen does
    - Weird on the output, whatever was displayed to screen gets displayed, there are escapes
    - New way:
    - on the **Input** there is a WS input map.
    - There will be a WS input field
    - You can put whatever you want in there,
    - Name value pair, or can be more complex
    - Will populate the GSH input field
    - Can take the map and and loop thru it or can convert to a bean in your GSH template so it is more programmatic
    - For **Output**, there is WS output of type output
    - When marshalled back to JSON will take either map or java bean
    - Will convert to JSON, including lists, arrays, etc
    - You can have arbitrary web services that can handle JSON input and return JSON output
    - Have a request for this at Penn
    - In the GSH template it is presented as a map,
    - Can loop thru or can convert to java bean structure
    - Using groovy, maps look like beans
