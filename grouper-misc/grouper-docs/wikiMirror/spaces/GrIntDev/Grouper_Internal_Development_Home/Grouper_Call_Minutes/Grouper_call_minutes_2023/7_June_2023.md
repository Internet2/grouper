**University of Virginia**

- Looking at Attestation
- Concerns:
- Attestation only seems to be a single stamp on entire group
- Not tied to state of group’s membership
- Concerned about UI/UX issues
- UVA might need UI changes and data model changes
- Not asking for changes currently
- UVA might be willing to support this work on improving Grouper attestation
- UVA will have requirement for a yearly attestation for all group
- Existing groups tool at UVA (not Grouper) has thousands of groups with owner no longer at University
- Issue that people just click through and click OK on attestation
- Concern : what if attestation is on an exclude group?
- Suggestion for a way for group admin to use a button to put a stamp on the membership that says “yes this person needs to be in this group”
- Or attest to the rule putting members into a group
- U Penn does reports with details on groups, how many members in the group, how many are not active, etc
- Duke makes it easy to add a comment on ad hoc memberships as a reminder of why that person was added
- UVA will kick the tires on current attestation features and suggest improvements
- Attestation could be a good ACAMP session

Can Telemetry be used to see who is using the attestation feature?
