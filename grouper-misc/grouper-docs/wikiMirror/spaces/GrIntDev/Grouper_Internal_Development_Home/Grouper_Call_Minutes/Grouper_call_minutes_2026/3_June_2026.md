**Notes from Zoom AI**

**Call Summary**

The meeting focused on updates and discussions regarding Grouper development, including improvements to the data dictionary interface, visualization updates, and plans to transition from Groovy to Java code execution. Vivek demonstrated new features for searching and managing data fields, including improved filtering and export options.

Shilen presented updated visualization improvements that make complex authorization rules more readable with clearer language and better formatting. Chris Hyzer introduced plans to migrate from Groovy to Java for custom code execution in Grouper, explaining the technical benefits including faster performance, better debugging capabilities, and improved type safety. The team discussed implementation approaches, security considerations, and the timeline for releasing these improvements, with general agreement on moving toward more frequent releases including V7 and potentially V8.

**Michigan AI Infrastructure Planning**

Gail discussed Michigan's AI infrastructure capabilities and mentioned her team's plans to experiment with making AI more useful in their services, including setting up their own protected data environment with multiple model options. Gail explained her goal to make AI tools more accessible to faculty members who lack deep technical knowledge of the underlying data. The group reviewed action items including documenting Confluence Cloud Migration options, gathering requirements information, and adding progress logging to provisioners in JIRA.

**Okta Provisioner Performance Issue**

Gail discussed an issue with a long-running provisioner that appears to be stuck without completing tasks, particularly when processing 700K members for Okta API services. Chris Hyzer suggested turning off command logging due to potential performance impacts, though Gail needs it enabled to monitor progress on the 100,000 row task. Bert recommended enabling thread name logging to help correlate with JStack output and identify the specific thread causing the issue.

**AVAC System Improvements Review**

The team reviewed recent improvements to the AVAC system, including a revamped data field dictionary page that allows users to search for data fields, aliases, descriptions, and export results in CSV or JSON format. Vivek demonstrated new features including URL-based filtering, the ability to copy and paste links, and a new button to copy group member descriptions.

The team discussed the growing number of data fields being implemented, with Gail and Ben noting they have around 25-100 attributes each, though they acknowledged the need to pare down and simplify the authorization attributes.

**Data Visualization Updates Demonstration**

Shilen demonstrated visualization updates that now allow adding friendly names to data fields for better readability in visualizations. Chris Hyzer suggested using sentence case for descriptions and provided guidance on capitalization requirements.

The team reviewed a complex visualization example that shows affiliation conditions, with improvements made to make it more English-readable and consistent with composite visualizations.

**Graphiz Visualization Design Review**

The team reviewed a third iteration of a visualization design, with Chris Hyzer explaining that Graphiz automatically lays out nodes and consolidates them in logical places. Gail suggested testing the design with customers, while Carey provided feedback about arrow styles and line differences for better clarity.

Shilen mentioned creating an alternative version with more options and clarified the handling of double knots in affiliation codes.

**Grouper Transition from Groovy to Java**

Chris Hyzer discussed plans to transition Grouper from Groovy to Java code, explaining that the current Groovy implementation is slower than compiled Java and creates maintenance challenges. The new system would compile custom Java code on-demand and provide better debugging capabilities, with a unified admin interface to track and manage all customizations. The team debated the timing of releasing V7/V8, with Ben suggesting consistency with annual releases and Chris considering whether to release soon or wait until the end of the year, though no final decision was made.
