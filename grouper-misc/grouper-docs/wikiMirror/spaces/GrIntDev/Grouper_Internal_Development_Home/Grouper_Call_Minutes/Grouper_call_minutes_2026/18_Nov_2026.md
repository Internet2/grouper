**Summary (From Zoom AI)**

The meeting focused on security updates and new features for Grouper.

Vivek demonstrated a new Change Log Monitor tool for diagnostics, including graphs and tables to track pending changes and consumer lag. He also reported fixes for a copy-paste error in entity link refreshing, an optimization for error retries based on error type, and expanded rule condition support for group extensions. Chris discussed long-term security hardening ideas, such as requiring explicit configuration for security groups, restricting root sessions in code, and potentially using a separate database schema for privileged groups and audit tables.

The group also touched on the recent Java exploit and the process for creating new containers. Shilen shared updates on MCP and the AI Assistant, including improved Jexal script creation and a potential fix for slow queries. Chad mentioned completing Playwright tests for the Grouper training environment and noted that AWS version 1 jars have been deprecated.

**Discussion (From Zoom AI)**

**Changelog Monitor Tool Updates** Vivek presented updates on recent work, including the development of a changelog monitor tool under Miscellaneous that provides diagnostics on daemon performance and consumer lag. He also fixed a copy-paste error in entity link refresh settings and implemented an optimization for error handling based on error types. Gail inquired about the readability of the changelog monitor with 32 consumers, and Vivek acknowledged the need to test visual clarity.

**Security Updates and Implementation Discussion** The team discussed security updates, including a Java exploit and patch implementation, with Chris noting that the security changes were proceeding well with minimal questions from users. Chad was asked to follow up with Rebecca regarding missing attributes and to check if the Grouper ListLoader fix was tested. The team also briefly touched on various other items including attestation protocol workflow, AI training materials, and custom composite eligibility group configuration for future consideration.

**Technical Issues and Server Migration** The team discussed several technical issues including Java doc updates and server migration plans to AWS, though no specific timeline was confirmed. Emily agreed to investigate an unclear action item that may involve Vivek instead of Rebecca. Gail raised concerns about target ID changes in the sync back system, noting that the current implementation leaves old target IDs in the system, which could potentially cause issues with ID reuse in provisioners. Chris indicated they would need to further investigate this target ID handling approach, particularly regarding its impact on systems like Duo that Bright uses.

**Grouper Security Improvement Recommendations** Chris led a discussion on security improvements for Grouper, presenting several recommendations including implementing coding standards for root sessions, centralizing authorization code, and adding logging for source IP addresses. The team discussed implementing a separate database schema for privileged operations, with Gail suggesting that privileged groups would need regular updates. Shilen mentioned their existing practice of using separate subjects for wheel users, and Chad noted that Grouper already requires MFA for access. The team also discussed restricting Tomcat user permissions and potentially implementing approval workflows for sensitive operations, though they acknowledged some proposals might be difficult to implement.

**Jexel Scripts Updates and Improvements**

Shilen reported updates to MCP and the AI Assistant to make Jexal scripts more user-friendly, including improved visualization and analysis capabilities. He also discussed potential improvements to query performance and outlined several JIRA items for future consideration, including different instructions for MCP versus the AI Assistant and support for refresh tokens. Chris and Shilen explored the possibility of implementing dynamic scope changes in MCP, though they acknowledged potential OAuth specification concerns. Chad announced completion of Playwright tests for the Grouper training environment and noted that AWS version 1 JARs have been deprecated for about a year, with version 2 alternatives available.
