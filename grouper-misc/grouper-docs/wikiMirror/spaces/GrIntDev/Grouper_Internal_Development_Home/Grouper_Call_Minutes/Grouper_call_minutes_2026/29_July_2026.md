**Call Summary (from Zoom AI)**

Chris led the discussion through various technical updates including research on replacing members and composite groups, with new functionality to handle existing memberships more gracefully during conversions. Shilen reported fixes to deep check issues in Oracle and updates to ABAC functionality including multi-valued global variables and time-based queries. Vivek shared multiple completed fixes including hook auto-registration improvements, external system test button enhancements, and data provider updates. Chad discussed upgrades to the CCARE provisioner for Michigan and updates to Tomcat versions, while also noting issues with loader diagnostics for JEXL scripted groups. The team also reviewed new form-based login authentication options and external system reference tracking features. Gail mentioned ongoing work on log output analysis for the 35-hour octa provisioner run, and Carey discussed ideas for moving code out of operational images and into Git repositories. The conversation ended with Julian being introduced as the new Grouper specialist at UVA, replacing Kellen who will continue working on Grouper alongside Julian.

### **Discussion (from Zoom AI)**

**Composite Group Functionality Updates**

The team discussed updates to composite group functionality, with Chris proposing new behavior for converting groups to composite groups that would handle existing members more gracefully. Shilen suggested adding a confirmation screen to show the number of members that would be added or removed, which Chris agreed to open a Jira ticket for as a potential Phase 2 feature. The team also addressed performance logging improvements, with Chris agreeing to implement progress tracking with timestamps in the debug log to help Gail monitor the progress of long-running operations more effectively. Carey raised questions about moving code out of the operational image and into Git repositories for better version control across deployment environments, though the team noted this would require specific implementation details based on deployment methods.

**Grouper Team Updates and Improvements**

Kellen introduced Julian Anderson as the new Grouper team member at UVA, though both Kellen and Julian will continue working on Grouper responsibilities. Shilen presented updates on database deep check improvements, including fixes for Oracle foreign key checking and column precision issues. Vivek shared updates on hook auto-registration fixes, addressing issues with failed registration hooks disabling other hooks at startup, and improvements to the Grouper external system test button to show proper error messages and logs.

**Bug Fixes and System Improvements**

Vivek presented updates on various bug fixes and improvements implemented over the past two weeks. Key changes included adding audit logs for daemon enable/disable operations, fixing URL behavior to prevent unintended state changes when using hyperlinks, implementing multiple assignment methods, and improving data retrieval performance with thread pooling. The team discussed the importance of maintaining consistent behavior for URL-based actions, with Chad emphasizing that right-click functionality should not be affected. Vivek agreed to create a JIRA ticket listing all places where URL changes need to be reviewed, and Gail expressed interest in testing the new parallelizable data retrieval feature.

**JIRA ABAC Enhancements Update**

Shilen presented updates on JIRA enhancements for ABAC, including support for multi-valued global variables and bug fixes for negative numbers and NOT conditions in the analyze screen. He also explained improvements to timestamp handling and the addition of time-based query support using various time units. Chad then provided an update on the CCARE provisioner implementation for Michigan, noting it was a specific use case for provisioning memberships in a separate user/group maintenance system.

**Grouper System Updates Discussion**

The team discussed several updates and issues related to Grouper, including a PR fix for service URL consistency, improvements to external system references, and the implementation of form-based login for non-production environments. Chris demonstrated new features like the internal browser for training and testing, and the external system reference tracking. The team also addressed concerns about loader diagnostics, job failure notifications, and potential issues with OAuth token expiration in Entra provisioners. Gail noted that the external system references feature might only show recent changes, suggesting a recalculation task during upgrades.
