**Call Summary (From Zoom AI)**

The meeting focused on recent development updates and bug fixes for Grouper. Vivek reported on several UI and backend improvements, including changing certain actions from URL-based navigation to Ajax posts for better security, fixing a Firefox-specific calendar time selector issue, and enhancing Okta integration resilience. He also demonstrated a fix for a broken error anchor URL in provisioning and a fix for orphan report instance rows in the database.

Shilen presented updates on the AI assistant, including improved contrast for accessibility, a fix for group find sorting, and a new feature allowing GSH templates to be treated as read-only under specific conditions. The team discussed the AI assistant's token usage and the possibility of streaming responses, though they noted technical constraints. Chad raised a concern about WCAG contrast requirements making it harder to distinguish direct and indirect memberships in the UI.

Chris Hyzer shared a wide range of updates, including a Smartsheet provisioner, a fix for a deadlock issue reported by Harvard, and a change to prevent clearing the cache while a daemon is running. The group also briefly discussed the plan for upgrading to Tomcat 10 and Jakarta.

**Discussion (From Zoom AI)**

**UI and Backend Improvements Update** Vivek presented updates on several UI and backend improvements, including fixing GET request issues that modified database state, resolving Firefox calendar selector problems, and enhancing Okta integration. The team discussed improvements to the AI assistant feature, with Vivek proposing to implement streaming responses and Markdown rendering, though Chris suggested focusing on basic functionality first. The group also explored deployment options for AI services, confirming that Light LLM and similar gateways can handle both OpenAI and Anthropic APIs through a reverse proxy approach.

**Bedrock Cost and Documentation Updates** The team discussed the high cost of using Bedrock with Cloud Code, with Chris Hyzer noting that 5 developers incurred a $4,000 bill in a single month. They reviewed documentation updates for Java, deciding to simplify the structure by maintaining only the latest stable branch and removing numbered versions. The team also discussed various action items including creating a release notes page that links to all active versions, investigating logout functionality, and testing AI agent security before rollout. Liam and Gail confirmed they successfully tested Okta provisioner fixes and planned to deploy them to version 751 after TechX.

**TOMCAT10 Upgrade Planning Meeting** The team discussed plans for upgrading TOMCAT10 in Jakarta, with Chris Hyzer planning to deploy the upgrade on Saturday before TechEX, while Kellen planned to deploy 7-9 on Tuesday after TechEX. Julian agreed to create a pull request with the necessary changes, which primarily involve imports and function signatures, with Chris suggesting they wait about a month after TechEx to implement the changes. The team also discussed the need to check Tomcat's default configuration changes and create upgrade instructions, with Chad tasked to coordinate with Internet 2 admins for Java docs and Vivek to investigate user lifecycle events using Julian's provided configs.

**GRP Updates and MCP Functionality** Shilen presented updates on several GRP items including fixing pen-specific descriptions, improving AI assistant contrast issues, and resolving recipe UI column problems. He demonstrated new MCP (MCP Read Only When) functionality that allows templates to be marked as read-only based on specific inputs, preventing unnecessary approval prompts. Chris Hyzer suggested removing the save button and discussed potential improvements to the JEXL configuration format. Shilen reported that MCP is currently being used by the IAM team at Duke, with one additional person recently gaining access, who raised questions about consent management and refresh tokens.

**Technical Updates and Improvements** The team discussed several technical updates and improvements. Shilen and Chris Hyzer explored reducing token size by sending only essential tool information initially, with plans to test this approach. Chad presented updates including support for private keys in OIDC external systems, fixes for UI accessibility issues, and improvements to SCIM and Duo integration. Julian shared his work on hiding default G-Shell templates in favor of organization-specific ones. The team also reviewed recent commits including performance improvements for full syncs and various bug fixes.
