**Overview and Discussion From Zoom AI**

Vivek presented updates on recent Jira work including fixes for group loader failsafe issues, UI improvements for the AI assistant with Markdown to HTML conversion, and support for custom HTTP headers with encryption for web service bearer tokens. The team discussed several technical improvements including a new "Who Am I" tool for MCP, database lock implementation for multiple JVM startups, and fail-safe fixes for provisioning scenarios. Shilen demonstrated significant improvements to the AI assistant including tool description optimization that reduces token usage and immediate saving functionality, while also discussing plans to create scripted groups through the API. The team reviewed recent TechEX conference sessions, particularly focusing on attestation protocols, identity-first approaches, and performance considerations for large-scale Grouper deployments. Chris Hyzer and the team discussed various technical challenges including daemon resource management, provisioner performance issues, and the need for better UI options to improve contrast in the interface.

**Grouper Jira Updates and Enhancements**Vivek presented updates on several Grouper Jiras, including fixes for the group-like string loader issue and improvements to the web service with support for custom HTTP headers and encrypted secrets. He also demonstrated UI enhancements for displaying group membership data in a table format with checkboxes and a "Who Am I" tool. The team discussed database locking mechanisms for handling multiple JVM startups, with Chris Hyzer asking about existing locks on upgrades.

**Markdown Security Implementation Discussion** Vsachdeva demonstrated several fixes including a markdown to HTML converter, fail-safe improvements, and handling of incremental to full sync conversions. The team discussed security considerations for the markdown renderer in the AI assistant, with Vivek confirming that only predefined allowed elements would be displayed to prevent security issues like XSS or phishing links. Chris Hyzer requested that Vivek consult with KI about the specific allowed tags and security constraints for the markdown renderer.

**Project Updates and Action Items**The team reviewed several ongoing projects and action items. Shilen confirmed completion of work on reducing tool size and testing ISS code review. The team discussed an issue where AI assistants sometimes request double approval, which Shilen attributed to institutional instructions in tools originally created for MCP. They agreed to create a Jira ticket to track different instruction sets for MCP and UI environments. Julian proposed skipping Tomcat 10 upgrade and going directly to Tomcat 11, which Chris Hyzer approved of, though they agreed to wait a few more weeks before proceeding with the PR.

**Attestation Protocol Integration Discussion** The team discussed a new attestation protocol proposal from Kellen and UVA, which is similar to SCIM and could potentially be integrated with Grouper. Kellen mentioned plans to demonstrate the protocol in an upcoming IAM online session either this month or in January. The discussion also touched on the potential for Grouper to serve as an attestation engine, with David working on a demo using WordPress and Moodle components.

**Identity Management System Improvements** Chris Hyzer and Chad discussed using Grouper as a tool for authorization, with Chad agreeing to follow up with Vivek on Slack about missing attributes. Gail mentioned plans to form a committee under CACTI to discuss identity-first initiatives, focusing on addressing duplicate records across multiple sources of record and simplifying preferred name updates. The discussion highlighted challenges with current systems requiring users to update information across multiple sources, with Gail proposing that the IAM system could serve as a central hub for managing personal data and directing users to appropriate change processes.

**AI Training and Implementation Updates**   
Chris Hyzer discussed the Grouper AI training session on Monday afternoon at TechEx that covered Grouper and AI interfaces, noting it could be developed into a full course. Shilen shared an example of how AI recipes helped resolve a complex reference group creation issue that had previously caused multiple tool calls and timeouts. The team discussed potential improvements including creating institution-specific dictionaries and implementing logging to identify inappropriate prompts that generate excessive tool calls. Kellen mentioned lessons learned from UVA regarding stem structure implementation and highlighted upcoming enhancements, including work on the Okta provisioner.

**Job Scheduling and Resource Management** The team discussed challenges with job scheduling and resource management in their system, particularly around daemon nodes and provisioners. Chris Hyzer explained that they prefer keeping the system simple by using identical-sized nodes rather than implementing complex scheduling features, as this avoids maintenance challenges. The group addressed performance issues with provisioners, with Gail noting that adding more RAM typically resolves most problems, though they also mentioned the need to adjust Tomcat's memory allocation when increasing system memory. The discussion concluded with a brief mention of new lifecycle events for membership-level attestation and workflow processes.

**Accessibility and Grouper Implementation Discussion** The team discussed several topics including accessibility features and Grouper implementation. Gail highlighted the importance of considering accessibility from the design stage rather than as an afterthought, noting that Keith Wessel's demonstration of using screen readers with Duo security was impressive. The group also discussed Grouper's provisioners, with Gail mentioning their work with large-scale group management involving 700,000 people and 96 gigabytes of data. Shilen and Chris explored the concept of a multi-master provisioner to handle direct changes to access control groups, while Kellen shared updates on his work with Agentic AI and semantic layers, including an upcoming talk at Community Exchange about Agentic AI and the Federation boundary.

**Grouper Updates and Improvements**

Shilen provided updates on several changes to Grouper, including removing the save button, implementing a new tool describe feature to reduce token usage in AI assistant interactions, and adding date information to LLM messages. He also discussed progress on making scripted groups creation easier through the API, which will eventually be exposed through JEXL. Chris agreed that creating a UI for custom composites and eligibility lists would be beneficial to make Grouper more user-friendly, and Shilen will add this to his list of future improvements.
