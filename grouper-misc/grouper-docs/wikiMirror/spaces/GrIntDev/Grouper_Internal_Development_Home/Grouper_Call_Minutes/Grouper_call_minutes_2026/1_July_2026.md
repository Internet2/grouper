**Summary**

The team reviewed multiple JIRA tickets covering Entity Data Field configuration improvements, performance optimization issues, SCIM provisioning diagnostics, and various bug fixes. Key updates included Vivek's work on adding new columns to Entity Data Field screens, Chad's progress on Azure provisioner migration and query performance investigations, and Reed's accessibility improvements across 112 files. The team also discussed the **successful migration to Confluence Cloud** and the need to grant access to team members who previously edited the wiki.

Additional topics included the new Dropbox provisioner implementation, global variables feature completion, and ongoing work on Sync Back functionality to improve provisioning performance.

**Entity Data Field Improvements Discussion**

Chris Hyzer and Vivek discussed improvements to Entity Data Field configuration screens, including a potential change from true-false to yes-no formatting, though they decided to maintain the current true-false pattern. They reviewed JIRA tickets, particularly focusing on performance issues with subject displays in Grouper, where Vivek had implemented batching solutions to reduce multiple database calls. The discussion also touched on a separate issue with display extensions causing errors when using display names.

**Grouper Display Name Issues**

The team discussed issues with display name handling in Grouper versions, particularly around folder paths and extensions. They agreed to restore the previous behavior where extensions could be entered without colons, and Chris updated the documentation accordingly. The group also addressed concerns about schema upgrade tasks and caching, with Vivek clarifying that the system now makes fewer metadata queries but needs to clear the cache after DDL changes to prevent conflicts. Finally, they briefly mentioned fixing a null pointer exception in the add members to group feature and noted an issue with SQL cleanup when JVMs crash during DDL operations.

**SQL Cache and JVM Solutions**

Chad reported issues with SQL cache locking up GSH, leading him to use raw GroovyShell as a workaround. Vivek explained a new solution for handling multiple JVMs running DDL operations, where if a heartbeat stops for 2 minutes, the waiting JVM will take over automatically. The team discussed improvements to SCIM provisioning diagnostics, with plans to add screenshots to the Grouper provisioning SCIM wiki to help users configure various options more effectively.

**Nested Group Conversion Strategy Discussion**

Chad and Chris Hyzer discussed the approach of performing deletes before inserts when converting nested groups to direct members. Chad explained that the current practice causes issues with changelog consumers that process instructions sequentially, potentially resulting in temporary user deletions and system blips. Chris Hyzer suggested making this a global default setting rather than loader-specific, with the option for users to revert to the old method if needed. The discussion highlighted the trade-offs between avoiding system blips and preventing unnecessary user deletions during the conversion process.

**User Management Operations Discussion**

Chris Hyzer and Chad discussed the order of operations for adding and removing users and groups, with Chris suggesting a more sophisticated approach that prioritizes adding groups first, removing memberships second, adding direct memberships third, and removing groups last. Chris also highlighted improvements to the AVAC data dictionary, including filtering capabilities and column consolidation to improve screen real estate. The conversation ended with a review of action items, including documenting code deployment strategies and coordinating task assignments.

**Global Variable Data Provider Feature**

Chris Hyzer explained that a Global Variable Data Provider feature is now complete, allowing single-valued attributes assigned to it to appear as global variables. The feature addresses use cases like tracking non-summer terms at Penn, where administrators can define global variables for current, previous, and next non-summer terms without adding extensive data to rows. Gail noted that while this addresses current needs, multi-valued arrays might be needed for some use cases where up to three terms could be current simultaneously.

**Confluence Wiki Migration Completion**

Chris Hyzer announced the completion of the wiki migration to Confluence Cloud and outlined the new access process, limiting edit rights to himself and Chris Hubing initially, with plans to add more users upon request. He emphasized the importance of using Confluence as the system of record and discussed automating page updates and maintaining consistency across pages. Chris also addressed concerns about community contributions, noting that older, inactive content would be removed to improve search functionality, and he requested feedback on the new page header design.

**Provisioning System Performance Improvements**

The team discussed ongoing work on provisioning issues, with Chad working on a Jira issue for progress logging in provisioners and planning to send a patch to Gail for implementation in version 7. Chris Hyzer reported progress on the Sync Back feature, which now uses generic tables to keep provisioners up to date, and identified the need for an option to read native object representations to improve performance, particularly for the slow Okta provisioner that took 35 hours. Liam noted that the initial data poll stage of a previous run took 29 of the 36 hours, though the breakdown between different elements was not clear.

**System Upgrade and Accessibility Updates**

Chris Hyzer discussed ongoing work on upgrade instructions and loader failsafe features, noting that while the sync pack part is complete, they are holding off on certain components pending further evaluation. Reed provided an update on accessibility improvements, reporting completion of missing labels form work across 112 files and title tab additions to about 108 pages, with bootstrap dropdown menus being the current focus area. Chris also mentioned working on a Dropbox provisioner and outlined its key features and documentation structure, noting that while it may be needed at Penn in the future, it currently lacks a target environment for testing.

**Cloud Service Integration Testing Updates**

The team discussed testing and implementation of various cloud service integrations, including Dropbox and Interfolio provisioners. Chad reported fixing issues with Azure mock server functionality, including group types and group owners features, and successfully migrated a legacy Azure consumer system to built-in provisioners. The discussion also covered converting mock services to Javelin for better readability and maintenance, though no immediate decision was made on this migration.

**Technical Issues and Database Upgrades**

The team discussed several technical issues and upgrades. Chris Hyzer explained a database limitation where group names in Postgres are restricted to 255 characters due to column width constraints, requiring views to be dropped and recreated during upgrades. The team also addressed a loader issue where groups were being incorrectly deleted along with their memberships, which has been fixed. Chris mentioned plans to release new versions for V4, V6, and V7 soon, incorporating Okta fixes. Gail mentioned exploring the possibility of using Dropbox's non-production environment with 5 user licenses for testing.
