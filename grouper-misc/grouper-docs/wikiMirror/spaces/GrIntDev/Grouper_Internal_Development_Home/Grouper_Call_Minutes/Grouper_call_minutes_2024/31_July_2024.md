ABAC

- In ABAC whether groups or attributes in the expression, as data changes about a user or as memberships change, it will send things to the change log for attribute changes.
- Incremental ABAC daemon (which is new) will process that, and see which groups are impacted and then reprocess the script for impacted users
- Incrementals for ABAC is key to next Grouper release
