**More from Zoom AI**

**ABAC Testing Performance Improvements**

Shilen reported progress on ABAC testing at Duke, including performance improvements achieved through changes to row configuration and index additions. He explained that combining multiple rows into single rows for Grouper storage, originally implemented as a workaround for performance issues with fields, has now been optimized. The team discussed how parentheses in SQL queries affected Oracle's optimization, with Gail providing context about different database engines' handling of OR operations.

**Database Query Performance Optimization**

Shilen discussed performance issues with a database query that was taking over two minutes to execute due to excessive joins with the members table. Chris and Gail helped identify that switching from fields to rows approach reduced the number of joins, significantly improving performance. Shilen noted that Oracle's query execution time could vary dramatically, running either in 20 milliseconds or 2 minutes, depending on how the database optimizes the query.

**OSGI Plugin and Okta Transition**

Chris discussed changes to the OSGI plugin and logic project, explaining the new build process and challenges with uploading large jars to Sonotype. He plans to continue work on the grouper installer script before implementing these changes. Chris also mentioned fixing a bug related to group scripts and discussed the upcoming release, which will include changes to the group screen. Gail shared her experience with using ABAC for the Okta transition, noting that it is working well despite some initial challenges. They briefly discussed potential improvements to the group screen and API changes.

**ABAC Group Change Management Tool**

Chris demonstrated a GSH template tool for managing ABAC group changes, which helps compare old and new group configurations before making changes. The tool currently works for two rows but could be expanded to handle more, and Chris has documented the process at Penn for changing ABAC configurations. Gail suggested creating sample templates that others could use as models, while Carey suggested incorporating similar functionality into the diagnostics feature. The group discussed the complexity of ABAC changes and the importance of having a systematic process to avoid unintended consequences.
