## **Current Work**

**User Lifecycle Policy Configuration Update (from Zoom AI)**

- [User Lifecycle events](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28544885/User+Lifecycle+events) (wiki page)

The team reviewed progress on a user lifecycle workstream, where Vivek presented a new configuration option under Miscellaneous that allows users to set up lifecycle events and policies. The system enables users to define events (such as group removal), actions (like setting an end date for membership), and policies (with low, medium, or high severity levels), with a maximum of 10 events per policy.

Vivek demonstrated how policies can be assigned to groups through the UI, with only one policy allowed per group, and explained that the configuration will be reflected in the attribute assignment section.

**User Lifecycle Events Implementation (from Zoom AI)**

The team discussed the implementation of user lifecycle events, including database tables and daemons for tracking events and managing group memberships.

Chris explained that a new daemon would check for lifecycle events in groups and adjust attributes accordingly, with manual override options for managers.

The team agreed to improve the UI visualization and documentation, and to invite Georgia Tech to the next dev call to review the implementation of their suggested features.

**User Sync Endpoint Progress Review ( from Zoom AI)**

Shilen reported progress on a new endpoint for syncing users with a data provider, including adding it to the grouper client and implementing group authorization.

He also fixed issues related to duplicate keys in source data and job status overrides. Chris reviewed Shilen's work and suggested documenting the new endpoint on the web service page.

They briefly discussed upcoming tasks and agreed to reconnect soon for a more detailed discussion.

**Grouper UI Announcement Banner Implementation (from Zoom AI)**

Chris discussed the implementation of an announcement banner in the Grouper UI, explaining its functionality and customization options. He outlined how the banner would display in different UI contexts and emphasized maintaining backwards compatibility for customizations. Chris also suggested potential applications for the banner, such as displaying training requirements for power users and admins.

**Group Screen Customization Overview (from Zoom AI)**

Chris explained how customization works with headers and divs, clarifying that it involves adding new elements rather than replacing existing ones. He described the structure of the group screen customization, including the use of HTML tables for alignment and the possibility of adding dynamic content through the groupViewLogic method. Chris also demonstrated a feature that counts the number of stems in a group, showcasing its functionality.

**System Updates and Bug Fixes (from Zoom AI)**

The team discussed several updates and bug fixes for their system. Chris explained improvements to group member addition functionality and performance optimizations for folder screens and GSH templates.

Chad reported progress on fixing the report editing screen issue, though some challenges remain due to the system's design.

Ben raised a request from service desk staff to access user-level audit logs without full sysadmin privileges, which Chris agreed to investigate further.

The team also discussed improvements to unique ID generation for reports and debugging logs.
