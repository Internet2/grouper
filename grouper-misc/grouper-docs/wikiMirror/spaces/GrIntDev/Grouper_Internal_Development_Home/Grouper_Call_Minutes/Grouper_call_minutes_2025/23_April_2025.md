**Call Overview (from Zoom AI)**

Vivek provided an update on recent developments in Azure integration, including support for directory extension attributes for groups and a new feature for controlling group visibility in Azure. The team also discussed recent updates to the Azure provisioner in Grouper, ongoing development issues and priorities, and the need to upgrade Apache Commons HttpClient from version 3 to 4. Lastly, they discussed creating new lessons for live training on custom UI and deprovisioning, and various technical issues related to user provisioning and authentication systems.
