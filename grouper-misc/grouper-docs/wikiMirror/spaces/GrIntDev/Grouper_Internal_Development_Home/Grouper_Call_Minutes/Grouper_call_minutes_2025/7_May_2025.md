- Incremental ABAC
  
  - **AI Chris and Shilen will discuss dependency table view and whether there should be new columns**

- - From Zoom AI: Chris discussed the dependency table and its categories, explaining that the table holds dependency types, internal ids, owners, and dependent things. He mentioned that when an ABAC script is used, the owner of that script is dependent on the objects it uses, and as they change in the change log, it will incrementally recalculate that user. Chris also talked about the need to ensure the table is in sync as people change ABAC scripts and the full sync will keep it in sync. He mentioned the need to design data providers so that things don't change that much. Chris also discussed the views that take all the dependencies into account and the need to join them to some things. Bert suggested documenting the owner and dependency type in the metadata table. Shilen asked about how this fits with the group cache and Chris clarified that the dependency table is not in the cache group table. They also discussed the need for more views and the possibility of adding columns to the metadata table.
