### **From Zoom AI**

**Grouper Release Update and Fixes**

Chris Hyzer discussed several updates and fixes in the latest Grouper release, including improvements to XML and GSH export-import functionality, updates to Tomcat, and enhancements to data field queries and sources. He highlighted changes to JEXL script operator precedence, removing the equals operator to simplify queries, and mentioned ongoing work to improve error messages for invalid scripts. Chris also noted that XML export import processes have been simplifed by removing ID index handling, and introduced a new fail safe feature for SQL syncs that checks for expected row counts. The team discussed upgrading Commons Ling to a more recent version, with Chris suggesting its removal from Grouper due to security concerns, though Chad expressed a preference to address this in Grouper v5 before moving to v6.

- [GRP-6288](https://grouper.atlassian.net/browse/GRP-6288) remove commons-lang

**V5 Upgrade and Technical Updates**

The team discussed technical issues and updates related to data providers, SQL caches, and upgrade processes for version 5. Chris explained that null and blank values would not be supported in data fields to avoid confusion, and changes were made to improve performance and fix bugs. Chad and Chris clarified upgrade steps for v5, particularly regarding SQL cache checks and test functionality for web services. The team briefly discussed deprovisioning configurations and rule improvements.
