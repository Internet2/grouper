**UVA Group Ownership Restructuring Plan (from Zoom AI)**

Kellen explained UVA's transition to a group ownership structure where each AD or LDAP group is represented by two or three groups in Grouper to support explicit owner attributes. He detailed the challenges of implementing user pickers and owner attributes in Grouper, noting that UVA will hire a Java developer to address these issues and potentially develop a more general attestation model. Kellen also described the current setup for legacy groups, where owners are visible in LDAP, and outlined plans to restructure Grouper groups to match this layout, which will allow for the population of owner attributes in LDAP. For AD, Kellen suggested surfacing ownership information on the group summary screen as a temporary solution, as AD administrators are not interested in adding custom attributes for owners.

**Group Ownership and Provisioning Challenges (from Zoom AI)**

The group ownership and provisioning discussion focused on challenges with AD and ENTRA integration, where Kellen explained they currently have a manual process through Access Management for group ownership queries, receiving about half a dozen requests weekly. Chris Hyzer suggested adding a new privilege to Grouper for shadow groups and discussed the purpose of owners being primarily for receiving attestation and user lifecycle emails rather than managing update privileges. The team agreed to explore direct provisioning of ENTRA groups early next year, with the goal of aligning with organizational expectations while maintaining appropriate access controls.

**Policy Group Ownership and Attestation (from Zoom AI)**

The team discussed the need for policy group owners and attestation processes, with Kellen explaining that his groups already have shadow groups and custom attributes for owners, making it relatively straightforward to implement ownership in the future. They explored the possibility of updating the LDAP provisioner to support multiple membership attributes, which would help reduce the current doubling of provisioners. Kellen also described their attestation process, which includes data cleanup and the ability to modify group descriptions, and mentioned that they would implement a delete template for deprovisioning.

**HTML Email Rendering Issues (from Zoom AI)**

The team discussed issues with HTML email functionality in the attestation system, where Kellen explained they needed to implement HTML emails due to InfoSec requirements but encountered problems with Outlook rendering. Chris Hyzer suggested examining why the Grouper email code isn't detecting HTML tags properly and agreed to look into fast-tracking a fix, while acknowledging that quick workarounds like using MailChimp might be necessary in the short term. The discussion concluded with plans to spend 20 minutes discussing V6, though the conversation ended before this topic was covered.

**Unit Test and Performance Challenges (from Zoom AI)**

The team discussed unit test challenges, with Chad reporting issues running tests that caused server crashes and proposing to run them locally on a faster machine. Chris Hyzer suggested creating a wiki in the dev group to track test progress and outlined a plan to address security issues in libraries, upgrade non-breaking dependencies, and refactor database calls back into DAO classes to prepare for moving away from Hibernate in V7. The team also addressed provisioning performance issues, with Gail reporting 6-7 hour runs, and agreed to investigate the bottleneck between Grouper and target systems.

**User Lifecycle Configuration Updates (from Zoom AI)**

The team discussed changes to the user lifecycle configuration, deciding to implement a floating-point number system instead of integers to allow for more precise prioritization. Chris agreed to create a Confluence page for the V6 release, which will include a list of unit tests and other tasks. The group clarified that V5 and V6 are essentially the same release, with no major upgrade instructions needed to move from V5 to V6. Kellen reported progress on scheduling a meeting with Dave Langenberg for January 28th. Chris expressed interest in creating a video to showcase Grouper's new features and recent developments.
