**VM Management System and Script Daemon from Zoom AI**

Chad explains the VM management system, which includes GSH templates for users to run AWS EC2 containers and a script daemon that terminates VMs when users exceed their allotted hours. Chris and Chad discuss the frequency of the script daemon, agreeing it should run every 15 minutes. The team then debates how to handle the VM startup process, considering options like adding a sleep function or educating users about potential connection delays. They decide to modify the user data script to set up SSH access earlier and include a 60-second sleep at the end to ensure all services are ready when users connect.

**Training Preparation and Grouper Updates from Zoom AI**

Chris discusses the remaining tasks for training preparation, including reviewing course content, renaming text-to-copy-paste sections, and updating quizzes. He mentions the possibility of tying each training lesson to a specific version of the grouper GTE, though this idea has pros and cons. Chad brings up a previous discussion about creating a separate Confluence space for training, but they decide against it to avoid breaking existing links. Chris mentions that four people will review the training material for functionality and feedback. He plans to show a data field subject source thing and mentions having more time for normal Grouper tasks once training preparation is complete.

**Accessibility Review of Grouper UI from Zoom AI**

Chris Hyzer discussed an upcoming accessibility review of Grouper by Arlen Johnson from SCG. The review will likely result in changes to the UI, including adjustments to contrast, font sizes, and form layouts to meet current accessibility standards.

Carey suggests adding notes for expected local customizations and improving the contrast between visual icons for groups, persons, and folders. The team also discussed the possibility of using color coding to differentiate between people and groups in membership lists.

**AI Chris Hyzer - discuss with Arlen Johnson improving icon contrast/size/color and differentiation (e.g. subject vs group)  in the Grouper UI for accessibility.**
