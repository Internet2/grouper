**Grouper and AI (from Zoom AI)**

**AI Development for Grouper Agents**

Evan and Chris discussed the development of AI-trained agents for Grouper, focusing on creating comprehensive documentation and examples to enhance functionality. Evan is compiling GSH wiki content into a structured document with example implementations, while Chris is integrating SQL and GSH templates to enable AI to generate more complex GSH commands and SQL queries. They also explored the potential of training AI agents to perform institution-specific tasks, with Chris outlining a maturity model for AI applications. The team plans to continue refining these tools and collaborating with Bill Kaufman to improve data collection and training processes.

**AI-Powered Grouper OAuth Interface**

Chris Hyzer demonstrated a proof of concept for an AI-powered interface that interacts with Grouper web services using OAuth authentication instead of basic auth. The system can resolve user information from email addresses and determine group affiliations, with the ability to fall back to Kerberos authentication when necessary. The implementation includes a GSH template that processes user emails and performs OAuth authentication before querying Grouper, allowing for more secure and user-specific access to web services.

**ABAC Query Tool Development**

Chris Hyzer discussed a tool for writing ABAC queries using Penn's data dictionary, which includes attributes and examples from database queries.  
 Gail suggested creating additional resources to help users navigate common challenges when working with HR data, such as understanding department affiliations and active status. The group explored the possibility of using AI to prompt users with relevant questions and provide tailored outputs based on their responses.

**Grouper AI Integration Demonstration**

Chris Hyzer demonstrated how Grouper can integrate with AI web services, showing examples of using GSH templates to interact with AI for tasks like checking MFA requirements. He explained that the goal is to create a chatbot within Grouper that institutions can customize, rather than replacing the entire UI with a chatbot.

**AI Integration for Log Analysis**

Bert and Chris discussed the use of AI and machine learning for analyzing logs and providing administrative support in their systems. Chris explained that while highly sensitive data cannot be shared with vendors like OpenAI, they can analyze logs and provide insights that would otherwise require manual review. They explored the possibility of implementing AI-driven solutions within their existing systems, such as Grouper, and discussed the use of standard APIs and proxies to support multiple AI vendors. Chris emphasized the importance of using AI for administrative tasks that can save time and improve efficiency, while ensuring that sensitive information remains protected.

**AI Implementation in Grouper Discussion**

The team discussed implementing AI capabilities in Grouper, with Chris Hyzer proposing a cloud container solution that could be run locally without web service calls, which might be more acceptable for schools.   
Chris Hubing mentioned their existing contract with Anthropic's Claude, and suggested experimenting with comparing different AI models.

The group also addressed caching and privacy concerns in the subject source implementation, with Shilen raising questions about caching behavior between different threads. Chris Hyzer clarified that the caching system uses the Grouper session subject as a key, and agreed to schedule a follow-up meeting to review the caching implementation further.
