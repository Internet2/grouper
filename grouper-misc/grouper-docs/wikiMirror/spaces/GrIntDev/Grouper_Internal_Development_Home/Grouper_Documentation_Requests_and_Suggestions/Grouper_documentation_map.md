This network diagram represents the Grouper space in Confluence. It is meant to show at a high level the major areas and relationships between them, and to also show areas that may need reorganization, updating, or deletion. The SVG images were generated using a python script [maintained in the Grouper source](https://github.com/Internet2/grouper/tree/GROUPER_4_BRANCH/grouper/misc/confluencePageGraph), running against the full XML export of the space in Confluence. Download the SVG file to better read individual nodes, which have tooltips of the page names on each node.
