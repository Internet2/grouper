## Evaluation and Research

 

- Define goals of redesign 
  
  - Usefulness/Effectiveness
  - Learnability
  - Attitude
- Conduct user interviews to help define top tasks, pain points
- Define usability objectives
- Define users/personas

 

#### Sample goals:

 

- Usefulness/Effectiveness: Users will have an optimized experience across all devices and are able to perform all tasks regardless of screen size. The site will comply with WCAG 2.0 AA requirements for accessibility.
- Learnability: No formal training will be required to use the website.
- Attitude: Users will be highly satisfied with the website.

 

#### Sample usability objectives:

 

- Effectiveness: with 1 hour of training, a user can accomplish task X in under 5 minutes
- Learnability: with no training, a user can learn to accomplish tasks X and Y in under 10 minutes
- Attitude: after 5 scenarios, 90% of users will rater their satisfaction at 5 or higher on a 7-point scale

 

## Mobile First

 

- Prototype small-screen solutions for common tasks
- Identify opportunities to simplify by: 
  
  - Removing
  - Organizing
  - Hiding
- Progressively enhance 
  
  - Build on small screen prototypes as you expand to larger formats

 

## Low Fidelity Testing

 

- Create wireframe prototypes in preparation for user testing
- Identify user test population and finalize user test scenarios
- Conduct user tests and evaluate results
- Rinse and repeat

 

## High Fidelity Testing/Graphic Design

 

- Develop working prototype
- Conduct user tests and evaluate results
- Rinse and repeat
- Graphic design can be done concurrently or following prototype tests
