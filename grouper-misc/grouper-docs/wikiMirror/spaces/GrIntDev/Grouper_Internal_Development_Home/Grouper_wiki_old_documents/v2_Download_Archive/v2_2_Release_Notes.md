# Release Notes for Grouper 2.2

Grouper v2.2.2 includes 56 fixes and improvements over v2.2.1. See the [full list in Jira](https://bugs.internet2.edu/jira/issues/?jql=project%20%3D%20GRP%20AND%20status%20%3D%20Resolved%20AND%20fixVersion%20%3D%202.2.2%20ORDER%20BY%20key%20ASC) [https://bugs.internet2.edu/jira/issues/?jql=fixVersion%20%3D%202.2.1%20AND%20project%20%3D%20GRP](https://bugs.internet2.edu/jira/issues/?jql=fixVersion%20%3D%202.2.1%20AND%20project%20%3D%20GRP)

Grouper v2.2.1 includes 55 fixes and improvements over v2.2.0. See the [full list in Jira](https://bugs.internet2.edu/jira/issues/?jql=fixVersion%20%3D%202.2.1%20AND%20project%20%3D%20GRP)

Grouper v2.2.0 includes 56 fixes and improvements over v2.1.5. See the [full list in Jira](https://bugs.internet2.edu/jira/issues/?jql=project%20%3D%20GRP%20AND%20fixVersion%20%3D%202.2.0%20AND%20status%20in%20(Resolved%2C%20Closed)).

## New Features in v2.2.0

| [New UI](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28543095/User+Interface) | There is a new more usable UI which makes Grouper easy to use by end users and administrators. It co-exists with the legacy Admin UI and the Lite UIs. |
| --- | --- |
| [Legacy attribute migration](https://grouper.atlassian.net/wiki/spaces/GrIntDev/pages/48793148/Legacy+attribute+migration) | Migrate from legacy attributes to the [new attribute framework](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28544741/Grouper+attribute+framework) in a transparent way. The API, WS, and UI work similar as they did before. |
| [SCIM events](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28548072/Grouper+SCIM+change+log+client) | SCIM events can be sent from Grouper to keep SCIM compatible systems in sync with Grouper. |
| [Improved configuration](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28549156/Grouper+configuration+files+and+overlays) | Grouper config files can have hierarchical overlays to make Grouper easier to deploy and upgrade across multiple environments. |
| [Unix GID management](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28544315/Integer+IDs+on+Grouper+objects) | Grouper objects now have a unique integer ID which can be used in GID management |
| [Services in Grouper](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28545262/Organizing+services+in+Grouper) | Ability to tag folders in Grouper (via the [attribute framework](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28544741/Grouper+attribute+framework)) so that folders, groups, permissions can be grouped into a "service". The API/UI/WS can filter search results based on the service to make it easier for users to perform tasks in Grouper. |

For more information about upcoming plans, see the [Grouper Product Roadmap](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28541781/Grouper+Product+Roadmap).

Many other fixes and improvements were also made to all components of the Grouper Toolkit: Grouper API, Administrative & Lite UIs, Grouper Web Services, Grouper Client, Grouper Shell, Grouper Loader, PSP, and the Subject API.
