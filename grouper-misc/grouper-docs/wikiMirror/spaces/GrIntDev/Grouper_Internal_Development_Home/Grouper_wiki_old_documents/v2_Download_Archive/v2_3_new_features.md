## New Features in Grouper 2.3.0

| PSPNG | Provisioning Service Provider Next Generation (PSPNG) implementation addresses performance problems and configuration complexity of the Provisioning Service Provider (PSP) |
| --- | --- |
| Loader improvements | Grouper loader improvements: scheduling configuration stored in database facilitates high-availability changes to loader config files do not require restarting the loader, handling unresolvable subjects |
| [Web Service operations](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28544233/Grouper+Web+Services) | New Web Service operations for attribute definitions, actions, and messaging |
| [Grouper messaging](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28544824/Grouper+messaging+system) | Grouper messaging system and WS with integration to the change log and ESB |
| UI screens | UI screens for attribute definitions and [inherited privileges](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28548700/Grouper+rules+privileges+inheritance+on+UI) |
| [Export to GSH](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28547766/Grouper+export+to+a+GSH+script) | Export Grouper objects to a Grouper Shell (GSH) script |
| [Folder privileges](https://bugs.internet2.edu/jira/browse/GRP-1169) | Refactor folder privileges to be “admin” and “create” instead of “stem” and “create”. See the glossary for updated privileges and definitions. |
