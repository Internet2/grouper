How to utilize "types" on objects (Folders, groups, etc...) in the user interface

1. Navigate to the desired object
2. Click on "actions" menu on the right
3. Select "Types" from the menu
4. Select "Type actions"
5. Click "Edit type settings"
6. Expand the drop down menu and select the type desired (pictured is "group types"
7. Indicate if the object has direct type configuration
8. Optionally assign "Data owner" and "Member description"
9. Click "Save"
10. The type will now appear at the top of the screen below the name of the object
