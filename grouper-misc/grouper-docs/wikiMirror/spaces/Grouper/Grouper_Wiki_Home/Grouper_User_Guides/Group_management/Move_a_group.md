1. Login
2. Navigate to the group you wish to move and open it
3. Select drop down menu “Group actions”
4. Select “Move group”
5. Enter the path to the new location of the group (use auto complete function to select the destination)  
    
    
  ** Note: “Set alternate names for groups” will allow the group to still be referenced in its original location. Use this if the group is already in use by webservices or scripts.
6. Click “Move”
7. You will receive confirmation that the group was successfully moved at the top of the screen
