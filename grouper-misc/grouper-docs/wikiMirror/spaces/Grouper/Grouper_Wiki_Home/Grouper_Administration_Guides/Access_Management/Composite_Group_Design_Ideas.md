- [Grouper UI – Creating a Composite](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28548883/Composite+group+-+example)
- [Membership UI Advanced Options](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28545447/Membership+view+advanced+options) (perform a custom composite on a membership list)
- [See Grouper Rules use cases involving composites](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28548037/Grouper+rules+patterns)
