### 

### To deprovision a user, click Miscellaneous

### Click Deprovisioning

### Select an affiliation

### More actions → Deprovision user

### Search for a user, View user access to deprovision

### Select what needs to be deprovisioned, and Deprovision user and remove access

Note, if something shouldn't be configured, you should probably [edit the settings on a folder / group / attribute](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28549004/Grouper+deprovisioning+settings+on+objects)

Under the Miscellaneous menu option you can View deprovisioned users.

To view users who were NOT deprovisioned use the [Deprovisioning Report](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28548487/Grouper+deprovisioning+report).
