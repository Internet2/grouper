## Move a group

1. Navigate to the group you wish to move and open it
2. Select drop down menu “Group actions”
3. Select “Move group”
4. Enter the path to the new location of the group (use auto complete function to select the destination)  
    
    
  ** Note: “Set alternate names for groups” will allow the group to still be referenced in its original location. Use this if the group is already in use by webservices or scripts.
5. Click “Move”
6. You will receive confirmation that the group was successfully moved at the top of the screen

## Copy a group

1. Navigate to the group you wish to copy
2. Expand the "Group actions" drop down and select "Copy Group"
3. Search for and select the name of the destination folder (you have to have permissions to create groups in the destination folder)
4. Copy options that are available are the same as if you are using the API/GSH  
    
  ** Select/unselect the options that you wish to have applied to your copied group
5. Click "Copy"
6. You will receive a confirmation message indicating it was a success
