Grouper has the capability to move and copy groups and folders from one folder to another. When performing these move and copy operations, there are various options that can be applied. This feature is part of the Grouper API and can also be used with the [GrouperShell](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28545249/GrouperShell+gsh) and the Grouper UI.
