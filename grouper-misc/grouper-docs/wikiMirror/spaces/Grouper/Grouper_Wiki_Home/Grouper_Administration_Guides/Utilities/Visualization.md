## Grouper Visualization

Grouper visualization allows for a user to create a graphical representation of the relationships between items in Grouper. This can be used for things like tracing memberships, explaining group math logic, and creating maps of how to maintain groups in the future. The tool can be accessed through either the [User Interface](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28548433/Visualization+UI) or via the [Visualization API](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28548424/Visualization+API).
