This is a public agent that will help code GSH for scripts, UI templates, WS templates, daemons, etc.

## Caveat

**All output must be carefully reviewed by a knowledgable human!**

## Access

Use this friendly URL since the resulting URL might change: [https://tinyurl.com/internet2grouperGshAgent](https://tinyurl.com/internet2grouperGshAgent)

Anyone with an openai account (including free account) can use this tool.

## Use

Type something into it: Write a GSH template to take the input of a group name (gsh_input_groupName) and add attestation to it... and give all the requirements. describe the inputs and results and validations.
