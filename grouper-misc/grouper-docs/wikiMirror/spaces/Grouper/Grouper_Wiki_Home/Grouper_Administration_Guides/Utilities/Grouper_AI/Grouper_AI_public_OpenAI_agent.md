This is a public agent that will answer general questions about Grouper

## Caveat

**All output must be carefully reviewed by a knowledgable human!**

This is a first pass at an agent for Grouper and is not currently giving good answers.

## Access

Use this friendly URL since the resulting URL might change: [https://tinyurl.com/internet2grouperAgent](https://tinyurl.com/internet2grouperAgent)

Anyone with an openai account (including free account) can use this tool.

## Use

Type something into it: How do I setup an app with delegated includes and excludes from various schools in the university?

## Training

This is trained from an export of the wiki. We will be iterating on this to find the best way to train. I would appreciate if something is missing or wrong if people slack incommon-grouper-ai.

We will make the training files available at some point.
