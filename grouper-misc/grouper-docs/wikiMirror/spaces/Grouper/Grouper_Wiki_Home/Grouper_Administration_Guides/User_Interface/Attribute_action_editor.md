You can create, view, edit, delete attribute action in the UI.

## See attribute actions

You can edit the implying relationship between actions by clicking on the 'Edit attribute action' button as shown in the screenshot below.

You can create a new attribute action by either clicking on the option in the big blue dropdown on the left top of the screen or by opening any attribute definition and clicking on the Create new attribute action in the More actions dropdown.
