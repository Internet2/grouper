Grouper loader diagnostics will

- look at the configuration
- validate queries
- look in logs to see if your loader job is healthy

It will give you suggestions on how to fix the job is something is detected to be broken or even not ideal. This feature will **not make any changes** to the registry, it does not run a loader job.

# Access the loader diagnostics screen from the UI

Access the grouperLoader UI screen for the group which has a loader job

Then click on "Loader diagnostics" from the "Loader actions" drop down:

Once you see the diagnostics screen, click the "Run loader diagnostics" button
