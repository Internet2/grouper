## What are they?

Provisioners utilize connections to external systems to push (provision) data to the external system. This data can include the following: Users, Memberships, Attributes, and Groups. Provisioners are also capable of getting data and removing the data from the external systems that they are connected to in a maintenance function. More documentation about how the provisioners work, how to set them up, and how to standardize them on the [Grouper Provisioning Framework](https://grouper.atlassian.net/wiki/spaces/Grouper/pages/28544760/Grouper+provisioning+framework) page.
