> Simulated institutional documentation for the Grouper Training Environment (GTE). The Institute of Higher Education (IHE) is a fictional university. This is not Grouper product documentation.

These pages describe the GTE as if it were a real institution's Grouper deployment: its folder conventions, reference groups and owners, access policy standards, and LDAP directory. In the MCP AI training, a daemon pulls these pages into Grouper so the AI can search them with the `doc_search` MCP tool.
