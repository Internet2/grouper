There are occasionally questions about how much disk space is used by Grouper in the various tables (e.g. primary tables vs user audit vs point in time audit). Here's Duke's usage using an Oracle database.

To get an idea of our size, here's are some counts of rows in a few tables:

grouper_attribute_assign - 84,599

grouper_memberships - 12,591,506

grouper_group_set - 6,593,297

grouper_groups - 504,764

grouper_members - 1,998,076

grouper_stems - 274,022

grouper_stem_set - 2,255,213

grouper_pit_attribute_assign - 177,782

grouper_pit_memberships - 21,352,983

grouper_pit_group_set - 12,506,323

grouper_pit_groups - 1,117,653

grouper_pit_members - 1,998,076

grouper_pit_stems - 676,182

The "pit" tables are for point in time audit. If you subtract the counts on the non-pit tables from the pit tables, those are the number of objects deleted in Grouper that are still in point in time. Note that all current objects need to be in point in time. So for example, I have 504,764 groups currently. The point in time audit has those plus an additional 612,889 that were deleted at some point.

grouper_audit_entry (user audit) - 21,612,122
