For any of the below images - if you download the image you see it is a web page you may open in a modern browser having links back to grouper for all the objects represented in the graph and therefore extends/augments the usual Grouper Web UI. There are 3 graphs represented below showing dependencies for a single group, a subject and starting at Root.

2018-11-25 Code has been made available on [GitHub grouper-graph](https://github.com/gettes/grouper-graph). The Grouper development team is discussing and pursuing how to incorporate this work into the Grouper web UI.

Graph of grouper group App:Two-Factor:Duo:Enrolled - the graph is generated started at this group and then including all dependencies related to this group.

Graph of groups related to subject rob@example.com - not based on [permissions of rob@example.com.](mailto:permissions of rob@example.com.)

Graph starting at Root - some folders are excluded because too many items to graph... these limits are configurable.
