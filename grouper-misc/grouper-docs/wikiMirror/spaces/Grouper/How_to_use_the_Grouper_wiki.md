## Browsing

Select the category from [Grouper wiki home](https://grouper.atlassian.net/wiki/spaces/Grouper/overview) to browse the wiki

## Authenticating

Request access here: [https://incommon.org/help/](https://incommon.org/help/)

If you want to contribute to the Grouper wiki, include that request in the access request.

Or send a message to the incommon-grouper slack channel (which you also get access from above link)

## Searching

- Sometimes a google search with "Internet2 Grouper <search term>", e.g. "internet2 grouper web services" works better then searching in Confluence (especially if not authenticated)
- If searching Confluence, filter by the Grouper space (only if authenticated to Confluence

## Out of date pages

If a wiki page needs updating, add this label: needsDocUpdate

Also add a comment which describes what needs updating specifically
