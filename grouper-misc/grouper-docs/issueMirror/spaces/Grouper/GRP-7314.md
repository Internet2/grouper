# GRP-7314  UI accessibility: ensure interactive controls meet minimum touch target size (WCAG 2.5.8)

Accessibility action-plan item 12 (P3). Small interactive controls in the Grouper v2 UI should meet the WCAG 2.5.8 minimum target size of 24x24 CSS px (or have adequate spacing). Audit and enlarge/space controls that fall short.

*Candidates to check:*

* Icon-only controls: the grey remove (fa-times) X buttons in group/subject import and role inheritance lists.
* Table-row action icons and the widget gear (more-actions) triggers on the home page panels.
* Breadcrumb links and other tightly-packed inline links.
* Checkbox/radio hit areas in filter forms.

The modal close button was already enlarged in an earlier pass; use that as the pattern. Prefer padding/min-width-height in grouperUi2.css over per-element inline styles, and bump the CSS cache-buster when changing it.
