# GRP-5183  quartz job triggers data corruption fix

_(no description)_

## Comments

### Chris Hyzer - 2023-12-10T19:36:09.616+0000

we have a problem with corruption in quartz tables where the triggers table doesnt have a corresponding entry in other tables. fix this with
{code:java}
select trigger_name from grouper_qz_triggers gqt where start_time < 30sec ago and
(gqt.trigger_type = 'CRON' and not exists (select 1 from grouper_qz_cron_triggers gqct where gqct.trigger_name = gqt.trigger_name))
or
(gqt.trigger_type = 'SIMPLE' and not exists (select 1 from grouper_qz_simple_triggers gqst where gqst.trigger_name = gqt.trigger_name))


if you get something, wait 10 seconds

delete from grouper_qz_triggers gqt where start_time < 30sec ago and
and trigger_name in (x,y,z)
(gqt.trigger_type = 'CRON' and not exists (select 1 from grouper_qz_cron_triggers gqct where gqct.trigger_name = gqt.trigger_name))
or
(gqt.trigger_type = 'SIMPLE' and not exists (select 1 from grouper_qz_simple_triggers gqst where gqst.trigger_name = gqt.trigger_name))

log the count deleted and update loader log
 {code}
