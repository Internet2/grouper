# GRP-887  Attribute based provisioning

Figure out some way to enable the PSP to selectively provision groups to targets based on an attribute for the target set on the group.  

Example would be how uchicago can set ADSync or LDAPSync attributes on groups and that controls whether or not the group is provisioned to that individual target
