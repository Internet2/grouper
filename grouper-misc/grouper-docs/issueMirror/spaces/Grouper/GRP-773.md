# GRP-773  training api part 2

A few suggestions

Add Diagram

 Include the attached diagram towards the beginning.

More Talking/Commentary on the Session Work

It is difficult to see what you're typing in the session screen.

When you are doing onscreen session work as an example, give maximum commentary to help the viewer follow and learn:

 For example when showing the Import / Export Example say,:  " I am copying this export command and pasting it into the session"

and

"Now I am typing the command to clear the registry which is < command> "  , 

In general, SAY ALOUD what you are typing.

Transitions

Include a few more transitions, such as "Now we are going to move on to the Configuration topic"

and 

"Now let's talk about the Import/Export of data from the Grouper Registry."

Before you say "Quick on the Quiz" say a little summary or wrap-up,
such as "So to review, we have covered GSH, Configuration and Import / Export"

State the Export items that are now not included Will be included in future 

When you talk about what's NOT included in the Export, make it clear this will (might) be changed in the future.
The doc page suggests this is a temporary situation, that some external subjects, for example , don't get exported


Starts and Stops

There is some start and stopping and lack of smoothness.  I guess you stopped recording and then began again, or did you edit the recording after it was done?
Yhere are probably ways to make it seem less choppy. 

Use Cases

Based on Lynn's feedback that use case are so helpful, maybe include a few sentences of why people do imports and exports. I know there are a zillion reasons, and it seems like implementers will know, but still maybe it's good to tie things to their uses when possible.
