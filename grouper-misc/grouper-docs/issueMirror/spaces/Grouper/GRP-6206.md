# GRP-6206  Paginating list of Attestable Groups

The current Attestation listing has a hard limit of 150 groups.  Some users are put in charge of more groups than that listed and are not able to reach those groups through that page.

Having the groups as a paginated list would allow users with 150+ groups be able to reach and attest the groups in question.  Allowing to filter based on a search field would also be desirable.
