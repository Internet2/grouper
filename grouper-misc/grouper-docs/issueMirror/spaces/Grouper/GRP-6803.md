# GRP-6803  teamdynamix should update groups with PUT of full state of group

It seems to flip the group to _not_ being active. The _PUT_ endpoint for groups, needs the full state of the group. So, if {{IsActive: true}} is not present, the group will be set to {{{}IsActive: false{}}}.  The workaround to this is usually to get the current state of the group and just update the fields you need. However, it looks like the code already handles this separately on group _creation_ by always manually setting IsActive in {{createTeamDynamixGroup}} but not in {{UpdateTeamDynamixGroup}} .
