# GRP-689  fix grouper subject sort order

The lite ui subject combo used to sort the subjectId or subjectIdentifier to the top of the list, so if you type in a netId (and it is a common search term), the desired result will be at the top. 

## Comments

### mchyzer - 2011-11-04T05:01:25.998+0000

This is done for the lite UI and for the admin UI subject searches.  The algorithm works like this:

1. if there is a subjectId or subjectIdentifier match, that goes to the top
2. If there are less than 5 other good matches, send those to the top
3. otherwise display the sorted results as they would normally be sorted (the admin UI, lite UI, or subject source itself has ways to do this)

Note, for the second item, it will look for the number of matching attributes of the subject.

i.e. if "smith" is searched for, 

- the person with netId "smith" will be at the top
- the two people with 3 subject attributes "smith" (case insensitive) will be next, and the rest (including people with 2 or 1 subject attributes of "smith") will be in alphabetical order
