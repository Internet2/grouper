# GRP-7473  Escape request values written into hidden and text inputs in UI JSPs

Security hardening: several UI JSPs wrote request-controlled values into input value attributes without escaping. Commits 4a34ee4a2cc8, 266bd9343a6a and 118da3c31357 (Chad Redman, 'Escape HTML in pages', no Jira) added fn:escapeXml in provisionerConfigAddHelper.jsp, adminJobHistoryChart.jsp (time and date filters, names-like filter, minimum elapsed seconds), configurationFileEditEntry.jsp, grouperObjectTypeObjectSettingsEditHelper.jsp, the provisioning settings edit helpers, and visualizationMain.jsp (objectId).

The pre-release review for 7.8.0 found one more in the same file: visualizationMain.jsp objectType, which UiV2Visualization sets from request.getParameter("objectType") the same way as objectId. Escaped in this Jira's commit.

Risk was low because of other validation on these parameters, so no security advisory is planned unless one of them is shown to be reachable.
