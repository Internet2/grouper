# GRP-7159  Azure full sync from sync-back cache for groups and memberships, with group owners captured into the group cache

Completes the Azure axes of full-sync-from-sync-back. The entities (users) axis was already enabled in GRP-7115; this adds the groups and memberships axes, so a full sync can serve groups and memberships from the grouper_prov_* sync-back cache and skip the bulk target pulls. The generic framework/adapter already routes Azure per-axis and honors the both-or-neither groups/memberships coupling, so the DAO change is to declare canFullSyncGroupsFromSyncBack and canFullSyncMembershipsFromSyncBack; write sites already keep the mirror current.

Azure group owners are a managed group attribute (groupOwners), fetched by a separate Microsoft Graph /owners call and previously never captured into the sync-back mirror. They are now folded into the group cache so a cache-reconstructed group carries its owners on the GROUP (never as memberships) and does not spuriously re-push them on every from-cache run.

Includes integration tests (warm-cache pull-skip per axis, add/remove incremental currency across all three axes, owners land in the group cache and not the membership cache, and owners survive the from-cache round-trip with no spurious re-push) plus unit tests for the owner capture. Follow-on to GRP-7115.
