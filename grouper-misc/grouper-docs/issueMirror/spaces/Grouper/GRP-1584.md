# GRP-1584  WS allow multiple login subject sources

The grouper-ws.properties parameter ws.logged.in.subject.default.source allows logins to WS from a specific source rather than all of them. I have a forthcoming patch to make this a comma-separated list instead of a single value. The use case for this is that either users or service accounts need access.
