# GRP-5673  Audit logs don't appear to show removal of direct group members during the delete event of the member group.

The following events were done and only the "Added <group_id> as a member" logs were observed.

Create GroupZ
Create GroupA
Create GroupB
Add GroupA to GroupZ
Add GroupB to GroupZ
Some time passes...
GroupA is deleted
GroupB is deleted

The attached screen shot shows the full audit log for "GroupZ" after all of the above events.

There is no "remove GroupA from GroupZ" or "remove GroupB from GroupZ"  logged.

If you remove the membership of GroupA from GroupZ (not delete GroupA) then you will see the expected audit log like:
