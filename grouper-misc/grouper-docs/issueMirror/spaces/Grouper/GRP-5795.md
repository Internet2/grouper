((HttpPost)httpRequestBase).setEntity(new StringEntity((this.body)));
 
the default for “StringEntity” is Consts.{*}_ISO_8859_1_{*}{_}.{_}  So I think I need to adjust that based on content type to be a UTF type or something… I can look at it at some point
