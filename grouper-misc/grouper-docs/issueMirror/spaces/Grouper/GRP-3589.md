# GRP-3589  default for provisioning ldap userSearchAllFilter

If you leave the userSearchAllFilter blank, it will default to searching for containing the search attribute and if there is an objectclass attribute then those will be included in the filter too.  e.g. (&(employeeId=*)(objectClass=eduPerson)(objectClass=top))
