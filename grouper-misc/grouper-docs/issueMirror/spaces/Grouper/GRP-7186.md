# GRP-7186  Loader run page: unclear error when running a newly configured loader job that is not yet scheduled

On the Grouper loader run page, when a newly configured loader job has not yet been scheduled on the daemon, clicking run produces a confusing low-level error.

Error scheduling group to run on the daemon

java.lang.RuntimeException: java.lang.RuntimeException: Job SQL_SIMPLE__etc:loaderFailTest__ac29130dd96548938ee918e9b81abebe is not enabled.

The error should instead tell the user in plain language that the job needs to be scheduled before it can be run, i.e. schedule the job first (or wait for it to be scheduled) and then run it, rather than surfacing the raw is not enabled RuntimeException.
