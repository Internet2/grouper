# GRP-2317  Performance issue with load subject

We found performance  is slower in this patch for loading subject screen. After debugging sql statements, we found some exact same sqls were executed a lot of times, i.e. for a subject who has 900 group memberships (direct and indirect), sql to retrieve attributeDefName for etc:objectTypes:grouperObjectTypeMarker hit db 2000+ (log is attached). Although the result returned in a few millisenconds, it still adds on several seconds in total. I attached the sql trace log. We enabled second level cache in GrouperObjectTypesAttributeNames.retrieveAttributeDefNameBase() that reduced calls to db and improve the performance.
