# GRP-7027  GSH Java template compilation — library template type and registry instance accessor

* Phase 7 (library). Builds on GRP-7010/7011 and the foundation ticket. Design doc sections "Shared logic and inter-template calls" and "Type 8 — library template".
 * Library templates have no dispatcher — they are plain compiled classes whose methods other templates call. Add a public accessor on {{GshTemplateClassLoaderRegistry}} (e.g. {{{}instanceForTemplate(String configId){}}}) that loads the {{{}GshTemplateConfig{}}}, reads source via {{{}GshTemplateConfig.readSource(){}}}, resolves the class, and returns a fresh {{newInstance()}} as {{{}Object{}}}. No required base class.
 * Supports the doc's sharing options: interface-cast against a parent-jar interface (Option B) and {{GrouperUtil.callMethod}} reflection (Option C).
 * Validate that {{templateType=library}} requires {{{}templateMode=compiled{}}}.
 * Tests: a library method is callable from another template both via interface cast and via {{{}GrouperUtil.callMethod{}}}; source change yields a fresh class/instance (hot-reload); statics reset on reload.
