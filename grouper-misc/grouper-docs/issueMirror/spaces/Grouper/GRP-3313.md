# GRP-3313  smtp external system should show all email configs

We need to refactor mail configs.

If you do not do this, it will use your settings if the new properties are not configured.

You should change your configs to the new keys (remove the old).

 You will get a reminder like this on startup if you dont do this:
{code:java}
2021-03-27 09:06:42,948: [main] ERROR GrouperCheckConfig.verifyMailConfigsMigrated(422) -  - Error: please change your grouper.properties config key: mail.debug to be mail.smtp.debug {code}
