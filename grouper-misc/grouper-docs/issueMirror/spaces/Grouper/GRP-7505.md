# GRP-7505  Restore Checkstyle config compatibility with modern Checkstyle versions (GitHub PR 274)

Restore compatibility of grouper-parent/src/checkstyle/checkstyle.xml with modern Checkstyle versions. Contributed in GitHub PR https://github.com/Internet2/grouper/pull/274 (by yxr8gy).

Changes: bump maven-checkstyle-plugin 3.1.0 -> 3.6.0; move the LineLength module from TreeWalker to Checker (required since Checkstyle 8.24); change JavadocVariable property scope -> accessModifiers (newer Checkstyle). Without this, IDEs with current Checkstyle reject the config outright.

Follow-up: the plugin bundles an older Checkstyle by default, so pin a com.puppycrawl.tools:checkstyle plugin dependency at 10.22 or later so the accessModifiers property is recognized in the Maven verify-phase checkstyle run.
