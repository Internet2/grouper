# GRP-3863  -e GROUPER_APACHE_REMOTE_IP_INTERNAL_PROXY 

GROUPER_APACHE_REMOTE_IP_TRUSTED_PROXY does not work for private IP ranges, which are used often.  The summary tag would sed in a RemoteIPInternalProxy into grouper-www.conf defined as one or more ipranges.  More info on the directive can be found [here|https://httpd.apache.org/docs/2.4/mod/mod_remoteip.html#remoteipinternalproxy]
