# GRP-562  grouper group source should have a limit on number of results

if someone is an admin, and searches for "pe" that will match all groups at penn since they start with "penn:", which will return 100k rows (all in groups table).  I think this search should work like the jdbc sources where it stops getting results after a limit (e.g. 1k).  Note that means it cant use hibernate unless it does multiple queries....
