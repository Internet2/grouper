# GRP-2274  PSPNG - JEXL Expressions - group.id (uuid), stemAttributes, groupAttributes

PSPNG's Jexl Expressions crash when variables are not available. Therefore, ensure that the following are defined for Existing, Deleted (PIT) and Deleted (no-PIT) groups:

idIndex

groupId (uuid, aka group.id)

stemAttributes

groupAttributes
