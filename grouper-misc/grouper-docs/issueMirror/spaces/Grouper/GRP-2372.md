### Carey Black  (osu.edu) - 2019-10-23T16:36:37.372+0000

Maybe this could be driven with respect to "group type" values?

  Maybe if the attestation has more of a "mode" ( direct and/or indirect subjects, vs structure of "group math").

    When walking the "group math" maybe it should stop at other groups that have their own attestation for that "mode"?

 

That way sub structures can be attested and the "stuff above" could be done independently?

 

Example:

Access control policy (ACP) is set to:

   attest "group math"

 

And the policy includes several ref groups ( that have their own attestation ) and a "include", "exclude"  groups that do not have attestation.

So the ACP attestation would only report/attest the math to include the ref groups (and include/exclude) and/or the membership of the "include", "exclude"  group memberships.
