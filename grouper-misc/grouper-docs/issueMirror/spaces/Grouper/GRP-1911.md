## Comments

### bert - 2018-10-03T15:35:58.531+0000

Your expectations are correct about what should change when a full-sync occurs, and the behavior you're seeing is unexpected.

The cause of this problem is that the [underlying code|https://github.com/Internet2/grouper/blob/GROUPER_2_3_BRANCH/grouper-misc/grouper-pspng/src/main/java/edu/internet2/middleware/grouper/pspng/LdapAttributeProvisioner.java#L190] uses a regular expression and takes the configured Prefix and adds .* to it.

Your Pipe character means that the code treats the following values as being within its scope: Grouper|.* which, of course, matches everything.

This is a bug in thinking something documented as a Prefix could be easily upgraded to a regular expression.

Fix: Use Pattern.quote() when the prefix is used as part of a regular expression and PspJexlUtils.escapeLdapFilter() when it is used as part of the ldap filter.

Workaround: Escape the | or any other regular-expression-relevant characters
