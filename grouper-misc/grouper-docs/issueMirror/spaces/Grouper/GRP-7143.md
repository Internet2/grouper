# GRP-7143  Add responseTimeout attribute to LDAP external system config UI

There is no UI field for LDAP responseTimeout, which means that it uses the ldaptive default of PT1M. The loosely related timeLimit is in the UI as "time limit", but this informs the server side and may not be honored anyway. The responseTimeout is what matters because Grouper will abort the call if it is exceeded. If you have a slow query you need the ability to bump this up.
