# GRP-7580  Security: Outside systems and Grouper credentials

Security fixes from the 2026 Grouper security review, category I. Each line is one fix, its severity, and the public advisory it belongs to:

- External messaging operations need an allowed group (medium, advisory H8)
- Provisioner diagnostics limited to sysadmins (medium, advisory M1)
- Message consumer WS URL and path checked (low, advisory H8)
- SCIM conflict recovery needs an exact external id match (medium, advisory M4)
- Provisioning matching keeps an existing account link (medium, advisory M1)
- Remedy and Digital Marketplace token caches kept per external system (low, advisory M1)
- Custom UI Azure and Duo user caches kept per external system (low, advisory M1)
- BPLogix provisioner XML parsing hardened (low, advisory M1)
- RabbitMQ TLS verifies the broker certificate (low, advisory M1)
- Duo, Adobe and Azure caches kept per external system (low, advisory M1)
- Provisioning group-reference metadata requires READ on the referenced group (medium, advisory M1)
- Interfolio provisioner matches accounts only on exact identifiers (medium, advisory M1)
- LDAP group DN override set by delegated users limited to the provisioner search base (low, advisory M1)

Fixed in 7.9.1 (GROUPER_7_9_0-branch). The same fixes were provided as security patches for earlier releases. See the security announcement for details and required steps.
