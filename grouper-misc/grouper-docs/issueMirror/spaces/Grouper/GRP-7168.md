# GRP-7168  Add navigation buttons between the GSH template screen and the daemon screen

The GSH template config screen and the script daemon config screen are related (a daemon template is configured on the GSH template screen and scheduled on the daemon screen), but there is no quick way to jump between them.

Request: add a button on the GSH template screen that links to the corresponding daemon screen when the template is a daemon, and a button on the daemon screen that links back to the corresponding GSH template screen.
