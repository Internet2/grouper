# GRP-527  add rule to allow/disallow sources

Penn would like to allow/disallow subjects to be added to groups based on rules.  Maybe eventually this could affect the subject search result on the UIs as well.  Basically on our root stem we would like to disallow external users.  Then on stems that have groups to allow, allow external users.  On an add/remove member it would go up the stems until it found a rule on that source, and if none found, then allow.  It could be extended later on a group by group level as well, in addition to the stem level
