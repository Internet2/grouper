# GRP-6844  TrueFoundry provisioner: remove user from teams before deleting

TrueFoundry returns a 400 error when hard-deleting a user who is still a member of any team. Fixed {{deleteUser}} to first look up the user's current teams via {{{}GET /api/svc/v1/subjects?query=\{email}{}}}, remove the user from each team (adding the default team member if the team would otherwise be left empty), and then issue the delete call.
