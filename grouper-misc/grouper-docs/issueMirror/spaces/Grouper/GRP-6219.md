# GRP-6219  oauth authentication class for WS with a fallback

_(no description)_

## Comments

### Chris Hyzer - 2025-06-30T07:16:37.138+0000

set this in grouper-ws.properties to use this authn
{code:java}
ws.security.non-rampart.authentication.class = edu.internet2.middleware.grouper.ws.security.WsGrouperOauthAuthentication{code}
set this in grouper-ws.properties to the authn if there is no oauth bearer token
{code:java}ws.security.authn.oauth.fallback.class = edu.internet2.middleware.grouper.ws.security.WsGrouperKerberosAuthentication {code}
pass in the param of the oidc config id: grouperOidcConfigId

if the version is used to identify the oidc config id, grouper-ws.properties config:
{code:java}ws.security.authn.oauth.clientVersion.2.432.567.grouperOidcConfigId = whateverOidcConfigId {code}
You can debug access tokens:
{code:java}ws.security.authn.oauth.debugAccessTokens = true {code}
In log4j2.xml you can debug authns
{code:java}<Logger name="edu.internet2.middleware.grouper.ws.security.WsGrouperOauthAuthentication" level="debug" additivity="false">{code}
