### Chad Redman  (unc.edu) - 2019-08-30T15:32:47.781+0000

The capability for STARTTLS was added in 2.4.0 patch 43. That was added 3 months after this issue was created, so I'm assuming that's the feature that was needed.

I set up a minimal postfix server to handle port 25, port 465 with ssl, and port 587 with starttls. The daily report worked in all cases, so I think GRP-2113 resolves this issue.

 Setup:
{noformat}import edu.internet2.middleware.grouper.app.loader.db.Hib3GrouperLoaderLog
import edu.internet2.middleware.grouper.cfg.GrouperConfig

GrouperConfig.retrieveConfig().propertiesOverrideMap().put("mail.from.address", "chad@localhost")
GrouperConfig.retrieveConfig().propertiesOverrideMap().put("mail.smtp.user", null)
GrouperConfig.retrieveConfig().propertiesOverrideMap().put("mail.smtp.server", "192.168.99.100")
GrouperConfig.retrieveConfig().propertiesOverrideMap().put("mail.debug", "true")

GrouperLoaderConfig.retrieveConfig().propertiesOverrideMap().put("daily.report.emailTo", "user2@localhost")


Hib3GrouperLoaderLog hib3GrouperLoaderLog = new Hib3GrouperLoaderLog()
hib3GrouperLoaderLog.setJobScheduleType("MANUAL_FROM_GSH")
hib3GrouperLoaderLog.setJobName("MAINTENANCE__grouperReport")
hib3GrouperLoaderLog.setJobType("MAINTENANCE")

def gs = GrouperSession.startRootSession()
