# GRP-106  Performance improvement in type validation in Group.getAttribute(String) 

From some quick profiling, I'm seeing that for each group going through the validation at the end of the method, 2 queries will be made in grouper_fields, 2 queries in grouper_types, and 1 query in grouper_groups_types.  This clearly becomes a problem when you have a large number of groups going through this validation code.  Caching should help reduce the queries to grouper_fields and grouper_types.
