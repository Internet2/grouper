# GRP-346  ldappc supports more advanced filters when selecting groups to be provisioned

As of 1.5.0, ldappc can use more advanced query filters to select the groups to be provisioned. For example, the configuration element :

<group-queries>
  <resolver-matching-queries>
    <data-connector-list>
      <data-connector id="filteredGroupDataConnector" />
    </data-connector-list>
  </resolver-matching-queries>
</group-queries>

will select groups based on the attribute resolver data connector :

<resolver:DataConnector id="filteredGroupDataConnector" xsi:type="grouper:GroupDataConnector">
  <grouper:GroupFilter xsi:type="grouper:Minus">
    <grouper:GroupFilter xsi:type="grouper:StemName" name="edu" scope="SUB" />
    <grouper:GroupFilter xsi:type="grouper:ExactAttribute" name="extension" value="groupD" />
  </grouper:GroupFilter>
</resolver:DataConnector>

other filters include ADD and OR.
