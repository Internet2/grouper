# GRP-7513  Generic provisioner Loader class name must extend the DAO class, so a provisioner with a loader cannot be saved in the UI

In grouper-loader.base.properties, provisioner.genericDaoProvisioner.genericLoaderClassName has mustExtendClass edu.internet2.middleware.grouper.app.provisioning.targetDao.GrouperProvisionerTargetDaoBase, copied from the DAO class field above it.

So saving any generic provisioner that has a loader class in the provisioner UI fails with: 'Loader class name' does not extend edu.internet2.middleware.grouper.app.provisioning.targetDao.GrouperProvisionerTargetDaoBase

It should be edu.internet2.middleware.grouper.app.provisioning.GrouperProvisioningLoader. Workaround: set the provisioner config through the config import screen instead of the provisioner edit screen.
