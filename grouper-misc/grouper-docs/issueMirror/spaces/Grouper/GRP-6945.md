# GRP-6945  Legacy LDAP subject source queries add OBJECT_SCOPE and ONELEVEL_SCOPE

In the drop down for a legacy LDAP subject source, there is a dropdown for Search subject scope, but the only option is SUBTREE_SCOPE. The option ONELEVEL_SCOPE should be a valid choice, and is not uncommon to need this. The other option OBJECT_SCOPE doesn't make sense here, but it can be added for completeness.
