# GRP-3162  ldap external system should default to false for tls

The TLS flag in LDAP external systems now defaults to false instead of true.  If you don't have this set and you are using TLS, set it to true.  You can setup a test filter in the external system and test it from the UI

If you have this as "false" explicitly, you can remove that config since the new default is false.
