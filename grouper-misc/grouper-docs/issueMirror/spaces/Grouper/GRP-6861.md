# GRP-6861  data field subject source should support resolving subject ID as identifier

When {{subjectIdResolvedAsIdentifier}} is set to {{true}} for a data field subject source, looking up a subject by its subject ID as an identifier should find the subject. This allows subject IDs to be used interchangeably as identifiers for data field subject sources, matching the behavior of other subject source adapters.
