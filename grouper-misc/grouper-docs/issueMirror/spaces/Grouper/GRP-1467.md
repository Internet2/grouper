# GRP-1467  allow UI "Left column" to resize(manually or automatic) so that longer paths can be displayed in the UI

The left column that has the "+Create new group" button, "Quick links", and "Browse folder" areas should be able to "drag to resize" ( at least from right to left) to allow the "Browse folder" function to display longer paths/names.

The current Max characters displayed is (about) 30. Most group structures will likely need a wider display to see the structure.

An easy example to see the problem is:
Root:Grouper Adminstration:Attribute:userData.
  Almost all of the children of userData are "truncated" by the right edge of the UI.

Yes there is a horizontal scroll bar, but that is not as nice as an expandable UI frame.

As another possible alternative: Make the "Browse Folders" span both columns in the UI at the very top. Leave it collapsed by default. (Just another thought.)
