# GRP-5624  When using SAML SSO support the use of Idp ErrorURLs for AuthN "failures"

REF: https://refeds.org/specifications/errorurl-v1

Specifically supporting the use of:
ERRORURL_TS
ERRORURL_RP
ERRORURL_TID
and
2.2. The required ERRORURL_CODE
  with  at least 2.2.1. Code Definitions
    
* IDENTIFICATION_FAILURE
* AUTHENTICATION_FAILURE
* AUTHORIZATION_FAILURE ( maybe a config setting to suppress output, but include this detail in the Grouper log only? )
* OTHER_ERROR

Maybe other global config settings could also be added to control/scope/limit/alter default messages as well?
