# GRP-6926  Accessing /status/grouper shouldn't log stacktraces for failed jobs

When running /grouper/status?diagnosticType=all, the grouper log writes a stacktrace of a runtime exception for every job that hasn't run successfully within its time period. This doesn't really add any benefit, since you're hitting a web page and not seeing the logs. It just adds a lot of noise to the log file.
