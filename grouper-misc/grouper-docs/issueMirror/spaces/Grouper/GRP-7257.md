# GRP-7257  Upgrade jsoup to 1.23.1 for security

Bump jsoup from 1.21.1 to 1.23.1 in grouper-parent/pom.xml, picking up 1.21.2, 1.22.1, 1.22.2 and 1.23.1.

This addresses CVE-2026-71497 / GHSA-pmhh-3w7g-xqp8 (moderate, CVSS:3.1/AV:N/AC:H/PR:N/UI:R/S:C/C:L/I:L/A:N), which affects jsoup 1.14.3 through 1.22.2 and is fixed in 1.23.1. When a custom Safelist permits certain raw-text elements, jsoup may incorrectly sanitize malformed HTML containing a tag name that ends in a control character. The tag can take on the parsing behavior of a different element, so content that should stay text is emitted as active markup after serialization, potentially allowing XSS. The built-in Safelists are unaffected.

Grouper does not use the jsoup Cleaner or any Safelist, so Grouper itself is not believed to be exposed to that CVE, but the dependency still scans as vulnerable and should be current.

The version range also brings other security hardening: a configurable maximum parser depth, defaulting to 512 for HTML to protect against unbounded stack growth; optional re2j regex engine support so regex-based CSS selectors evaluate in linear time when user-supplied queries are involved; IndexOutOfBoundsException and ValidationException on crafted or malformed input downgraded to logged parse errors instead of thrown exceptions; and, in the HTTP client, authorization headers and request cookies are no longer forwarded across origins on redirect, with redirect handling brought in line with the spec.

It also fixes several correctness and thread-safety bugs, including a race in Element.children() when called concurrently on the same element, a ConcurrentModificationException from TagSet copies mutating their template under shared sessions, incomplete reads when a multibyte character straddled an InputStream buffer boundary, and retained memoized StructuralEvaluator results increasing memory use across long-lived threads.

Risk is low. Grouper touches a very small part of the jsoup API, in six classes: Jsoup.parse, Document.getElementsByTag, Element.attr for read and write, Document.html, and org.jsoup.internal.StringUtil.isBlank. All are present and unchanged in 1.23.1, and the jar is still Java 8 bytecode. The self-closing tag parsing change that could have mattered landed in 1.20.1, which Grouper is already past, and jsoup has scheduled removal of currently deprecated APIs for 1.24.1, not 1.23.1, so nothing Grouper calls goes away here. The one behavior change worth noting is that 1.22.2 updated the default tag set, making button, ins, del, audio, video and canvas inline and adding text boundaries for controls, which can slightly change whitespace when the workflow config classes reparse and reserialize form HTML through Document.html. That is cosmetic whitespace, not structural.
