# GRP-5866  move wizard inline spans to classes with css

Came across this while implementing custom CSS for our deployment. Our default font is bigger than that used by the Provisioner config for its radio button labels.  Unfortunately, those label spans have no id's to reference and they are prolific in the config, which makes individual targeting a hassle at minimum.  Any chance we can pull those inline-css configs into the base css, where users can override if needed?
