# GRP-354  gsh commands which expect group/stem names as input are nearly unusable if group/stem name contains umlauts

Gsh has lots of useful commands like "getMembers(group name)" or "revokePriv(stem name, subject id, privilege". However, depending on the shell's character encoding and keymap, it's often impossible to correctly input these if the name contains an umlaut. This is also a problem with gsh scripts (i.e. Bad Membership Finder and others). 

A solution could be to extend those commands to also accept UUIDs instead of names.
