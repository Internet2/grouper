# GRP-5125  LDAP group provisioner getting wrong counts of members

Group is provisioned to an LDAP group.

Group in Grouper has 10654 person members.

Verbose log shows Grouper target group: attr[member]: TreeSet(10700)

Verbose log shows Target provisioning group: attr[member]: HashSet(10706)

1) The Grouper group is wrong, and thinks extra members need to be provisioned.
2) There are less members on the Grouper side, yet, it does not delete any members from the target

Tried to delete the cache buckets, but no change. Currently trying with cleared all cache state.
