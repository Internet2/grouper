# GRP-5835  Ability to add custom menu links

Some customers want custom links in the left link menu, but the only way to do it is to customize the jsp page. There would be less technical debt it this was configurable through properties. Alternatively, there could be a jsp include for custom items, and it would be blank by default but they could override it.

## Comments

### Chad Redman - 2024-11-21T03:09:59.041+0000

If you have customized the UI index.jsp page to add extra links to the upper left Quick Links menu, you can move these modifications into grouperUi2/assetsJsp/quicklinks-nav.jsp instead. If you only want to add extra links at the end of the default links, you can instead add it to grouperUi2/assetsJsp/quicklinks-nav-extra.jsp. If these are the only changes from the default index.jsp page, you can revert index.jsp back to the default page.
