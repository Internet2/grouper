# GRP-7410  Clicking on error anchor in provisioning rewrites to broken url

If I create a provisioner but there is an error, I get a flash message at the top, e.g., {{Error: 'Entity attr email - translate from grouperProvisioningEntity field' is required}}. If I click on that link it jumps to the offending form field. But it also rewrites the URL.

From: [http://localhost:8080/grouper/grouperUi/app/UiV2Main.index?operation=UiV2ProvisionerConfiguration.addProvisionerConfiguration|http://localhost:8080/grouper/grouperUi/app/UiV2Main.index?operation=UiV2ProvisionerConfiguration.addProvisionerConfiguration]

To: [http://localhost:8080/grouper/grouperUi/app/config_targetEntityAttribute.1.translateFromGrouperProvisioningEntityField_spanid|http://localhost:8080/grouper/grouperUi/app/config_targetEntityAttribute.1.translateFromGrouperProvisioningEntityField_spanid]

That URL base is persistent, and you can click around other pages and they are still functional because it’s all AJAX updates. However, right-clicking doesn’t work at all and you get a blank page, because it’s not a real URL.
