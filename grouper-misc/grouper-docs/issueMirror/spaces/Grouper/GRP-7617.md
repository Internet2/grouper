# GRP-7617  Security review follow-ons for 7.10.0: hardening

Follow-on hardening from the 2026 security review (GRP-7572 to GRP-7585, released in 7.9.1) that landed on GROUPER_7_BRANCH after 7.9.1 and ships in 7.10.0. The commits use the original issue numbers.

- 69ac942c5327 (GRP-7573 commit 2): report config view instances, enable/disable and delete only accept a report config of the group or folder on the screen
- a1e5d20da092 (GRP-7582 commit 2): escape provisionerName, gshTemplateConfigId, reportConfigId and USDU subject string in audit text, with a test that every audits_ expression is escaped
- b993826611f0 (GRP-7577 commit 2): config screens load a class named in the request only if it is a public concrete subclass of the expected type, without initializing it first
- 95f722421896 (GRP-7583 commit 2): GroupSave and StemSave check a chosen uuid before creating missing parent folders; test that a Custom UI LDAP filter that becomes an expression after substitution is refused
- cf88cf27d075 (GRP-7579 commit 2): WS JSONP HTTP test covers the wrapper refused when ws.allowJsonWrapper is off
- 74459d2edbb6 (GRP-7572 commit 3): tests for the Add daemon link and handlers for non sysadmins, the group inherited privileges gate, and the loader edit screen template upload cleanup
