# GRP-3359  convert groovysh shell for templates, other jobs, and custom ui, to jsr223

Groovy that runs inside Grouper in daemon or UI now uses JSR223 groovy instead of Groovysh.  There are no plans to support non-groovy languages (due to support and documentation)
