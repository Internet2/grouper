# GRP-2188  Add Cc, Bcc and Reply-To to GrouperEmail options

Currently the GrouperEmail class only has an option to set the to address (a single address or comma-delimited list). There is no option for Cc, Bcc, or Reply-To. The first two would be good for Identity Management to be aware of certain emails that go out to the users. The last would be good if the From address is not a good reply address.
