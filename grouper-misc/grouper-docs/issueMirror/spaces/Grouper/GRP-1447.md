Subject: [grouper-users] Old version of mysql connector jar lurking in the V2.3.0 web service installation

Hi, all,

I was having database connection problems from our web service. Thanks to some clever troubleshooting ideas from a coworker, I tracked it down to a version conflict between the connecter jar our web service was using and our MySQL 5.7 server.

Wondered if there was a reason that mysql-connector-java-5.1.5-bin.jar is installed in grouper.ws-2.3.0/grouper-ws/lib/grouper-ws. The API has a new version under grouper.api-2.3.0/lib/jdbcsamples which allowed my API and UI to work fine and, once I removed the 5.1.5 version from the WS lib dir and rebuilt, the web service is also working fine.

Was that version included intentionally?
