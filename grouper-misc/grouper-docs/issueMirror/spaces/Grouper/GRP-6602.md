# GRP-6602  Visualizations should include when a loader job last ran and optionally it's schedule in the diagram

It would be helpful when reviewing a visualization to see if a loader job is "active and current" or if it is disabled or scheduled so that it will never run.

Knowing how fresh the data is in a group is critical to understanding the diagram.
If a group is "static" because the loader is disabled that makes a big difference in understanding the visualization.
