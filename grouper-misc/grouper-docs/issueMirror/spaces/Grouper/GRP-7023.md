# GRP-7023  Remove stray "Hello" debug text before "Direct group members:" on group summary screen

On the group summary tab, under "Show more information" in the Members section, the row that lists direct group members renders as "Hello Direct group members:". The word "Hello" is leftover debug text.

The externalized label {{groupSummaryPageMembershipsDirectGroupMembers}} ("Direct group members:") is correct; the stray "Hello " was hardcoded in the JSP in front of it. This row only appears when a group has another group as a direct member ({{{}directGroupMembersCount > 0{}}}), so it is not seen on groups whose members are all entities.

Fix: remove "Hello " from grouper-ui/webapp/WEB-INF/grouperUi2/group/groupSummaryMoreMemberships.jsp line 10. Introduced in commit 6385c8c6 (GRP-6360, group summary cached membership size performance work).
