# GRP-4159  Grouper validation: enable / disable dates

When a user adds a member to a group the enable / disable dates are provided (thank you - those are awesome). The ask is for Grouper to have a standard validation that if an enabled date is entered that the disabled date must be greater than that date. 

It would also be super cool if Grouper could have a date / time picker.
