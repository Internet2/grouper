# GRP-2048  Improve save/refresh behavior of stem navigator tree

Please consider improving the UI stem tree widget response when a user performs a save/refresh after doing stem maintenance such as add/move/delete entity.  The current behavior when an entity save occurs is that the tree does not auto-refresh.  A manual refresh completely collapses the tree back to the root level.  This behavior can be tedious when performing tree maintenance in deep level tree structures.

 

Please consider the following enhancements:

1.  Auto-refresh the tree on save.

2.  On refresh, keep/return (as nearly as possible) the tree to it's prior expanded state.

 

Thanks for the consideration.
