# GRP-865  insert a new group with lite ui that exists will overwrite instead of give error

Hi,
Using the lite UI, if I try to create a group with the same name as one in the same folder, the Lite UI will overwrite the existing group’s value for those specified in the creation page. This is a confusing behaviour since we would expect to see a “This group already exists” error message or at least a warning asking “This group already exist, are you sure you want to overwrite the existing values ?” with a Yes/No option. Right now it simply says “Group saved”.
 
The Admin UI doesn’t have that behaviour, it shows a “group already exists with name:…” error. So this behaviour is conflicting.
 
Is it possible to modify the Lite UI’s behaviour ?
 
Thanks
 
Sébastien Gagné

simpleGroupUpdate.errorInsertGroupExists = Error: Group already exists, edit the existing group with the panel at the top, instead of creating a new one

Add this to: SimpleGroupUpdate.java in the UI:

import edu.internet2.middleware.grouper.internal.dao.QueryOptions;
import edu.internet2.middleware.grouper.misc.GrouperSessionHandler;

TO:

        if (StringUtils.isBlank(extension)) {
          guiResponseJs.addAction(GuiScreenAction.newAlert(GrouperUiUtils.message("simpleGroupUpdate.errorExtensionRequired", false)));
          return;
        }
       
        
        stem = StemFinder.findByUuid(grouperSession, stemId, true);
        final String GROUP_NAME = stem.getName() + ":" + extension;
        //see if the group exists, do this as admin, since the user might not be able to see it
        boolean exists = (Boolean)GrouperSession.callbackGrouperSession(grouperSession.internal_getRootSession(), new GrouperSessionHandler() {
          
          @Override
          public Object callback(GrouperSession grouperSessionSystem) throws GrouperSessionException {

            Group group = GroupFinder.findByName(grouperSessionSystem, GROUP_NAME, false, new QueryOptions().secondLevelCache(false));
            return group != null;
          }
        });
        
        if (exists) {
          guiResponseJs.addAction(GuiScreenAction.newAlert(GrouperUiUtils.message("simpleGroupUpdate.errorInsertGroupExists", false)));
          return;
        }
        
      }

      String displayExtension = httpServletRequest.getParameter("groupToEditDisplayExtension");
