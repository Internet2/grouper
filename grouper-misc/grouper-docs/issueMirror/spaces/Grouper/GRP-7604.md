# GRP-7604  Add MCP tools to find, create and update attribute definitions and attribute def names

The Grouper MCP server can find attribute def names (attribute_def_name_find) and read and write attribute assignments (attribute_assignment_get, attribute_assignment_save), but it cannot create or edit attribute definitions or attribute def names. Creating them takes the UI or a GSH script.

This came up while setting up a custom UI that stamps a timestamp on a membership: the attributeDef (value type timestamp, multi valued, assignable to immediate memberships) and its attribute def name had to be created outside MCP, and a missing attribute name went unnoticed until the custom UI script failed at click time.

Add MCP tools to:
- find attribute definitions and show their settings (type, value type, multi valued, multi assignable, and what they can be assigned to)
- create or update an attribute definition with those settings
- create or update an attribute def name under a definition

Follow the existing MCP conventions: readwrite scope checks, privilege checks on the folder, tests, servlet registration, and the MCP wiki documentation.
