# GRP-7029  GSH Java template compilation — compiled provisioner dispatch via GshTemplateProvisionerBase

* Phase 7 (provisioner). Builds on the foundation (GRP-7026) and GRP-7010/7011. Design doc {{grouper/temp/trash/gshCompileImprovement.html}}.
 * A compiled GSH provisioner template extends {{GshTemplateProvisionerBase}} (which extends {{{}GrouperProvisioner{}}}) directly — the legacy "wrap the body in a {{GshTemplateV2}} and attach via output" pattern is dropped for compiled mode.
 * Branch the GSH-provisioner dispatch so {{templateMode=compiled}} resolves the class through {{GshTemplateCompiledDispatch.instantiate(configId, config, GshTemplateProvisionerBase.class)}} instead of compiling Groovy; interpreted mode keeps the existing path.
 * Errors surface through the provisioner's normal failure/validation channel.
 * Tests: a compiled provisioner template loads and runs through the provisioning dispatch; wrong base → clear error.
