# GRP-5586  usdu needs utility to clean up data from sources that no longer exist

During early setup of Grouper, an institution may set up a subject source, then change their mind and remove it, or replace it with some other config Id. If the old members are in groups, and their subject source is one that is no longer defined, it causes problems, and the only way to clean it up is direct SQL. The group page fails with an error about the unknown subject source, so you can't even see what the problem is. Usdu fails with a similar error about the missing subject source.

Maybe a new menu action can be added to usdu to manage these and clean them up?

 

These are the commands I run, which are to clean up an undefined subject source. There shouldn't be any issues flat-out deleting records this way.

 
{code}/** all memberships for the bad source; review for any concerns */
select ms.id, g.name, s.name, m.subject_id from grouper_memberships ms
  left join grouper_groups g on ms.owner_group_id = g.id
  left join grouper_stems s on ms.owner_stem_id = s.id
  join grouper_members m on ms.member_id = m.id
 where member_id in (select id from grouper_members where subject_source = 'jdbc');

select count(*), subject_source from grouper_members group by subject_source;

delete from grouper_memberships where member_id in (select id from grouper_members where subject_source = 'jdbc');

delete from grouper_pit_memberships where member_id in (select id from grouper_pit_members where subject_source = 'jdbc');

delete from grouper_members where subject_source = 'jdbc';

delete from grouper_pit_members where subject_source = 'jdbc';

select count(*), subject_source from grouper_members group by subject_source;
{code}
