# GRP-964  SQL loader job group add event should include description

When a SQL loader job creates a group there is a change log entry of type addGroup that includes the name of the group but not the description (assuming a description is created by the loader job). A second change log entry of type updateGroup follows and includes the description.

It would be helpful if the addGroup change log entry included both the group name and the description.

Additionally if the addGroup change log entry includes both the name and the description then it would be helpful if the following updateGroup change log entry did not follow.
