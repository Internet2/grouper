# GRP-7420  Add AssetSonar (EZO) member provisioner and AssetSonar external system

New entity-only provisioner for AssetSonar (EZO IT asset inventory) members via the native REST API (/members.api, token header, form-encoded user[...] writes). Matches on email, caches the numeric member id, selects active and inactive members, deactivates with status=0 instead of DELETE, and computes the access tier (role_id) from Grouper group membership.

Adds an AssetSonar external system (baseUrl, apiToken, optional SCIM connector key, tenant-specific role ids) whose connection test fails if the inactive filter is silently ignored. Includes a mock service handler reproducing the API quirks and tests. Teams are not provisioned: the API has no team detail or membership endpoint.
