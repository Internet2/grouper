# GRP-7510  Create report or page on changelog monitoring

When the changelog temp is backed up and updates are running behind, admins don’t know what’s happening and may not know what’s causing it. They also want to know how it’s progressing. Also give more insight than just the raw number of pending changes, because one entry may trigger adding new entries to the queue, so the number sometimes increases instead of decreases.

Maybe a graph on the page would be good too, so they can eyeball the trend.
