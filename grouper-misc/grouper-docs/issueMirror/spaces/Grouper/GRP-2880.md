# GRP-2880  Limited-privilege users cannot revoke membership from subject page

Limited privilege users who have admin privileges on a group can revoke users from the Group's membership list.  However, if the user goes to a member's page and attempts to revoke the group membership from there, a 'Group not found' error is encountered and membership is not revoked.

## Comments

### Carey Black  (osu.edu) - 2020-07-09T20:29:56.807+0000

The same user can navigate to said group and use the "same" Actions -> Revoke Membership and it'll work from the Group UI page.
