# GRP-2550  Upgrade quartz schedule to 2.3.2

Quartz scheduler in the api is currently 2.3.0, which is from April 2017. The latest version is 2.3.2 from Oct. 2019. This version isn't currently listed on the [quartz scheduler download|http://www.quartz-scheduler.org/downloads/] site as available. However it is the current release in the [git project|https://github.com/quartz-scheduler/quartz/releases], and is also available in [Maven Central|https://search.maven.org/artifact/org.quartz-scheduler/quartz/2.3.2/jar].

Even though it's not mentioned on the Quartz website, it is the version used by Spring Boot since 11/2019, in the latest two releases. So it should be safe enough for us to use.

 

See the [github release page for changelog|https://github.com/quartz-scheduler/quartz/releases].
