# GRP-7103  SCIM2 provisioner cannot match groups or entities by externalId (only id/displayName and id/userName/email)

Extended to entities as well: {{retrieveEntityHelper}} now searches by {{externalId}} when it is a configured entity search attribute, after the id/userName/email lookups. This mirrors the group change and the existing emailValue search path. New test {{testEntitySearchByExternalId}} covers it. Both changes are opt-in via {{groupSearchAttributes}} / {{entitySearchAttributes}} and are backward compatible.
