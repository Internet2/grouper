# GRP-2250  Convert au.com.bytecode.opencsv api calls to org.apache.commons.csv

The UI has been using CSV reader/writer classes from the au.com.bytecode.opencsv library for a while. Now that the API has started using org.apache.commons.csv classes for reporting, we may be able to rewrite the former API to use commons-csv, eliminating the need for two libraries to perform the same functions.
