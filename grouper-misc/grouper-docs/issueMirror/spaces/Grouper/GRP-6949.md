# GRP-6949  Incremental sql loader improvements

[https://spaces.at.internet2.edu/x/Og0ZBg]


This is mostly an improvement for SQL_GROUP_LIST.

membership incremental
 - id
 - subject_id
 - subject_identifier
 - subject_id_or_identifier
 - subject_source_id
 - loader_group_name
 - timestamp
 - completed_timestamp
 - mship_recalc_group_name - NEW COLUMN OPTIONAL - sync user with this group only
 - mship_recalc_type - NEW COLUMN OPTIONAL IF mship_recalc_group_name specified - add_member, remove_member (defaults to recalc).

group incremental (NEW TABLE):
 - id - REQUIRED
 - loader_group_name - REQUIRED
 - group_name - REQUIRED - sync this group
 - sync_type - REQUIRED - metadata, memberships, all
 - timestamp - REQUIRED
 - completed_timestamp
