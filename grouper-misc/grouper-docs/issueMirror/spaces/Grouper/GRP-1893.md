A few details on what was found:

Patch 17 added a FullSync on a group when Group-Updates (description, path, extension, attributes) occur so that the Group's non-membership attributes could be updated. Unfortunately, that process did not check if the group was supposed to be provisioned.

Patch 21 adds [a check|https://github.com/Internet2/grouper/blob/9b336868e27e757476a945a920991ce060c1b6b1/grouper-misc/grouper-pspng/src/main/java/edu/internet2/middleware/grouper/pspng/Provisioner.java#L437

] to make sure unselected groups mentioned in the changelog are always skipped.
