# GRP-6343  make snowflake database access faster

inserts should have a batch size of the size of the batch (no max)
updates should do the same batch size, and should create a temp table, batch insert into that, and merge to eventual table, and delete the temp table
deletes should do the same batch size, insert keys into a temp table, delete where exists in temp table, and delete the temp table

This works for SQL sync (which used to crawl)
