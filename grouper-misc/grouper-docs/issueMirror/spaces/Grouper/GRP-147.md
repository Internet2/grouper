# GRP-147  future and function of grouper_sessions table

I discussed this with Gary briefly, but I would like to discuss at one of our meetings.

The grouper_sessions table get a record when a grouper session is started.  Then when (but only if) a grouper_session is stopped, the record is deleted.  If the session is never stopped, then the record is never deleted.

A couple of questions:

1. Should stopping a session delete the record?
2. If not, should we make a process (e.g. in the loader scheduler) which cleans or archives this table
3. Can we drop this table since we will have auditing soon, or should we plan to enhance it to give more information, or leave it alone
