# GRP-2190  UI overuse of "More"

It can be challenging for a "normal" user (not a developer on this project) to find things. There's a "More" tab next to the Privileges tab. There's a "More Actions" under the orange "Add members" button. And in relatively small light type, there's a "More" link below the group name.  A little more specificity and a little less "more" could help potential users currently scared by the UI.

Hi, there. Recently, @Justin Robinson shared the proposed Group Action dropdown menu changes with our IU team for feedback. Here’s what we came up with (see screenshot), and I wanted to see what the community thought of this approach. A few notes:
The broad goal was to break these up into relevant sections of 5 options or less, to make it easier for users to scan/understand the menu
Within each section, order is determined by a common way of understanding the section grouping. For example, Membership logic is ordered by processing progression, staring with Loader and ending with Visualization. But for the Manage group section, it’s ordered by common grouping (group, then composite). And some are just ordered alphabetically (e.g., Group settings)
It also includes some name change proposals, with the original name/ticket rename below
View audit log/Audit log --> Group log
View membership audit log/Audit log - actions —> Actions log
View action audit log/Audit log - memberships —> Memberships log
View privilege audit log/Audit log - privileges —> Privileges log
Electronic forms —> Forms
Attribute assignments —> Attributes
Membership attribute assignments/Attribute assignments on memberships —> Attributes on memberships
Types —> Type settings
What do you all think?
