# GRP-102  validate grouper setup on startup and give detailed error messages if problems

At some point we should have a formal process of discovery when grouper starts up that makes sure certain jars, config files, settings, etc are  valid and if not give detailed instructions on how to fix before cryptic errors (or silent errors) occur...  Im sure we could mine the list serv for examples, and once the basic process is in place, we can augment it as people post to the listserv or have issues.
