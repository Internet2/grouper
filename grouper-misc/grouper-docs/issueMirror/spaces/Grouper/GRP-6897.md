# GRP-6897  Provisioner framework: NPE in compareTargetMemberships when replaceMemberships is enabled and target-only memberships exist

When replaceMemberships=true and a full sync encounters a membership that exists in the target but not in Grouper (e.g. a manually added member or a default service account), GrouperProvisioningCompare.compareTargetMemberships throws a NullPointerException at line 1945:
 {{Cannot invoke "ProvisioningMembership.getProvisioningGroup()" because the return value of "ProvisioningMembershipWrapper.getGrouperTargetMembership()" is null}}
 
The replaceMemberships code path unconditionally calls getGrouperTargetMembership().getProvisioningGroup() without null-checking. For target-only memberships, grouperTargetMembership is null because Grouper has no corresponding membership.

Fix: when grouperTargetMembership is null, fall back to the wrapper's getProvisioningGroupWrapper().getGrouperTargetGroup() to derive the group key. Only add to the replace list and call put on the map when grouperTargetMembership is non-null and not a delete.
