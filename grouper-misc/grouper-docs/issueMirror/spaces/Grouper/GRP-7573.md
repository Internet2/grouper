# GRP-7573  Security: Request IDs bound to the object they name (IDOR)

Security fixes from the 2026 Grouper security review, category B. Each line is one fix, its severity, and the public advisory it belongs to:

- Rule edits must belong to the object being saved (medium, advisory H3)
- Attribute value edits bound to their assignment (medium, advisory M2)
- Permission limit changes check privileges first (medium, advisory M2)
- Inherited privilege rules edited only from their folder (medium, advisory M3)
- Workflow requests bound to their group (low, advisory H1)
- Provisioner permission cache keyed by subject source (low, advisory M1)
- Provisioning sync rows bound to the page's object (medium, advisory M1)
- Workflow requesters matched by source and id (low, advisory H1)
- GSH template download links tied to the file version (medium, advisory C3)
- Report downloads bound to the requested group or folder (low, advisory M7)
- Folder report attestation uses only the folder's own readable report configurations (low, advisory M5)
- Attribute action edit screen bound to its attribute definition (low, advisory M2)

Fixed in 7.9.1 (GROUPER_7_9_0-branch). The same fixes were provided as security patches for earlier releases. See the security announcement for details and required steps.
