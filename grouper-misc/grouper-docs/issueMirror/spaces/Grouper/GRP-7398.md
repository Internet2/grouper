# GRP-7398  Remove jquery compatibility library (query-migrate.js)

Since moving off of the dojo libraries, the jQuery compatability library (invoked in commonHead.jsp) may no longer be needed.

Note there are some annoying warnings that show up in the browser console it warns about:

{noformat}jQuery.fn.bind() is deprecated
jQuery.fn.change() event shorthand is deprecated
jQuery.fn.click() event shorthand is deprecated
jQuery.fn.delegate() is deprecated
jQuery.fn.focusout() event shorthand is deprecated
jQuery.fn.keydown() event shorthand is deprecated
jQuery.fn.submit() event shorthand is deprecated
jQuery.fn.unbind() is deprecated
jQuery.isFunction() is deprecated{noformat}

These are still deprecated in the current jQuery in use, 3.7.1. So removing the migrate library shouldn’t break anything. We just need to fully test the UI to see if anything else is using it.

Meanwhile, the deprecated functions can also be fixed, in preparation for jQuery 4+.
