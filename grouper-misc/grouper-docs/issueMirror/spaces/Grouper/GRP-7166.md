# GRP-7166  GSH template config: hide template version prompt when templateMode is compiled (always V2)

On the GSH template configuration screen, when templateMode is compiled, the UI still prompts for the template version. Compiled templates are always V2, so asking for the version is unnecessary and can lead to a mismatched or invalid selection.

Request: when templateMode is compiled, do not show or prompt for the template version. Treat it as V2 automatically.
