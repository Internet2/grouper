# GRP-5565  Provisionable groups list should be accurate data not from cache

The provisioning action "Provisionable groups" only gets its information from the sync tables, so it only reflects what was calculated to be provisionable during the last run. If you create a provisioner, set some groups to provision, then look at this page, you see "There are no provisionable groups found for: xxx" which is not true and confusing.

If someone is going to view this page, it should reflect accurate information on provisionable groups.
