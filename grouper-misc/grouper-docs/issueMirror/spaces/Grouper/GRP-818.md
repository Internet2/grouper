# GRP-818  [psp] incorrectly deletes groups when provisioning Active Directory

As of 2.1.1, the psp will delete groups from Active Directory after provisioning because identifiers are compared case sensitively.

### Tom Zeller - 2012-09-05T18:53:55.871+0000

Actually the issue is that identifiers (spml pso-ids) are compared case sensitively. Active Directory typically returns uppercase ldap dn attribute types. When provisioning Active Directory, care must be taken to make sure that all ldap dn attribute types are the correct case in the psp (psp-*) and grouper configurations (sources.xml). The examples in psp-grouper-to-active-directory have been updated.

This bug was inadvertently introduced in version 2.1.1 during performance modifications. In version 2.1.1 and earlier, ldap dn attribute types are hardcoded to "ou". As of version 2.1.2, ldap dn attribute types are configurable in psp-resolver.xml, and default to "OU" in the Active Directory examples.

The lastest 2.1.2 snapshot should be used in replace of version 2.1.1.
