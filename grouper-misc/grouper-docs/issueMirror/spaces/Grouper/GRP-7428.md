# GRP-7428  Inherited privileges rule labels incorrect set of valid privileges

When using a stem rule to add inherited privileges, the label on the privilege field (which is text, not a dropdown) says certain fields are valid, which doesn’t correspond with the Java code. Note also that due to bug [https://todos.grouper.internet2.edu/browse/GRP-7427|https://todos.grouper.internet2.edu/browse/GRP-7427|smart-link], it lowercases the names before validating, so fields with mixed case are impossible to set anyway.

|*Type*|*Actual (Java)*|*Label*|
|Group|read, admin, update|read, admin, update, view, optin, optout, groupAttrRead, groupAttrUpdate|
|SelfPrivTonewGroup|admin, optin, read, system, update|read, admin, update, view, optin, optout, groupAttrRead, groupAttrUpdate|
|Stem|stem, create|stemView, create, stemAdmin, stemAttrRead, stemAttrUpdate|
|AttributeDef|attrRead, attrUpdate, attrView, attrAdmin, attrOptin, attrOptout|attrAdmin, attrOptin, attrOptout, attrRead, attrUpdate, attrView, attrDefAttrRead, attrDefAttrUpdate|
