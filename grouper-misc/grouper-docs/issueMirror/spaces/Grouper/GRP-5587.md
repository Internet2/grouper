# GRP-5587  grouper loader subjob failsafe

Jeffrey Crawford
  12:53 PM
Morning, A bit of a feature request, when we are looking to get more information about a loader job failsafe, and we go to the loader job logs, we can select the “error” checkbox to find that the loader job ran into failsafe, but when we select subjob checkbox to get the list of groups it processed, and then select the “error” checkbox, it doesn’t show the individual groups that hit the failsafe, however, if I look at the timestamp it is listed, just doesn’t show up when the “error” checkbox is select. Would be nice that we select subjobs and error and get the list of groups that ran into the failsafe.
This job manages thousands of Groups so it not easy to just go through them one by one.
