# GRP-6773  Jexl3 can't access public methods of class instance variables

{code:java}
${myUtilClass.myMethod(x)} {code}

Where myUtilClass is an instance variable of a custom class. It has public method myMethod(String var), which was callable in Grouper V5 but returns null in V6. In Grouper V6, the Jexl3 library was upgraded, and a new permissions model was introduced in jexl version 3.3.0 (https://issues.apache.org/jira/browse/JEXL-357). Arbitrary methods are now restricted, but the prior behavior can be restored by adding lenient permissions.

This could potentially impact jexl scripts that call methods outside of the GrouperUtil class in order to perform calculations, and would affected loaders, provisioners, and subject source definitions. If the user has control over the class source code, they can simply make the method static which will be accessible by scripts. But for a general fix so that Grouper restores original functionality, adding lenient permissions to the jexl engine would be the solution.
