# GRP-1225  WS Diagnostic servlet doesn't report patch-level

The grouper status servlet displays the currently running grouper, but no information about installed patches.  Since Grouper doesn't do point releases for patches or security updates, it would be very handy if the status servlet could display the installed patch lists.
