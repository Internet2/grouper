# GRP-7379  Container and installer: bump Tomcat to 9.0.122 for CVE-2026-86350, CVE-2026-76183 and others

The container (v6, v7) and the v4 grouper installer pinned TOMCAT_VERSION=9.0.121. Tomcat 9.0.122 was released 2026-09-15 as a security release fixing 12 CVEs, all affecting 9.0.121 and earlier.

Important: CVE-2026-86350 (regression in the fix for CVE-2026-41293 can trigger request header mix-up), CVE-2026-76183 (bypass of security constraints for WebSocket endpoints), CVE-2026-77791 (DoS via busy wait during WebSocket close), CVE-2026-78383 (AJP DoS via missing request body).

Moderate: CVE-2026-79677 (WebSocket DoS due to lost async write timeout), CVE-2026-86248 (incomplete fix for CVE-2026-34500, OCSP checks can soft-fail with FFM), CVE-2026-73581 (OpenSSL TLS implementations ignore CRLs when certificate uses a keystore).

Low: CVE-2026-87022 (WebSocket message smuggling with per-message-deflate), CVE-2026-78437 (HTTP/2 DoS via malformed request), CVE-2026-77762 (stale HPACK emitter injects trailers into recycled request), CVE-2026-77756 (Transfer-Encoding honored for HTTP/1.0), CVE-2026-75973 (cross-context authentication mix-up with Jakarta Authentication).

The header mix-up applies to every deployment. AJP is off by default in the container (GROUPER_TOMCAT_AJP_PORT=-1) so CVE-2026-78383 only affects sites that enable AJP. Grouper does not use WebSockets but the support is loaded in the default Tomcat install.

This is a one line change: ARG TOMCAT_VERSION in the v6 and v7 container Dockerfile, and TOMCAT_VERSION in GrouperInstaller.java for v4. No configuration work is needed. The entire conf directory (server.xml, web.xml, context.xml, tomcat-users.xml, logging.properties, catalina.properties) is byte identical between 9.0.121 and 9.0.122, server.xml.original still matches the stock 9.0.122 server.xml exactly, and server.xml.grouper.patch applies cleanly to the stock 9.0.122 server.xml producing server.xml.grouper exactly.

The apache-tomcat-9.0.122.tar.gz tarball needs to be staged on software.internet2.edu under grouper/downloads/tools, which is where the build fetches it from.
