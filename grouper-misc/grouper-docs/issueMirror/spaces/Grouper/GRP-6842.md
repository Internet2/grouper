# GRP-6842  TrueFoundry provisioner: read role memberships from subjects endpoint rolesWithResource

The TrueFoundry provisioner previously had no way to retrieve existing role assignments during a full sync (Retrieve All). Added parsing of the {{rolesWithResource}} array returned for each user by the subjects endpoint ({{{}GET /api/svc/v1/subjects{}}}). Each entry's {{roleId}} is cross-referenced against the role list to resolve the role group. This enables the provisioner to detect and reconcile role membership drift. Tests and documentation updated.
