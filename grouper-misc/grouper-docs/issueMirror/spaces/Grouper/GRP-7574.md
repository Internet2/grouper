# GRP-7574  Security: Link operations and delegated privileges

Security fixes from the 2026 Grouper security review, category C. Each line is one fix, its severity, and the public advisory it belongs to:

- Legacy type assignments need the type's edit right (low, advisory M2)
- Role inheritance changes need ADMIN on both roles (medium, advisory M2)
- WS attribute def action changes need ATTR_ADMIN (medium, advisory M2)
- WS attribute name creation needs ATTR_ADMIN (medium, advisory M2)
- Include/exclude group renames need ADMIN on the group family (medium, advisory M3)
- Attribute def delete needs ATTR_ADMIN (medium, advisory M2)
- Folder copy can require privileges on child objects (opt-in setting) (low, advisory M3)

Fixed in 7.9.1 (GROUPER_7_9_0-branch). The same fixes were provided as security patches for earlier releases. See the security announcement for details and required steps.
