# GRP-7528  MCP tool to show who am I: the logged-in subject, MCP access groups, and granted scopes

Add a read-only MCP tool, e.g. entity_whoami, that tells the AI client who is logged in and what this login can do. Today there is no tool for this, so a prompt like: who am I logged in to Grouper as, and what can I do? has no good answer.

The tool should return:
- The logged-in subject: source id, subject id, identifier, and name
- Which etc:mcp access groups the subject is in (readonly, readwrite, admin readonly, admin readwrite, SQL readonly, limited admin, LDAP limited access groups)
- The scopes granted on this OAuth token: read-only, read-write and its folder/group/subject limits, SQL read-only, admin read-only, admin read-write
- Whether the subject is a Grouper sysadmin
- Which tools are available with this token

This helps people check their MCP connection and troubleshoot scopes. It came up in the TechEx 2026 Grouper MCP/AI training, where new users wanted to confirm who they were connected as after signing in or re-authenticating.

Include tests, servlet registration, the tool name constant, and the MCP wiki documentation.
