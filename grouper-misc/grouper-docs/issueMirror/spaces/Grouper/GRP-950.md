## Comments

### langedb - 2014-01-17T21:49:06.730+0000

This is happening because psp-grouper-ldap/src/main/java/edu/internet2/middleware/psp/shibboleth/LdapDnFromGrouperNamePSOIdentifierAttributeDefinition.java

lines 218 - 222 cause the baseStem name to be stripped out of the DN with a starsWith() / replaceFirst().  The reason it's biting Bryan Wooten is because he has a similarly named base-stem candidate uofu-ref which happens to start with the same baseStem of uofu.  Suggested first plan for handing this would be to change the match to an equals() rather than a startsWith().
