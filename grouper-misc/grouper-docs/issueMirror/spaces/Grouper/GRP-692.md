### mchyzer - 2011-11-08T21:12:31.044+0000

This is done in a new transaction and in a new thread, and without the hibernate version.

If there is a failure it will be logged but will not affect any processing.

If two processes update at the same time, it will work, and the changes will overwrite the same data, no problem.
