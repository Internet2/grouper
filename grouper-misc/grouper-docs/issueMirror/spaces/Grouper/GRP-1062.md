### mchyzer - 2014-10-16T00:33:26.407+0000

https://github.com/Internet2/grouper/commit/b58807f3bd1213c5eb232bca04d0323046e0d2d6

The interface 

edu.internet2.middleware.grouperClient.encryption.GcEncryptionInterface

Can be used for various types of encryption.  The one that is implemented is:

edu.internet2.middleware.grouperClient.encryption.GcSymmetricEncryptAesCbcPkcs5Padding

This needs to take in a base64 128 bit key which can be generated from:

edu.internet2.middleware.grouperClient.encryption.GcGenerateKey

The encryption will use an initialization vector and base64 encode the results.  Here is an example (do not reuse this secret):

From the main in the encryption implementation class:

Key is: 8Irso9KJPpe4RFTtHx+S2w==
xyz encrypted: /wFCJFB0pNO3GLg0LQicnzajhtyZm5YQu5cdrM1hEXU=
Clear (should be xyz): xyz
xyz encrypted (should be different with different initialization vector): vlAVpqRCa7m4tC++qTdQg0j11fCJ1eZc0JDSGN2QYBk=
Clear (should be xyz): xyz
