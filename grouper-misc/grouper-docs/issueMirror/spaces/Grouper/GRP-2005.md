# GRP-2005  Allow receiving messages from topics as well

There is a check in GrouperMessagingEngine#receive method that does not allow to receive messages from topics. I believe it was added when there was the builtin messaging engine only. RabbitMq and ActiveMq allow reading from topics, so we should move the check to individual implementations.
