# GRP-7366  grouper-wiki-edit skill: embed only raster diagrams, do not attach or reference SVG source

Clarify the diagram guidance in the grouper-wiki-edit skill. Confluence Cloud does not render SVG inline, so the skill should tell the author to convert any locally authored SVG to PNG or JPG and attach and embed only the raster.

Previously the skill said to attach both the SVG source and the raster (matching names). That leaves an SVG source on the page that does not render and adds confusion. New guidance: do not attach the .svg and do not reference an SVG source on the page. The draw.io alternative (attach its .drawio/.xml source) is unchanged.
