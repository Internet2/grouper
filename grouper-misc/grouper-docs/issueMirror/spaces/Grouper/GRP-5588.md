## Comments

### Chris Hyzer - 2024-09-11T06:06:11.443+0000

Set this variable in the WS container:

GROUPERWS_URL_WITH_CONTEXT_NOSLASH

Example value: https://myws.inst.edu/grouper-ws
Substitute the WS url in the swagger file so the URLs are correct.  
Note, this is only used in the WS container where the docs are.
This must have the http or https, domain, port (optional), and the context (e.g. grouper-ws) and no slash at end
Note the GROUPERWS_URL_CONTEXT is used to substitute in swagger too

Test swagger after build: https://myws.inst.edu/grouper-ws/docs
