# GRP-6925  MCP oauth-protected-resource well-known endpoint returns localhost URL when behind a reverse proxy

* {{/grouper-ws/.well-known/oauth-protected-resource}} built its URL from {{{}request.getScheme()/getServerName()/getServerPort(){}}}, so sites with a reverse proxy in front of Tomcat got {{localhost:<internal-port>}} in the {{resource}} and {{authorization_servers}} fields
 * {{GrouperMcpWellKnownServlet}} already prefers {{GrouperConfig.getGrouperWsUrl(false)}} with a request-based fallback; {{GrouperMcpProtectedResourceServlet}} was not updated to match
 * Fix: use {{GrouperConfig.getGrouperWsUrl(false)}} first, fall back to the request-derived URL, mirroring the WellKnown servlet
