# GRP-5606  if provisioner cannot do a group sync (e.g. only syncing users), then incremental changes over 500 users will get skipped until the next full sync.

Workaround is to set the setting in provisioner configuration advanced "Memberships convert to group sync threshold" to a high number (e.g. 20k) temporarily until you upgrade
