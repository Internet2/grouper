# GRP-542  grouper client encrypts passwords differently than grouper API

Grouper client takes the encrypt secret and does something different than the API, which makes running the client inside the server (for group sync) a little confusing.

## Comments

### mchyzer - 2011-01-17T08:16:07.189+0000

If you do nothing but upgrade, you will get the old behavior.  If you sync this over int he grouper.client.properties, then you will get the new behavior.  All new downloads of the client and config get the new behavior:

# pre grouper 2.0, the client encrypted passwords differently than the server.  Now that the client is part of the server,
# there are more reasons to be consistent.  Change to false for pre-2.0 password encryption behavior
encrypt.encryptLikeServer = true
