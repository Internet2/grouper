# GRP-7577  Security: Authentication and admission (WS OAuth, JWT, OIDC, act-as, cross-site requests)

Security fixes from the 2026 Grouper security review, category F. Each line is one fix, its severity, and the public advisory it belongs to:

- WS OAuth tokens checked for audience and issuer (high, advisory H7)
- External UI path limited to self-registration screens (medium, advisory H7)
- WS header act-as checks the caller's WS access (low, advisory H7)
- VOOT applies the WS client group (low, advisory H7)
- ESB HTTP listener requires authentication (high, advisory H8)
- Trusted JWT subject source claim limited to configured sources (low, advisory H7)
- UI actions cannot run from a link (critical, advisory C1)
- Require and lockout group allowedToUse settings honored (medium, advisory M3)
- WS changes cannot be sent with HTTP GET (low, advisory C1)
- UI OIDC route matching independent of URL encoding (medium, advisory H7)
- Disabled local entities lose WS JWT access (low, advisory H7)
- UI OIDC callback tied to the login session (medium, advisory C1)
- GSH template act-as cannot target sysadmins (high, advisory H4)
- Basic authentication honors credential expiration and allowed networks (medium, advisory H7)
- Configuration screens opened from a link do not evaluate expressions (critical, advisory C1)
- WS LDAP authentication refuses blank passwords and escapes the login name (high, advisory H7)
- UI OIDC logins bound to the connector and its subject sources (medium, advisory H7)
- UI pages refuse framing by other sites (medium, advisory C1)

Fixed in 7.9.1 (GROUPER_7_9_0-branch). The same fixes were provided as security patches for earlier releases. See the security announcement for details and required steps.
