# GRP-841  multivalued subject attributes do not display correctly in UI

Hello,

in order to help group updaters to distinguish between homonyms,
the sources.xml has been configured to obtain a few attributes that
are displayed when requesting the "Entity details" (Admin UI)
or "Member details" (Lite UI).
If such an attribute is multi-valued it is not displayed correctly:
E.g. if attribute employeeType has values student and staff, it is displayed
without separator in the Admin UI:

   employeeType   studentstaff

and in the Lite UI, only one value is displayed:

   employeeType   student

This happens both with Grouper 1.6.1 and 2.1.1 (using LdapSourceAdapter).

- Is there a way to fix this in the configuration? E.g. it would
be convenient to display the values on multiple lines:

   employeeType   student
                  staff


Thanks in advance for your replies!
