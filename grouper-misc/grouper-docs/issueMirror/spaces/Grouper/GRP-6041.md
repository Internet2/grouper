# GRP-6041  With GROUPER_TOMCAT_LOG_ACCESS set, tomcat should log to logpipe, not a file in /opt/grouper/logs

With GROUPER_TOMCAT_LOG_ACCESS set, Grouper startup adds the following to server.xml
{code}<Valve className="org.apache.catalina.valves.AccessLogValve" requestAttributesEnabled="true" directory="/opt/grouper/logs" prefix="tomcat_access_log" rotatable="false" pattern="%h %l %u %t &quot;%r&quot; %s %b" />
{code}
This creates a file in the container /opt/grouper/logs/tomcat_access_log. However, if you don't have access to the container, and are logging everything else to pipes, having it in a file isn't useful.

I haven't tried this yet, but it might work:
{code}<Valve className="org.apache.catalina.valves.AccessLogValve"
       directory="/tmp"
       prefix="logpipe"
       suffix=""
       pattern="%h %l %u %t &quot;%r&quot; %s %b"
       rotatable="false" />
{code}
