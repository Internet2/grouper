# GRP-1906  What PSPNG needs before it officially replaces PSP

This JIRA is here to capture references to other Jiras that are necessary for PSPNG to completely replace PSP.

 

From the Grouper-Users mailing list:

TL;DR: What does PSPNG need so that PSP is not necessary in Grouper 2.4?

 

The longer form...

We know that PSPNG was designed and written to be less flexible than PSP, but that it should grow to handle the necessary use cases and replace PSP over time[[wiki|https://spaces.at.internet2.edu/display/Grouper/Post+PSP+Provisioning]]. I know we're not there right now, but that we're pretty close.

 

The purpose of this email is to identify what needs to change in PSPNG and see if we can make Grouper 2.4's PSPNG ready so that PSP doesn't have to be included/supported in 2.4. Yes, this conversation should have happened earlier, but it's better late than never.

 

So... If you're using the old PSP...

 

What features do you use within PSP that are missing in PSPNG?

What bugs does PSPNG have that keep you from migrating to it from PSP?

What is your timeline for upgrading to Grouper 2.4?
