# GRP-7281  GitHub provisioner: provision organization teams and memberships from Grouper

New membership-driven provisioner mapping Grouper folders to GitHub organizations, groups to organization teams, and group members to team members, with org membership as a derived prerequisite. Uses the GitHub REST API for teams, members, and invitations, plus the GraphQL enterprise external-identities map to resolve Grouper subjects to GitHub logins by SAML nameId.

v1 is membership-driven: teams pre-exist, memberships are added via team-add (which invites a known login to the org as the derived prerequisite), and entity delete is a full org deprovision. Includes model classes, API commands, target DAO, two config classes, a mock service handler, sync-back native reporting, and 24 JUnit tests. Generic and config-driven: managed orgs, enterprise slug, and ignore lists are all configuration; nothing is institution-specific.
