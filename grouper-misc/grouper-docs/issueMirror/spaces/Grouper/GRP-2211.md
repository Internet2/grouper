# GRP-2211  PSPNG - CacheSize=0: Should not enable unlimited caching

EhCache (underneath GrouperCache) changed size=0 to mean unlimited at some point. Therefore, pspng needs to map size=0 to size=1 to best respect the user's intentions of minimizing memory.  This also means that the cache-size warnings need to be disabled when size=1.
