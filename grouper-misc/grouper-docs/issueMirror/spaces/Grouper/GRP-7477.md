# GRP-7477  MCP recipe add and edit screens show the config id one column to the right of the other fields

On the MCP recipe add and edit screens, the config id field and its help text sit one column to the right of every other field.



The config id row is written by hand in the JSP with three cells: the label, an empty spacer, and the value. The spacer lines up with the expression language checkbox column of the other config screens. GRP-7385 hid that column on the recipe screens (shouldShowElCheckbox false), so the other rows now have two cells, label and value, but the config id row kept its spacer.



Fix: mcpRecipeAdd.jsp and mcpRecipeEdit.jsp drop the spacer cell from the config id row, and the section headings span 2 columns instead of 3. Display only, no behavior change.
