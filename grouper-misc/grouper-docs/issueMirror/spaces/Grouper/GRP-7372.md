# GRP-7372  Limit appearance of stacktraces in pac4j login failures

See: [CWE-209: Generation of Error Message Containing Sensitive Information|https://cwe.mitre.org/data/definitions/209.html]

Pac4j exceptions should be caught and logged, but only present simple error messages for users.

## Comments

### Chad Redman - 2026-09-29T16:23:55.796-0400

There is a new text property, {{externalAuthenticationLoginFailed}}, where you can configure the custom user message. It can optionally include the exception message, but it no longer includes the stacktrace. The stacktrace still shows up in the log.
