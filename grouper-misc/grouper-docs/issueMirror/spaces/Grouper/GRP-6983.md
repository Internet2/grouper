# GRP-6983  Generic provisioner sync-back framework and per-protocol capture wiring

* Adds the strict-native sync-back framework that records the most recent target-side state for every provisioned object into {{grouper_prov_user}} / {{grouper_prov_group}} / {{grouper_prov_mship}} (plus per-provisioner attribute catalogs and values). Captures happen on the read path of any DAO that declares {{{}canSyncBack=true{}}}; no extra API calls.
 * Enabled per-provisioner via {{loadEntitiesToGenericGrouperTable}} / {{loadGroupsToGenericGrouperTable}} / {{{}loadMembershipsToGenericGrouperTable{}}}.
 * New {{*ProvisioningTargetNativeSync}} class and DAO capture hooks wired up across all 13 protocols: Adobe, Azure, Box, Datadog, Duo, FreshRequester, Google, LDAP, Okta, Remedy, SCIM, TeamDynamix, TrueFoundry.
