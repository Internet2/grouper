# GRP-2141  Admin notifications of important changes to a group ( Permissions, maybe memberships too? )

Origin of the idea:

Maybe when "a subject no longer exists and a privilege is removed" then the Admins of the affected objects (groups, attrDefs,folders) should be told that "Elvis has left the building". They may have "new work" to start to find a new Elvis, or not. That would be hard for the system to decide, but easy to notify under those conditions. ( And hard for the Admins to "see" after the fact too. )

 

 

Other kinds of "monitoring/notifications" could be helpful for "workflow" / "Audit"  / "awareness" kinds of activity from Grouper.

 

Some groups Admins might want to notify an arbitrary email address, or the Admin , and/or the Update privileged users when:

   Membership changes

   Privileges are changed.

   The group is added/removed from other groups.

  The group is granted privileges to other objects ( grouips, folders, attributeDef's, etc...)

  Other details??
