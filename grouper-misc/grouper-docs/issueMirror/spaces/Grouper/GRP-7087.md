# GRP-7087  Accessibility: missing or uninformative page title (all pages but e.g. new datafield)

Added accessible page titles across ~108 Grouper UI pages using the {{grouper:title}} / {{grouper:titleFromKeyAndText}} tag, so screen readers announce a meaningful, unique title on each page (previously many pages had a missing or generic title).

While editing {{{}attributeDefEdit.jsp{}}}, also added {{{}aria-label{}}}s to the "assign to" checkboxes on the attribute-definition edit page so those controls are announced correctly.

Low-risk: almost entirely one added line per page, no logic changes. Resolves a large batch of the page-title accessibility findings.
