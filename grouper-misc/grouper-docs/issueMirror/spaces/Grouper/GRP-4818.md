# GRP-4818  allow source IP address filtering on tomcat ports

The server.xml has this in the host part


{code:java}
        <!--GROUPER_REMOTE_CIDR_VALVE--> {code}
If you pass this env var to the container
{code:java}
-e GROUPER_TOMCAT_REMOTE_CIDR_VALVE_ALLOW='1.2.3.4/32' {code}
Then the server.xml will have
{code:java}
<Valve className="org.apache.catalina.valves.RemoteCIDRValve" allow="1.2.3.4/32"/> {code}
