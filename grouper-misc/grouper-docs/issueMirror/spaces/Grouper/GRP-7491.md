# GRP-7491  SCIMv2 with Google cloudidentityscim returns "resources" array

Interacting with [{color:#ffffff}https://cloudidentityscim.googleapis.com/v1/customers{color}|https://cloudidentityscim.googleapis.com/v1/customers] Users and Groups endpoints return the “resources” array instead of “Resources” array and Grouper says it can’t find any objects.

## Comments

### Chris Hyzer - 2026-10-15T15:55:36.903-0400

Fixed. SCIM attribute names are case insensitive (RFC 7643 section 2.1), so a lowercase resources array in a ListResponse is valid. GrouperScim2ApiCommands now canonicalizes top level response field names right after parsing (resources becomes Resources), so the existing lookups find the array. Other field names can be added to the canonical name map if more servers vary the case.
