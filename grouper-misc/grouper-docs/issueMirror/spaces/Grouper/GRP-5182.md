# GRP-5182  External system for WS basic auth, including username

The external system configs are useful for storing and getting connection properties like the base URL and password for REST clients. The WS Bearer Token external system has a UI field for client secret, but nothing for username.

If the Bearer Token external system had an optional username, or if a similar WS client external system were created, this would be more useful for REST clients that used basic auth.
