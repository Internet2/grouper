# GRP-6874  JEXL scripted group analysis should warn about unresolvable or deleted subjects matching the script

When analyzing a JEXL scripted group in the UI, the population count query filters out subjects that are unresolvable or deleted (subject_resolution_resolvable = 'F' or subject_resolution_deleted = 'T'). This means an admin has no visibility into subjects that match the script but are being silently excluded.

Added a check in the analysis screen that runs the overall JEXL script query against unresolvable/deleted members. If any are found, a warning is displayed at the top of the screen showing the count and up to 10 example subject IDs (e.g. "There are 3 unresolvable or deleted entities matching this script, first 3: jsmith, rjones, mbrown").
