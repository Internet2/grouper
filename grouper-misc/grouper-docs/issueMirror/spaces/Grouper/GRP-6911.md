# GRP-6911  TrueFoundry provisioner: team managers not provisioned correctly

On first full provision, team managers are not set because the entity attribute cache ({{{}entityAttributeValueCache0{}}}) is not yet populated at translation time. Added a fallback that resolves manager entity IDs from the in-memory entity wrappers using the email field when the cache returns empty. Also updated test group names to use kebab-case to match TrueFoundry naming conventions, and fixed test settings to explicitly set tenantName/ssoId for SCIM display name updates.
