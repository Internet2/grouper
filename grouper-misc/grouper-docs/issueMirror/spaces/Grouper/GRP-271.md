# GRP-271  Extend repository browser configuration to allow flat mode to be the default

Request from Loris Bennet to be able to have flat mode as default and to turn off the ability to switch to browsing.

## Comments

### Gary Brown - 2009-04-24T14:26:35.514+0000

media.properties supports:

 repository.browser.<browse mode>.flat-is-default=true

to enable default mode to be flat. If set to true and flat-capable set to false then user is 'stuck' with flat mode.

RepositoryBrowser and AbstractRepositoryBrowser modified to read property and make a public method isFlatDefault available. flatten.jsp modified to enforce isFlatCapable. LowLevelGrouperCapableAction updated 'processFlatForMode' method to ensure default is used when none has been set
