# GRP-5600  When filtering visualization by member ID and limiting sibling objects, ensure their group is included

When using a member ID to highlight groups in visualization, if sibling objects is truncated, the sibling group the member is in may not show up. If the member is in one of the sibling groups, make sure it's among the included ones and not excluded.
