# GRP-7537  Report config UI: choose GSH script or compiled report template, and validate the template id and script length

The report config add and edit screens showed the GSH script textarea and the compiled template config id (GRP-7031) side by side, with the template id optional and silently winning over the script.

Add a GSH source dropdown (GSH script entered here, or compiled GSH report template) that shows only the field for the chosen source and clears the other on save. Validate that the chosen field is filled in, that a compiled template config id refers to a grouperGshTemplate with templateType=report and templateMode=compiled, and that an interpreted script is 4000 characters or less (longer scripts failed with a database error on save).
