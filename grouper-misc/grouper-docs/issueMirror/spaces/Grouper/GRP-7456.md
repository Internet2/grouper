# GRP-7456  Publish stub -javadoc.jar to Maven Central (point to source) to reduce release size

Maven Central now enforces a monthly Release Size limit (80 MB/month for Internet2). The -javadoc.jar artifacts are about 32 MB of a roughly 66 MB release (grouper core javadoc alone is 21 MB).

Central requires a javadoc jar per artifact but does not validate its contents. Developers get javadoc from the git source or from the -sources.jar (Eclipse/IntelliJ build hover docs from it), so the full javadoc jar is not needed on Central.

Change: the release profile no longer runs maven-javadoc-plugin. Instead it attaches a small stub -javadoc.jar (README.txt and index.html) pointing to the source on GitHub at the GROUPER_RELEASE_<version> tag and to the -sources.jar. Release size drops to about 34 MB. Downside: new versions on javadoc.io will show the stub (older versions keep their real javadoc). Release builds are also faster since javadoc is not generated.
