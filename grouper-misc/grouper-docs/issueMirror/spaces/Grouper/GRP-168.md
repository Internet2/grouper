# GRP-168  Circular Memberships Cause Incorrect Effective Memberships

If Group A is a direct member of Group B and B is a direct member of A and A's membership is added last, then A will have one effective membership, but B will have two....

## Comments

### shilen - 2008-09-17T16:44:47.501+0000

The solution should be that A should not be a member of A and B should not be a member of B.

### shilen - 2008-10-09T13:54:04.141+0000

The issue described in the description has been resolved.

However, we can still create circular membership paths that don't behave consistently when composites are involved.  The issue arises when you have a membership path between a composite factor and the composite group.

### shilen - 2008-11-02T21:37:37.697+0000

We decided on the 10/29 conference call that we're not allowing membership paths between a composite factor and a composite group as shown in the attached image.
