# GRP-7181  Add CCure external system and provisioner

Contribution from Michigan and Unicon. A membership-only provisioner for clearance pairs – combinations of Clearances and Personnel. This will be an MVP, in which a subject identifier is in the Int1 field of personnel. If users need subject ids from other Personnel fields, the source code can be modified to support it.

Due to [https://todos.grouper.internet2.edu/browse/GRP-6193|https://todos.grouper.internet2.edu/browse/GRP-6193|smart-link] which is currently open, sessions will eventually call the logout function when the external system runs finalize(), but this is not deterministic and depends on GC. Ideally the provisioner should call close() to explicitly clean up any resources it uses.
