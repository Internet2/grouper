# GRP-2710  LDAP authentication failures return 400 instead of 401

_(no description)_

## Comments

### Chad Redman  (unc.edu) - 2020-08-24T23:17:14.039+0000

With the property ws.security.non-rampart.error.401.authentication.error left as the default true, this also causes two calls to authentication -- the first to check if it needs to send a 401, and the second a normal authentcation in WS. If there is caching of credentials, (e.g. the Kerberos auth class), it's not a performance hit, but it will log an extra "Retrieved cached login" at debug level for every WS request, even for fresh authentications.
