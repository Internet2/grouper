# GRP-2600  daemon jobs can stop and not restart

[Jeffrey F Williams|https://app.slack.com/team/UDHELDNF2]  [12 hours ago|https://internet2.slack.com/archives/C7V0UQDJ4/p1582168058132800?thread_ts=1582116040.120400&cid=C7V0UQDJ4]
Thanks to [@mchyzer|https://internet2.slack.com/team/U2ZF1FB36] and [@Shilen Patel|https://internet2.slack.com/team/UEG798FT6] for the assist. I was able to get the CLC's running again without having to bring everything down: # stop all daemon containers.
 # In a SQL app of your choosing, connect to grouperdb and do the following:
 # UPDATE GROUPER_QZ_TRIGGERS SET TRIGGER_STATE = 'WAITING';
 # DELETE FROM GROUPER_QZ_FIRED_TRIGGERS;
 # restart daemon containers and wait for logs to start generating again.

It took a couple of hours to catch up on a few days of changes, but it seems to be back to normal. Thanks again, guys!
