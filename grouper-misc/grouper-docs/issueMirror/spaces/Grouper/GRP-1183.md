# GRP-1183  status servlet gives error if loader job is not configured correctly

Error in status: java.lang.RuntimeException: Cant find GrouperLoaderType from string: '', expecting one of: SQL_SIMPLE, MAINTENANCE

One of your loader jobs is not properly configured... see which groups have the loader attribute, see the attributes for those jobs, and see which one is missing a type :)  Yes, should be easier to track down...
