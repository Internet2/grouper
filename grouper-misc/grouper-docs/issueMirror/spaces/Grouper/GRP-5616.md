# GRP-5616  In loaders, allow sql query to be > 4000 char

From Tushar Walaskar:

I understand the query limit for grouper loaders currently is 4000 characters because of Oracle compatibility. But since we are  using postgres as the database for grouper, would it be possible to increase 4000 character limit to something larger?

## Comments

### Carey Black - 2024-08-08T20:43:48.301+0000

REF: https://todos.internet2.edu/browse/GRP-4532  "allow sql loader queries to be brought in by config or other way"

### Chris Hyzer - 2024-08-18T19:56:09.441+0000

If you have a large query (e.g. over ~4k characters), configure a property in grouper-loader.properties (e.g. from the UI) where the key is arbitrary (e.g. loaderSqlQueryFor_testLoader2) and the value is the query. Then configure this value to be an EL script, e.g. ${edu.internet2.middleware.grouper.app.loader.GrouperLoaderConfig.retrieveConfig().propertyValueString("loaderSqlQueryFor_testLoader2")}
