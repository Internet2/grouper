# GRP-1345  PSPNG-Group-attribute updates

From [grouper-users, July 2016|https://lists.internet2.edu/sympa/arc/grouper-users/2016-07/msg00036.html].

Changes to non-membership attributes of groups are correctly defined when groups need to be created, but are not updated when data is changed in Grouper. For example, when the description attribute of an ldap group should be updated when the group's description is changed in grouper. 

bq. changeLog.consumer.pspng_groupOfNames.groupCreationLdifTemplate = dn: ${utils.bushyDn(group.name, "cn", "ou")}||objectclass: groupOfNames||description: ${group.description}


Note, this ticket is limited to mirroring changes outside of the LDAP DN. Updating Group DNs will be a part GRP-1346.
