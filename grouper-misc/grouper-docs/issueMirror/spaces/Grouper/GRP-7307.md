# GRP-7307  UI accessibility: convert dropdown-toggle anchors to native buttons

Follow-on to the fake-button-anchor work (GRP-7306). The dropdown TRIGGERS (the more-actions gear menus and other menus) are still a href=# data-toggle=dropdown role=button anchors. They open an in-page menu, so per accessibility item 5 they should be native button type=button. They are already styled with class btn ... dropdown-toggle and carry aria-haspopup/aria-expanded (and aria-controls where added in GRP-7301), so converting a-tag to button is visually and behaviorally neutral (bootstrap dropdown JS binds to data-toggle on a button too); href=# and the now-redundant role=button are dropped.
