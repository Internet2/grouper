### mchyzer - 2016-08-24T19:02:14.754+0000

proposed change:

Defaults in grouper.hibernate.base.properties will address this.

FROM:
hibernate.c3p0.max_size = 16
hibernate.c3p0.acquireRetryAttempts=2
hibernate.c3p0.acquireRetryDelay=500
hibernate.c3p0.checkoutTimeout=30000

TO:
hibernate.c3p0.max_size = 100
hibernate.c3p0.acquireRetryAttempts=5
hibernate.c3p0.acquireRetryDelay=2000
hibernate.c3p0.checkoutTimeout=180000

Thanks
Chris


### mchyzer - 2016-08-24T22:51:14.566+0000

these connections were not pooled in the past.  Now they are by default.  If there is a problem you can turn off pooling with this param:

#if the db connections should be pooled (this is new as of 2.3.0.patch)
grouperLoader.db.connections.pool = true

You can set pooling per connection like this (note "warehouse" is the db config name), or you can inherit from the grouper.hibernate(.base).properties:
 
##optional pooling params, these will default to the grouper.hibernate(.base).properties pooling settings
#db.warehouse.c3p0.max_size = 100
#db.warehouse.c3p0.min_size = 0
##seconds
#db.warehouse.c3p0.timeout = 100
#db.warehouse.c3p0.max_statements = 0
#db.warehouse.c3p0.idle_test_period = 100
#db.warehouse.c3p0.acquire_increment = 1
#db.warehouse.c3p0.validate = false
