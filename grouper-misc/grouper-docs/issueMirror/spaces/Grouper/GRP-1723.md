# GRP-1723  Restore directory grouper/ext/lib

In a commit from a few months ago, the file grouper/ext/lib/temp.txt was removed with the assumption that it wasn't used. However, Git doesn't create empty directories, so the directory is effectively removed on a fresh clone. This breaks the ant build of grouper which expects the directory to be there.
