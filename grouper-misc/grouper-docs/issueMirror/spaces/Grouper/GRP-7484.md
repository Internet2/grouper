# GRP-7484  MCP recipe tool description ends with a double period when the last recipe summary is a full sentence

GrouperMcpRecipeTool builds the recipe tool description by listing each recipe’s summary and then always adding a period. Recipe summaries are encouraged to be full sentences, so when the last one already ends in sentence punctuation, the description the MCP client reads ends in a double period (e.g. “per product..”). The fix only adds the closing period when the last character isn’t already a period, question mark or exclamation point.
