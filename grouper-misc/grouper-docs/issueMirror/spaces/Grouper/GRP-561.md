# GRP-561  restrict search on UI to sources that allowed to be searched by rules

_(no description)_

## Comments

### mchyzer - 2011-02-15T19:26:23.443+0000

If you are on the admin or lite UI, and you are searching for a user to add to a group or privilege, then only sources (if not specified explicitly) that are applicable based on folder restrict rules will show results.  We would like to change this for the final 2.0 so that it is at a group level and not a subject source level, i.e. if there is a group of people that are allowed to be assigned, they will show up in the search results.  Note that in the admin UI, the browsing for a result is not affected.
