# GRP-1337  Use a separate directory to download Grouper artifacts during install

Grouper always downloads artifacts, when doing a live install, into the current directory. This pollutes the configuration quite a bit. Define a separate directory instead that is used for downloads only; This shall include not only grouper's core artifacts, but also zipped archives of ant, tomcat, etc.
