# GRP-7045  v6 Group Summary tab should show "needs refreshed" indicator after 'Add members' (and maybe other features) are used that make the summary 'stale' ( Maybe include a "refresh button' on the Summary UI? )

The user can take actions that alter the state of the summary information and make it "invalid".
It is not auto updated.
The user should be able to know when it is invalid/outdated and be able to easily ask the system to recalculate/correct the displayed summary.
