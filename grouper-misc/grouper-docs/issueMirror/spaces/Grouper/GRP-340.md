# GRP-340  Would like to be able to provision the group read and view privs of a group to the directory

We would like to be able to provision the group read and view privs of a group to the directory. For example, we have created the "cornelledugroupreadpriv" attribute in our groups branch, and would like to have the ldappc provision subjects with that priv to it.  Currently we are doing this on our own.  The "cornelledugroupreadpriv" attribute is used to build aci's for access to the group membership information.
