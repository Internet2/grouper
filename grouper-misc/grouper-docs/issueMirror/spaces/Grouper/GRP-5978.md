# GRP-5978  Provisioner "Debug log" option doesn't do much besides log memory usage

In provisioners there are a few options for showing debugging. The first in the list is "Debug log", which doesn't have an explanation of what it is logging. In fact, all it does is add some memory diagnostics to the output map. Maybe it can be renamed, or add or description to the information?
