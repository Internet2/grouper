# GRP-4127  Remove old copies of UI images

For Grouper 2.0.0, images locations were changed from grouper/images to grouperExternal/public/assets/images. The configuration was changed (04eecb88, 5924b75c) and the files were added to the corresponding directories, but were not removed from the old locations. There shouldn't be any references to the old paths (but test to make sure). Removing these extra copies will make it less confusing for deployers who want to replace those files and don't know which one is in use.

 
 - ./grouper-ui/webapp/grouper/images/organisation-logo.gif
 - ./grouper-ui/webapp/grouper/images/grouper.gif
 - ./grouper-ui/webapp/grouper/images/infodot.gif

 

There are other cases of images that are unused or are only used in the legacy Lite or Admin UI. In the case of legacy UI usage, those images should be moved to grouper-misc/grouper-legacy-ui
