# GRP-7145  Add shared AI skills folder to grouper-docs (grouper-wiki-edit skill)

Add a version-controlled "skills" folder to grouper-docs so AI skills can be committed in git and shared among Grouper developers, instead of each person keeping a private copy or copy/pasting a snapshot out of the wiki.

Added:
- grouper-misc/grouper-docs/skills/README.md - what an AI skill is, how to install one (symlink into ~/.claude/skills/), and the no-credentials-in-git rule.
- grouper-misc/grouper-docs/skills/grouper-wiki-edit/SKILL.md - the grouper-wiki-edit skill (read via MCP, write only via Confluence REST API with a token, keep the Navigation include first, follow the living style guide).

Also updated the wiki page "Using AI to edit the Grouper wiki" to point at this git folder as the canonical, maintained source, keeping the inline block only as a convenience snapshot.
