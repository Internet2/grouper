# GRP-7493  Dropbox provisioner: add persistentId entity attribute for SAML SSO account matching

Dropbox teams that use SAML SSO with persistent ID matching link each member to the value of a configured SAML attribute (for example eduPersonPrincipalName). The stored value is written with member_persistent_id on members/add_v2 and new_persistent_id on members/set_profile, and is read back as profile.persistent_id. Dropbox requires every member to have a unique persistent ID, and they must all be reset when the team changes IdP issuer.

The Dropbox provisioner has no way to set it today: DropboxUser only sends a fixed set of fields and persistentId is not in the entity attribute list.

Add a persistentId entity attribute: read persistent_id from the member profile, send member_persistent_id on create and new_persistent_id on update, add it to the targetEntityAttribute option list in grouper-loader.base.properties, support it in the Dropbox mock service, and cover it in the provisioner test. It can then be configured with a translation (for example the subject ePPN), and identifier renames become normal attribute updates.
