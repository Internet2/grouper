# GRP-7504  Upgrade netty to 4.2.19.Final via netty-bom in grouper-parent (security)

A jar scan of the 7.8.0 container image found netty to be the only vulnerable library family. Three netty versions were bundled: 4.1.72 (via qpid), 4.1.135 (via ldaptive) and 4.2.18 (via amqp-client).

netty 4.1.72 has 7 HIGH advisories. They are mostly server-side, and Grouper uses netty only as a client, so actual exposure was low.

Fix: grouper-parent now imports netty-bom 4.2.19.Final so all netty dependencies resolve to one patched version. qpid JMS messaging should be smoke tested against the upgraded netty.

No other vulnerable dependencies were found. There is no Tomcat update for the container in this release (no applicable Tomcat security issues).
