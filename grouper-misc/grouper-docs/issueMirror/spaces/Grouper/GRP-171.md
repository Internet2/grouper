# GRP-171  Incorrect setting for default.browse.stem gives undescriptive error

Martti Jokipii reported a problem upgrading to 1.3.1 from 1.3.0 - after logging in, the content area showed a jsp error (NullPointerException).

The error was probably due to uncommenting default.browse.stem in build.properties - the default value 'root' would cause the error, though changes to media.properties could also give the same error.

The 'root' value may once have worked - assuming StemFinder.findStemByName recognised 'root', but won't have for some time. 

'default.browse.stem' in build.properties is used to substitute the same key in media.properties, however, the description given there is wrong - or, it appears twice and the first instance is wrong.

I will change build.properties.template to have #default.stem.name=<stem_name> and remove the erroneous description from media.properties. In addition, I will change PrepareRepositoryBrowserAction so that it no longer swallows the StemNotFoundException and ensure a more appropriate log file message
