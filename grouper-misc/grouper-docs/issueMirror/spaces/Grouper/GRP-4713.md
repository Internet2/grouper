# GRP-4713  usdu should fail if max unresolvables is hit

Dan Nygard
  17 hours ago
Is there a way to have the usduDaemon report a failure if the number of unresolvable subjects exceeds the maximum value set in usdu.failsafe.maxUnresolvableSubjects? We're on version 4.1.2, and it currently returns success even if the maximum is exceeded. It would also be good if the Job message in Daemon Logs included a note in these cases.

## Comments

### Shilen Patel - 2023-05-03T14:03:34.558+0000

If the max is reached, the job will end with a status of ERROR with a message in the job message.
