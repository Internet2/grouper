# GRP-2071  Add visualization option for full screen

The visualization SVG output currently starts expanded to full size, often scrolling past the right edge of the browser window. This works but is ugly. The alternative of forcing it to fit in the main content div isn't helpful because the margins are too small to see much.

We should have an option to make this expand to full screen and back. Possibly a lightbox?
