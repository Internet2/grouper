# GRP-7622  Upgrade ant to 1.10.18 for security

The 7.10.0 image ships Apache Ant 1.10.15, which image scanners flag for CVE-2026-78254 (path traversal in the ftp and scp tasks), fixed in 1.10.18. Grouper does not use those tasks, but the jar is bumped so scans are clean.

Change: ant.version 1.10.15 to 1.10.18 in grouper-parent/pom.xml.
