# GRP-4451  daemon job for reports gives error "Error: can't find daemon config for jobName grouper_report_c39b4..."

I've been using reports for a while, so I don't know when this started showing up. After creating a CSV report on a group, going to the daemon jobs page shows an error: 
{code:java}
Error: can't find daemon config for jobName grouper_report_c39b4013cbab41809c9969ca4ef8501a_eb84d81e51ef48609470cf35d35dac06 {code}
The job names in quartz start with "grouper_report_", while the UI builder for the daemon job list is expecting the names to start with MAINTENANCE, CHANGELOG, OTHER_JOB, etc.
