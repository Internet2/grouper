# GRP-6459  SQL Loader should (optionally) create unresolved groups

This is related to this thread - [https://internet2.slack.com/archives/C7V0UQDJ4/p1763583702083419]

 

We're using the incremental SQL loader, and we occasionally get situations where the loader cannot find the group that was referenced, and it complains that it's unresolvable.

```

2025-11-19T15:04:00,758: [pool-3-thread-37036] WARN GrouperLoaderIncrementalJob.processOneSQLRow(822) - [] - Found unresolvable subject: subjectColumn=subject_id_or_identifier, subjectValue=app:mcomm:107-0600-20251119200306472-0462

```

At techex, Hyzer suggested that it wouldn't be unreasonable for grouper to create those groups in this situation.  Maybe a configurable option?   We're trying to prevent the full loader from getting triggered too often.. so it would be super helpful if the incremental could create the missing group and then populate it.
