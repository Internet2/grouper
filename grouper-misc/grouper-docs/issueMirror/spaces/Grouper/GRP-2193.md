# GRP-2193  add "recently viewed" to the widgets available on the front page

The a ability to choose what widgets to show on the front page is nice. But I wish an option where "Recently Viewed."  "Recently Used" appears to be a list of groups I've actually performed an action on. A quick way to get back to the last 10 groups I viewed (but didn't modify in any way) would be really helpful.
