# GRP-7147  Jira issues archived as markdown in git

During the on-prem to cloud Jira migration, every GRP issue was also written to a permanent, full-fidelity, plain-text archive of markdown files in git - one file per issue (about 7,034 files).

Location: grouper-misc/grouper-docs/issueMirror/spaces/Grouper (in the grouper source repo). Each file has YAML frontmatter (key, type, status, reporter, assignee, dates, components, versions, links) plus the description and all comments with their original authors and dates. Personal email domains are redacted (replaced with example.com); display names are kept.

This gives a searchable, offline, version-controlled record that outlives both Jira instances, and can feed the MCP doc_search index.
