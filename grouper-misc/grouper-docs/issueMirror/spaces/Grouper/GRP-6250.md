# GRP-6250  WS WsRestGetSubjectsRequest should allow empty searchString

{code}{
  "WsRestGetSubjectsRequest": {
    "sourceIds": [
      "eduLDAP"
    ],
    "searchString": ""
  }
}
{code}
This finds no results, because it specifically aborts with a blank string. Desired behavior is to find all subjects for the source.

Alternatively, the LDAP search could collapse multiple "**" values so the query works. Then you could put in "*" and the query would find everyone.
