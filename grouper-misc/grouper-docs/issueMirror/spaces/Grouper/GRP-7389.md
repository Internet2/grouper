# GRP-7389  HTML escape folder, group and role names in a few more UI places (follow up to GRP-7331 and GRP-7332)

GRP-7331 and GRP-7332 escaped folder names in the left tree and the parent path on My folders. A review found the same missing escaping in a few other places where a name or display name is written into the page:

* guiServiceShortLink and guiServiceLink (My services panel on the home page and the My services page): the parent path when showPath is false.
* Left browse tree: the top node when default.browse.stem is configured (UiV2Main).
* Trace privileges subheader (privilegesTrace*SubjectSubHeader) for groups, folders and attribute definitions, en and fr text files.
* Role inheritance screen (roleInheritance.jsp): role display extensions and extensions.
* guiGroupShortLink and guiGroupLink: the data-gr-browse-group-name attribute. In guiGroupLink the attribute had also been inserted inside the onclick (GRP-5500), which made the onclick invalid JavaScript, so the link fell back to a full page load.

Fix: escape each value the same way the neighboring code does (grouperUtil.xmlEscape in text templates, GrouperUtil.escapeHtml in Java, grouper:escapeHtml in JSPs), and restore a valid onclick on guiGroupLink.
