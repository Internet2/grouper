## Comments

### Chad Redman  (unc.edu) - 2019-08-08T17:57:58.372+0000

Fixed in 2.4. For requests sent to Grouper WS, it can handle both application/json and text/x-json. For responses from Grouper, it will send back different responses which are compatible with more applications:

* json: application/json
* xml: application/xml
* xhtml: application/xhtml+xml

These response types are set by properties in grouper-ws.base.properties ws.restResponseContentType*. These can be overridden grouper-ws.properties, an institution needs to send back different content types.
