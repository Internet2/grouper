### mchyzer - 2008-08-26T16:35:59.774+0000

I tweaked this in the ErrorFilter, and it seems to address it.  I the the problem is if an error occurs before a JSP is displayed, then an include is called, which doesnt set up the response correctly.  So if we see if we are in the middle of a JSP, stay with the include.  If not, then forward to the error jsp (and set mimetype)...

FROM
			RequestDispatcher rd = request.getRequestDispatcher("/filterError.do");
			try {
				rd.include(request, response);

TO
			//for some reason this has to be able the getRequestDispatcher...
      boolean committed = response.isCommitted();
			RequestDispatcher rd = request.getRequestDispatcher("/filterError.do");
			try {
        if (!committed) {
			    response.setContentType("text/html");
          rd.forward(request, response);
			  } else {
			    rd.include(request, response);
			  }

I think this is obscure, and infrequent, so I will just leave in 1.4...
