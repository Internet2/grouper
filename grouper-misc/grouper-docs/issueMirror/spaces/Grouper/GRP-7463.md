# GRP-7463  Grouper UI success, info and warning text has too little contrast (WCAG AA)

The Grouper UI uses Bootstrap 2's alert and warning text colors, which are too light on their own backgrounds for WCAG AA (4.5:1 for normal text). Only error alerts had been darkened (grouperUi2.css).



Before:

Success messages (the green message after most saves): #468847 on #dff0d8, about 3.6:1

Info messages and info boxes: #3a87ad on #d9edf7, about 3.3:1

Warning boxes (e.g. MCP not enabled, the confidential OAuth client secret notice, the AI assistant's approval box): #c09853 on #fcf8e3, about 2.5:1

Warning text (text-warning, e.g. empty MCP tool log and OAuth registration lists): #c09853 on white, about 2.7:1



Fix: grouperUi2.css sets Bootstrap 3's darker shades of the same colors, about 4.5:1 or better: #3c763d for success, #31708f for info, #8a6d3b for warning boxes and warning text. Alert headings get the same color as their alert. Error alerts are unchanged.



Not included: the white-on-color labels (label-warning, label-info, label-success) also fail, but fixing them means darker backgrounds, which changes how they look. The message close button (x) is also low contrast.
