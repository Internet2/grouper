# GRP-7060  default.browse.stem is broken

If you use the default.browse.stem property their are two rendering problems.  The first is that the view in the file tree still has the Root folder displayed.  Second, if you click on the stem that is intended to be used as the default, then the main UI panel will display the contents of the Root folder, instead of the default browse stem.  For the attached picture, I have default.browse.set set to "etc".

Claude says the bug is in 

grouper-ui/java/src/edu/internet2/middleware/grouper/grouperUi/serviceLogic/UiV2Main.java

 

 357 -        //the id has to be root or it will make another request                                           

 358 -        String id = stem.isRootStem() ? "root" : stem.getUuid();
