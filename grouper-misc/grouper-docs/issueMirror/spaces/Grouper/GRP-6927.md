# GRP-6927  Add per-user UI preference to default the group Members tab to direct memberships only

On the group Members tab, allow a user to set a preference to default the filter to direct memberships for faster initial load on large groups. Most day-to-day work for some users uses direct memberships (child groups, override groups) rather than expanded membership. Implement as a per-user UI preference so the global default behavior is unchanged — otherwise users could see a filtered list and think members are missing. User sets it, then expects direct-only on subsequent visits and can expand to all when needed.
