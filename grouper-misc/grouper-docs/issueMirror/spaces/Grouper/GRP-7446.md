# GRP-7446  grouper_file can store binary files (file_contents_blob) and GSH templates can download them

Add a nullable file_contents_blob column to grouper_file (postgres bytea, oracle BLOB, mysql LONGBLOB) so binary files (zip, xlsx, pdf, etc) can be stored without base64. A row holds either text (file_contents_varchar or file_contents_clob) or binary (file_contents_blob), file_contents_bytes is the real byte length so grouperFile.maxSizeBytes applies.

GSH templates can return a binary download file (GshTemplateOutput.assignDownloadFile with a byte array), e.g. a zipped csv. The UI download sends the bytes and does not gzip files that are already compressed. Builds on GRP-7438, GRP-7440, GRP-7443.
