# GRP-2186  Inconsistent behavior re: Copying loader groups' metadata, attributes

When copying a loader ldap group, it's metadata nor any other directly assigned attributes are not copied over when 'Copy attributes?' is selected. 

With legacyGroupType_grouperLoader, the metadata is preserved, but other directly assigned attributes are not.
