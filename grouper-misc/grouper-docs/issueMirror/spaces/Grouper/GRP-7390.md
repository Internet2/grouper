# GRP-7390  MCP recipe name, summary and body have no maximum length

MCP recipes (GRP-7324) did not limit the length of the name, summary or body. The summary is added to tool descriptions, so it goes out in every tools/list for everyone the recipe reaches; a very long summary bloats every client's tool list. The body is returned by the recipe get action (errors already cap it with grouper.mcp.recipe.maxBodyCharsOnError).

Fix: GrouperMcpRecipe.fieldTooLongError is the one place the limits are defined (name 100, summary 300, body 20000 characters). Both save paths use it so they cannot disagree: the MCP update path (GrouperMcpRecipe.validateFieldValues) and the recipe screens (GrouperMcpRecipeConfiguration.validatePreSave). The configuration metadata has no way to declare a length, so this is written out in Java. Tests in GrouperMcpRecipeToolTest: testFieldTooLongError, testSummaryTooLongRefusedOverMcp, testSummaryTooLongRefusedOnRecipeScreen.
