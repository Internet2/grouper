# GRP-7208  Expose attribute assignment notes field in the UI

There has been a long-standing API method to set notes on an attribute assignment. But there is no way to see this in the UI. You can only report on this using DB queries.

{noformat}import edu.internet2.middleware.grouper.attr.assign.AttributeAssign
import edu.internet2.middleware.grouper.misc.GrouperDAOFactory

String attributeAssignId = "de1900e1f9fa44fe877850caaa697fb7"
String notes = "some notes here"

AttributeAssign attributeAssign = GrouperDAOFactory.getFactory().
  getAttributeAssign().
  findById(attributeAssignId, true)
attributeAssign.notes = notes
attributeAssign.saveOrUpdate(){noformat}

This correctly sets the notes field for the attribute assignment:



{code:sql}select group_name, name_of_attribute_def, attribute_assign_notes
from grouper_attr_asn_group_v
where group_name = 'test:testGroup'
  and name_of_attribute_def = 'etc:attribute:xxx:testDef';{code}

{noformat}+--------------+-------------------------+----------------------+
|group_name    |name_of_attribute_def    |attribute_assign_notes|
+--------------+-------------------------+----------------------+
|test:testGroup|etc:attribute:xxx:testDef|some notes here       |
+--------------+-------------------------+----------------------+{noformat}

This also appears in the audit log:

{code:sql}select audit_category, action_name, grouper_engine, description
from grouper_audit_entry_v
order by created_on desc
limit 1;{code}

{noformat}+--------------------+--------------------------+--------------+-----------------------------------------------------+
|audit_category      |action_name               |grouper_engine|description                                          |
+--------------------+--------------------------+--------------+-----------------------------------------------------+
|attributeAssignGroup|updateAttributeAssignGroup|grouperShell  |Updated attribute assignment: Fields changed: notes. |
|                    |                          |              |notes: FROM: 'null', TO: 'some notes here'           |
+--------------------+--------------------------+--------------+-----------------------------------------------------+
{noformat}

But in the UI, the audit log only shows “Edited attribute test to group testGroup .” You can see the detail if you select “show extended results”. This is really the only way to see the value in the UI.
