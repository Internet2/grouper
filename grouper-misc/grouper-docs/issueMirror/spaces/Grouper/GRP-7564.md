# GRP-7564  UI: required field asterisk is a keyboard tab stop with no tooltip text

In the UI, the red asterisk shown next to required fields on config-style forms (for example the edit form for Send email due to disabled date) is a keyboard tab stop. It has no tooltip text (data-original-title is empty), so focusing it shows nothing and just adds noise for keyboard and screen-reader users.

Cause: grouper.js (grouperTooltipA11yMakeFocusable) adds tabindex=0 to every span[rel=tooltip] so real tooltips are reachable by keyboard. ConfigFormElement.java and GrouperProvisioningObjectMetadataItemFormElement.java emit the requiredField asterisk span with rel=tooltip but no text, so it is caught too.

Fix: (1) only add tabindex=0 to rel=tooltip spans that have title or data-original-title text; (2) add aria-hidden=true to the requiredField asterisk spans, since the asterisk is a visual cue only (WCAG 3.3.2: the required state should be conveyed programmatically on the input, e.g. required or aria-required).
