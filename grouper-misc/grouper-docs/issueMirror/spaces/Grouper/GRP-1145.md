### mchyzer - 2015-07-12T16:16:49.261+0000

this is done, the patcher will allow test patches named like this (with whatever module and index and version)

grouper_v2_2_1_api_patch_0_test.tar.gz

Put this in the grouper.installer.properties to use test patches

# if patches that are named grouper_v2_2_1_api_patch_0_test.tar.gz should be used to test a patch
grouperInstaller.useTestPatches = false

then run installer with:

UNIX (colon):
/whatever/something> java -cp .:grouperInstaller.jar edu.internet2.middleware.grouperInstaller.GrouperInstaller
  
WINDOWS(semicolon):
C:\temp\installGrouper2.3>java -cp .;grouperInstaller.jar edu.internet2.middleware.grouperInstaller.GrouperInstaller
