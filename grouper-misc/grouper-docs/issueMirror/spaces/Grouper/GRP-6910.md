# GRP-6910  LDAP bushy provisioner option to preserve case of folder DNs

When using bushy DN mode in the LDAP provisioner, ldaptive lowercases folder DN components by default (e.g. {{ou=somestem}} instead of {{{}ou=SomeStem{}}}). Some LDAP directories like Active Directory should preserve the original case from Grouper stem names.

Added a new boolean config option {{bushyFolderPreserveCase}} (default false). When true, folder OUs created during bushy provisioning will preserve the case of Grouper stem extensions in their DNs and attribute values.
