### Chad Redman - 2025-04-03T18:51:19.202+0000

Probably no quick fix for this without affecting people. It's using class.ForName() to register the driver, which is the normal way to register. Normally you don't have multiple drivers responding to the same jdbc string. We fixed this by removing the Grouper image's built-in mysql jar and adding the mysql v5 one.

There is a way to get connections directly from the driver. But that may impact people, especially older installations that had to put in the driver manually.

{code}
ClassLoader cl = ClassLoader.getSystemClassLoader();
// or use some other classloader, if you like

Driver dr = (Driver) cl.loadClass(yourDriver).newInstance();
Properties prop = new Properties();
prop.setProperty("user", yourUserName);
prop.setProperty("password", yourPassword);
Connection  conn = dr.connect(someUrl, prop);
{code}
