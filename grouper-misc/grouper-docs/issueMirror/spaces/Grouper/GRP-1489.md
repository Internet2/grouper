# GRP-1489  Can't type multiple lines in Add Members copy/paste

After a recent patch, I can no longer type multiple lines into the Add Members copy/paste textarea. I can still copy/paste multiple lines. This is possibly related to GRP-1448, which added a carriage return prevention. It is definitely somewhere between patches 23 and 55, since the change only appears in systems where I have applied those patches.

### cer28 - 2017-03-31T15:23:35.326+0000

Can this be solved by leaving the keypress preventDefault() on just the specific input element instead of the parent form? The fix in GRP1448 was a modification to grouperExternal\public\assets\js\grouperUi.js::grouperDisableEnterOnCombo() to block carriage returns. The function is passed in the Id of the input element; however the function itself walks back to find the form containing it, and setting preventDefault() on the whole form. This causes the current issue, as the unrelated textarea#entityListId is contained in the same form.

Possible fix?

{code:java}
function grouperDisableEnterOnCombo(jqueryHandleOfFormElement) {
  var jqueryElement = $(jqueryHandleOfFormElement);
- if (!jqueryElement.is('form')) {
-   jqueryElement = jqueryElement.closest('form');
- }
  if (jqueryElement.length !== 0) {
    jqueryElement.on('keyup keypress', function(e) {
      var keyCode = e.keyCode || e.which;
      if (keyCode === 13) {
        e.preventDefault();
        return false;
      }
    });
  }
}
