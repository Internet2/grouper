# GRP-6062  AWS and Github SCIM mock service shouldn't require a provisioner to work

Not sure what the intention was with the awsScim and githubScim mock services. It scans all the provisioners to find ones tied to their bearer token external systems, and fails unless there is exactly one. It doesn't use the provisioner for anything, except to initialize the full sync daemon for it.
