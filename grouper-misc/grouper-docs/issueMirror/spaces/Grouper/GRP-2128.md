# GRP-2128  Detect object types based on folders' extensions and allow auto assigning object types

* Add a new item "Auto-assign types in folder" in "Type actions" dropdown under Folder -> More actions -> Types
 * Only folder admins can see this option
 * Clicking on this new option will traverse all the child folders and look for folders whose extension is: ref, basis, policy, bundle, etc.
 * Matching folders will be shown on the screen with a checkbox next to them, and the type that is detected.
 * Clicking on the checkbox will open up two text fields. one for data owner and another one for member description. 
 * There will be a submit button at the bottom of the entire screen
 * Clicking on the submit button will assign the selected object types to selected folders.
 * Users cannot edit assigned object types from this screen. To un-assign, they need to go to the individual folder and un-assign there.
