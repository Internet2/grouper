# GRP-1760  Invalid options when viewing actions for attribute assignments

Go to the attribute assignments for a group.
 * If you click Actions for a "Metadata on assignment", you have the option to add a metadata assignment, which is not valid.  e.g. "Error: Cannot add metadata assignment on a metadata assignment"
 * Those actions and the actions when clicking on the down arrow next to the values don't take into account what you can actually do.  e.g. I can see "Delete the attribute assignment" when I don't actually have that privilege.  It does correctly error though - "You are not allowed to edit the attribute assignment"
