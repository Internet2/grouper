# GRP-261  web service kerberos authentication optimization

Memory problems in WS

## Comments

### mchyzer - 2009-03-27T06:40:05.934+0000

There is a big memory leak using kerberos and java v6.0.6 (and before).  If you upgrade to the latest JDK, it will be fixed.

http://bugs.sun.com/bugdatabase/view_bug.do?bug_id=6578538

Also, I added in authentication caching of the SHA hash of the authentication header for WS kerberos authentication.  This will only hit kerberos every 30 minutes per user.  You can configure with ehcache.
