# GRP-6810  privacy realm public, authenticated, and sysadmin should have view, read, update

Is realm public
if this field can be seen by anyone, even if not authenticated. Default value is 'false'.

Is realm authenticated
if this field can be seen by anyone who is authenticated. Default value is 'false'.

Can sysadmins access
if this field can be seen by grouper sysadmins who are not in the viewers group. Default value is 'true'.
