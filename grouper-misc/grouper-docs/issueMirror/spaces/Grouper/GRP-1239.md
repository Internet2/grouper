I will open a bug for this.  If you turn off the non ssl port in tomcat which you might want to do, that should make it work.  Otherwise skip that step in the installer and do it manually.

Set URIEncoding="UTF-8" in the HTTP connector elements  (you have it in 8080 but not in the SSL one)
