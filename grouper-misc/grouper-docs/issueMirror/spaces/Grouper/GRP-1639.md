### mchyzer - 2017-11-29T19:10:00.609+0000

this is because the entry in grouper-loader.base.properties was put in a patch, but the MessageConsumerDaemon was not.

 

Also, before we put that in a patch, we need to fix this part:
{code:java}#otherJob.messageConsumerDaemon.class = edu.internet2.middleware.grouper.app.messaging.MessageConsumerDaemon
#otherJob.messageConsumerDaemon.quartzCron = 0 * * ? * *

# there can be multiple entries, "wsMessagingBridge" is the name of this one, change that for each config section

# the messaging system name must correspond to a messaging system in the grouper.client.properties
# grouper.messaging.wsMessagingBridge.messagingSystemName = rabbitMqMessaging
grouper.messaging.wsMessagingBridge.messagingSystemName =

{code}
 

The "wsMessagingBridge" is hard coded, and you cant have multiple sections
{code:java}String queueOrTopicName = GrouperLoaderConfig.retrieveConfig().propertyValueString("grouper.messaging.wsMessagingBridge.queueOrTopicName");
String routingKey = GrouperLoaderConfig.retrieveConfig().propertyValueString("grouper.messaging.wsMessagingBridge.routingKey");
String messageQueueType = GrouperLoaderConfig.retrieveConfig().propertyValueString("grouper.messaging.wsMessagingBridge.messageQueueType");
String actAsSubjectSourceId = GrouperLoaderConfig.retrieveConfig().propertyValueString("grouper.messaging.wsMessagingBridge.actAsSubjectSourceId");
{code}
Also, I know if there is no messagingSystemName that it wont be valid, but I think we should just leave it commented out by default, like this:
{code:java}
# the messaging system name must correspond to a messaging system in the grouper.client.properties

# the queue or topic to check

# routingKey is only valid for rabbitmq; for others, it's ignored
#grouper.messaging.wsMessagingBridge.routingKey =

#grouper.messaging.wsMessagingBridge.messageQueueType = queue

# the source id of the source of the user to act as
#grouper.messaging.wsMessagingBridge.actAsSubjectSourceId = g:isa

# the subject id of the user to act as
#grouper.messaging.wsMessagingBridge.actAsSubjectId = GrouperSystem

# the long polling seconds, listen to the queue for this many seconds for messages
