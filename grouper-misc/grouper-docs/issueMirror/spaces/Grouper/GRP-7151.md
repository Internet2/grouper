# GRP-7151  Add grouper-jira skill to create, transition, and resolve GRP issues via Jira Cloud REST API

Add a grouper-jira skill that drives the grouper.atlassian.net Jira Cloud REST API with an API token to create, comment on, transition, and resolve GRP issues. This supports the convention of one GRP issue per code commit without hand-editing issues in the UI.

Notes captured in the skill: descriptions use ADF (not markdown), the resolution field is not on the transition screen (transition to Resolved without a resolution to avoid HTTP 400), and writes go through REST with the cross-site token rather than MCP.
