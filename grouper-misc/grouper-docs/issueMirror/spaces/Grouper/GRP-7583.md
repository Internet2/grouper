# GRP-7583  Security: Injection and file paths

Security fixes from the 2026 Grouper security review, category L. Each line is one fix, its severity, and the public advisory it belongs to:

- WS sort fields limited to plain field names (critical, advisory C2)
- GSH template uploads checked before saving files (critical, advisory C3)
- Configuration history filter uses bound parameters (medium, advisory C2)
- Custom composite lookup uses bound parameters (medium, advisory C2)
- MCP LDAP search filters cannot contain expressions (medium, advisory MCP)
- (separate commit) Caller-supplied object UUIDs validated on save, which also closes stored cross-site scripting through hand-picked UUIDs.

Fixed in 7.9.1 (GROUPER_7_9_0-branch). The same fixes were provided as security patches for earlier releases. See the security announcement for details and required steps.
