# GRP-5589  Grouper Midpoint provisioner does not cleanup when Deleted Column is set to 'T'

As per bullet number ten at the following page: [https://spaces.at.internet2.edu/display/Grouper/Grouper+MidPoint+provisioner,]

"Grouper can delete deleted rows from the table after a week (configurable),"

deleted entries are not being deleted. 

 

This does not appear to be happening, deleted entries have the column toggled to deleted = 'T' in the database, but are never removed.
