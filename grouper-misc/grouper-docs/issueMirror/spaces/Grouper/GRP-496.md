# GRP-496  allow a filter on membership lite subject finder on add member and import for group name

Add a config so that you can only show subject search results that are in a certain group.  e.g. employee.  Note that the user could go to the admin UI and get around it, but it is helpful if there is a composite or rule on the group...

## Comments

### mchyzer - 2010-10-05T18:55:32.490+0000

This is done.  Configure this in the membership lite config file (media.properties, or the one specified to that config, or whatever:

#subject search box ensures people are in this group (e.g. school:employees) 
simpleMembershipUpdate.subjectSearchRequireGroup=
