# GRP-4518  Docker image contains an old, now defunct source of SP packages.

This file in the Docker image is apparently unused because it points to an out of date source of SP packages, and the source URL is now finally dead.

{{/etc/yum.repos.d/security\:shibboleth.repo}}

I don't know how the SP is involved if at all in the build anymore, but it couldn't have been from there so removing the file should be a no-op.

may be affecting anyone who has a {{yum update}} (or other yum command) in their derived image.One way to mitigate this in your image if upgrading isn't an option: add {{yum-config-manager --disable security_shibboleth}} before the yum update
