# GRP-7607  Add MCP tools for attribute definition actions, scopes and implied attribute names

Beyond the basic settings in GRP-7604, attribute definitions have configuration the Grouper MCP server cannot read or change:
- custom actions on the definition (other than the default assign action)
- assignment scopes that limit where the definition can be assigned (for example to groups in a certain folder)
- implied attribute def names (name hierarchy), where assigning one name implies another

Add MCP tools to view and manage these, so an attribute definition can be fully set up and inspected without the UI or GSH. Follow the existing MCP conventions: readwrite scope checks, ATTR_ADMIN privilege checks, tests, servlet registration and the MCP wiki documentation.
