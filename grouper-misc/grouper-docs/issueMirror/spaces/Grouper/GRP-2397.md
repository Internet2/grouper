# GRP-2397  make log4j support EL or DB config

an issue going to aws for us is our log4j mail config.  dont want to put the smtp user/pass in log4j.properties since its a password and that puts it in git.  also would be nice to configure dynamically.  wondering if it would work and be useful to have the log4j properties to use config overlay (and db configuration? and edit at runtime with ui?) and configure the loggers dynamically.  even if its not DB config (bootstrap issues...  cant log properly without being able to communicate with DB), then at least it could use EL to be able to use a pass from env variable or secrets manager or something...
