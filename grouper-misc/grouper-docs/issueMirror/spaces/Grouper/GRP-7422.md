# GRP-7422  AssetSonar provisioner sync-back (grouper_prov_user) and fullSyncUsersFromSyncBack

Add sync-back to the AssetSonar provisioner (GRP-7420): capture each member read from the REST API (active and inactive pages, read by id, lookup by email) into grouper_prov_user, record writes (create, reactivate, update, deactivate) so the end-of-run drain re-reads them, and advertise canFullSyncEntitiesFromSyncBack so fullSyncUsersFromSyncBack can skip paging the whole member list. Default captured attributes are the managed ones (email, first_name, last_name, employee_id, employee_identification_number, role_id, status) as strings; nativeAttributesEntities can add others such as role_name or creation_source.
