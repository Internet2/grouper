# GRP-3588  default for provisioning ldap groupSearchAllFilter

If you leave the groupSearchAllFilter blank, it will default to searching for containing the search attribute and if there is an objectclass attribute then those will be included in the filter too.  e.g. (&(gidNumber=*)(objectClass=posixGroup)(objectClass=top))
