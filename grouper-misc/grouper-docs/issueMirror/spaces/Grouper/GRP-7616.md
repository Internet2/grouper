# GRP-7616  Upgrade task V47 has no description text and says version 7.9.2

The upgrade tasks screen showed V47 (from GRP-7532) as "$$not found: upgradeTaskDescription_UpgradeTaskV47$$" with version 7.9.2.

- Add the text key upgradeTaskDescription_UpgradeTaskV47 to grouper.textNg.en.us.base.properties.
- UpgradeTaskV47.versionIntroduced() said 7.9.2, which was never released. Change it to 7.10.0, the release that shipped the task.

Display only: the upgrade task itself runs the same.
