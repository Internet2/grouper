## Comments

### Chris Hyzer - 2022-11-03T17:19:06.512+0000

label = URL (single node*)

description = Specify the ldap connection url.  Note the URL should start with ldap:  or ldaps: if it is SSL.  It should contain the server and port (optional if 389/636).  e.g. ldaps://ldapserver.school.edu:636 &nbsp; You should not want specify the base dn here. If you do then all ldap filters will use this base dn.  If you still want to specify the base dn, here is an example: ldaps://ldapserver.school.edu:636/dc=school,dc=edu &nbsp; *If you have a round robin LDAP URL, then errors will occur as replication does not happen fast enough.  You should have a VIP that have fail over load balancing so that updates occur to a single node and if that node is down will point to another single node.  Or point to one hard-coded node and update that if the node is down.
