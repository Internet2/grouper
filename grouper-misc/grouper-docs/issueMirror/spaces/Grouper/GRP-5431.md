# GRP-5431  Drop Down GSH Template values from attributes 

It would be nice if the values of a drop down input field for a GSH template could be loaded from the folder or group the template is being ran on.  This would allow for more generic templates that can be customized depending on where they are deployed.  

This might allow a single template to be used by an institution instead of having to maintain several templates that are mostly the same.
