# GRP-380  the simple UI will get confused if two windows or tabs of the same browser are editing different groups

If a user is logged in to the membership update lite UI and opens a new tab to edit a different group, then if they add or delete in each window then both windows will show the respective groups, but will edit the same (most recent) group.

## Comments

### mchyzer - 2010-02-22T19:54:49.883+0000

Now if there is a mismatch between the screen and the server session, the user will get a message:

"The group you are editing is out of sync in the user interface.  Perhaps you have two browser tabs open editing different groups.  This group will be refreshed, please start over."

The server state will refresh with the group the screen is editing, and the screen will refresh with the latest data, and the user can click "OK", and perform the operation again.
