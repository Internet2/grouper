# GRP-3424  do not allow groups with same name and different case

This includes name, display name, and alternate name.

If you want to have stems with same name case-insensitive, set this in grouper.properties

 
|grouperHook.GroupUniqueNameCaseInsensitiveHook.autoRegister = false|

 

To see if you have two stems with same name, run this query
  
{code:java}select * from grouper_groups gg1, grouper_groups gg2
where gg1.id != gg2.id and 
(lower(gg1.name) = lower(gg2.name)
or lower(gg1.display_name) = lower(gg2.display_name)
or lower(gg1.name) = lower(gg2.alternate_name)
or lower(gg1.alternate_name) = lower(gg2.name)
or lower(gg1.alternate_name) = lower(gg2.alternate_name))
 {code}
