# GRP-7595  LibreChat provisioner sync-back

Add sync-back to the LibreChat provisioner (GRP-7594), v7+ only.

- Capture every LibreChat user read, every local group read (with source and idOnTheSource), and the full member list of each managed group read, into the generic grouper_prov_user / grouper_prov_group / grouper_prov_mship tables.
- Write-track group creates and updates and each membership add and remove.
- Full sync can then read users, groups and/or memberships from the sync-back cache instead of the API (fullSyncUsersFromSyncBack, fullSyncGroupsFromSyncBack, fullSyncMembershipsFromSyncBack). Memberships are the main saving: otherwise each managed group costs one members call per full sync.
- Cached groups get the same rule as a live read: only source local with the idOnTheSource prefix are kept, with the prefix removed; memberships are kept only for those groups.
