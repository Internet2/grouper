# GRP-7581  Security: Secrets and logging

Security fixes from the 2026 Grouper security review, category J. Each line is one fix, its severity, and the public advisory it belongs to:

- External system secrets stored and shown as passwords (medium, advisory M1)
- WS OAuth logs token fingerprints, not tokens (low, advisory H7)
- Provisioner HTTP logs mask credentials (medium, advisory M1)
- GSH template password inputs masked in audits and logs (low, advisory H4)

Fixed in 7.9.1 (GROUPER_7_9_0-branch). The same fixes were provided as security patches for earlier releases. See the security announcement for details and required steps.
