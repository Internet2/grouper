# GRP-1330  grouperInstaller grouper.hibernate.properties  cache factory_class configuration problem

Upgrading from Grouper 2.1.5 to 2.3.0. The grouperInstaller.jar took the attached grouper.hibernate.properties file and evolved it but it put in the evolved version the line

hibernate.cache.region.factory_class = net.sf.ehcache.hibernate.EhCacheRegionFactory
