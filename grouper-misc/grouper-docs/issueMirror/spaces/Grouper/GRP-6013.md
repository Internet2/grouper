# GRP-6013  Daemon logs change last updated timestamp when log or counts aren't changing

When watching a long running daemon job, users need to check the job message for progress. If they could rely on the last updated timestamp to reflect real changes, they wouldn't need to repeatedly copy the log to see nothing changed.
