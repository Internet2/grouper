# GRP-5153  add option to run tomcat as another user

If running tomcat as a different user, and not using supervisord, and if the container is running as root, it will run the tomat process as another user.

Previous behavior was to run tomcat as the current user of the container.

Check everything is ok if the previous container tomcat user (ps -ef) is the same as the new one after upgrading

### Chris Hyzer - 2023-11-26T08:18:58.881+0000

If GROUPER_RUN_PROCESSES_AS_USERS=true, and the container is running as root, and you are not running supervisord (option in v4 and default in v5), then tomcat will run as the tomcat user.  Note you can set the UID above (again, if container is running as root)

Note GROUPER_RUN_PROCESSES_AS_USERS defaults to true if running the container as root user
