# GRP-895  load attributes should strip whitespace where appropriate

Subject: [grouper-users] Found an interesting bug in the lite ui

When I assign a value to the “Grouper loader LDAP subject expression” attribute for a Group loader group I discovered either a leading or trailing space on the value ${loaderLdapElUtils.convertDnToSpecificValue(subjectId)} will cause the loader to fail. It will be able to find the member subjects in the defined ldap source.
