# GRP-5095  UI: Predictable Deep Links to groups

This might already exist, but I thought I'd write it down as a suggestion....

It would be helpful to be able to have predictable deep links to Groups... Something like https://grouper.example.edu/grouper/g/<group name>

This would theoretically redirect to the 'proper' link for the group

While our use cases don't really call for it, the same idea could be helpful for subjects or other items. Perhaps, this could be done with several paths (/g/ for groups and /s/ for subjects) or a generic path (/f for find or /s for short). However, that generic path gets more complicated if entity labels overlap (ie, /f/xyz could refer to both a subject or a group-id), then using parameters or using parameters when it is ambiguous seem necessary.
