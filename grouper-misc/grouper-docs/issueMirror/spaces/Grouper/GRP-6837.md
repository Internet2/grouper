# GRP-6837  add hasAttributeBetween function for string range comparisons in ABAC

Add a {{hasAttributeBetween}} function for ABAC scripted groups that supports string range comparisons with configurable inclusive/exclusive bounds.

*Syntax:*
 {{entity.hasRow('affiliation', "hasAttributeBetween('engl' < affiliationOrg, affiliationOrg <= 'math')")}}
 
Each bound supports {{<}} (exclusive) or {{<=}} (inclusive), and both bounds are required.

*Additional changes:*
 * Disallow {{{}<{}}}, {{{}<={}}}, {{{}>{}}}, {{>=}} operators on string data fields (throw error with helpful message directing to {{{}hasAttributeBetween{}}}). These operators remain supported for integer/timestamp fields.
 * Add test verifying string ordering operators throw an exception
 * Add tests for {{hasAttributeBetween}} with various inclusive/exclusive combinations
