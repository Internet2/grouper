# GRP-5113  group_id_index issue with midpoint provisioner

_(no description)_

## Comments

### Chris Hyzer - 2023-11-09T20:41:22.619+0000

If you are affected you can add something like this (edit config id) to your configuration.  Note you cannot do this on the provisioning screen but rather in config in the database (import), or in a config file.  Then after 4.8.1 you can remove it.


{code:java}
provisioner.midPointSQL.groupAttributeValueCacheHas = true
provisioner.midPointSQL.groupAttributeValueCache0has = true
provisioner.midPointSQL.groupAttributeValueCache0source = target
provisioner.midPointSQL.groupAttributeValueCache0type = groupAttribute
provisioner.midPointSQL.groupAttributeValueCache0groupAttribute = id_index
 {code}
