# GRP-1980  ws message about versions is backwards

    <resultWarnings>, Client version: 2.4.0 is less than (major/minor) server version: 2.3.0, Client version: 2.4.0 is less than (major/minor) server version: 2.3.0</resultWarnings>

 

should be "greater than"

## Comments

### Chad Redman  (unc.edu) - 2019-08-25T04:30:49.375+0000

Per the issue where this warning was introduced: "If the client has greater version than the server (only considering major and minor version, not considering build number or release candidate number), then there will be a warning returned to the client"

Thus, the warning should be ".. has greater version than (major/minor) server ..."
