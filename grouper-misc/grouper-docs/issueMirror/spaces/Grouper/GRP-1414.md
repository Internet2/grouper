When configuring the grouper.installer.properties file for the non-interactive Grouper Installer there’s this property that I was expecting to control where the location of the downloaded tarballs.

# autorun, uncomment to make work, Enter in a Grouper temp directory to download tarballs
# default is controller in a config in this config file: grouperInstaller.default.tarballDirectory
# if that is blank or not configured, default is current working directory

However, when I run the installer with this configuration, the tarballs still go in the current working directory.  Is there another setting that I missed?
