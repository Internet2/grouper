# GRP-6990  Externalize hardcoded English strings in visualization legend and description pane

* All legend node/edge labels in {{grouperVisualization.js}} (getGraphModuleD3Legend and related) are hardcoded English — e.g. "Legend", "start folder", "start group", "folder or group", "contains", "has member", "loader group", "group loaded", "loads group", "simple loader group", "complement group", "include group", "exclude group", "intersected with"
 * Description-pane strings rendered by the right-side info panel are also hardcoded — e.g. "Entity is member of group", "Entity is not member of group", "Direct membership in these groups:", "Loaded by job:", "Provision to:", "Composite owner of", "minus", "(Root folder)", "none", "unknown object", "{_}unknown operation{_}"
 * Move all of these into {{grouper.textNg.en.us.base.properties}} and expose them to the JS via the existing {{textContainer}} pattern (either inline {{<script>}} block populating a {{grouperVizText}} object on the page, or a JSON endpoint)
 * This is also the foundation for any future French / other-locale support of the visualization page
