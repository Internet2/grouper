### Chris Hyzer - 2020-04-08T04:32:41.415+0000

There is a workaround for 2.5.20 in the Dockerfile.  (remove this in the next version of Grouper)
{code:java}FROM i2incommon/grouper:2.5.20

RUN rm /opt/grouper/grouperWebapp/WEB-INF/lib/slf4j-log4j12-1.7.25.jar
RUN rm /opt/grouper/grouperWebapp/WEB-INF/lib/slf4j-api-1.7.25.jar
RUN cp /opt/tomee/lib/slf4j-api-1.7.21.jar /opt/grouper/grouperWebapp/WEB-INF/lib/
RUN cp /opt/tomee/lib/slf4j-jdk14-1.7.21.jar /opt/grouper/grouperWebapp/WEB-INF/lib/
 {code}
 Also you should download this:

[https://repo1.maven.org/maven2/org/slf4j/slf4j-log4j12/1.7.21/slf4j-log4j12-1.7.21.jar]

Here:

slashRoot/opt/grouper/grouperWebapp/WEB-INF/lib

and /tomee/lib/slf4j-jdk14-1.7.21.jar to WEB-INF/lib
