# GRP-1571  Making the Google Provisioner's subjectIdentifierExpression more flexible

The Google Apps Provisioner constructs the subject's email address by concat the subjectId and domain specified in the property file. This could be a lot more flexible if the subject object was passed into the expression.

## Comments

### jgasper - 2017-06-22T19:51:39.211+0000

Code pushed to https://github.com/Internet2/grouper/pull/75

If the calculated subjectIdentifierExpression does not include an "@" then the old logic of taking the calculated subjectIdentifierExpression value and appending the domain will still be used. Otherwise, whatever the subjectIdentifierExpression produces will be used.

{{
subjectIdentifierExpression = ${subjectId}          => jgasper@example.com
subjectIdentifierExpression = ${subject.getId + "@domain.edu"}         => jgasper@example.com
}}
Theoretically it should be possible to construct the address using a subject attribute, but this hasn't been tested:
{{
subjectIdentifierExpression = ${subject.getAttributeValue("mail", false)}         => jgasper@example.com
}}
