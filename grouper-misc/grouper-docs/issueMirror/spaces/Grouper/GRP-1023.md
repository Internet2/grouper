# GRP-1023  Make default widgets configurable

Provide configuration option to select which widgets are going to be displayed by default on the main page.

## Comments

### mchyzer - 2014-09-20T01:38:02.943+0000

https://github.com/Internet2/grouper/commit/e5993aeb137a14174ac42d26f4ff451179f69e6f

configure the defaults in the grouper-ui.properties:

# what defaults in widget cols (0,1,2): [IndexContainer.IndexPanel enum]: 
# GroupsImanage, MyFavorites, MyMemberships, MyServices, RecentlyUsed, StemsImanage
uiV2.widget0 = MyFavorites
uiV2.widget1 = RecentlyUsed
uiV2.widget2 = MyServices


The defaults are used for a user who has not changed their widgets.  If a user changes their widget, it will store that preference in the database so when they go to the dashboard again (either in the same session or not), they will see the same widgets.
