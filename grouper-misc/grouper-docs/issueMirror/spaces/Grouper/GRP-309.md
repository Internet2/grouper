# GRP-309  Update UI to use the latest servlet API and JSTL

The UI has not kept pace with updates in the Servlet API and JSTL. IN order to make it easier to integrate newer technologies e.g. Ajax, ensure that the UI web.xml references the latest ServletAPI version supported by Tomcat 5.5 and update JAR files.

Differences in JSTL parsing may lead to some issues.
