### cer28 - 2018-03-27T02:56:11.337+0000

Found the email, his point was good. The subdomain is an issue, but EmailValidator also checks the tld vs. valid gTLDs and ccTLDs. So a@idp.b.c was invalid for two reasons -- the subdomain, plus "c" isn't a valid TLD. I changed the code to allow subdomains, plus changed the domain in the tests from @(*.)b.c to @(*.)example.edu.
