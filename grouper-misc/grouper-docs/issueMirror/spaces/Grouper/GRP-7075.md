# GRP-7075  Loader diagnostics: verify groups in like string corresponds with groups in query

If you put in the wrong pattern for a group loader like string, it's going to see everything out of scope and either delete the groups or remove the memberships (depending on property settings). The diagnostics should verify that if the like string returns any groups, at least one of them is in the loader query (group query or membership query).

Currently:
{code}######## CONFIGURATION ########
...
SUCCESS: 'groups like' SQL config is set to 'etc:%' for SQL_GROUP_LIST

######## CHECKING QUERIES ########
...
SUCCESS: GROUP_NAME exists and contains a colon: 'base:hr:dept:216210:member'
{code}
This should give an error because the like string does not return any groups that the loader loads.
