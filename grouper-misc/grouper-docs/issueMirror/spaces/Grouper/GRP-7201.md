# GRP-7201  Redirect old on-prem wiki (spaces.at.internet2.edu) Grouper space to Cloud docs

The old on-prem Grouper wiki space at spaces.at.internet2.edu is still indexed by Google and duplicates the new Cloud docs site at docs.grouper.internet2.edu. This is a one-time migration cleanup: 301-redirect the old space URLs to their new Cloud pages so the old URLs leave Google, users and bookmarks forward to the right page, and ranking signals consolidate on the new site while the old server stays up.

Added grouper-misc/grouper-docs/redirects/ with a generator (build_redirects.py), an Apache RewriteMap of 988 old-pageId to new-Cloud-URL entries matched 1:1 by title (9 old pages renamed or dropped in migration fall back to the space home), an Apache mod_rewrite config, a match report, and a README. Canonical and viewpage.action URLs become single 301s; tiny links and display URLs ride Confluence own 302 to the canonical URL first.

Hand the map and config to the Internet2 infra team to deploy. Two must-dos are documented: allow Googlebot through the AWS ELB/WAF (which currently 403s it) so the 301s are actually seen, and place the rules before the ProxyPass to Confluence. This is a one-time task and is intentionally separate from the per-release wiki mirror and sitemap tooling.
