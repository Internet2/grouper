# GRP-7128  Correct DDL deep check subtitle to reference gsh.sh instead of gsh

The subtitle on the "Database DDL deep check" configuration page tells the admin the UI check is equivalent to a command-line invocation, but it names the command as {{{}gsh -registry -deep -check{}}}. The executable is {{{}gsh.sh{}}}, so the copy-pasted command does not run.

Fix the text so it reads {{{}gsh.sh -registry -deep -check{}}}.
 * File: grouper/conf/grouperText/grouper.textNg.en.us.base.properties
 * Property: {{configurationDdlDeepCheckSubtitle}}

No functional/logic change - text only.
