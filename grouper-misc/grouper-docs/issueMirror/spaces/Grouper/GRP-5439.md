### Chad Redman - 2024-05-21T15:32:11.629+0000

This logic seems backwards

{code:java}
      Long lastSequenceProcessed = GrouperUtil.longObjectValue(grouperGroovyResult.getResult(), true);  
      
      if (lastSequenceProcessed == null) {
        lastSequenceProcessed = this.provisioningSyncConsumerResult.getLastProcessedSequenceNumber();
      } else {
        GrouperUtil.assertion(this.provisioningSyncConsumerResult.getLastProcessedSequenceNumber() == null 
            || this.provisioningSyncConsumerResult.getLastProcessedSequenceNumber().longValue() == lastSequenceProcessed, 
            "Setting lastSequence processed " + this.provisioningSyncConsumerResult.getLastProcessedSequenceNumber() 
            + " does not match return value " + lastSequenceProcessed);
        this.provisioningSyncConsumerResult.setLastProcessedSequenceNumber(lastSequenceProcessed);
      }
{code}

The lastSequenceProcessed value is the correct value after processing. The provisioningSyncConsumerResult.getLastProcessedSequenceNumber() is the value from before it ran. It isn't going to pass the assertion if something was processed since the numbers are different. And it won't call setLastProcessedSequenceNumber(lastSequenceProcessed) to set it since the failed assertion acts as a thrown exception.

### Chad Redman - 2024-05-21T15:49:22.669+0000

As a single batch (a small changelog or a large batch size), it doesn't fail because this.provisioningSyncConsumerResult.getLastProcessedSequenceNumber() is null, so it passes the assertion.
