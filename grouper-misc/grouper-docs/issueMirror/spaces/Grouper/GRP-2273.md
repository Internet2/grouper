# GRP-2273  Subject Lookups: Null subject_id leads to NullPointerException

When loader jobs return null subject_id column values, Subject Caching and SubjectSourceAdaptors can throw NullPointerExceptions. While it could be argued that loader queries should not do it, it is better to recover gracefully.
