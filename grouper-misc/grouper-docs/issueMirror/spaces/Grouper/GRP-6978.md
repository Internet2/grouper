# GRP-6978  Fix sync-back config labels, descriptions, and showEl chains in provisioner wizard

* Rename labels from "Load X into generic grouper table" → "Sync X back into generic grouper tables" (plural; "sync back" matches the feature name) for the three load flags.
 * Rename "Native attributes (entities)" / "Native attributes (groups)" → "Native entity attributes" / "Native group attributes".
 * Rewrite the {{nativeAttributesEntities}} / {{nativeAttributesGroups}} descriptions: explicitly say leave blank for the curated default set (which may evolve), and that a configured value REPLACES the defaults rather than adding to them.
 * Fix {{showEl}} regressions so the load flags appear when their axis is selectable (not only when selectAll is on), and the {{nativeAttributes*}} fields disappear when their load flag is off or not shown. Update {{loadMembershipsToGenericGrouperTable}} showEl to require the full both-axis chain.
 * Mirror the description rewrite in {{grouper-loader.base.properties}} comments.
