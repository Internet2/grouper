# GRP-7508  Improve error message when user is not allowed to create a send-email rule

When a user who is not allowed to create send-email rules picks one of the send-email rule patterns, the error was only: You are not allowed to select this pattern. That gives no reason and no next step.

Changed the default text of grouperRuleConfigNotInEmailSenderGroup in grouper.textNg.en.us.base.properties to: Only authorized users can create rules that send email. Contact your Grouper administrator if you need this access, or if you would like them to configure this rule for you.

Sites can still customize this by overlaying grouperRuleConfigNotInEmailSenderGroup in grouper.text.en.us.properties. The patterns are still shown in the dropdown so users know they exist.
