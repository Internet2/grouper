# GRP-4363  grouper container should be able to log to file or pipe or both

-e GROUPER_LOG_TO_HOST=true
-e GROUPER_LOG_TO_PIPE=true

Defaults to pipe.  If log to host is true, and log to pipe is unset, then set log to pipe to false.
