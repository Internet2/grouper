### Chad Redman - 2024-09-19T19:16:09.088+0000

The SQL building part and the bind variable part of the code are in different places. The quick hack I did to patch this for a customer was to set the bind variable for the group id to -1 if the cache group doesn't exist. It ends up working as needed; since no group has internal id of -1, it acts like an empty group when used in the exists and not exists queries.
