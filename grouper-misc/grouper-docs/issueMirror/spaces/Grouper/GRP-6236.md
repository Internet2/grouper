# GRP-6236  Member.isImmediateMember() calls the same query twice

{code:java}
edu.internet2.middleware.grouper.Member#isImmediateMember(edu.internet2.middleware.grouper.Group, edu.internet2.middleware.grouper.Field)

Subject subj = this.getSubject();
try {
  MembershipFinder.findImmediateMembership(GrouperSession.staticGrouperSession(), g, subj, f, true);
  rv = true;
}
catch (MembershipNotFoundException eMNF) {
  try {
    GrouperDAOFactory.getFactory().getMembership().findByGroupOwnerAndMemberAndFieldAndType(
      g.getUuid(), MemberFinder.internal_findAllMember().getUuid(), f, MembershipType.IMMEDIATE.getTypeString(), true, true
    );
    rv = true;
  }
  catch (MembershipNotFoundException anotherMNF) {
    // ignore
  }
 {code}

It's not obvious, but the methods in both the try and the catch end up calling the same method Hib3MembershipDAO.findByGroupOwnerAndMemberAndFieldAndType().
