# GRP-7423  MCP admin_external_system_get: look up AssetSonar members

Add AssetSonar (GRP-7420) as a type in the MCP admin_external_system_get tool. The type is auto-detected from the AssetSonar external system. Lookup fields are email (filter=email, verified to be narrowed, finds deactivated members too) and id. The result returns an allow-list of member fields (id, email, names, employee ids, role_id, role_name, status, provenance and timestamps), never the raw record, which carries secrets such as webstore_authentication_token and secure_code.
