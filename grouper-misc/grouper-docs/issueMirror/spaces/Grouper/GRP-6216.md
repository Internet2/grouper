# GRP-6216  Allow a daemon job to be added to My Favorites

It gets tedious to not be able to get directly to a daemon job, and you need to go to the full list every time and search for the same thing.

In recent versions you can right click to open it in a new window. But if you don't do that, redoing searches, or scanning all the pages of jobs to find it, are the only ways to get to it
