# GRP-1338  Allow the adopter to create/define a subject source during Grouper install

It would be MUCH MUCH easier if the installer during setup, simply auto-configured a given subject source. Take the most common scenarios for JDBC and LDAP sources, and walk the user through the configuration process rather than forcing them to pull up sources.xml.
