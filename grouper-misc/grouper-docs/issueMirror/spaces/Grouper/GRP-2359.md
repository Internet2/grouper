# GRP-2359  populate owner for attribute assignment change in ChangeLog 

For actions like add/remove attribute/value assignment, it would be good to add the owner (i.e. owner_group, owner_stem, owner_member) in changeLog so that it can easily find out which group/stem/member has the attribute change. Currently in grouper_change_log_entry table, there has a few columns not populating data for attribute assignment changes (string07~string12), is it possible to populate the owners using these columns? It's useful especially for attribute/value removal.
