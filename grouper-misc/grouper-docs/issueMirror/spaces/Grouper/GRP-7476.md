# GRP-7476  Escape HTML in UI input values (provisioner config, job history chart, config editor, provisioning/object type settings, visualization)

Several Grouper UI v2 JSPs write request-derived values into HTML input value attributes without escaping them, which is an XSS risk. This change wraps those values in fn:escapeXml. Many of the fields are already limited by other validation, and most are on admin-only screens, so the risk is low. It is defense in depth.

Pages and fields fixed:

* provisionerConfigs/provisionerConfigAddHelper.jsp: startWithSessionId (hidden)
* admin/adminJobHistoryChart.jsp: dateFrom, timeFrom, dateTo, timeTo, minElapsedSeconds, namesLikeFilter
* configure/configurationFileEditEntry.jsp: propertyNameName (hidden)
* grouperObjectTypes/grouperObjectTypeObjectSettingsEditHelper.jsp: grouperObjectTypePreviousTypeName (hidden)
* provisioning/provisioningGroupMembershipSettingsEditHelper.jsp, provisioningObjectSettingsEditHelper.jsp, provisioningSubjectMembershipSettingsEditHelper.jsp, provisioningSubjectSettingsEditHelper.jsp: provisioningPreviousTargetName (hidden)
* visualization/visualizationMain.jsp: objectId (hidden)
