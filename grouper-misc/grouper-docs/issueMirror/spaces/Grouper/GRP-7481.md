# GRP-7481  MCP group_save: moveGroup action to move a group to a different folder

h2. Problem

There is no way to move a group to a different folder over MCP, or in the AI assistant in the Grouper UI. {{group_save}} has a {{renameGroup}} action, but it renames a group in place and refuses a fully qualified new name, since a rename cannot move a group.

h2. Changes

h3. New {{moveGroup}} action on {{group_save}}

* Arguments:
** {{newFolderName}}: the fully qualified name of the folder to move the group to. Required. The folder must already exist
** {{setAlternateNameIfMove}}: whether to keep the old name as the group's alternate ID path, so lookups by the old name still find it. Defaults to {{false}}
* The group keeps its group ID, uuid, memberships, privileges and attribute assignments. Only the folder part of its name changes
* Uses the {{GroupMove}} API, in the caller's own Grouper session

h3. Checks before anything is changed

* {{newFolderName}} must be given, and must not be the folder the group is already in
* The old name is checked for protection as for every {{group_save}} action, and the new name is checked too, so a group cannot be moved into the built-in objects folder ({{etc}} by default) or a folder in {{grouper.mcp.protectedFolders}}
* The group must exist and be visible to the caller
* The caller must have ADMIN on the group and CREATE on the destination folder. Both are checked first for a clear message, and {{GroupMove}} enforces them again
* For OAuth clients, both names must be in the consented read-write scope:
** the old name, as for every {{group_save}} action
** the new name, checked the way a new group's name is: it must be inside a consented folder or be a consented group name. A consent for the group alone allows changing it, but not moving it to another folder

h3. Approval box in the UI assistant

A move is shown as {{Move group 'a:b' to folder 'c:d'}}, followed by any other arguments.

h3. Related wording

The {{renameGroup}} description and its "not a fully qualified name" error now point to {{moveGroup}} for moving a group.
