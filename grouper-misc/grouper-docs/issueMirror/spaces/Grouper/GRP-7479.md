# GRP-7479  UI AI assistant approval box shows each institutional tool input on its own line

h3. Summary

The AI assistant approval box in the Grouper UI shows institutional tool inputs as one long line of JSON. This makes the approval text hard to read when a template has many inputs.

h3. Context

When the AI assistant asks to run an institutional tool, the approval box is the user’s chance to check what will run.

h3. Acceptance criteria

* The summary lists each input on its own line.
* Each input is shown as {{name: 'value'}}.
* Inputs are shown in the order the model gave them.
* Other arguments, such as the owner, are still listed after the headline as before.
* Inputs which are empty, missing or not an object are shown the old way.
* A value or an input name cannot add a line of its own.
* A new line inside one input is still shown as {{ }}.
* Hidden or control characters are still escaped.
* The approval box keeps the summary's own line breaks ({{white-space: pre-line}}), on the single change paragraph and inside the checkbox label when several changes are waiting.
* This applies to every institutional tool, not one institution's template.
* Other summaries contain no line breaks, so they look the same.

h3. Other information

Current approval box text example:

{noformat}Run institutional tool 'x', a script which can make changes (also given: inputs: {"action":"create","groupName":"a:b","description":"...", ...}){noformat}

Desired approval box text example:

{noformat}Run institutional tool 'x', a script which can make changes

inputs:

action: 'create'

groupName: 'a:b'

description: '...'{noformat}
