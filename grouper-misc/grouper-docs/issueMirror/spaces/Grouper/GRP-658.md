# GRP-658  [ldappcg] support case-insensitive attribute values

Provide an option to compare attribute or reference values case insensitively.

https://lists.internet2.edu/sympa/arc/grouper-users/2011-09/msg00075.html

## Comments

### tzeller@example.com - 2012-03-15T17:41:45.738+0000

Reference IDs may be compared case insensitively. For example :

<!-- The ldap group "member" attribute. -->
    <references
      name="member"
      caseSensitive="false">
