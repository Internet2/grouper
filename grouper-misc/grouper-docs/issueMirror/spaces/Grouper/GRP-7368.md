# GRP-7368  MCP group_find tool description incorrectly implies stemNameScope works with approximate name search

In the MCP {{group_find}} tool, the {{stemNameScope}} parameter description says "Scope when searching in a stem." Together with the {{stemName}} description ("or to scope a FIND_BY_GROUP_NAME_APPROXIMATE search"), that leads AI clients to send {{stemNameScope}} with {{FIND_BY_GROUP_NAME_APPROXIMATE}}. The web service rejects that combination:

{noformat}Query should not contain stemNameScope, but contains: 'ALL_IN_SUBTREE'{noformat}

{{WsQueryFilterType}} only accepts {{stemNameScope}} with {{FIND_BY_STEM_NAME}}. Every other filter type calls {{validateNoStemNameScope()}}.

The fix updates the {{stemNameScope}} description in {{GrouperMcpFindGroups}} to say it is only valid with {{FIND_BY_STEM_NAME}}, matching how {{folder_find}} already words {{parentStemNameScope}} ("Only valid with FIND_BY_PARENT_STEM_NAME"). Only the description text changes; there is no functional change.
