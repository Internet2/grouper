# GRP-6318  Configuration in UI for v4.19.1 shows version as 4.19.0

The issue stems from the container build. The Grouper version is 4.19.1, but the container version was not bumped up as it should be. The default for how it shows up in the UI is text property configurationIndexSubtitle, which uses utility method GrouperVersion.grouperContainerVersionOrMavenVersion(). This returns the version from the container environment property which is 4.19.0, rather than from the jar files which are 4.19.1.
