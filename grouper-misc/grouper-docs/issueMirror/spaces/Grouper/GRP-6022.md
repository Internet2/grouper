# GRP-6022  Add sftp capability to group reports, so it doesn't needs a separate daemon job just for that

There are two reporting features in Grouper. The group-based report can do SQL or GSH, can save to a file or upload to S3, and saves history for 30 days and versions have timestamps. A less featured version is a standalone SQL to CSV daemon job, which can just SQL to the same file name each run. The only unique feature of the daemon job is that it can do SFTP. If the group report could also do SFTP, there wouldn't be a reason to maintain two similar features for reporting.
