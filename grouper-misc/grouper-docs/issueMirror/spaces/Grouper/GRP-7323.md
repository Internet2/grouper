# GRP-7323  Add feature to enable configuration of order of operations for Okta provisioner to prioritize adds before deletes 

Harvard would like an enhancement to the Okta provisioner so we are able to prioritize group adds before deletes. This will enable us to grant members of the community quicker access to resources during high volume leaver and joiner events by configuring adds to precedence over deletes. The current implementation prioritizes deletes before adds
