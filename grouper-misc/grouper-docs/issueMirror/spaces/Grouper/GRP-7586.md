# GRP-7586  Upgrade Java Corretto to 17.0.21.1.2 for security

Upgrade the container Java to Amazon Corretto 17.0.21.1.2 (released 2026-11-17) for security. Grouper 7.9.0 shipped Corretto 17.0.20.12.1 (2026-09-25).

This picks up the CVE fixes in three Corretto releases since 7.9.0:

17.0.21.0.10 (2026-10-20): the October 2026 Java critical patch update, 42 CVEs.

17.0.21.0.11 (2026-10-24): CVE-2026-114820 (CVSS 9.1, security-libs/java.security).

17.0.21.1.2 (2026-11-17): CVE-2026-114938 (8.1, hotspot/compiler), CVE-2026-114939 (7.4, security-libs/org.ietf.jgss), CVE-2026-114940 (7.4, security-libs/javax.net.ssl), CVE-2026-114942 (7.0, core-libs), CVE-2026-114943 (6.5, hotspot/runtime), CVE-2026-114944 (5.9, core-svc/java.lang.management), CVE-2026-114945 (5.3, core-libs/java.lang), CVE-2026-114946 (4.8, hotspot/compiler). It also removes the emSign C1 and C3 roots from the Corretto cacerts and updates tzdata to 2026f.

Source: https://github.com/corretto/corretto-17/blob/develop/CHANGELOG.md

The container installs the latest Corretto 17 at build time, so no Dockerfile change was needed. The 7.9.1 image reports Corretto-17.0.21.1.2.
