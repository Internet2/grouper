## Comments

### Chris Hyzer - 2024-11-12T18:20:24.556+0000

After configuring the job, you will not see it in the job list

Import this into the config for grouper-loader.properties (Miscellaneous → Configure → Configuration files → Import)
{code:java}
otherJob.ldapAnames.ldapSqlDbConnection = grouper
otherJob.ldapAnames.class = edu.internet2.middleware.grouper.app.ldapToSql.LdapToSqlSyncDaemon
otherJob.ldapAnames.quartzCron = 8 7 6 * * ? {code}

You need to substitute your ldap to sql config id, and your sql config id, and your cron

Schedule jobs. Since there was changes to the configs, after the wizard, this is telling the daemons to look in the configs for daemons to schedule
