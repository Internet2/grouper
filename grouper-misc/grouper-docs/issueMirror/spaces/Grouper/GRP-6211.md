### Christopher Bongaarts - 2025-06-25T16:25:51.051+0000

looks like this might be related to a change in 4.10.0 in [https://github.com/Internet2/grouper/commit/ed738eeba0e3c5502a1b9769b1221c12cd846ae0]

GshTemplateValidationService added a check to validateOwnerType:
 
{code:java}
if (!templateConfig.canGroupRunTemplate(ownerGroup)) {
    throw new RuntimeException("ownerGroup "+ownerGroup.getName() + " is not allowed to run this gsh template");
}
{code}
but  canGroupRunTemplate immediately returns false unless ShowInGroup is set true for this template.  I'm not sure why this was added here; the actual check for "is user in the ownerGroup" happens later on in validateSecurityRunType.
