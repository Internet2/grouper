# GRP-7164  Add grouper-release skill to grouper-docs for cutting and recording a release

Add a grouper-release AI skill under grouper-misc/grouper-docs/skills/. It is the end-to-end checklist for cutting and recording a Grouper container release: bump the container Tomcat/base versions, confirm the stock server.xml patch still applies and the Tomcat tarball is on the Internet2 mirror, confirm no DDL/upgrade-task changes since the last release, resolve the shipped GRP issues and tag them with the new fixVersion, and add the release row to the v7 Release Notes wiki page.

It delegates Jira writes to the grouper-jira skill and wiki writes to the grouper-wiki-edit skill, and documents the release-notes table contract: the five-column layout, the Date/Status and merged Upgrade cells, no line breaks in the sha digest, the Versions and Enhancements formats, and the status-to-cell-colour map (LATEST STABLE is yellow and only one at a time). README updated with the new skill.
