# GRP-1162  Testing search queries to JDBC subject source causes SQL CAST error

When gsh attempts to call upon a grouper subject source, it first attempts to test the connection by running the search query and supplying it with a dummy subject id. The dummy subject id value is a varchar. The field itself may not be. 

While the field in the WHERE clause can be wrapped in a CAST, it might better to simply modify the query to work with everything.
