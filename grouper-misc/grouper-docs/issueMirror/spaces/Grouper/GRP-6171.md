# GRP-6171  Add UI button to Enable/Disable loader jobs

Please add a button in the UI to Enable/Disable (pause) an individual loader job or ALL loader jobs.

This feature would be useful when an upgrade or other kinds of Grouper maintenance is needed while still allowing the Grouper daemon(s) to continue running other types of jobs.  Perhaps it would also be useful to be able to Enable/Disable other types of jobs as well.
