# GRP-7444  Configurable max file size for grouper_file

Add grouper.properties grouperFile.maxSizeBytes (default 52428800, 50MB, -1 for no limit). GrouperFileDao.store throws a clear error when the file contents are larger than this, instead of storing a value that is slow or fails to read back (postgres bytea / text values have a 1GB hard limit and hex reads double the size; the whole value is held in memory).

Applies to all grouper_file stores (reports, workflow, GSH template download files) and to the upcoming binary contents column.
