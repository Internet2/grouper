# GRP-657  [ldappcng] remove getAllIdentifiers() from DataConnector extension

Remove the getAllIdentifiers() kludge from grouper-shib DataConnector extensions in lieu of something else, perhaps GetAllIdentifierDataConnectors.

## Comments

### tzeller@example.com - 2012-02-23T07:01:32.118+0000

The identifiers of all source objects are now configured for each provisioned object, for example :

<pso id="group" allSourceIdentifiersRef="groupNames" />

where "groupNames" is an attribute definition returning the names of all groups.

See the psp-grouper-source project.
