# GRP-1826  Disable/Enable Loader job

It would be nice to have a checkbox next to each loader job in the Miscellaneous Loaderjobs page to disable/enable a loader job.  Sometimes, things go wrong, or a DB needs to be taken down or whatever, and quickly being able to disable and enable is very handy.

I hope you consider this request useful.
