# GRP-683  ClassNotFoundException org/hsqldb/Session

There is accidentally a reference to hsql in the subject api.  if you dont deploy with the hsqldb.jar, you could get this exception.  To workaround, before you upgrade to 2.0.2, just add the hsqldb jar :)  Or remove the reference from SubjectUtils and recompile
