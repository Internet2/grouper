# GRP-603  [grouper-shib] genericize grouper data connector match filters

Previous to 2.0.0, Grouper DataConnectors supported an optional element which would filter groups returned from a DataConnector. This filter has been genericized to filter other objects in addition to groups, for example, stems or members.

Configuration files will need to be refactored.

The filter element has been renamed from

 <grouper:GroupFilter />

to

 <grouper:Filter />

The

 <grouper:GroupFilter xsi:type="grouper:ExactAttribute" />

filter has been renamed to

 <grouper:Filter xsi:type="grouper:GroupExactAttribute" />

The

 <grouper:GroupFilter xsi:type="grouper:StemName" />

filter has been renamed to

  <grouper:Filter xsi:type="grouper:GroupInStem" />

For example, the following :

  <resolver:DataConnector id="testFilterExactAttribute" xsi:type="grouper:GroupDataConnector">
    <grouper:GroupFilter xsi:type="grouper:ExactAttribute" name="name" value="parentStem:groupA" />
  </resolver:DataConnector>

will need to be refactored to :

  <resolver:DataConnector id="testFilterExactAttribute" xsi:type="grouper:GroupDataConnector">
    <grouper:Filter xsi:type="grouper:GroupExactAttribute" name="name" value="parentStem:groupA" />
  </resolver:DataConnector>
