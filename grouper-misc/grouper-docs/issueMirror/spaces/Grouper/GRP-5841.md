# GRP-5841  add option for qualified and unqualified name in scim

e.g. default is to patch "familyName", (unqualified), if you select "qualified", it will patch "name.familyName".

When implementing a SCIM provisioner, the Grouper admin will either need to read the docs from the target, or will need to try it and if it fails, try the other one.
