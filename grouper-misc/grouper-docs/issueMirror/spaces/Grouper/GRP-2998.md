# GRP-2998  Daemon job page get job links working in new tab

The daemon jobs page has a list of jobs, but to see the logs for a job you need to click on the link. The links only work when you click them directly. If you right click and open in a new tab, it's just another copy of the daemon jobs page. Also applies to the job options in the pull down menus.

## Comments

### Chad Redman - 2024-08-23T16:08:41.860+0000

Working in v5; can copy to v4 if generally works in all browsers. In addition, the daemon job detail page now has a "Daemon job: ..." title like the other pages.

There is a new Grouper JS function handleGuiV2LinkClick(event, url, options) that can be called instead of calling guiV2link(url, options) directly. This will detect right-click or control-click and if so will use the href to open the url directly; otherwise it will use the internal ajax url. If this works, it can be a general solution for other pages where new tabs don't work. Example:
{code}<a href="?operation=UiV2Admin.viewLogs&jobName=${grouper:escapeUrl(guiDaemonJob.jobName)}"
    onclick="return handleGuiV2LinkClick(event, 'operation=UiV2Admin.viewLogs&jobName=${grouper:escapeUrl(guiDaemonJob.jobName)}');">${guiDaemonJob.jobName}</a>
{code}
