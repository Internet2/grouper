# GRP-7407  GSH daemon template fails after UI edit: runAsType/securityRunType hidden for daemon type but still required

GRP-7167 (commit b98645df4771, 2026-08-30) added the showEl {{${templateType != 'provisioner' && templateType != 'daemon'}}} to {{grouperGshTemplate.<id>.runAsType}} and {{grouperGshTemplate.<id>.securityRunType}} in grouper.base.properties. Those fields are now hidden in the GSH template config UI for templateType=daemon, and saving a daemon template in the UI deletes those two keys.

But {{GshTemplateConfig.populateConfiguration()}} still calls {{propertyValueStringRequired}} for runAsType (GshTemplateConfig.java around line 731) and securityRunType (around line 821) for every template type except provisioner.

Result: after editing a daemon template in the UI (e.g. pasting new compiled source), the OtherJobScript daemon fails immediately with: Cant find property: grouperGshTemplate.<id>.runAsType in properties file: grouper.properties, it is required. Seen at Penn on 7.6.0 in prod.

Workaround: re-add {{grouperGshTemplate.<id>.runAsType = GrouperSystem}} and {{grouperGshTemplate.<id>.securityRunType = wheel}} via config import.

Fix: in GshTemplateConfig, treat GshTemplateType.daemon like provisioner for these two fields (runAsType defaults to GrouperSystem, securityRunType not required), or unhide them for daemon in grouper.base.properties.

For the fix, I'd change {{GshTemplateConfig}}, lines 730 and 820, so a daemon is treated like a provisioner. That way a daemon template keeps working without two settings the UI doesn't show. Once you have the GRP number I can make that change in grouper_v7.

Test out a compiled daemon and have a unit test too

## Comments

### Chris Hyzer - 2026-10-04T17:14:31.465-0400

Fixed in GshTemplateConfig.populateConfiguration(): daemon templates are now treated like provisioner templates. They always run as GrouperSystem (daemons run as root) and runAsType / securityRunType are ignored, so a UI save that removes those hidden fields no longer breaks the daemon. securityRunType is set to wheel for daemons instead of being left null.

Test: GshTemplateDaemonTest.testCompiledDaemonWithoutRunAsAndSecurityRunType removes both keys (as a UI save does), checks the config loads as GrouperSystem / wheel, and runs the compiled daemon through OtherJobScript.
