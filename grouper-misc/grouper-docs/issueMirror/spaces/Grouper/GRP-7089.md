# GRP-7089  Build Dropbox Business provisioner for Grouper (groups, members, memberships, admin roles, lifecycle states)

Overview

New Grouper-native provisioner for Dropbox Business, provisioning team groups, team members, and group memberships against the Dropbox Team API (api.dropboxapi.com/2/team/...). Modeled on the TrueFoundry/Datadog provisioners; membershipObjects model.

Scope delivered

- Core CRUD - groups (create/update/delete), members/entities (add/update/remove), memberships (add/remove); matching on externalId (Grouper-set), native ids (group_id/team_member_id) carried for selectors.
- Admin-role overlay - the 8 built-in Dropbox admin tiers driven from a configured folder of marker groups; highest tier wins; set_admin_permissions_v2.
- Lifecycle overlay - member states sourced from one lifecycle folder of marker groups: Suspended (members/suspend/unsuspend) and Downgrade (on deprovision, convert to a free Basic account via members/remove keep_account=true, setting an alumni/forwarding email first from a configured subject attribute). Default paths remain active-member and full-delete.
- Edge cases - recover-on-re-add within the 7-day window (members/recover), and invited-but-not-accepted downgrade fallback (409 cannot_keep_invited_user_account ‚Üí plain delete).
- OAuth2 auth - supports a static bearer token or, recommended, an app-key/secret/refresh-token config; short-lived (4h) access tokens are minted and cached (refreshed ~5 min before expiry) with no daemon.
- Sync-back - captures target state into grouper_prov_group/_user/_mship; memberships write-tracked on add/remove plus read-populated on full sync.
- Registrations/config/docs - Hib3DAO mappings, ProvisioningConfiguration registration, MockServiceServlet route, grouper-loader.base.properties + textNg entries, mock service handler, and HTML docs (external system doc current).
- Tests - API-level CRUD, full + incremental sync, group/membership-only, admin-role overlay, lifecycle suspend + downgrade, recover, invited fallback, refresh-token auth, sync-back full/incremental, native-sync unit.
