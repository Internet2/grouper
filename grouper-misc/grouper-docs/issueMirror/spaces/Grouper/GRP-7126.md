# GRP-7126  Visualizations should support a list of folder roots ( and all sub folders below those roots) to ignore and/or be limited too..

Using :test and :users folders can lead to lots of noise in visualizations. Due to "testing" and other "one off" things.

It would be helpful if visualizations could ignore a list of folders to focus what is visualized.

It might also be helpful to add a "only in this folders" list too. 

But both features should be implemented independently. Some times you know you only want to look in "app" and other times you don't know where you want to look. While still knowing you want to exclude :test and :users too.
