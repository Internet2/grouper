# GRP-6147  Add an option to the TDX Provisioner to set the isNotified value on group membership

Currently the TDX provision ignores the isNotified attribute for group memberships and it defaults to false.  It would be nice if there was to specify what this value should be set to.  The current ask is that some groups should have it set to true, while others have it set to false, and that it would be set the same for all members of the group.

This should be done in 4.x as well as 5.

https://tdx.cornell.edu/TDWebApi/Home/section/People#PUTapi/people/\{uid}/groups/\{groupID}?isPrimary=\{isPrimary}&isNotified=\{isNotified}&isManager=\{isManager}
