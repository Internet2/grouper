# GRP-7396  Provisioner labels for translation script don't document all object fields

The label for group translationScript groupProvisioningGroup reads:

{{grouperProvisioningGroup (ProvisioningGroup.java): this is the Grouper representation of the group. Fields include: id, idIndex, name, displayName. Attributes include: description.}}

But extension and displayExtenion are also usable fields. Also, description is a field, even though it’s mentioned as an attribute.

Similarly for provisioning entity: {{Fields include: email (needs configuration), id, loginId (needs configuration), name, subjectId. Attributes include: subjectSourceId, description, subjectIdentifier0.}}

  Valid ProvisionEntity fields not listed in the label:

* idIndex
* subjectIdentifier (the generic one that resolves to whichever of 0/1/2 is configured)
* subjectIdentifier1
* subjectIdentifier2
* internalId
* subjectResolutionResolvable
