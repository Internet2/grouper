# GRP-7163  Bump bundled Tomcat to 9.0.120 to clear open 9.0.118 CVEs

The Grouper container (v7) bundles Apache Tomcat 9.0.118, which has 8 open CVEs as of the latest release: one Moderate (CVE-2026-55956) and seven Low, all fixed in 9.0.119 and 9.0.120. The higher-severity EncryptInterceptor issues from earlier in 2026 (CVE-2026-29146, CVE-2026-34486) were already fixed in 9.0.117.

Fix: bump TOMCAT_VERSION from 9.0.118 to 9.0.120 in the container Dockerfile. Verified that stock conf/server.xml is byte-identical between 9.0.118 and 9.0.120 (and matches the container reference original), so the runtime server.xml.grouper.patch still applies cleanly (patch dry-run exit 0) and container startup will not fail. The 9.0.120 tarball is present on the Internet2 software mirror.
