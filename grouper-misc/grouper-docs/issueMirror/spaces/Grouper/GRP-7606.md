# GRP-7606  Add attribute definition privileges to the MCP privilege_get and privilege_assign tools

privilege_get and privilege_assign in the Grouper MCP server only handle group (access) and folder (naming) privileges. They cannot read or change privileges on an attribute definition: attrAdmin, attrRead, attrUpdate, attrView, attrOptin, attrOptout, attrDefAttrRead and attrDefAttrUpdate.

Without these, after an attribute definition is created (see GRP-7604) there is no MCP way to let a service's readers see the attribute values or let its updaters assign them, so that step still needs the UI or GSH.

Extend privilege_get and privilege_assign with an attribute definition privilege type (or add attribute def privilege tools). Follow the existing MCP conventions: readwrite scope checks, privilege checks, tests, servlet registration and the MCP wiki documentation.
