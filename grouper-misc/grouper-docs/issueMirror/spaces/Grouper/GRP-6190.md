# GRP-6190  TeamDynamix Provisioner uses 'name like' search, throws exception if names are equal

The issue seems to be that the name of the group that Grouper is searching TDX for doesn't exactly match the name of the group in TDX.
 
The log shows the group search call that Grouper is doing:
 
{code:java}
HTTP URL: https://tdx.umsystem.edu/SBTDWebApi/api/groups/search
HTTP request header: Authorization: *
HTTP request header: Content-Type: application/json
HTTP request body: {"IsActive":true,"NameLike":"UM Employees"}{code}

 
And then we see the response:
 
{code:java}
[{"ID":388,"Name":"UM Employees GRPR","Description":"UM Employees GRPR","IsActive":true,"ExternalID":"","CreatedDate":"2025-03-27T21:32:57.31Z","ModifiedDate":"2025-04-04T07:35:03.043Z","PlatformApplications":[]}]{code}

 
Where the Name is really UM Employees GRPR.
 
So the search is doing a name like search, and then the code is doing a name equals check:
 

TeamDynamixApiCommands Lines 746-756:
{code:java}
while (iterator.hasNext()) {

}
return groups.get(0);{code}
