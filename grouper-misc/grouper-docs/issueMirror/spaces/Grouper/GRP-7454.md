# GRP-7454  grouperClient: stop publishing bin.zip and bin.tar.gz to reduce Maven Central release size

Maven Central now enforces a monthly Release Size limit (80 MB/month for Internet2). A full Grouper release is about 95 MB. The grouperClient assembly publishes both grouperClient-VERSION-bin.zip (11.7 MB) and grouperClient-VERSION-bin.tar.gz (10.2 MB) with identical contents.

Change: grouper-misc/grouperClient/src/main/assembly/bin.xml now builds only the zip format. Saves about 10 MB per release. Nothing in the Grouper source or container build consumes the tar.gz.
