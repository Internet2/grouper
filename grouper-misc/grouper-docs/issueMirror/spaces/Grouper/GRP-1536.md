# GRP-1536  Group configuration option to restrict types of memberships in the group.

It would be helpful if a group could have an attribute that would restrict the type of members in the group to be either;

)   Individual or Group ( The current default, and likely the future default)
)   Groups only
)   Individuals only

This attribute of the group likely would need to be protected by the Admin privilege to be changed/set for the group.
