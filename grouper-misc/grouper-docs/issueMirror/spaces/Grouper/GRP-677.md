### tzeller@example.com - 2011-10-28T01:19:19.778+0000

Looks like a xerces version issue. The version of xerces we want is from the shibboleth dependency. Excluding older versions of xerces from grouper-parent dependencies seems to be the solution.

grouper-parent/pom.xml :

      <dependency>
        <groupId>commons-dbcp</groupId>
        <artifactId>commons-dbcp</artifactId>
        <version>1.2.1</version>
        <exclusions>
          <exclusion>
            <groupId>xerces</groupId>
            <artifactId>xerces</artifactId>
          </exclusion>
        </exclusions>
      </dependency>

      <dependency>
        <groupId>xom</groupId>
        <artifactId>xom</artifactId>
        <version>1.1</version>
        <exclusions>
          <exclusion>
            <groupId>xerces</groupId>
            <artifactId>xercesImpl</artifactId>
          </exclusion>        
        </exclusions>
      </dependency>

### Lawrence Klug - 2011-11-03T14:21:25.313+0000

Tom Z pointed out the version conflict.  Resolved issue by changing Xerces 2.7.1 to Xerces 2.10.0 with scope "compile" in the POM:
<dependency>
<groupId>xerces</groupId>
 <artifactId>xercesImpl</artifactId>
 <version>2.10.0</version>
 <scope>compile</scope>
 </dependency>
GRP-677 can be closed.
