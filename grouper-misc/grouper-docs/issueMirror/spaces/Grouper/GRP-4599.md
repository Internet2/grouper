# GRP-4599  Provisioner needs case-insensitive search/match option

If your subject ID or identifier is upper case in LDAP but lower case in Grouper (e.g. subject property SubjectID_formatToLowerCase.value is true), it is able to find records in LDAP, does retrieve the ldap_dn, but then doesn't act on it since it doesn't act on it since it's not a case-sensitive match. It doesn't fail in a helpful way - it just quietly does nothing in the provisioner with no errors.

There should be a checkbox to make the match be case-insensitive, so the records get acted on.
