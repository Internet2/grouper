# GRP-1362  PSPNG-Recover from LDAP Connections dying in pool

LDAP connections are not being tested and rebuilt properly when idle-out or otherwise break while checked into the connection pool.

Connection testing and recovery should be enabled by default, but configuration values should allow additional configuration of the ldap pools as ldaptive allows.
