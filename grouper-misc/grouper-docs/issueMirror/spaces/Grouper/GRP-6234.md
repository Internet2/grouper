# GRP-6234  grouper.properties grouperQuerySubjectsMultipleQueriesCommaSeparated not documented

The grouper.properties value for grouperQuerySubjectsMultipleQueriesCommaSeparated governs whether a comma in a search string returns the results from multiple queries. The property is missing from grouper.base.properties, so it's not generally known that this is something that can be set
