## Comments

### Shilen Patel - 2020-08-21T11:43:41.769+0000

Composite issues that were previously handled nightly be default will be handled pretty quickly now (about a minute).

This does not take care of all issues that are handled by bad membership finder (e.g. group set issues).  So the large nightly job is still needed.  This would be a future improvement although currently the change log consumer wouldn't have access to all the data to do this reliably all the time.  Another possible future improvement would be to make sure this change log consumer doesn't run while the nightly fix is running.
