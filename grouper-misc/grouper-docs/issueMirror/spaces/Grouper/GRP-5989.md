# GRP-5989  New installs include the jdbc example in subject.properties

 

The example file grouper/misc/subject.example.properties includes the jdbc sample adapter, uncommented. The installer takes all the *.example.properties files, removes .example, and puts them into WEB-INF/classes. This means everyone will have the jdbc example source, unless they have their own subject.properties file to replace the file. Since users are moving more to database configs, they will be less likely over time to have a file-based property file.
