# GRP-5744  add "days before to email" for attestation.  default to a global config which defaults to 0

After "Send email" if that is Yes, then have a new field (and attribute).

Label: Send email early by days
Description: If the 'Days until recertify' is the limit of when the group should be recertified, and the emails should start before that date, then start sending emails and allow the group to be recertified early by this number of days.  If the group is not auto-disabling, then this defaults to 0, if the group is auto-disabling, then this defaults to 14 (two weeks).
