# GRP-2295  Daemon: OtherJob stayed scheduled and enabled

I commented out an otherJob (incremental loading) from the grouper-loader.properties and restarted my daemon container. Unfortunately, the job remained scheduled and removed thousands of memberships.

I would expect that all daemon jobs created via .properties file would be removed when no longer mentioned in the properties.

I think something similar happens for loader jobs when the loader-job groups no longer exist and for changelog subscribers when they are cleaned up. But, if this doesn't already happen, it should, too.

 

Thanks, Bert
