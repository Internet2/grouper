# GRP-7411  Failsafe should report on groups triggering the failsafe

If a provisioner (maybe a loader too) triggers because one or more groups lost too many members, the job log doesn’t report on which groups caused the trigger. You need to somehow get the answer from SQL queries or spot checking the groups.

If it’s triggered by global delta, maybe it’s hard to report on specific groups. But if the settings are to trigger on deltas per group and that gets triggered, it would be helpful to know which groups to look at.
