# GRP-1350  Exception if subject identifier is updated to null

I think if you're attaching params and a value is null, the wrong thing is done.  Though it doesn't matter unless the last param is null.  In which case, you get this.  I'm not sure if this is a bug in hibernate or a bug in how we're using this part of the hibernate api.
