### Gary Brown - 2010-07-22T07:50:16.466+0000

ErrorFilter.initNDC actually does this but you have to use an appropriate 'pattern', including %x to output it. The log4j,properties.template that comes with the UI has this pattern:
log4j.appender.grouper_log.layout.ConversionPattern   = %d{ISO8601} %5p %c{2}: %x %m%n

You have to have 'use.local.log4j=true' in build.properties
