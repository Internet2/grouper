# GRP-7605  Add MCP tools to delete attribute definitions and attribute def names

The Grouper MCP server has no way to delete an attribute definition or an attribute def name. GRP-7604 covers finding, creating and updating them; this covers removal.

Add MCP tools (or actions on the GRP-7604 tools) to delete an attribute def name and to delete an attribute definition. The response should say what else goes with it, for example the assignments that use the name and the names under the definition, since deleting a definition or name also removes its assignments and values. Follow the existing MCP conventions: readwrite scope checks, ATTR_ADMIN privilege checks, tests, servlet registration and the MCP wiki documentation.
