# GRP-7176  External system test button logs nothing and hides the root cause of issues

This was found in Entra, but any external system should log the stack as error.

When configuring an Azure/Entra external system with certificate authentication and clicking the test button in External Systems, a failure shows only the generic message 'Unable to retrieve Azure authentication token: Error building client_assertion JWT for azure config <id>' with no indication of the underlying cause, and NOTHING is written to the Grouper logs.

Root cause in edu.internet2.middleware.grouper.app.azure.AzureGrouperExternalSystem (grouper/src/grouper/edu/internet2/middleware/grouper/app/azure/AzureGrouperExternalSystem.java):

1. test() (around lines 149-155) catches the exception and only does ret.add('Unable to retrieve Azure authentication token: ' + e.getMessage()). The class has no logger at all, so nothing is logged.

2. The exception surfaced is the outer wrapper RuntimeException('Error building client_assertion JWT for azure config ' + configId, e) thrown around line 260. e.getMessage() is only that generic wrapper string; the real cause (e.g. 'Unrecognized PEM header in private key', 'Encrypted private key not supported', a certificateThumbprint hex parse error, or a Base64 decode failure in loadRsaPrivateKeyFromPem) is in getCause() and is neither shown in the UI nor logged.

3. retrieveBearerTokenForAzureConfigId already builds a full stack trace via debugMap.put('azureTokenError', GrouperUtil.getFullStackTrace(re)) around line 313, but test() passes a throwaway new HashMap() (line 151) and never reads it back, so that detail is discarded too.

Impact: cert-auth misconfigurations (bad private key PEM, encrypted key, wrong thumbprint) are effectively undiagnosable from either the UI or the logs.

Suggested fix: add a logger to the class and LOG.error the throwable in test()'s catch; include the full cause chain (GrouperUtil.getFullStackTrace(e) or unwrap getCause()) in the returned message; and/or read back the debugMap that test() already passes into retrieveBearerTokenForAzureConfigId and surface azureTokenError.
