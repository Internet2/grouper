# GRP-5827  Add icon configuration to the UI subject source editor

Custom icons for subject sources can be set through grouper-ui.properties. These could be surfaced in the subject source editor for easier setup. If there are multiple subject sources in an environment, it helps visually if they have different icons.

{code}
grouperUi.screenSubjectIcon2.sourceId.1 = demoService
grouperUi.screenSubjectIcon2.screenHtmlEl.1 = ${'<i class="fa fa-cubes"></i> '}
{code}

There could be a font-awesome icon picker to help. Or they could be set manually, if more complex jexl is used (maybe different icons depending on an attribute)
