# GRP-7097  Accessibility: make button icon match black button text

The Font Awesome icon inside primary/warning buttons (e.g. the "+" on "Add to a group") was still forced white by a bootstrap rule after the button text was darkened to black, leaving the icon low-contrast. Recolored the icon to black to match the label.
