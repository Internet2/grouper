# GRP-6935  Document SQL batching and DDL comment conventions in CLAUDE.md

* Add SQL Batching section: prefer {{GcDbAccess.batchBindVars(...).executeBatchSql()}} over per-row {{executeSql()}} loops; only fall back to row-by-row after explicit discussion
 * Add DDL Comments section requiring {{COMMENT ON TABLE/VIEW/COLUMN}} for any new table, column, or view in postgres and oracle install SQL (MySQL does not support {{{}COMMENT ON{}}})
 * Document the postgres-vs-oracle view comment syntax difference ({{{}COMMENT ON VIEW{}}} vs {{{}COMMENT ON TABLE{}}}) and the corresponding {{GrouperDdlUtils.isPostgres() ? "VIEW" : "TABLE"}} pattern in Java upgrade tasks
