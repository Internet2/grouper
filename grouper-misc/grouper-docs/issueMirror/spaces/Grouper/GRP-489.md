# GRP-489  Admin UI 'Act As' permanent preference

It would be nice if we could set a permanent preference in the Admin UI for whether we start in "Act As Self" or "Act As Admin" mode.  Being a grouper admin, it is extremely rare to not be working in admin mode and it would be nice if I didn't have to set admin mode every time I enter the application.
