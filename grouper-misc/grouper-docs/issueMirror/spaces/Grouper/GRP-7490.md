# GRP-7490  Provisioning sync-back: let the target DAO filter objects reconstructed from the cache

The sync-back mirror (grouper_prov_user, grouper_prov_group, grouper_prov_mship) is the full view of the target. When fullSyncUsersFromSyncBack / fullSyncGroupsFromSyncBack / fullSyncMembershipsFromSyncBack serves a full sync from that cache, the reconstructed objects skip the filtering a provisioner applies on a live retrieve (ignore lists, treating disabled or deactivated accounts as absent), so the cache-served run can disagree with a live run.

Add filterTargetEntitiesFromSyncBack, filterTargetGroupsFromSyncBack and filterTargetMembershipsFromSyncBack to GrouperProvisionerTargetDaoBase (default: no filtering) and call them on the reconstructed objects before they enter the compare, so a provisioner can apply the same logic whether the target data comes from the target or from the cache. The mirror itself keeps the filtered objects. First user: the Smartsheet provisioner (GRP-7489).
