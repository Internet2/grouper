# GRP-2276  Add new JIRA status "Ready for Release" or similar

Currently in Jira there are only a few common status options – To Do, Open, In Progress, Resolved, Done, and Closed. We normally put an issue in the Resolved state when it's in a patch or the master branch for the next version. This makes it hard to track when a change has completed work, is ready to go into a patch, but the patch hasn't been made yet. The option for now is to leave things in the In Progress state, but then it's hard to separate at a glance which issues are still being worked on. If there were another status like "Ready for Release" (or Awaiting Release, and other options), it would be easier to keep track of.
