# GRP-6850  deprecated CompositeSave wrapper missing getSaveResultType() method

When GRP-5608 consolidated the two CompositeSave classes, the deprecated wrapper at edu.internet2.middleware.grouper.group.CompositeSave was converted to delegate to edu.internet2.middleware.grouper.CompositeSave. However, the getSaveResultType() method was not carried forward as a delegation method. This causes a NoSuchMethodError for any code referencing the deprecated class and calling getSaveResultType(). Also updated three internal references (XmlExportMain, GraphSampleData, loadGraphSampleData.groovy) to use the canonical class instead of the deprecated wrapper.
