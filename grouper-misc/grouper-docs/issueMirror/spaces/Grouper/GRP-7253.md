# GRP-7253  Upgrade ldaptive to 2.5.1

Upgrade the ldaptive dependency from 2.4.2 to 2.5.1 (ldaptive.version in grouper-parent/pom.xml, the only place the version is declared). 2.5.1 is the current release on maven central. Note the central solr search index is stale and still reports 2.4.1 as newest; maven-metadata.xml is correct.

Picks up netty 4.1.135 to address netty CVEs. Grouper does not pin netty, so it comes in transitively through ldaptive.

API compatibility was checked by diffing the public signatures of every class in the 2.4.2 and 2.5.1 jars against the org.ldaptive types Grouper references. No classes were removed. Four were added (AbstractResponseControl, schema.NamedElement, SchemaElementFormatter, SchemaElementRegistry). Response controls now extend AbstractResponseControl and lost their setters, PasswordPolicyControl constructors changed shape, and AgePruneStrategy priority / setPrunePriority moved from long to int. Grouper does not use any of those directly - the prune strategy is configured with a property string rather than the builder - so nothing failed to compile.

One removal does affect Grouper: Result.ENCODE_CNTRL_CHARS and the org.ldaptive.response.ENCODE_CNTRL_CHARS system property are gone in 2.5, and control characters are now percent-encoded unconditionally. Handled separately - see the linked issue for removing the now dead ldaptiveEncodeControlChars config.

Behavior change worth knowing about on upgrade: 2.5 added argument assertions to LdapUtils (assertNotNullArg and friends), so an ldap external system with a blank org.ldaptive.ldapUrl now fails immediately at connection pool creation with an IllegalArgumentException reading that urls cannot be null or empty, instead of surfacing later as a connection failure. LdaptiveConfiguration.createPooledConnectionFactory deliberately tolerates a blank url, so the failure comes out of ldaptive rather than as a Grouper config message. The error is clearer than what 2.4.2 produced, but it moves earlier and will be seen by anyone whose ldap config is incomplete.
