# GRP-2722  Remove daily.report.usdu.daysToRun and daily.report.badMembership.daysToRun options from grouper loader config

We're removing two options from the grouper loader config.

daily.report.usdu.daysToRun was being ignored already.  USDU stats will continue to be included in the Grouper Report.

Bad membership finder will no longer run as part of the Grouper Report.  Note that all it was doing was reporting on the issue but not fixing it.  There's another daemon job that runs every day by default and fixes issues as well.  And if it's unable to fix any memberships, the status of the job becomes ERROR and that is visible in the All Daemon Jobs page and is also indicated as a failure in the diagnostics/status page.  The schedule for that job can be changed using the config otherJob.findBadMemberships.quartzCron.
