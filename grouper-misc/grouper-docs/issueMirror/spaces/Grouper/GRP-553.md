# GRP-553  grouper api subjectfinder and subjectresolver adjust "type"

-----Original Message-----
From: Chris Hyzer 
Sent: Sunday, February 06, 2011 11:50 PM
To: grouper-dev
Subject: grouper api subjectfinder and subjectresolver

Hey,

When we designed WS we simplified subject searches to:

Id
Identifier
Id/source
Identifier/source
IdOrIdentifier
IdOrIdentifier/source

Originally in the grouper API you could put subject type in there too.  I'm fixing some caching issues and I would like to deprecate the subjectfinder methods that use type, delete the subject resolver methods that use type,  and standardize on the above possibilities.  I would think you would only disagree if you are using the API directly and you have subject sources with the same Id but different type...  So... Anyone object?

Thanks,
