# GRP-6933  OAuth consent readwrite folder/group/subject input only splits on commas, not whitespace/newlines

* The OAuth consent screen for MCP read-write scope ({{/UiV2OAuth.authorize}}) accepts folders, groups, and subjects in three input fields
 * The server splits the input on commas only ({{{}UiV2OAuth.splitAndTrimNonEmpty{}}})
 * Pasting a list separated by spaces or newlines results in the entire string being treated as one folder/group/subject and failing with "Folder not found: <whole concatenated string>"
 * Fix: also split on whitespace and newlines so paste-from-list works without manual reformatting
 * Update field help text to make accepted delimiters explicit
