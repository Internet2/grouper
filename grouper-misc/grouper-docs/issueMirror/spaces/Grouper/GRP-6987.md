# GRP-6987  Fix ldapConvertLDAPMemberDnToSubjectIdOrGroup truncating domain suffix and not escaping search filter

* Previously the domain suffix was chopped off because the LDAP URL allowed the base DN to be specified (e.g. {{{}ldaps://ldap.example.edu/dc=example,dc=edu{}}}); that form is no longer supported, so the baseDN is now the DN of the group members.
 * Use {{FilterUtils.escape}} to escape special characters in the LDAP search filter.
 * File: {{grouper/src/grouper/edu/internet2/middleware/grouper/util/GrouperUtil.java}}.
 * Contributed by mshaher ({{shaher@example.com}}, UCBoulder) on GROUPER_6_BRANCH; cherry-picked to GROUPER_7_BRANCH.
