# GRP-5563  Improve public API for GrouperProvisioningService.retrieveAssignments()

As far as I can tell, this method the most accurate way to get the actual provisionable groups and folders, since it relies on attributes and not the sync tables which are only populated after the provisioner runs. To improve:

 
 * Don't return Object[]. At least return String[], so everybody doesn't need to cast to strings
 * Put the sort into the query; don't need a separate compare closure for this
 * Don't use a StringBuilder for a basic string
 * Create another version of this that returns a list of some new class, so users don't need to look up everything from the object name and the provisioner name. The class would have:
 ** GrouperObject (look up the group/folder by name)
 ** GrouperObjectGrouperProvisioningAttributeValue (provisioner name is already passed into the method, so look it up)
