# GRP-2264  Attestation UI doesn't show correct date to recertify and email info

For non-report attestation where the attestation config is on a folder, set the following config:

 

Use default recertify days      No, use custom recertify days

Days until recertify    30

 

Now if you view a group in that folder, the UI shows incorrect information:

 

Date needs recertify    2020/02/02

Use default recertify days      Yes, use default recertify days (180 days)

 

Similar issue with whether emails are sent and if they are sent to a custom list of addresses.
