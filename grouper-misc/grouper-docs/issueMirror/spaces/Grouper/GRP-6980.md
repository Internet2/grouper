# GRP-6980  User-facing validation errors for nativeAttributesEntities/Groups config parse failures

* Introduce {{NativeAttributeConfigException}} (nested in {{{}GrouperProvisioningNativeAttributeConfig{}}}) carrying an i18n {{textKey}} plus named args. Replace eight inline {{RuntimeException}} throws in {{parseAndValidate}} with structured codes: {{{}csvLooksLikeJson{}}}, {{{}csvDuplicateName{}}}, {{{}invalidJson{}}}, {{{}notArray{}}}, {{{}entryNotObject{}}}, {{{}missingName{}}}, {{{}duplicateName{}}}, {{{}invalidType{}}}.
 * {{GrouperProvisioningConfigurationValidation.validateNativeAttributesField}} catches the typed exception and renders the user-facing message via {{{}provisioning.configuration.validation.nativeAttributes.<textKey>{}}}, substituting {{$$configLabel$$}} from the field's own localized label key plus any named args. Errors are pinned to the field via jqueryHandle so the UI highlights the bad textarea.
 * Eight new i18n keys in {{{}grouper.textNg.en.us.base.properties{}}}.
 * New {{GrouperProvisioningNativeAttributeConfigTest}} covering each typed error code plus the English-fallback path and the render-message helper.
