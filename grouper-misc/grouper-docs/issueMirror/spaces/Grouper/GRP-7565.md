# GRP-7565  AWS v1 jars deprecated

AWS SDK for Java 1.x (aws-java-sdk-* JARs) is deprecated and officially reached End-of-Support on December 31, 2025. These legacy libraries no longer receive security patches, bug fixes, or feature updates, and projects should migrate to AWS SDK for Java 2.x.

*Key Changes When Migrating to v2*

* *Maven Coordinates and Packages.* Update group IDs and package imports from {{com.amazonaws}} to {{software.amazon.awssdk}}.
* *Client Instantiation.* Replace v1 client builders (such as {{AmazonS3ClientBuilder}}) with v2 builders (such as {{S3Client.builder()}}) and explicitly close clients when finished.
* *Method Naming and Immutability.* Request and response objects are immutable in v2. Builder methods drop {{with}} and {{set}} prefixes, getters drop {{get}}, and response classes end in {{Response}} instead of {{Result}}.
* *Side-by-Side Execution.* Both v1 and v2 JARs use separate package namespaces. You can run them in the same application to migrate incrementally.
