# GRP-2694  add env var to switch to maturity level 0 logging

In a future version we would like an env var to switch to lof4j file so people do not need to overlay and so we can control the configuration internally on upgrades (we could add a section).

So if people pass in

GROUPER_LOG_TO_HOST=true

Then copy 

/opt/grouper/grouperWebapp/WEB-INF/classes/log4j.grouperContainerHost.properties

to

/opt/grouper/grouperWebapp/WEB-INF/classes/log4j.properties
