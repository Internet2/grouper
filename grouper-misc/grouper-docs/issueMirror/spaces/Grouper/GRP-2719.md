# GRP-2719  Restrict access to diagnostics/status page

Will probably add more options but initially can set a new property to restrict by ip in grouper.properties:

 

ws.diagnostic.sourceIpAddresses   (default is send everywhere)

 

And there's also an option now to avoid sending details in the response:

 

ws.diagnostic.sendDetailsInResponse   (default is true)
