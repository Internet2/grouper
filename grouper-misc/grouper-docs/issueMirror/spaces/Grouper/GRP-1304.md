# GRP-1304  delete membership from UI has major performance problem

Remove a user in Oracle with a large database and get a timeout.  Eventually it will complete but the user waits more than a minute and get an error since ajax timed out.

## Comments

### mchyzer - 2016-05-25T20:24:33.343+0000

discussed with shilen, the problem is membership.uuid in (x), since uuid is a concat of two fields and causes a full table scan: AS select ms.id || ':' || gs.id as membership_id ....

change from:

(membership1_.membership_id in ('9ba6717e88994e1fa9094c2a95a2f3c1:44cb710cfe1c44bfb6241733c3dd4ef2'))

to:

SELECT COUNT (*) AS col_0_0_
  FROM grouper_members member0_
       CROSS JOIN grouper_memberships_all_v membership1_
       CROSS JOIN grouper_groups group2_
       CROSS JOIN grouper_fields field3_
 WHERE     membership1_.owner_group_id = group2_.id
       AND membership1_.member_id = member0_.id
       AND membership1_.field_id = field3_.id
       AND field3_.TYPE = 'list'
       AND MEMBERSHIP1_.IMMEDIATE_MEMBERSHIP_ID = '9ba6717e88994e1fa9094c2a95a2f3c1'
       and MEMBERSHIP1_.group_set_id = '44cb710cfe1c44bfb6241733c3dd4ef2'
