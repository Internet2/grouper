# GRP-5867  Google provisioner - add option for whoCanModerateMembers

Group permissions in the Google API ([https://developers.google.com/admin-sdk/groups-settings/v1/reference/groups#resource)] are deprecated. Two of these are permission options in the provisioner UI.
 * whoCanInvite (used in provisioner)
 * whoCanAdd (used in provisioner)
 * whoCanApproveMembers
 * whoCanBanUsers
 * whoCanModifyMembers

For all of these, the recommendation is to use whoCanModerateMembers. This isn't an option in the new provisioner, but it was an option in the legacy googleapps provisioner (see GRP-2870).
