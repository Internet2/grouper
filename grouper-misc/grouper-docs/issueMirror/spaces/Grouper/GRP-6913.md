# GRP-6913  TrueFoundry provisioner: default role configs not exposed in UI wizard

The {{trueFoundryDefaultRole}} and {{trueFoundryDefaultRoleResourceType}} config properties are read by {{TrueFoundryProvisionerConfiguration}} and have externalized labels/descriptions in {{{}grouper.textNg.en.us.base.properties{}}}, but they were never declared in {{grouper-loader.base.properties}} with the metadata annotations the UI config wizard uses to render fields.

As a result, these options did not appear in the provisioner configuration wizard and could only be set by editing the raw config in the database or properties file directly.

Added the metadata declarations for both properties (order 27 and 28, after the SCIM fields) so they render in the UI with the existing externalized labels and defaults ({{{}read-only-member{}}} and {{{}account{}}}).
