# GRP-7028  GSH Java template compilation — compiled daemon dispatch via OtherJobScript

* Phase 7 (daemon). Builds on the foundation ticket and GRP-7010/7011. Design doc {{grouper/temp/trash/gshCompileImprovement.html}}.
 * Add a {{scriptType=compiledJava}} branch in {{OtherJobScript.run()}} alongside the existing {{{}sql{}}}/{{{}gsh{}}} branches (~lines 98–161). Read the template config id from a new property {{{}otherJob.\{jobName}.gshTemplateConfigId{}}}; resolve via the shared {{GshTemplateCompiledDispatch}} helper, cast to {{{}GrouperTemplateDaemon{}}}.
 * Build the input: {{OtherJobTemplateInput in = new OtherJobTemplateInput(); parentOtherJobInput.copyFieldsTo(in);}} then set {{gshTemplateConfigId}} + resolved {{{}GshTemplateConfig{}}}; call {{{}runDaemon(in){}}}.
 * Errors propagate to {{{}OtherJobBase{}}}, which records status/exception on the {{hib3GrouperLoaderLog}} — same as the existing script paths.
 * Config metadata: add {{compiledJava}} to the {{scriptType}} dropdown {{optionValues}} in {{{}GrouperDaemonOtherJobScriptConfiguration{}}}, and the new {{gshTemplateConfigId}} property shown when {{{}scriptType==compiledJava{}}}. Externalized label/description in {{grouper.textNg.en.us.base.properties}} only.
 * Tests: a compiled daemon fires via the bridge, runs {{{}runDaemon{}}}, records success on the loader log; wrong base → clear error; a thrown exception marks the log row failed.
