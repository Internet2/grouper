# GRP-7161  Include public Grouper wiki docs on disk in the Grouper container

The Grouper container build now copies the public Grouper wiki documentation (markdown) into the image so it is present on disk in the running container for reference and doc search.

The docs already ship in the grouper source tree that the container build checks out, under grouper-misc/grouper-docs/wikiMirror/spaces/Grouper, so this is just a local copy at build time -- nothing extra is downloaded and it does not touch the Dockerfile. The install script (containerDockerfileInstallGrouper.sh) copies that folder into the staged container tree at grouper/docs/wiki/Grouper, which the final image stage maps to /opt/grouper/docs/wiki/Grouper.

Only the public Grouper space is included; internal-development spaces are left out. Adds roughly 9 MB uncompressed to the image (a few MB to the pulled layer, since it is markdown). The build hard-fails if the source docs are missing or the copy produces no files, so an image never silently ships without docs.
