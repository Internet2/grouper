# GRP-5726  GrouperProvisioningJob shows config error and needs to be removed from config

this is a minor issue.  there is a daemon configured which doesnt exist anymore, if you want to remove the false error from the status page:

add this to grouper.properties:
{code:java}ws.diagnostic.ignore.loader_OTHER_JOB_grouperProvisioningDaemon = true {code}
