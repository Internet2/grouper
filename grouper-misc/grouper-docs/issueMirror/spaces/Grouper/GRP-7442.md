# GRP-7442  GcDbAccess lifecycle hook GcDbAccessLifecycle (dbPreStore / dbPreDelete) like hibernate onPreSave

Add a lifecycle hook to GcDbAccess object persistence, like the Hibernate onPreSave / onPreUpdate / onPreDelete callbacks in GrouperAPI. New interface GcDbAccessLifecycle with dbPreStore(boolean isInsert) and dbPreDelete(). GcDbAccess calls dbPreStore after it decides insert vs update and before it reads the field values, so changes the bean makes are persisted, and calls dbPreDelete before the delete.

This lets beans that move off Hibernate (e.g. GrouperFile in GRP-7440) set context_id and created / updated timestamps themselves instead of every DAO doing it. Classes that do not implement the interface behave exactly as before.
