# GRP-592  real-time incremental provisioning

LDAPPCNG should support incremental provisioning in real-time, for example, "add member M to group G". This should include object renaming.

## Comments

### tzeller@example.com - 2011-10-05T13:46:00.184+0000

Added support for SPML search requests containing "hasReference" query clauses. These hasReference searches, e.g. an ldap filter of the form (member = cn=rdn,dc=edu), will be useful when determining when add or delete member operations should be performed.

### tzeller@example.com - 2012-02-22T21:14:24.076+0000

Limited real-time provisioning will be available as of 2.1.0.
