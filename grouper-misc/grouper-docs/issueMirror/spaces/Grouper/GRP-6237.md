# GRP-6237  JDBC subject sources should return all subjects when query is blank

This can be improved to return all subjects from the table when the query is blank.

edu.internet2.middleware.subject.provider.JDBCSourceAdapter2.searchHelper()
{code}    //if there is nothing, what are we searching on?
    if (StringUtils.isBlank(searchValue)) {
      throw new RuntimeException("You need to supply a search value: '" + searchValue
          + "'");
    }
{code}
 

The JDBC subject source queries the lower search column with prefix and suffix wildcards. It could just skip the where clause if the query is blank
