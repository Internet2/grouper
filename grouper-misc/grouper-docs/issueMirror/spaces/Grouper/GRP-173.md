# GRP-173  Composites don't work correctly when type is intersection or complement and factors have memberships with a depth greater than 0

When you have a composite group of type intersection or complement and a membership is added to a factor that has a depth of greater than 0, the composite membership may be added when it should not OR the composite membership may not be added when it should.  The code just assumes that the composite type is a union actually and doesn't take into account that it might be a complement or intersection.
