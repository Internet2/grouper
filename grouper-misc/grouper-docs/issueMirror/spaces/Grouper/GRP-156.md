# GRP-156  Issues with membership deletes

I've found some issues today where deleting immediate memberships does not always do the right thing in terms of deleting effective memberships.  I'll add more details of the issues when I have a chance to further dive into the problems.  

I've assigned this issue to the 1.4.0 release rather than the 1.3.1 release since it doesn't seem like a critical issue at the moment (nobody else has reported the problem yet).  But if this needs to be resolved in 1.3.1 we can certainly aim for that.

## Comments

### shilen - 2008-10-25T16:37:52.149+0000

The bugs I've identified and fixed are:

1.  When an effective membership is deleted (as a result of an immediate membership delete) and the owner of the effective membership is a factor of a composite, the composite group and groups that have the composite group as members are not updated.

2.  If there are two memberships between a group and a subject where one is for the default list and you delete the other membership, forward memberships due to the default list are also deleted when they should not be.
