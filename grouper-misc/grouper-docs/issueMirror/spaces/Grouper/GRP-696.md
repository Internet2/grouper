# GRP-696  [ldappc] [ldappcng] The lastModifyTime command line option is no longer supported.

The lastModifyTime command line option when running ldappc[ng] via gsh is no longer supported because it became too difficult to select objects for provisioning which have been changed since a particular point in time. Provisioning via the change log replaces this functionality.
