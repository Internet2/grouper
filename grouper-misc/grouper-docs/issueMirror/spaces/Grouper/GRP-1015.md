# GRP-1015  New UI has poor timeout handling

When your session on the new 2.2 UI times out, you wind up landing at an error screen asking you to restart your session.  It would be better if the app instead was smart enough to just cause your browser to do the re-load, thus sparing the user from seeing the error.

### mchyzer - 2014-08-17T12:53:15.074+0000

This is fixed

There is an issue with the UI where if you let your session timeout (java session), then  your CSRF token expire, and the next request (if a post) will send you to the CSRF error screen where you can start over.  In the new UI, there is now code so that the CSRF screen is not needed.

https://github.com/Internet2/grouper/commit/6f1177388d304dd3bdb3dc46d2faea5e41dec76c
