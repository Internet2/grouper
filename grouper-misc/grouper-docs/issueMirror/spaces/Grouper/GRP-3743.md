# GRP-3743  add new privilege on stems: stemView

If you roll back from 2.6.6 to a previous version, you need to find immediate stemView assignments, back up (if you need to re-apply), and remove:
{code:java}
select * from grouper_memberships_all_v gmav, grouper_fields gf where gmav.MSHIP_TYPE = 'immediate' and gmav.FIELD_ID = gf.id and gf.name = 'stemViewers' ; {code}
