# GRP-6563  Remove gh-pages branch

This branch was used from 2014-2016 to automatically build a full javadoc site available on github.io. It was integrated into travis to build after every commit. It was not optimized to minimize changes, so every build changed a timestamp in every file, meaning a large number of commits for every build. We are now using a process on i2midev to build javadocs weekly, so this branch isn't useful anymore.
