# GRP-7429  Group provisioning view config/logs when not provisioned causes NPE

Going to provisioning settings on a group that is not provisioned, and choosing “View configuration” or “View logs” gives a misleading error:

{{Error: Cannot invoke "edu.internet2.middleware.grouper.app.provisioning.GrouperProvisioningAttributeValue.getTargetName()" because "grouperProvisioningAttributeValue" is null, Problem calling method viewProvisioningTargetLogsOnGroup on edu.internet2.middleware.grouper.grouperUi.serviceLogic.UiV2Provisioning}}

It should still be an error, but something less cryptic that says you should set provisioning first to see the config and log. If it echoes the bad name, make sure it’s HTML escaped to prevent XSS. Alternatively, don’t have it in the dropdown until provisioning is set.

Also, the NPE causing failure is the only guard in viewProvisioningConfigurationOnGroup. it would need an explicit Invalid targetName check to give users a clear message
