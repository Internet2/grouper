# GRP-935  real time loader messaging

Penn State would like real time loader messaging since their system of record can sent notifications about which field changed for a user and the old value and new value.  How this would work is that loader jobs could be configured for a list of attributes, and would either fully run the job or incrementally  run the job for the one user (if this is possible)
