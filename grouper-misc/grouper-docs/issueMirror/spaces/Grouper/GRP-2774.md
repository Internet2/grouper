# GRP-2774  SELF_SIGNED_CERT has no effect for image

The SELF_SIGNED_CERT environment variable has no useful effect and HTTPS is always configured for the image because the file /etc/httpd/conf.d/ssl-enabled.conf is included in the SP base image upon which the Grouper image is built.
