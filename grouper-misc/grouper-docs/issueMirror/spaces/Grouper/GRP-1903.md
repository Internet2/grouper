### bert - 2018-09-20T16:47:49.223+0000

There is a problem where GroupSelection in PSPNG's FullSyncs are too tied to Grouper Attributes.

{{changeLog.consumer.pspng_attrFrEduLilHabilitation.groupSelectionExpression = $\{name.startsWith("app:") && name.contains(":habil:")}}}

 

How to make this work:

TODAY (before this bug is fixed): Put provision_to attributes on parent folder(s) of the groups you want to provision, even though your GroupSelection expression does not reference the attribute.

 

When this Bug is fixed:  You'll be able to set attributesUsedInGroupSelectionExpression to an empty string.
