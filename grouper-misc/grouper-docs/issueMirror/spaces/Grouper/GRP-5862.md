# GRP-5862  Global deny group slow to display when used in many composites

A customer had trouble displaying the global deny group, when the load balancer timeout was set to 1 minute. When the timeout was increased, it took 90 seconds for the group to show up, even though there weren't any members in it. Showing the detail, the group was used in a large number of composites, which is probably why it was slow to load.

Maybe the queries can be improved to display the page faster?
