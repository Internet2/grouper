# GRP-6439  Subject source comparison should allow input of any number of random subjects

Currently if no subject data is entered, it will randomly select 100.  That 100 should be an input value that the user can choose.  But if something greater than 100 is chosen, results after 100 should be summarized to prevent overwhelming the screen.
