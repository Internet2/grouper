### Bert Bee-Lindgren - 2023-10-26T12:24:16.312+0000

This Jira is reporting problems with our config that only had a membership table in the target system. Besides to the 4.8.0 fix posted last night, Chris also recommended a 3-4 table approach (groups, entities, memberships, and (optionally) group attributes) as a setup that should work better with <4.8.0 as well as, perhaps, be a more mainstream approach after 4.8.0.

This [wiki posting|https://spaces.at.internet2.edu/display/Grouper/Grouper+SQL+provisioner+with+groups%2C+entities%2C+memberships] describes the schema for this approach.
