# GRP-799  psp - real-time provisioning - option to block on errors

Per discussion on the grouper-dev mailing list, have an option for blocking realtime provisioning on ldap (and other systems?) errors.

See the thread at https://lists.internet2.edu/sympa/arc/grouper-dev/2012-05/msg00035.html

I hope this is a sufficient request.

## Comments

### tzeller@example.com - 2012-06-20T23:14:22.857+0000

This optional behavior may now be controlled in grouper-loader.properties :

# To retry processing a change log entry if an error occurs, set retryOnError to true. Defaults to false.
# changeLog.consumer.psp.retryOnError = false

An error is considered to be any Exception.
