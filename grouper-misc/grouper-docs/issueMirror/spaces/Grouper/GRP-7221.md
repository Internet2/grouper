# GRP-7221  Add Jamf Pro admin-account provisioner

New provisioner that manages Jamf Pro admin accounts and account-group (role) membership via the Jamf Classic API. Provisioning type is membershipObjects.

Account groups (roles) are read-only: Jamf admins own the privilege sets, so Grouper resolves a role by name and manages only its membership. Admin accounts are create-only: Grouper creates an account by EPPN when needed so it can be added to a role, and never updates or deletes accounts. Membership is applied by full-list replace of the role members (retrieve-modify-write), sending only name and members so a membership change never rewrites a role privilege set.

Authentication is OAuth 2.0 client credentials via a WsBearerToken external system. All communication with the Classic API is XML. Includes sync-back to the generic native mirror tables, a mock service handler, base properties, externalized text, and JUnit tests (API-level plus full and incremental sync).
