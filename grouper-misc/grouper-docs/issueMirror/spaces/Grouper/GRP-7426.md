# GRP-7426  Provisioner action "provisioned groups" add filter for name

The provision action “Provisionable assignments” shows what objects actually have provisioning set, which the “Provisioned groups” is the computed list of all groups that had provisioning set during the last full sync. But the list is truncated, so you can’t see all groups. For troubleshooting, it would help to have a filter to see if a group or groups matching a pattern actually had provisioning set during the last run.
