# GRP-111  XmlImporter does not keep creatorUuid for groups and stems

When performing an XmlImporter, the group and stem creatorUuid is not updated based on the XML file.  One way to solve this is to simply add update="true" on the creatorUuid property in the Hib3GroupDAO.hbm.xml and Hib3StemDAO.hbm.xml files.  At the moment, I'm not sure if this will cause any other problems or if there's a better solution.  I'll look at this more Tuesday and/or Wednesday.
