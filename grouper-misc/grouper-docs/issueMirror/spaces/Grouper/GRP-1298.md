# GRP-1298  PSPNG: Add IDIndex to the groupAttributes (jexl) map

While all the group attributes are supposed to be represented in the groupAttributes jexl map, the IDIndex slipped through and is not represented. 

Add IDIndex to the groupAttributes so it can be used, particularly as a value of gidNumber with 

gidNumber: ${groupAttributes['IDIndex']}
