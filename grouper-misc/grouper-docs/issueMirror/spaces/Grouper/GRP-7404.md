# GRP-7404  Log target commands sometimes not logging anything

As seen by Michigan, about 20% of the time an Okta full sync will not log any target commands in the retrieveAllTargetData stage. It was still logging every N records that data was being loaded, which indicates data really was coming in during that phase.

In later phases like to retrieve individual data, it will, however, log target commands being sent and received.

The log showed in the config section that the option to show target commands was set; it did not get flipped off for the run.
