# GRP-6899  TrueFoundry provisioner: team managers not provisioned correctly

Team managers are never provisioned as managers in TrueFoundry. The TrueFoundryProvisioningTranslator populates a group-level "managers" attribute (set of native entity IDs derived from the md_trueFoundryManagerGroupName metadata), but the DAO's insertMemberships reads a per-membership metadata attribute that is never set. The two paths are disconnected so isManager is always false and all users are added as regular members.

Fix: implement replaceGroupMemberships in TrueFoundryTargetDao with canReplaceGroupMemberships capability, and a new replaceTeamMembers API method that PUTs the full team manifest with the correct member/manager split. The DAO checks each membership's native entity ID against the translator-populated "managers" group attribute to determine the role. Also fix insertMemberships to do the same check for incremental inserts.

Requires provisioner config: replaceMemberships=true.

Also added the managers groups as members of their respective team groups so managers are automatically team members.
