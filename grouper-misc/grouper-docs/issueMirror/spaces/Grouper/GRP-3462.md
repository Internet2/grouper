# GRP-3462  allProvisionedValuesPrefix not stored correctly in database

Using Grouper 2.5.29 and the UI editor to save a configuration for the allProvisionedValuesPrefix property for a PSP-NG provisioner where the value is an asterisk ("*") results in the configuration entry

 id: 83a8fdd1c0894058a49edf3dff1e607f
 config_file_name: grouper-loader.properties
 config_key: changeLog.consumer.pspng_isMemberOfperson.allProvisionedValuesPrefix
 config_value: *
 config_comment: NULL
 config_file_hierarchy: INSTITUTION
 config_encrypted: T
 config_sequence: 0
 config_version_index: 0
 last_updated: 1621265034992
hibernate_version_number: 4

Note that the value for config_encrypted is 'T', even though the toggle in the UI was explicitly set NOT to encrypt.
The result is that the asterisk string is NOT sent to the PSP-NG and the configuration does not work as expected.
