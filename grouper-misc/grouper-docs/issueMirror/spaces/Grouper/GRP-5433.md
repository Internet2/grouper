# GRP-5433  Move from jexl2 to jexl3 everywhere

Some parts of Grouper are using jexl3 and some are using jexl2. I don't know which functions are using which version.

The last commit for Jexl 2 was December 2011. Jexl 3 was released January 2016. At that time, the documentation page was changed  to jexl3 syntax. The syntax for jexl2 is only available in their [github repository|https://github.com/apache/commons-jexl/tree/2.1.1/src/site/xdoc/reference], or through the [internet archive.|https://web.archive.org/web/20151226233318/https://commons.apache.org/proper/commons-jexl/]

Jexl2 syntax is limited, and has bugs that are fixed in jexl3. For example, sets, pragmas, annotations, '??' operator, '?.' and '?[...]' safe-access operators, unicode literals, try/catch, try-with-resources, and functions are not in v2.
