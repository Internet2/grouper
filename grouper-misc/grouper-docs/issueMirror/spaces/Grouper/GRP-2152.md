# GRP-2152  visualization: change arrow for simple loader from loader color to membership

I can't find the original comment noting this. But if a simple loader is a member of a group, the visualization engine currently sets the arrow as a loader type, not a membership type, and thus draws it as a green dashed arrow. It should be the black dashed arrow since it is just a membership relationship.
