# GRP-1410  UI Accessibility Improvements: The bread crumb above the main content is not identified as a bread crumb to the screen reader, losing its value as a navigation tool for the screen reader user.

Solution:
Place a heading before the breadcrumb with text of “breadcrumb.” Use CSS to hide this from the visual user.
