I noticed yesterday that EveryEntity had a few Attribute privileges that we
didn't recall adding.  They were:

entitySubjectIdentifierDef (Read,Update)

### mchyzer - 2017-09-05T17:24:01.140+0000

{code}
Set this in grouper.properties to not have everyentity privileges on builtin attributes and permissions automatically

# allow privileges for attributes be assigned to every entity
# note: there is also: grouper.permissions.limits.builtin.createAs.public
grouper.attribute.allow.everyEntity.privileges = false

# if the permissions limits should be readable and updatable by GrouperAll (set when created)...
# note there is also: grouper.attribute.allow.everyEntity.privileges
grouper.permissions.limits.builtin.createAs.public = false
{code}
