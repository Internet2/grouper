# GRP-6932  Enhance the 'Advanced Filter' for Group memberships with 'Subject Source'

There are good reasons why you would want to isolate a list of members by the subject source they are from. Maybe you want to see only the 'Grouper Groups' as members, or conversely filter out all 'Gropuer Groups' as members. Maybe you want to see members from a 'service account' subject source.

Preferably this filter exists as a drop down of all defined subject sources (including the native subject source for Groups as members).
