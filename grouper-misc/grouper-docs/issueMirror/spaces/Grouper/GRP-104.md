# GRP-104  Apply new database transactions to UI so that UI operations become atomic

I did a proof of concept of this and was able to implement it globally in one place. Need to handle any errors if something goes wrong.

## Comments

### Gary Brown - 2008-04-02T12:26:17.130+0000

Added 'grouperTransactionExecute' method which is now called by 'execute'. 'grouperTransactionExecute' wraps 'grouperExecute'
in: 'GrouperTransaction.callbackGrouperTransaction' which takes care of commit  - or rolback if an Exception occurs. This now means that saveGroup is atomic - all or nothing. Previously the code created a group, added attributes, group types, privileges etc as separate steps. An error in a final step would still see the Group created but in an inconsistent state. Now any database writes would be rolled back.
