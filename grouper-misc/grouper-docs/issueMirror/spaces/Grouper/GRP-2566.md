# GRP-2566  Performance issues for serveral operations when a lot of Rules are assigned

We had many groups assigned rules for Composite Intersection. However as more were added, we noticed performance problems. Through some testing I believe that when operations like creating groups, folders, or assigning permissions scan the repository to collect all rules for analysis. The result of this when having over 1 million rule assignments that processes use excessive memory and excessive computation.

I believe that these operations should only examine rules that are permanent to the operation being executed to reduce resource exhaustion.
