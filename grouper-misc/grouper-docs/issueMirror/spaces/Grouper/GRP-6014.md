# GRP-6014  Allow Okta Incremental Daemon To Process Entities if Required Entity Attribute Is Populated Instead of Wating for the Full Sync

I would like for the Okta provisioner incremental daemon to process group memberships for entities that are ignored due to an entity attribute that is set as required. This will enable faster processing instead of waiting for a full sync which takes hours due to API rate limitations.
