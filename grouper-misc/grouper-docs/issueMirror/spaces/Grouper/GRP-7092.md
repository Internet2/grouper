# GRP-7092  Accessibility: Subtitle Color Contrast

!image-2026-07-01-16-10-05-226.png!

Change h1 .small (#999999) to the teal blue 

## Comments

### Chris Hyzer - 2026-07-01T20:26:29.075+0000

Fixed. The subtitle under the "Grouper" title (the {{<small>}} in {{{}.page-header h1{}}}, e.g. "Grouper demo server v6") was inheriting Bootstrap's {{{}#999999{}}}, which is only ~2.85:1 on the {{#e5eef1}} header background and fails WCAG AA (needs 4.5:1).

Added a scoped override recoloring just that subtitle to the title teal {{{}#1c6070{}}}, matching the "Grouper" title directly above it. Contrast is now ~6:1 on the header background, passing AA.

Change is in {{grouperExternal/public/assets/css/grouperUi2.css}}:


 
 
 
.page-header h1 small {
color: #1c6070;
}
 
Scoped to {{.page-header}} so no other heading {{<small>}} in the UI is affected, and vendor {{bootstrap.css}} is left untouched. Cache-buster on the {{grouperUi2.css}} link in {{commonHead.jsp}} was bumped so browsers pick up the change.
