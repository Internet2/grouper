# GRP-7486  Smartsheet provisioner: membership add by id, unset flags not sent, link-only mode

Follow-up to GRP-7485 (Smartsheet provisioner). Group member adds send the Smartsheet user id first and fall back to email. An account flag (admin, licensedSheetCreator, groupAdmin, resourceViewer) with no value is left out of a user update instead of being sent as false.

Adds a debug log note for DECLINED users, a test for link-only mode (insertEntities=false), and documentation: both user modes, a dedicated service account for the API token on the ignore list, IdP / directory integration and email domain limits on deactivate, read-only mode and failsafe for the first run, and displayExtension as the example group name.
