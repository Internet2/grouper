# GRP-3529  Configuration UI doesn't validate configurationEditor.sourceIpAddresses

Managed to "brick" my test environment by appending an IP address to *grouperUi.configurationEditor.sourceIpAddresses* that wasn't in the proper CIDR block notation. Subsequent attempts at going back to the config UI were met with an error: 

{color:#FF0000}Error: String must contain slash and CIDR network bits, e.g. 1.2.3.4/14, Problem calling method index on edu.internet2.middleware.grouper.grouperUi.serviceLogic.UiV2Configure.{color} 

Now no one can get into the Config UI to make any corrections.  Need to block that condition from happening.
