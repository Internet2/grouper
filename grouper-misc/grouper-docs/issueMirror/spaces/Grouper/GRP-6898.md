# GRP-6898  TrueFoundry provisioner: assign default role when user removed from all role groups

When a user is removed from all provisioned TrueFoundry role groups, their role in TrueFoundry is unchanged (deleteMemberships for roles was a no-op). The user keeps their previous role indefinitely.

Fix: in deleteMemberships, assign the configured trueFoundryDefaultRole instead of doing nothing. In replaceGroupMemberships for roles, after assigning desired users, demote users who had this role at the start of the sync but are no longer in the desired list to the default role. A usersAssignedRoleThisSync tracking set prevents the default-role fallback from clobbering a role that was just assigned by a different group's replace call in the same sync (e.g. user moving role X to role Y).
