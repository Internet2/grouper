# GRP-7122  Fix GrouperProvisioningNativeAttributeConfigTest assertion after native-attributes label rename

{{GrouperProvisioningNativeAttributeConfigTest.testBulkMatchesPerRow}} (grouper/src/test/edu/internet2/middleware/grouper/app/provisioning/GrouperProvisioningNativeAttributeConfigTest.java) was asserting against the old localized field label {{{}Native attributes (entities){}}}. The label was renamed to {{Native entity attributes}} (config.GenericConfiguration.attribute.nativeAttributesEntities.label in grouper/conf/grouperText/grouper.textNg.en.us.base.properties), so the test's expected substring no longer matched and it failed.

Update the assertion to expect the current label {{{}Native entity attributes{}}}. Test-only change - no product code affected.
