# GRP-1051  grouper loader performance bulk subject queries

Grouper loader looks up each subject one at a time, but the subject API can lookup multiple subjects at once

## Comments

### mchyzer - 2014-09-29T13:47:22.790+0000

The default grouper-loader.base.properties setting:

#################################
## Performance enhancements
#################################

# if you want to bulk retrieve subjects to add/remove
loader.bulkLookupSubjects = true

This will get subjects in batches of 100 across all jobs in a list (or just one job)
