## Comments

### Gary Brown - 2008-12-15T15:46:08.970+0000

Whenever the GrouperHelper methods that query Fields are called they 'accumulate' in UIThreadLocal a set of Field names. This is compared to the cached set of Fields in the session. If a new Field is encountered the whole cache is refreshed.

Note that any changes to nav.properties to give 'ncie' names to fields require a restart of the webapp.
