# GRP-1336  Allow the Grouper installer to auto-encrypt credentials

Credentials provided by the adopter during the installation process must be auto-encrypted by Grouper. This is a best practice that should NOT be left up to the adopter to configure; rather it should be forced by the project. 

Turn on this behavior by default. Expose an option to disable it if one needs to.
