# GRP-7158  Bump jackson to 2.22.1 to address jackson-databind security vulnerabilities

Bump the jackson.version property in grouper-parent/pom.xml from 2.20.1 to 2.22.1 (latest 2.x on Maven Central) to address reported security vulnerabilities in jackson-databind.

The single jackson.version property drives jackson-databind, jackson-jaxrs-base, and jackson-jaxrs-json-provider; jackson-core and jackson-annotations follow transitively. No other jackson version is hard-coded. One-line change.
