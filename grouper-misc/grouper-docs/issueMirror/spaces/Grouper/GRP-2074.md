# GRP-2074  UI search feature in top right corner does not handle % values correctly

using the Grouperdemo 2.4 server.

Search for the string "Dep" in the upper right hand corner and you will get results.

Search for the string "Dep%:apps" in the "Search Results" form and you will get a more focused result set.

 

If you search on "Dep%:apps" in the upper right hand corner and you will get a broken UI where the "main part of the app" is "missing".

    The best way to get it back is to either manually edit the URL by removing the "searchQuery=" parameter and do a browser level refresh.

 

So one string "breaks" the UI.

( I have also reproduced this in the 2.3 UI as well. So patching that would be welcome. )
