# GRP-7308  UI accessibility: header logo link uses descriptive alt text

The header logo image is inside a link that goes to the home page. Per accessibility item 5/8 (SC 1.1.1, 2.4.4), the logo link needs an accessible name that describes the destination rather than the image type.

Change: the logo image now carries alt=Grouper home (the ariaLabelGrouperHome text key) in header.jsp, per the plan guidance to use alt text such as Grouper home. It previously had alt= (empty) with the name supplied on the link via aria-label - an equivalent accessible outcome - but the name was moved onto the image alt and the now-redundant link aria-label removed, since having both would duplicate the name. The link keeps its real href to UiV2Main.indexMain and title=Institute of Higher Education. Verified live: the computed accessible name is Grouper home.
