# GRP-685  Change the default sort string for groups

The default sort string for groups will be changed from "name" to "displayExtension".  Note that the admin UI shows displayExtension when showing membership lists, but the lite UI shows the displayName.  So even with the new default, the membership list in the lite UI will not look like it is sorted correctly.  Perhaps in 2.2, the lite UI will show the displayExtension instead.
