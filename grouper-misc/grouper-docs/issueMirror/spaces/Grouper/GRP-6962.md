# GRP-6962  Generic provisioner sync back — strict native-target capture with configurable extra attributes

* Add three native-target beans ({{{}GrouperProvisioningTargetNativeUser/Group/Membership{}}}) decoupled from the wrapper set so reporting can include target objects that Grouper does not track
 * {{GrouperProvisioningData}} gains {{targetNativeUsers/Groups/Memberships}} lists; {{GrouperProvisioningDataIndex}} gains {{buildNativeIndexes(debugMap)}} with failsafe dup tracking (counts + examples written to the debug map)
 * New config {{nativeAttributesEntities}} / {{nativeAttributesGroups}} (per provisioner) for additional native attributes to capture. Accepts two forms: comma-separated names (LDAP-style, e.g. {{{}sn, mail, telephoneNumber{}}}) or JSON array ({{{}[\{"name":"...","path":"...","type":"..."}]{}}}) for nested paths / explicit types
 * UI validation: bad input attaches the error to the textarea via {{assignJqueryHandle}} so the field is highlighted
 * {{GrouperProvisioningLogic.loadDataToGenericProvisionerTables}} rewritten to read strict-native lists; pre-fetches existing catalog rows by {{(grouper_sync_internal_id, attribute_name)}} so re-runs reuse internal_ids instead of colliding on the unique constraint
 * {{syncGenericProvisionerTable}} normalizes JDBC {{BigDecimal}} reads to {{Long}} so MultiKey-based PK comparison succeeds (without this, every catalog row got deleted in the DELETES_ONLY phase)
 * LDAP DAO: {{LdapProvisioningTargetNativeBuilder}} widens the LDAP attribute search list with native paths and populates native bean lists inline; wired into all four select methods (retrieveAllGroups, retrieveGroups by-id, retrieveAllEntities, retrieveEntities by-id)
 * DDL: non-unique {{idx2}} on {{target_user_id}} / {{{}target_group_id{}}}; columns widened to {{VARCHAR(1000)}} to accommodate LDAP DNs; {{_attr}} schema restructured to a per-provisioner catalog with unique constraint on {{(sync_id, attribute_name)}} — mirrored across postgres / oracle / mysql install SQL, {{{}UpgradeTaskV41{}}}, {{{}GrouperDdl7_2_0{}}}, and {{aiGshDdl.txt}}
 * Tests: {{GrouperProvisioningNativeAttributeConfigTest}} (17 unit cases covering both forms + error paths); {{LdapProvisionerGenericTableTest}} with group-side and entity-side full-provision coverage, plus CSV-form and JSON-form tests asserting multi-valued LDAP attributes produce multiple value rows
