# GRP-7570  LDAP external system label Search results handle should be Search results handlers

Fix: grouper/conf/grouperText/grouper.textNg.en.us.base.properties line 14069
config.LdapGrouperExternalSystem.attribute.searchResultHandlers.label = Search results handle
should be
config.LdapGrouperExternalSystem.attribute.searchResultHandlers.label = Search results handlers
