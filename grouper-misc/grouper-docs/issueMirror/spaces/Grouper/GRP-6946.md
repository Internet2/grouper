# GRP-6946  LDAP subject source has form field for "Extra attributes from source" which is unused

Creating a new LDAPsource in the UI corresponds to
{color:#000000}GrouperLdapSourceAdapter2_5{color}. The UI has a form field for "Extra attributes from source". But the value of this property (subjectApi.source.CONFIGID.extraAttributesFromSource) is never read by the class. The SQL subject source does honor it, but not the LDAP one.
 
I assume the only workaround is to explicitly name a field, with translation type "Same attribute name".
