# GRP-5544  Add docs on avoiding folder/group "can only contain letters, numbers, underscore, or dash"

{code}
edu.internet2.middleware.grouper.hooks.logic.HookVeto: veto.stem.attribute.name.regex.extension: The folder ID can only contain letters, numbers, underscore, or dash
{code}

The default behavior on folder and group names is restrictive, and almost every institution needs to override these restrictive defaults. There should be some hint in the error message, or a wiki page when searching for the error, so people can easily find how to fix this problem

### Chad Redman - 2024-11-22T05:42:01.453+0000

(1) [https://spaces.at.internet2.edu/display/Grouper/Configuring+object+name+constraints|https://spaces.at.internet2.edu/display/Grouper/Group+object+name+constraints]

(2) Rewrote the property metadata in grouper.properties to be more clear, and moved properties for the different object types so they appear in the right sections

(3) Refactored the naming hook classes to also log the property and regex triggering the veto. It doesn't show up in the UI but is in the logs. It will do that for both configured checks and the default one, so admins will know where to find the right property. The previous log message tag "veto.group.attribute.name.regex.extension" was a complete red herring; it was a made up reference to a text property that never existed. It has led me on a wild goose chase on multiple occasions.
