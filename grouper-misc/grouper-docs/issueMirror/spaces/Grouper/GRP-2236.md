# GRP-2236  UI should have a way to report the current version/patch level.

It would be helpful for Grouper deployments to have the UI (and maybe the WS as well?) be able to report the detailed version and patch level.

 

Maybe something like "Miscellaneous version".

I am not sure that this needs to be "protected"/"restricted information, but maybe that is a conservative approach to limit it to "admin" only.
