# GRP-5195  v4 grouper_loader_log_indexes

These indexes will be added automatically on an upgrade task.
{code:java}
CREATE INDEX grouper_loader_log_temp_st_idx ON grouper_loader_log (job_name,started_time);
CREATE INDEX grouper_loader_log_temp_s2_idx ON grouper_loader_log (job_name,status,last_updated);
CREATE INDEX grouper_loader_log_temp_s3_idx ON grouper_loader_log (status,last_updated);
CREATE INDEX grouper_loader_log_temp_s4_idx ON grouper_loader_log (parent_job_name); {code}
Verify the upgrade task daemon added these indexes.  If not, then add them yourself since the DB credential that grouper uses could not add them.  If you have other rogue indexes on grouper_loader_log that werent added by grouper, and they are covered here, you can remove them
