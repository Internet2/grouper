# GRP-7623  Upgrade commons-codec to 1.23.0 for security

The 7.10.0 image ships Apache Commons Codec 1.20.0, which image scanners flag for CVE-2026-119078 (Blake3 doFinalize documentation, affects 1.16.0 before 1.23.0). Grouper does not use Blake3, but the jar is bumped so scans are clean.

Change: commons.codec.version 1.20.0 to 1.23.0 in grouper-parent/pom.xml.
