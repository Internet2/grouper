# GRP-7587  Adding attestation in GTE results in two days left attributes, one must be deleted

In the GTE (Grouper Training Environment), Chad added attestation to an object and ended up with two "days left" attributes (attestation days until recertify) assigned. He had to manually delete one of them.

Adding attestation should only result in a single days-left attribute. Please investigate why a duplicate is created (e.g. the attestation daemon and the UI both assigning it, or a re-save not reusing the existing assignment) and fix it so only one exists.
