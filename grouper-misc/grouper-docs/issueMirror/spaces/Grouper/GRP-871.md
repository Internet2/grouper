# GRP-871  MembershipFinder.findMemberships doesn't appear to be producing distinct results

The result of this is that the Admin UI incorrectly reports that a membership exists by multiple paths.

## Comments

### Sebastien Gagne - 2012-12-14T16:09:45.928+0000

We have this problem at U of Montreal.
* Using an acount with SysAdmin rights, all memberships path are correctly shown. 
* If I use a delegated admin account and check groups I have update rights, all paths are doubled (by 2 paths when only 1, 10 paths instead of 5). Checking the same group using the sysadmin shows normal results.
* If I use a delegated admin account and Explore groups I only have Read/View rights, memberships seems to be fine

Clicking on the description of the paths yield normal results
