# GRP-6164  Remove old log4j files

Three files that don't serve a purpose in the container anymore.

* log4j.properties: from the image build; this should be deleted when a new release is pushed
* log4j2.example.xml: from the Grouper distro. The installer copies it to log4j2.xml, but it’s overwritten in the image so it’s a futile action. Having the example file there confuses users because they may think it's the file they should be basing changes from
* log4j.grouperContainerHost.properties: from the Grouper distro. It is not used anywhere and should be deleted
