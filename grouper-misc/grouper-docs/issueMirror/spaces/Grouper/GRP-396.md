# GRP-396  Multiple Queries for the same subject

The Subject API makes two LDAP queries for a subject during typical operations like viewing group memberships on the UI.  The first is done by JNDISourceAdapter.getSubject() while creating the Subject object and the second is done by JNDISourceAdapter.loadAttributes().  There should be a performance benefit by retrieving all of the attributes during the first query.
