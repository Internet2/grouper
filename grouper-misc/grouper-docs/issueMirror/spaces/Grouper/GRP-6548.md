# GRP-6548  Daemon shouldn't connect to all defined databases on startup

When the daemon starts up, it calls GrouperCheckConfig.checkGrouperLoaderConfigDbs(), which looks for all db.*.url and tries to connect to them. But some may be disabled, or just not in use. Or maybe a db is not available at startup but will accept connections later when a provisioner or loader uses the external system.

The code is from 2008, long before external systems were a thing.
