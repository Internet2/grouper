# GRP-6924  XmlExportGshScript incorrect import class

In 4.16.1, two separate CompositeSave classes were merged.

{code}
- import edu.internet2.middleware.grouper.group.CompositeSave;
+ import edu.internet2.middleware.grouper.CompositeSave;
{code}

The XML export to GSH script is using the older class, and the script fails because it's a method the script is trying to call. Just updating the import manually fixes the script.
