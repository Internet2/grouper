# GRP-7180  Config option to email on daemon job failure

This has been an occasional ask from multiple customers. They want someone notified when specific daemon jobs fail (or success, or any completion). To set this per job may be as simple as adding a new form field to the daemon edit page.

In addition, there might be a desire to have emails for certain types of jobs; e.g.,

* all non-official jobs
* all loader jobs
* all loader jobs/provisioners of a specific type
* all loader jobs/provisioners for a specific external system

Maybe the grouper-loader properties would look like this:

{{## allCustom|jobType|jobTypeAndExternalSystem|externalSystem|regexp|jobTypeAndRegexp}}

{{job.notifications.0.triggerType = jobTypeAndExternalSystem}}

{{## (ERROR|SUCCESS|COMPLETE|…)}}

{{job.notifications.0.triggerStatus = ERROR}}

{{job.notifications.0.jobType = SQL_LOADER}}

{{job.notifications.0.externalSystem = myDWH}}

{{job.notifications.0.emailToGroup = etc:sysadmin@grouper}}
