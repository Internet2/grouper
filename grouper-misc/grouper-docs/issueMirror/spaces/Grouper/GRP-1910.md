# GRP-1910  Documentation for grouper-loader.properties

We discovered that the ldaptive Search Validator failed with the examples provided on the Knowledge base. 

The following example seams to have resolved our issue. 

 

ldap.personLdap.url = ldap://ldap.example.com
# Disble TLS if needed
# ldap.personLdap.tls = false
ldap.personLdap.baseDn = dc=example,dc=com
ldap.personLdap.user = cn=example,dc=example,dc=com
ldap.personLdap.pass = somepassword

# Disable LDAPTIVE Paging as it is not supported by DSEE, Oracle Unified Directory
ldap.personLdap.searchResultPagingEnabled = false
ldap.personLdap.searchResultPagingSize = 0
