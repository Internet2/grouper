# GRP-5732  Scripted loader syntax error sometimes redirects to "Click here to start over." page

If a scripted jexl in a loader has a syntax error, sometimes it shows on the page to allow further editing. But sometimes it redirects to the generic "There was an error with your request. Click here to start over." page, and the user has to start all over with setting up the query.

 

An example which triggers this (there is a syntax error with "! and" but the trigger for the larger crash seems to be the size of the comment)

{code}
entity.hasRow('hr_positions', " (role == 'faculty' or role == 'staff') and org_code == 'AS' ")
and
(
  /* but not if they have a staff role in a sensitive department and have not completed training */
  entity.memberOf('ref:training:trainingRequired:privacy_cert_required') 
  ! and entity.memberOf('ref:training:trainingCompleted:privacy_certified')
)
{code}
