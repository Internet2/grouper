# GRP-440  add "replace" as operation in attribute framework and permissions WS and client

## Comments

### mchyzer - 2010-05-25T16:47:40.013+0000

this is done.

there is an operation for replace attribute or permissions (in the existing assign web services): replace_attrs, replace_permissions

You can only replace attributes or permissions that you have access to edit.

Also, you can restrict the attributes with these params to the WS or client:

Here is the client switches (same for WS)

[--attributeDefNamesToReplace=a:b,b:c] [--attributeDefUuidsToReplace=1a,2b] 

[--actionsToReplace=read,write] 

(attributes only, not permissions) [--attributeDefTypesToReplace=attr,perm,limit,domain,type]

For permissions, only "perm" attributeDefTypes will be affected.  The others mean that you can clamp down on the amount of data which will be removed when the replace occurs (i.e. you might only want to replace permissions of a certain type but leave the others).  Note that this is by owner (i.e. it wont remove attributes or permissions for owners not passed in)...
