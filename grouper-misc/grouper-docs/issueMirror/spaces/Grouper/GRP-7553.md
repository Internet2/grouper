# GRP-7553  AI assistant default prompt does not tell the model to check recipes first

The MCP server's general instructions (grouper.mcp.instructions) tell the client to check recipes before acting. The AI assistant's default system prompt (GrouperAiAgent.DEFAULT_SYSTEM_PROMPT) has no similar statement. The only thing pointing the assistant to a recipe is the pointer added to a tool's description, and that pointer only exists when the recipe lists the tool in toolNames. So a recipe without tool references may never be read by the assistant.

Suggested fix: add a line to the default prompt, similar to the MCP instructions, telling the model to check the recipe tool's recipes before acting.
