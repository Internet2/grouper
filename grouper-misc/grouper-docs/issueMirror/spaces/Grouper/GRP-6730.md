# GRP-6730  Okta Provisioner - Load users that are in memberships but were not fetched while retrieving users

* Okta provisioner in retrieveAllData fetches users
 * Our assumption is that not all users are fetched
 * After that memberships are fetched and some user ids that are part of memberships were missed while fetching users
 * The solution is to compare user ids that came back in memberships with user ids that came back in retrieveOktaUsers call. The user ids that only exist in memberships, go back to Okta API and fetch those users individually
