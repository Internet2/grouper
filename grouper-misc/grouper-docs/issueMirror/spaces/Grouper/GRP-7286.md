# GRP-7286  v4/v6 only: okta test fixtures never set up the wsBearerToken external system, so GrouperOktaProvisionerTest cannot run

GrouperOktaProvisionerTest cannot pass on v6. It fails with: Cant find property: grouper.wsBearerToken.myOkta.endpoint in properties file: grouper-loader.properties, it is required.

Cause: GrouperOktaApiCommands.executeMethod reads the okta connection from grouper.wsBearerToken.<configId>.*, and it has done so on v6 since at least 6.3.0 - the class is byte identical on GROUPER_6_BRANCH and GROUPER_RELEASE_7.4.0. But v6's OktaProvisionerTestUtils.setupOktaExternalSystem only sets up the legacy grouper.oktaConnector.myOkta.* keys, so the external system the test creates is not the one the code reads. This is a pre-existing v6 test fixture gap, not a regression from the 6.4.0 backport.

On v7 the fixture was updated to also write the wsBearerToken keys (endpoint, httpAuthnType=oauthClientCredentials, tokenUrl, grantType, clientId, clientCredentialType=publicPrivateKey, privateKey, and grouperClient.wsBearerToken.myOkta.publicKeyId), adjust the mock tenantDomain so OktaMockServiceHandler's two path-segment strip lines up, and clear the config cache. A second v7 fix in OktaMockServiceHandler makes the mocked OAuth expires_in a RELATIVE seconds-to-live rather than an absolute epoch - emitting an epoch made the bearer token client cache the token effectively forever and then 401 once the stored row expired, which broke okta tests running more than about an hour into a long suite.

Both v7 changes arrived inside sync-back commits (GRP-6983 and GRP-7078) which are deliberately not backported to v6, and both landed before the 6.4.0 backport window, so neither came across. Only the test fixture halves are being taken here: OktaProvisionerTestUtils.java and OktaMockServiceHandler.java are copied from GROUPER_RELEASE_7.4.0. Both were verified to contain no sync-back references and no v7 only API, and the production class they support, GrouperOktaApiCommands, is already identical between the branches.

v6 only. v7 already has both fixes.
