# GRP-2247  UI for large/long attribute name values does not "flex" to allow the user to see the whole value

Reproduce:

Assign an attributeName to a folder/group/whatever.

Assign a value to the attributeName that is "long". ( Say... 100 chars or longer, but less than 4000)

Then try to edit the value.

The UI has a 'Value to edit' field that is fixed in size and way to small. ( It only displays about 40 characters. Depending on your font size.)

 

The UI should be able to display the entire 4K (or max length for the attriuteName value) so the user can edit the value easily. ( And preferribly support mult-line display and values
