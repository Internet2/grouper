# GRP-7315  UI accessibility: finish converting remaining fake-button anchors and fix dead links (WCAG 4.1.2)

Follow-on cleanup from accessibility action-plan item 5 (native buttons instead of role=button anchors). The main families were converted; these leftovers remain:

* Generic <a class="btn" href="#"> action buttons that are not navigation (e.g. adminDaemonJobs Apply/Reset) should become native <button type="button">.
* The 3 dead "Back to previous page" trace links (href="#" with no handler) - give them a real target or make them buttons with an action.
* guiV2link navigation anchors that use href="#" - give them a real hyperlink target so they work without JS and expose a proper destination (WCAG 2.1.1 / 4.1.2).

Low severity / polish. Reuse the .grouper-linkbutton and .grouper-menuitem helpers added in grouperUi2.css during the item-5 pass so converted controls keep their existing look.
