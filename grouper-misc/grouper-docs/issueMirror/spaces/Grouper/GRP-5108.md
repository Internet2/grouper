# GRP-5108  Attributes in group view/edit only handles markers and strings

[https://spaces.at.internet2.edu/display/Grouper/Grouper+attribute+framework+attributes+editable+in+group+edit+screen]

 

The UI logic for this only display the fields if the attribute is a marker or a string. This should be able to treat other attributes like integers or guids as string-like fields for the purpose of viewing and editing.
