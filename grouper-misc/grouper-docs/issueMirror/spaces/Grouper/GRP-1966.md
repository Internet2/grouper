# GRP-1966  UI Visualization

Create a visualization feature in the UI. When viewing a group, stem, subject, etc., draw a graph showing the entities as nodes with connector lines showing its relationship to other entities. Relationships may be folder to group, loader job to group, group members to the owner group, etc. Styles for components should be configurable in grouper-ui.properties. The user can set various options for drawing the group, such as how many levels deep, whether to count group members, etc. There should also be a text-only version for accessibility, and maybe performance too.
