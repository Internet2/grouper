# GRP-7026  GSH Java template compilation — compiled-Java branch in GshTemplateExec and shared dispatch helper

* Phase 4b foundation. Builds on the per-template classloader registry (GRP-7010) and the type framework (GRP-7011). Design doc: {{grouper/temp/trash/gshCompileImprovement.html}}.
 * Extract source-reading (today the private {{GshTemplateExec.getGshTemplateFromConfig}} — inline {{gshTemplate}} vs container file {{gshTemplateFileName}} chosen by {{{}gshTemplateSourceType{}}}) into a public {{{}GshTemplateConfig.readSource(){}}}, reused by both {{GshTemplateExec}} and the new helper.
 * Add a reusable {{GshTemplateCompiledDispatch}} helper (grouper module): {{{}instantiate(String configId, GshTemplateConfig config, Class<T> baseClass) → T{}}}. Reads source, calls {{{}GshTemplateClassLoaderRegistry.resolve{}}}, casts via {{asSubclass}} with a clear error if the author extended the wrong base, instantiates. Parse/compile failures surface the registry diagnostics.
 * Add a {{templateMode == compiled}} branch in {{GshTemplateExec}} next to the existing V1/V2 source-hash cache (~lines 737–804): compiled → helper resolves a {{GshTemplateV2}} subclass through the registry, then {{{}gshRunLogic(input, output){}}}; existing {{GshTemplateExecOutput}} handling unchanged. Covers {{templateType}} *gsh* and {*}abac{*}.
 * Tests: compiled gsh template runs end-to-end and produces output; editing source recompiles (hash change, statics reset); wrong base → clear {{{}ClassCastException{}}}; compile error blocks with line/column diagnostics; interpreted path unchanged.
 * House rules: no streams/lambdas; explicit loops/ifs.
