The "finder" apis should help with queris like this so we dont have to go to the DAOs...

If you want values, do this
try something like this:

Set<Group> groupsWithAttribute = new GroupFinder().assignNameOfAttributeDefName("some:attributeName").assignAttributeValue("adProvisioner").findGroups();

Set<Stem> stemsWithAttribute = new StemFinder().assignNameOfAttributeDefName("some:attributeName").assignAttributeValue("adProvisioner").findStems();

If you DONT want values, do this
try something like this:

Set<Group> groupsWithAttribute = new GroupFinder().assignNameOfAttributeDefName("some:attributeName").findGroups();

Set<Stem> stemsWithAttribute = new StemFinder().assignNameOfAttributeDefName("some:attributeName").findStems();

Find the groups in a stem

Set<Group> groupsInStem = new GroupFinder().assignParentStemId("abc123").assignStemScope(Scope.SUB).findGroups();

If you wanted to roll all that up in one static method in GroupFinder, could be useful for others.

But I guess you dont have values, you just want groups with an attribute assign to group or folder?  you can just do soemthing like this (but there is caching and it doenst return all groups, just if a group has it [or ancestor folder]):

Group.getAttributeDelegate().hasAttributeOrAncestorHasAttribute(final String attributeFlagName, final boolean checkSecurity)
