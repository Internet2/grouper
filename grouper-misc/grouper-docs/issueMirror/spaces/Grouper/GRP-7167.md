# GRP-7167  GSH template config: hide fields that do not apply to daemon templateType

On the GSH template configuration screen, when templateType is daemon, the UI still prompts for several fields that do not apply to a daemon template.

Request: when templateType is daemon, do not show or prompt for the following fields:

* Security run type
* Run as type
* Display error messages and output on error
* Allow WS from no owner
* MCP enabled
* Number of inputs
