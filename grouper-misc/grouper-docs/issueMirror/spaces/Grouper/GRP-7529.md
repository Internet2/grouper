# GRP-7529  GTE: set registry.checkMembershipCacheIsPopulated = false so startup does not log the membership cache error

Every time the GTE starts, Grouper logs this at ERROR level and prints it to the console:

Error: set this to false in grouper.hibernate.properties after your membership cache is populated and you are in version v5.19.0+: registry.checkMembershipCacheIsPopulated = false

It comes from GrouperStartup.ensureSqlMembershipCacheIsPopulated(). When the membership cache check passes, Grouper still logs this instruction as an error until the check is turned off. The GTE is on v7 and its membership cache is populated, so the check is not needed and the error only confuses training attendees. It came up in the TechEx 2026 Grouper MCP/AI training run-through.

Suggested fix: in the GTE grouper.hibernate.properties, set registry.checkMembershipCacheIsPopulated = false (or set the environment variable GROUPER_CHECK_MEMBERSHIP_CACHE_IS_POPULATED=false in the GTE container), then rebuild the GTE images.
