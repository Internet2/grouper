# GRP-4415  Add option to dump ddlScript output to stdout instead of a file

When needing to run a registry check with {code}gsh -registry -check -deep{code} or similar, the output gets saved to a local file. Users may not have a convenient option to mount the ddlScripts folder on demand, and logging it to standard output may be an easier option.

If stdout is a problem due to being to much output which prevents it from being captured, it may be advantageous to rewrite this to log the output using log4j, and then the user will have the ability to set appenders as needed.
