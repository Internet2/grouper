# GRP-1897  loader changelog, audit entries should not be there

 

 

*From:* grouper-core-request@example.com <grouper-core-request@example.com> *On Behalf Of* Redman, Chad
 *Sent:* Friday, September 07, 2018 11:32 AM
 *To:* grouper-core@example.com
 *Subject:* [grouper-core] Loader jobs and auditing after GRP-1624

 

Since upgrading to 2.4, every group involved in a loader job gets updated loaderMetadata attributes related to the last run time, job uuid, and result. This means our audit log has changed from 100 records per day to 200,000, and 99.9% of the audit log is now loader metadata. Looks like this is GRP-1624 Add loader metadata attributes to groups that are loaded via grouper loader. It's a 2.3 patch too.

 

The wiki for deprovisioning [https://spaces.at.internet2.edu/x/oQ79Bg] says that these shouldn't be logged in PIT and the change log, but it seems like they are logged to change log and audit log. This is counts per day of change_log:

 

STRING07            STRING08            STRING09            COUNT(*)

etc:attribute:loaderMetadata:grouperLoaderMetadataLastSummary     assign    F              27822

etc:attribute:loaderMetadata:grouperLoaderMetadataGroupId               assign    F              27822

etc:attribute:loaderMetadata:loaderMetadata  assign    F              27822

etc:attribute:loaderMetadata:grouperLoaderMetadataLoaded assign    F              27822

etc:attribute:loaderMetadata:grouperLoaderMetadataLastFullMillisSince1970   assign    F              27822

...

 

and audit_entry:

 

DESCRIPTION     STRING03            STRING05            COUNT(*)

Added attribute assignment       etc:attribute:loaderMetadata:grouperLoaderMetadataGroupId               assign    27822

Added attribute assignment       etc:attribute:loaderMetadata:grouperLoaderMetadataLastFullMillisSince1970                assign    27822

Added attribute assignment       etc:attribute:loaderMetadata:grouperLoaderMetadataLoaded assign    27822

Added attribute assignment       etc:attribute:loaderMetadata:grouperLoaderMetadataLastSummary     assign    27822

...

 

 

Loader jobs also take 4x the time since upgrading. It also slows down changelog consumers because they get a hit for every attribute change.

I guess we can throw more database resources, but I would think it would eventually slow down auditing.

 

-Chad
