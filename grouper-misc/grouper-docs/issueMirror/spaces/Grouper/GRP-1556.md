# GRP-1556  UI Accessibility - Error (and success) messages are displayed above the page heading and all content, unapparent to screenreaders

Place the notifications and errors closer to the main content area of the page and use a background/foreground color combination with at least a 4.5:1 contrast ratio. Use a tool such as the TPG Color Contrast Analyzer https://www.paciellogroup.com/resources/contrastanalyser/ to evaluate and select sufficient color combinations.
