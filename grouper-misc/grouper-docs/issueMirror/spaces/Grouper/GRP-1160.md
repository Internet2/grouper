# GRP-1160  Grouper-WS module builds with java installed on machine

The ant build invoked by the installer does not specify a source/target java version for the ws module. As a result, ws gets built with the default JDK installed on this machine, which would be one that is incompatible with grouper. This creates a world of problems. Make sure the build.xml specifies versions that are compatible with Grouper
