# GRP-1419  Add note to property uiV2.group.allowGroupAdminsToRefreshLoaderJobs

GRP-1131 added a new parameter to grouper-ui.properties, uiV2.group.allowGroupAdminsToRefreshLoaderJobs, to allow group admins to run the loader process. What isn't obvious is that the admins also need READ access to etc:attribute:loaderLdap:grouperLoaderLdap. Can this be added to the wiki and the properties file? For example, this is what I put into our own config just so we don't forget:


{noformat}
# allow group admins to refresh loader groups
# https://bugs.internet2.edu/jira/browse/GRP-1131
# Note, in order for someone to see the button they need to be ADMIN on the group, and they need to have READ of the loader attribute definitions
# (usually, this is attribute definition "etc:attribute:loaderLdap:grouperLoaderLdap")
uiV2.group.allowGroupAdminsToRefreshLoaderJobs=true
{noformat}
