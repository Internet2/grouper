# GRP-7615  Container log4j_fix jars: upgrade to log4j 2.26.1 to match the webapp

The v7 container's container_files/log4j_fix jars (tomcatBin: log4j-api, log4j-core, log4j-jul; webinfLib: log4j-1.2-api) were still 2.26.0, while the webapp (grouper-parent log4j.version) has been on 2.26.1 since 7.9.0.

Swap them to 2.26.1 so Tomcat and the webapp use the same log4j version.
