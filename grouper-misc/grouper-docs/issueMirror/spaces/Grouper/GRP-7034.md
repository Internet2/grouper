# GRP-7034  GSH Java template compilation — compile-status columns on the GSH template inventory list

* Phase 5c (part 1). Builds on GRP-7006 (compiler), GRP-7010 (registry), GRP-7011 (modes/types), GRP-7033 (compile-on-save). Design doc {{grouper/temp/trash/gshCompileImprovement.html}}, section "Unified admin inventory".
 * The existing GSH template list screen ({{{}UiV2GshTemplateConfig.viewGshTemplates{}}} → {{{}gshTemplateConfigs.jsp{}}}) already enumerates every {{grouperGshTemplate}} config, which is every compiled artifact — so extend it in place rather than build a new screen.
 * New per-JVM compile-status cache {{{}GshTemplateCompileStatus{}}}, keyed by {{{}(configId, sourceHash){}}}: compiles a compiled template's source once via the GRP-7006 compiler and reuses the result until the source changes (same source-hash invalidation as the runtime registry). Read-only — does not define classes or affect the runtime per-template classloader registry.
 * Add inventory columns to the list: {*}Type{*}, *Mode* (interpreted/compiled), *Source* (inline/file), and *Compile status* (Compiled OK / Compile failed with diagnostics tooltip / Source file missing / em-dash for interpreted), with a last-compiled timestamp. Implemented via display getters on {{GuiGshTemplateConfiguration}} that read the already-loaded config cheaply.
 * Compile status is computed synchronously on render and cached; the async background pre-warm + progress indicator and the mode/status/type filters are a follow-up JIRA.
 * Externalized text for the new column headers and status values in {{grouper.textNg.en.us.base.properties}} only.
 * Tests: valid source → success; bad source → failure with diagnostics; cache hit returns the same result; source change recomputes.
