# GRP-6194  Add provisioner jexl function to get origin of a membership

Requested by a customer. They want a provisioner jexl function to get the name of the group for direct members, or the name of the parent group for an indirect membership. They think just one level up is good enough for most people.

Coincidentally, it's another use case for updating of non-key membership fields, and also for external membership attributes.
