# GRP-7261  grouper-docs: links should point to docs.grouper.internet2.edu, not grouper.atlassian.net

The markdown mirrors and scripts under grouper-misc/grouper-docs contain hardcoded links to grouper.atlassian.net. These should point at the public docs site, docs.grouper.internet2.edu, so readers of the mirrored docs land on the canonical published documentation rather than the Confluence cloud instance.

Current scope (as of this writing): about 11,600 occurrences of grouper.atlassian.net across roughly 1,380 files, including wikiMirror/spaces/Grouper (the bulk of it), issueMirror/spaces/Grouper, and the generator/helper scripts wikiMirror/wikiToMarkdown.py, issueMirror/jiraToMarkdown.py, redirects/build_redirects.py, plus the AI instruction files convertToMarkdownAiInstructions.md and convertJiraToMarkdownAiInstructions.md.

Fix both sides: rewrite the existing mirrored content, and update the generator scripts and instruction files so newly generated pages emit docs.grouper.internet2.edu URLs going forward. Note that Jira issue links in issueMirror may need different handling than wiki page links, since issues live in Jira and not on the docs site.
