# GRP-6064  grouper ui with oidc should be able to have multiple registrations

If you want a custom UI to reauth the user, you can register a second OIDC (can use the same registration)
{code:java}
grouper.oidcExternalSystem.ui_authn_test_pennkey.uiPathRegexes = ^.*UiV2CustomUi\.customUiGroup[?&]groupId=eb011719793842848e606ef9a686e590.*$
grouper.oidcExternalSystem.ui_authn_test_pennkey.authnTimeoutSeconds = 10
grouper.oidcExternalSystem.ui_authn_test_pennkey.extraAuthorizeParams = max_age=0
 {code}
