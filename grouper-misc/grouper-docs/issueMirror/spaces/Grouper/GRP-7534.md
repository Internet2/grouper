# GRP-7534  Google cloudidentity SCIM memberships

Google cloudidentity SCIM memberships needs special handling.
Google does not allow for returning all Users and all Groups.  When selecting a User - you do not see the groups it is in via SCIM.  When selecting a group - you do not see the members.
Google can enable the following url in SCIM as Users/ID?attributes=groups to return the groups that ID is in.  Grouper will be source for all users as we cannot obtain a list from the server of all users or groups.
