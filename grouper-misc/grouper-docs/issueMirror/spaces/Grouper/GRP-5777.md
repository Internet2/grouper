# GRP-5777  Group UI should hide (or support ) Import a list of Privileges when the group UI is in Privileges mode

From the Group UI.
I click on the "Privileges" tab.
I then want to add multiple people to have Privileges to the current group so I click on the 'Import a list of members" link.

But that only lets me add memberships *not Privileges*.

I think that link should be "hidden" ( not displayed ) when the Group UI is in "Privileges" mode.
OR ( better yet)
The window that is opened should support the 'Assign these privileges' options when opened from the Group UI is in "Privileges" mode
