# GRP-7033  GSH Java template compilation — mode picker and compile-on-save in the GSH template config UI

* Phase 5a. Builds on GRP-7006 (compiler), GRP-7010 (registry), GRP-7011 (modes/types), GRP-7026 (helper). Design doc {{grouper/temp/trash/gshCompileImprovement.html}} (sections "Compile on save", "Phase 5").
 * Add a *mode picker* ({{{}Interpreted Groovy/Java (legacy){}}} vs {{{}Compiled Java{}}}) on the GSH template config edit screen, wired to {{{}templateMode{}}}. Available {{templateType}} options depend on mode (compiled exposes daemon/daemonChangeLog/report/customUi/hook/library; interpreted stays gsh/abac/provisioner).
 * *Single Save button* (no separate Validate). On save of a compiled template, before persisting: run {{GshTemplateJavaCompiler}} (via the registry's parse+compile), then type-specific validation (correct framework base for the chosen {{{}templateType{}}}). Block save on compile error (render diagnostics inline with line/column + caret from {{{}GshTemplateCompileDiagnostic{}}}) or base mismatch; the existing saved version stays active.
 * Inline source editor for {{{}gshTemplateSourceType=textArea{}}}, or a container-file-path field for {{=file}} (one or the other per template).
 * Externalized text for the mode picker + error messages in {{grouper.textNg.en.us.base.properties}} only.
 * Tests: save with a valid compiled template persists; compile error blocks save with diagnostics; wrong base blocks save; interpreted save unchanged.
