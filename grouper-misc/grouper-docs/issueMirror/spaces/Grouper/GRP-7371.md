# GRP-7371  Limit appearance of stacktraces in UI and WS

See: [CWE-209: Generation of Error Message Containing Sensitive Information|https://cwe.mitre.org/data/definitions/209.html]

Stacktraces appear inconsistently in certain places in the UI and WS, and can disclose information on the underlying source code that can help in discovering future attacks.

Stacktraces can be logged for administrator troubleshooting, but should be hidden from end users.

This also affects pac4j, which will be a separate Jira.
