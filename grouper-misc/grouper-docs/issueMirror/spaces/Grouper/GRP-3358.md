# GRP-3358  cache GSH template compilation

GSH templates are now compiled and cached on first execution.  This means we can not worry so much about "lightweight" scripts.  The compile time should be less than 10 seconds.  If there is an common import we need in the groovy.profile we will add it.  We have added some more common imports from examples on wiki.  No examples on wiki will need imports when we add them all.
