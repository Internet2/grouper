# GRP-7449  GSH template config UI only shows fields that apply to the selected template type

Several GSH template config fields were shown for template types that never read them. Only gsh templates (run screen, WS, MCP) and abac templates (loader edit tab) run through GshTemplateExec; the other types (daemon, daemonChangeLog, report, customUi, hook, library, provisioner) are loaded by their own callers.

Changes: mcpEnabled shows only for gsh (was all but daemon). numberOfInputs and the input fields show only for gsh and abac (was all but provisioner and daemon). allowWsFromNoOwner shows only for gsh, since abac always has an owner group. useIndividualAudits now also shows for abac, which uses it. displayErrorOutput shows only for gsh, since abac errors are always displayed by the loader edit tab.

Display only; no config keys change and no runtime behavior changes.
