# GRP-7172  Create API methods to convert composite to/from direct memberships without delete/add cycle

If a user wants to change a composite group to a group containing direct members, the only way is to delete the composite which removes all the members, and then add the members directly.

In GSH, this is also the only way. This will lead to a large set of deleteMembership actions in the changelog stack after the deleteGroupComposite. Any adding back of members will happen after this, so there is no way to avoid a delete/add blip in downstream systems.

One option to mitigate this is to create a Group method that will convert the current membership of the group to its direct members as one atomic action. The method would somehow put the deleteGroupComposite on the changelog temp stack without triggering the deletion of all the members. I don’t know if it needs to do any addMembership or deleteMembership actions at all. It would depend on whether anything acting on the changelog would care whether it’s a direct or indirect member.

There are use cases for both converting a group from a composite and also to a composite from direct members. There should be methods that allow either of these to happen without deleting and adding everyone.
