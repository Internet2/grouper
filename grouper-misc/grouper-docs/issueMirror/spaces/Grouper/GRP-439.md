# GRP-439  add enabled/disabled dates to addMember WS and client

_(no description)_

## Comments

### mchyzer - 2010-05-24T15:43:46.003+0000

this is done.  For the WS, you can use this in the Lite or Batched modes:

     * @param disabledTime date this membership will be disabled, yyyy/MM/dd HH:mm:ss.SSS
     * @param enabledTime date this membership will be enabled (for future provisioning), yyyy/MM/dd HH:mm:ss.SSS

Note if either is blank, then that will blank out the enabled or disabled dates

for the client, same thing,  just use --enabledTime or --disabledTime.  Note for the client the time format is a lot more flexible:  e.g. you can do: 2009/3/2 or 3-Jan-2003 etc.  This is backwards compatible with the old format.
