# GRP-792  make grouper client easier to do scheduled jobs and incremental jobs

_(no description)_

## Comments

### mchyzer - 2012-05-14T19:28:54.370+0000

This is done.

To schedule an incremental job:

     GrouperClientXmppMain.xmppLoop(new GrouperClientXmppMessageHandler() {
      
      @Override
      public void handleMessage(Message message) {
        
        //whatever message we get, we know it is from the right sender based on
        //config, so just schedule a full refresh a minute from now
        scheduleFullRefresh();

      }
    });


To schedule a croned job (you need a unique job name):

    String jobName = "clusterLinuxFullRefreshJob";
    
    //e.g. 0 0 4 * * ?
    String quartzCronString = GrouperClientUtils.propertiesValue("clusterLinux.fullRefreshQuartzCron", false);
    
    GrouperClientXmppMain.scheduleJob(jobName, quartzCronString, ClusterLinuxJob.class);
