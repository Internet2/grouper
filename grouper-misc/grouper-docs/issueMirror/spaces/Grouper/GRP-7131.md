# GRP-7131  Add a rule action to set a membership end date (e.g. now + N days) when a member is added to a group in a folder

*What I want to do*

Attach a rule to a folder so that any membership added to a group within that folder automatically gets an end date set to a relative time in the future (in my case, 2 days from when the member is added). The membership should then expire/disable on its own at that end date.

*What happens now*

I configured a rule on the folder intended to set the end date on add-member, created a group in the folder, and added a member. The member is added, but no end date (membership disabled/end date) is assigned. Benjamin Rappleyea reproduced the same behavior independently: member added, no end date set. In one attempt the folder rule also blocked group creation until the group existed first.

*Expected behavior*

When a membership is added to a group covered by the folder rule, Grouper should stamp the membership's end/disabled date to {{now + N}} (configurable offset, e.g. 2 days), so the membership auto-expires.

*Notes*
 * This appears to be a new/unsupported rule capability rather than a bug in an existing one -- there does not seem to be an existing rule action that sets a relative membership end date on add. Confirmed with Chris Hyzer; agreed it should work and we can add it.
 * Ideally the offset is configurable (days/hours) and works at the folder level so it applies to all groups (existing and future) in that folder.
