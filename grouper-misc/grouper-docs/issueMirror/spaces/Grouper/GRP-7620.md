# GRP-7620  Upgrade proton-j to 0.35.0 for security

The 7.10.0 image ships Apache Qpid proton-j 0.33.10 (transitive from qpid-jms-client 0.61.0), which image scanners flag for these CVEs, all fixed in 0.35.0:

CVE-2026-66257, CVE-2026-66273, CVE-2026-66274 (HIGH), CVE-2026-66275, CVE-2026-66276, CVE-2026-66277

Change: pin org.apache.qpid:proton-j 0.35.0 (proton-j.version) in the dependency management of grouper-parent/pom.xml and of the three grouper-container poms, which do not inherit grouper-parent. qpid-jms-client 0.61.0 accepts proton-j [0.33.2,0.40.0), so qpid-jms-client stays at 0.61.0.
