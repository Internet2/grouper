# GRP-6317  output debugLog as json for better parsing

The debug log in Grouper is a key-value map that gets logged to container output or job logs. The output format is close to json, but not exactly because there may be commas in values. If it were a true json or some other format that could be parsed reliably, it would help tools that need to ingest it.
