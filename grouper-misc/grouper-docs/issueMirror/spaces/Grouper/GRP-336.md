# GRP-336  [ldappc] source-subject-name-map failed to lookup subject-attribute="id|name"

When the <source-subject-name-map subject-attribute="id|name" ...>, ldappc would not always provision the subject since   subject.getAttributeValue("id|name") may return null for the supplied source/subject adapters. Now ldappc calls subject.getId() or subject.getName() if appropriate after trying subject.getAttributeValue().
