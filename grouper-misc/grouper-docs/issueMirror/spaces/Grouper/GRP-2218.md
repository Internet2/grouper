# GRP-2218  UI fails to refresh group membership when users "Joins" the group.

When a user ( of the UI ) uses the "More Actions" --> "Join group" ( or "Leave group" ) the displayed list of members  (Assuming the user is displaying the "Members" tab) does not update to reflect the add/remove of the current user.

 

confirmed on the 2.4 (and v2.3 ) Demo server.
