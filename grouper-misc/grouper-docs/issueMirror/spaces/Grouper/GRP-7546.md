# GRP-7546  Freshservice agent provisioner: provision Grouper groups to agent roles as well as agent groups

Freshservice agent provisioner (GRP-7539): let a Grouper group provision to either a Freshservice agent group or a Freshservice agent role.

A new provisioning metadata dropdown (group or role, default group), assignable on a folder or a group, tells the provisioner which type each Grouper group is. It feeds a groupType target group attribute, like the Datadog provisioner (teams and roles) and the Azure group type metadata.

Freshservice roles are read-only in the API (list and view only), so roles must already exist in Freshservice. A role group matches an existing role by name or id. If the role does not exist, that group is skipped with an object error, the rest of the provisioning still runs, and the job ends in error. Grouper never creates, updates, or deletes roles.

Role memberships are the roles array on the agent: the provisioner GETs the agent, adds or removes the role in its current roles, and PUTs the roles back.

Requested by NDSU. Includes mock service support for roles, unit tests, and wiki updates.
