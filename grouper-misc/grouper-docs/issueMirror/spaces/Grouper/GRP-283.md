### mchyzer - 2009-05-29T04:48:44.846+0000

I turned caching on, changed some defaults so the cache timeout is small (10 seconds), and setup some regions for stem/group find by id/name.  It reduces queries in the UI.  Also, hibernate is pretty smart in that if an object is updated in the same instance, it will update the cache...  I think changes in members/groups/stems/fields happen less frequently than memberships, so I think that is a reasonable optimization.
