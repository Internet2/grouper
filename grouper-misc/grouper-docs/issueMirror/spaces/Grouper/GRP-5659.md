# GRP-5659  ability to compare memberships between two groups ( side by side ) in the UI, optional filters to:  exclude "intersection", show unique Group 1 members, show only unique Group 2 members

It would be helpful to be able to compare groups in the Grouper UI.

There are often times when users "manually construct groups" that end up being a LOT like a Reference group. Being able to compare the groups and see how similar or dissimilar they are would be useful.
