# GRP-5713  MembershipSave.save() says that it will throw a GroupNotFoundException, but it does not.

Documentation for the MembershipSave.save() method states that it throws a GroupNotFoundException if the group is not found.  However if you examine the code, it does not.  Instead it makes a GrouperUtil.assertion() call, which then throws a runtime exception.
