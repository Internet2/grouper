# GRP-6025  TeamDynamix needs throttling

The TeamDynamix provisioner for a client is failing because too many requests are coming in at once. There should be an option to limit the number of requests per minute, or maybe hour

## Comments

### Jim Beard - 2025-02-17T16:17:56.955+0000

The client in question is using 4.15.8.  While the codebase appears to look for the error string "Please try again later." in TeamDynamixApiCommands.java, then pause for 70 seconds, in practice the provisioner is erroring out with the following RuntimeException, 
{code:java}
Java.lang.RuntimeException: com.fasterxml.jackson.core.JsonParseException: Unrecognized token 'This': was expecting (JSON String, Number, Array, Object or token 'null', 'true' or 'false'){code}
I'm also concerned that this approach to the throttling will cause the provisioner to execute for a minute (until it hits the limit) and then pause for 70 seconds, then execute for a minute (until it hits the limit again) and then pause again for 70 seconds, etc.  Essentially causing the provisioner to spend half of it's time pausing processing.
