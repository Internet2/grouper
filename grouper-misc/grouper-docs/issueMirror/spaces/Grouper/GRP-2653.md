# GRP-2653  instrumentation graphs y-axes become increasingly large

Home > Miscellaneous > Instrumentation graphs

This displays 4 graphs of object activity. The first graph looks normal, but each subsequent graph has a y-axis the is double the size of the previous one. By the 4th graph, the display takes multiple screenfuls.

This bug may have been introduced with either visualization or the recent daemon job gantt chart

## Comments

### Chad Redman  (unc.edu) - 2020-04-20T21:00:13.791+0000

Confirmed that this started with the initial c3 upgrade for visualization, not anything with the job history chart. So introduced in 2.4 UI patch 14 (2.4.0-a29-u14-w3-p2).

It's hard to tell from the minified c3 javascript, but somehow it's not defaulting the svg parent divs to max-height 320 like it used to. This can be fixed by adding a style to all the graph component divs to max height 320, and the result looks like like it used to.
