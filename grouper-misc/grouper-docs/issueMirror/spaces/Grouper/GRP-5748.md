# GRP-5748  allow un-attested groups to be disabled

After "Days until recertify", add a config called "Disable group if not attested".  

Description is: If the group is not attested by its recertify date, then the group will be disabled and users will lose access.  The emails will go out before the recertify date as configured in the days before to remind setting (default two weeks).

There should be an audit about who did not certify the group and when it because disabled for attestation reasons.  Note if this option is selected, the emails to the reviewers should clearly state that if they do not attest the group by X date that the group will become disabled and users will lose access.
