# GRP-2948  Job history chart should show "incomplete" jobs

"Miscellaneous > Daemon jobs > Job history chart"
   Does the graph only show "success"/"completed" jobs?  ( I am guessing that it only does that. )Maybe it should also show All "Start times" with some assumed "N -minute" block for any jobs that don't have a "Stop time"? ( Maybe with an "include incomplete" option? )

I suspect that my daemon process was running something and was "killed" ( by the OS ) while it was running. However, when I look at the "Job history chart" I see nothing but Success ("green"). At the moment of the culling.Maybe nothing was running at the time. But then why would the OS have killed it?
I suspect that there is a job that is not shown on the chart..... Which is why I asked... Maybe I need to go digging through the DB to try to find it.... Hum...

I think it would be useful to assume some "short time" (5-10 minutes?) end time  for all jobs that don't yet have an end time.
And show the color based on their  status as documented by the log data.
