# GRP-2259  Loader log message bad format "found (object reference) members overall"

{noformat}
2019-08-01 13:04:48,271: [main] DEBUG GrouperLoaderType$4.runJob(425) - etc:loader:ref:by-affiliation: start syncing membership
2019-08-01 13:04:49,791: [main] DEBUG GrouperLoaderType$4.runJob(437) - etc:loader:ref:by-affiliation: found edu.internet2.middleware.grouper.app.loader.db.GrouperLoaderResultset@66b6873f members overall
{noformat}

This is specific to SQL_GROUPS_LIST jobs; other jobs have a similar output but correctly prints a number.

GrouperLoaderType#SQL_GROUP_LIST#runJob
{code}
          if (LOG.isDebugEnabled()) {
            LOG.debug(groupNameOverall + ": found " + grouperLoaderResultsetOverall + " members overall");
          }
{code}

Versus

GrouperLoaderType#syncGroupList
{code}
      if (LOG.isDebugEnabled()) {
        LOG.debug(groupNameOverall + ": found " + grouperLoaderResultsetOverall.numberOfRows() + " members overall");
      }
{code}

The code has been this way since v2.1!
