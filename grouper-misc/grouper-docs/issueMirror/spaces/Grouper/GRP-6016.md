# GRP-6016  Okta Provisioner should ignore entities or memberships that are missing an entity attribute set as required

Okta provisioner currently searches for entities and or memberships when an entity attribute is set as required. It should ignore them until the attribute is no longer null. This will save resources from making any API calls to Okta

m_error_code: REQ

m_error_message: Entity does not exist in target or cannot be found, and not creating entities
