# GRP-2530  Expand on reference group models - rosters, orgs, affiliations, etc

acamp 2019 feedback
 * Reference groups: section on a couple different reference trees: orgs, affiliations,...Course enrollments; LDAP makes it easy with wildcards, Grouper, the hierarchy has to be built.
 * Provide specific examples for how things, like reference groups, work in real world deployments; case studies...
 * Case studies keyed off the GDG, link off to community contribution pages, e.g. U Penn Course groups, GA Tech Course Groups
 * Ref Group models and another thing: refactoring groups: Start with what are the access policies you need to set, THEN decide on the reference groups you need to implement that particular policy, grow it organically by supporting additional access policy use cases
 * For new adopters, it would be reassuring to know that group structures can be refactored as you go along, converging on what really works for your organization. (See refactoring caveats below from Hyzer)
 * Perhaps a "Quick Start" version that reassures and gives the quick ways to get going.
