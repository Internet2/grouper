# GRP-7040  Expand SyncBackAllProtocolsTestHarness to aggregate full-sync and incremental tests across all provisioner protocols

* {{SyncBackAllProtocolsTestHarness}} previously aggregated only the FreshService Requester sync-back smoke tests into its {{{}TestSuite{}}}.
 * Expanded it to pull the full-sync ({{{}test<Protocol>FullSyncPopulatesGenericTables{}}}) and, where it exists, the incremental-sync test for each supported provisioner protocol: Adobe, Azure, Box, Datadog, Duo, FreshService Requester, Google, LDAP, Okta, Remedy, SCIM, TeamDynamix, TrueFoundry.
 * Adobe and Remedy have no incremental coverage in the existing tests, so only their full-sync test is included.
 * Lets the whole provisioning sync-back/full/incremental surface be exercised in one run while iterating on the framework (write-shadow precision pass, flush reorder, etc.).
 * Updated the class Javadoc to reflect the broader scope.
 * Not added to {{AllAppTests}} / {{All<Protocol>ProvisionerTests}} by design — each protocol's per-suite aggregator already includes its own tests; this harness is a convenience duplicate and is explicitly marked "DO NOT ADD THIS TO THE HARNESS, IT IS A DUPLICATE."
