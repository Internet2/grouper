# GRP-7575  Security: User-supplied configuration and expressions no longer run as root

Security fixes from the 2026 Grouper security review, category D. Each line is one fix, its severity, and the public advisory it belongs to:

- Workflow configs check the author's privileges on named groups (high, advisory H1)
- Expression language runs in a restricted mode (high, advisory H2)
- Loader config import uses the loader screen's checks (medium, advisory H2)
- Provisioner and unrestricted GSH templates limited to sysadmins (high, advisory H4)
- GSH template forms check access before running code (high, advisory H4)
- Delegated daemon admins limited to non-script daemon types (medium, advisory H4)
- Scripted group row checks follow privacy realms (medium, advisory H2)
- JEXL script tester limited to sysadmins in its group (medium, advisory H2)
- Disabled compiled hooks do not run (medium, advisory H4)
- Rules run-daemon option limited to what the form offers (medium, advisory H3)
- Built-in folder templates check folder and group admin before assigning types or inherited privileges (medium, advisory M3)
- Send-email rule fields limited to predefined variables for non-sysadmins (high, advisory H3)
- Loader query expressions limited to sysadmins (high, advisory H2)
- Custom UI variable names limited to letters, digits and underscores (medium, advisory H4)
- Rules that fail validation do not run (high, advisory H3)
- Custom UI LDAP filter results are not evaluated again (medium, advisory H2)
- Inherited privilege rules that run with wheel rights cannot carry expressions (high, advisory H3)
- Workflow configuration changes group view privileges only as an admin (low, advisory H1)
- Delegated loader editors limited to groups under folders they administer (high, advisory H2)

Fixed in 7.9.1 (GROUPER_7_9_0-branch). The same fixes were provided as security patches for earlier releases. See the security announcement for details and required steps.
