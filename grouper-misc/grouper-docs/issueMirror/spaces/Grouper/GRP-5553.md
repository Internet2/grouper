# GRP-5553  Reword description of "Delete value only if managed by Grouper"

The description of this field is
_During a full sync, Grouper will keep track of all membership values for all provisionable users/groups. If this is true, then during a full sync, if selecting all users in entity attributes or all groups in group attributes then remove Grouper managed membership values from all users/groups which are supposed to be removed (this includes users/groups which are not provisionable). i.e. if that value is in another membership then it is allowed. If not, then do not delete it. Default value is 'false'.
_


I know the original description was already improved once, but I still cannot parse what this means and what effect this has. If values are based on groups, why would the same membership exist in a different context? Other than that, what does this do that "Delete memberships if not exist in Grouper" wouldn't do normally? What is the use case for this option?
