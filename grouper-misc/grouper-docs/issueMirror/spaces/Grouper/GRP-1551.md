# GRP-1551  PSPNG - Encrypted passwords in grouper-loader.properties

The ldap passwords necessary in grouper-loader.properties for PSPNG should be encryptable.

This will be done by wrapping appropriate strings in a call similar to decryptIfEncrypted( )
