# GRP-4483  grouper_members ddl is too large for some mysql configurations

im getting this in mysql for grouper_members... change size of search strings to 1500 instead of 2048

Caused by: java.sql.SQLSyntaxErrorException: Row size too large. The maximum row size for the used table type, not counting BLOBs, is 65535. This includes storage overhead, check the manual. You have to change some columns to TEXT or BLOBs

## Comments

### Andrew Morgan - 2025-04-14T21:07:38.881+0000

The code change in Grouper only applies to new installs on MySQL/MariaDB.  On an existing Grouper system that is being upgraded, run the following SQL *before* upgrading to Grouper v2.6:
{code:java}
ALTER TABLE grouper_members 
 MODIFY search_string0 VARCHAR(1500) NULL,
 MODIFY search_string1 VARCHAR(1500) NULL,
 MODIFY search_string2 VARCHAR(1500) NULL,
 MODIFY search_string3 VARCHAR(1500) NULL,
 MODIFY search_string4 VARCHAR(1500) NULL; {code}
The old size of these columns was 2048.
