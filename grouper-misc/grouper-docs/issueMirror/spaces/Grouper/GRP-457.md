# GRP-457  grouper ui should default to "explore" view

It is confusing in the UI when you are browsing groups, and dont see the group you expect to see.  This is because the default view is memberships that the user is a member of.  Most people in the UI are not looking at their memberships, instead they are browsing or managing groups.  So the default should be "explore" or "manage groups".  Since manage groups would also filter groups and potentially be confusing, the default should be explore.  This should be configurable.
