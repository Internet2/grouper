# GRP-7296  Google Provisioner doesn't handle result code 500

If google returns an error code of 500 for an internal error.  Grouper doesn't seem to handle that by default and simply fails to make any retries on it.  Google’s doc’s say these can be transient issues and recommend implementing exponential backoff and retry the request after a short delay.  Grouper treats these as an outright failure and does not try rerunning them.
