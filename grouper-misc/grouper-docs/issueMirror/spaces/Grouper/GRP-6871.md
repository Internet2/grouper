# GRP-6871  MCP well-known endpoint should use grouper.ws.url config instead of request-derived URL

When Grouper WS runs behind a reverse proxy, the MCP OpenID configuration endpoint (/.well-known/openid-configuration) returns URLs with the internal container hostname (e.g. localhost:8081) instead of the external hostname. This is because the servlet builds URLs from request.getServerName() and request.getServerPort(), which reflect the local Tomcat listener rather than the external-facing URL.

The fix uses the existing grouper.ws.url config property (via GrouperConfig.getGrouperWsUrl()) to build the issuer, token_endpoint, registration_endpoint, and jwks_uri URLs, falling back to the request-derived URL if the property is not configured.

Deployers can also work around this by enabling the Tomcat RemoteIpValve (GROUPER_TOMCAT_REMOTE_IP_VALVE=true) and configuring their proxy to forward the appropriate headers.
