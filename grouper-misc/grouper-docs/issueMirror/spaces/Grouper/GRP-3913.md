# GRP-3913  add ability to manage scope for attribute definitions

_(no description)_

## Comments

### Chris Hyzer - 2022-03-06T21:41:39.229+0000

scope is where attributes can be assigned.  This is mostly important for assignments on assignments to specify that they can only be assigned on certain markers.  With the addition of editing attributes on the group edit screen, we need scopes for assignments on assignments so we know which sub form elements relate to their parent.

Name of marker attribute def:   [=================]

                                assignment on assignment can be assigned (e.g. a:b:c:myMarkerDef){code}
