# GRP-3698  allow GrouperSystem password to be set by env var in container (not in quickstart mode)

_(no description)_

## Comments

### Chris Hyzer - 2021-11-17T14:36:28.561+0000

You can set this in a container running any command (e.g. ui)
{code:java}
GROUPERSYSTEM_QUICKSTART_PASS=pass{code}
Note, either the quickstart needs to be running or GROUPER_UI_GROUPER_AUTH needs to be true to set that pass in the UI

Note, either the quickstart needs to be running or GROUPER_WS_GROUPER_AUTH needs to be true to set that pass in the UI

Note, if you use different auth (e.g. shib), then this password will have no effect

Only set this password temporarily while bootstrapping, then remove this env var
