# GRP-1229  Field.isGroupListField() is implemented wrong, shouldnt have access in there

FROM

  public boolean isGroupListField() {
    return StringUtils.equals("list", this.type)
      || StringUtils.equals("access", this.type);
  }

TO

  public boolean isGroupListField() {
    return StringUtils.equals("list", this.type);
  }

Note, all the uses of this method need to be changed
