# GRP-5852  scim provisioner does not remove custom json pointer fields correctly

 json pointer is:
{code:java}
/urn:ietf:params:scim:schemas:extension:servicenow:2.0:User/department/value {code}
should be something like this
{code:java}{
  "schemas": [
    "urn:ietf:params:scim:api:messages:2.0:PatchOp"
  ],
  "Operations": [
    {
      "op": "remove",
      "path": "urn:ietf:params:scim:schemas:extension:servicenow:2.0:User:department.value"
    }
  ]
}

 {code}
