# GRP-4126  Remove old ant project grouper-qs-builder

Grouper top level project grouper-qs-builder is a very old (i.e. back to the very first CVS commit) ant build. It was used as a general reference for customizing many aspects of Grouper, none of which work anymore. The demo data files (quickstart.xml, subjects.sql) are also in grouper/misc/testdata as an exact copy.

Script grouper/misc/buildGrouperQs.sh also references this folder. Should it also be removed, or left as a breadcrumb so someone can see where the original directory was?
