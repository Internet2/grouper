# GRP-7200  Generate a Google sitemap for docs.grouper.internet2.edu from the wiki mirror

wikiToMarkdown.py now also emits sitemap.xml for the public docs custom domain docs.grouper.internet2.edu. Only the Grouper space is listed; the internal GrIntDev space is excluded so its pages are never advertised to search engines. URLs are de-duplicated and sorted so the file is idempotent (an unchanged wiki produces byte-identical output).

Confluence Cloud is fully managed and cannot serve a static sitemap on the docs custom domain, so the file is cross-hosted on grouperdemo.internet2.edu (Internet2 box i2midev6, /var/www/html) and submitted to Google Search Console using multi-site sitemap support, with both hosts verified in the same account. Google read it successfully and discovered all 1009 pages.

Added --sitemap-only and --no-sitemap flags to wikiToMarkdown.py and documented generation, deploy to i2midev6, and the one-time Search Console setup in section 11 of convertToMarkdownAiInstructions.md.
