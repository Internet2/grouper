# GRP-7109  Full sync: resolve memberships from the sync-back cache instead of retrieving from the target

Adds {{{}provisioner.<configId>.fullSyncMembershipsFromSyncBack{}}}, the memberships analogue of the users option. When on, full sync reconstructs the target memberships from {{grouper_prov_mship}} (joined to {{{}grouper_prov_user{}}}/{{{}grouper_prov_group{}}} for the target ids) instead of pulling them from the target. For group-centric targets (Okta) this skips the expensive per-group {{skinny_users}} iteration.

Same cache-first model: empty membership cache → normal target retrieval (repopulates the cache); non-empty → serve as the target membership set. The cache is treated as the target set, so the normal compare still adds memberships present in Grouper but not the cache and removes stale ones (memberships aren't individually re-read; only referenced users are, via the existing path). Gated by DAO capability {{canRetrieveAllDataExcludingMemberships}} and request flag {{{}retrieveMemberships{}}}. Wired for Okta; hidden for Adobe/Duo/TrueFoundry (memberships derived from the user pull) and LDAP.
