# GRP-7520  AI assistant: the scope checkboxes save as soon as they change, without a Save button

On the AI assistant page, the checkboxes for what the assistant may do in this session (read-only, read and write, SQL, admin) only took effect after the user clicked Save. People forgot to, and then the assistant still could not do what they had just ticked.

The Save button is removed. Each checkbox saves the scope when it changes, and a status line next to the boxes says it was saved and that it applies from the assistant's next step. Screen readers announce it. Keyboard focus stays on the box just changed: the boxes are only redrawn when what was saved differs from what was sent, e.g. a category the user's groups no longer allow.

What is saved and how it is enforced does not change: the scope can only narrow what the user's groups allow, and it is checked each time a tool runs.
