# GRP-7310  UI accessibility: stacked layout and visible labels for inline filter forms

Several filter forms use a cramped inline (form-inline form-filter) layout that squeezes controls across one row and, in places, relies on a placeholder as the only visible label. Convert each to a stacked form-horizontal layout (each control on its own line: label, then control, then an Apply/Reset actions row) and add a visible associated label wherever the field relied on a placeholder. This fixes the missing-visible-label problem (SC 3.3.2) and the layout crowding.

Scope: the ~12 form-inline form-filter screens - myStems (My folders, DONE), plus stem/viewStem (folder view), stem/stemPrivileges, myGroups, myGroupsMemberships, myGroupsJoin, myServices, myFavorites, myActivity, admin/adminDaemonJobs, admin/adminDaemonJobsViewLogs, group/grouperLoaderOverall, group/grouperLoaderViewLogsTab. Each is restructured and verified live individually since their controls differ. NOTE: trailing-colon label cleanup is a separate consistency ticket (GRP-7311); removing zebra striping from the striped-table filters is GRP-7312 (pending Kara).
