# GRP-962  GroupID/FolderID - default to foldername

It is somewhat annoying to have provided a GroupID/FolderID.  We believe by default it should be set to the same name as the group/folder since this is what everyone does.  It is rare it set to a different value.  It would be really nice if this enhancement could be made for the 2.2.0 release as it would greatly aid in the simplified use of creating groups/folders for our users.
