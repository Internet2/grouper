## Comments

### Gary Brown - 2008-12-12T15:48:25.211+0000

I created a group for which no one had privileges and then searched for it as a non-wheel user. The Group was found and the group icon displayed but no name/attributes were displayed. Clicking the group icon gave an error because the API would not allow the user to view the group. So, I don't think it was ever possible to browse the group. If GrouperAll has privileges that could lead to some confusion.

I have modified DoSearchSubjectsAction to process any result list. If a subject is a group it tries to instantiate it. If it fails the subject is removed from the results. A search which returns many groups could become quite slow, but we'll have to consider that if and when it becomes a problem.
