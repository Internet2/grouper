# GRP-1563  PSPNG - FullSync on startup (Post PSPNG Patch #11)

PSPNG Patch #11 stopped using PSP's FullSync configuration paragraph that included a RunAtStartup option. 

Because the new, OtherJob syntax that is used after Patch #11 (probably) does not have a RunAtStartup option, such an option should be added to the Provisioner's Configuration options. This would then be used when the background full-sync engine is created to trigger a queuing of all the groups.
