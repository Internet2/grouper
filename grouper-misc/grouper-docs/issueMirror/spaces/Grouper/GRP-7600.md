# GRP-7600  Group summary Privileges section says "Group is not a member of any other groups" when the group has no privileges

On the group Summary tab (Show more information), when the group has no privileges counted, the Privileges section shows "Group is not a member of any other groups", the same line as the Memberships section above it.

Cause: groupSummaryMorePrivileges.jsp uses the memberships text key groupSummaryPageMembershipsGroupNotUsedMessage in its otherwise branch (since GRP-6368).

Fix: new text key groupSummaryPagePrivilegesNone for the privileges section.
