# GRP-160  Indirect privileges for GrouperAll (Every Entity) are not displayed and link is 'broken'

Trying to reproduce JDK 1.6 issue I noticed that GrouperAll privileges are not displayed + link has no parameters and so clicking it gives an error. 

## Comments

### Gary Brown - 2008-08-27T15:09:48.208+0000

subjectHasPrivilegeView.jsp depended on params and privMap being passed from a higher level tile. This was not working for some reason with JDK 1.6  which used to give an error. The error stopped happening with v1.6 of subjectHasPrivilegeView.jsp as a jsp:useBean tag ensured params was always available, however, it did not address the underlying problem.

I have worked around the issue - params -> linkParams and privMap is now shifted to the SubjectAsMap instance that is passed. This works for JDK 1.5 and 1.6
