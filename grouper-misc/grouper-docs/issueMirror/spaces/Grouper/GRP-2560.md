# GRP-2560  Consider a fake user for grouper loading groups with no members

In some cases, you want to create groups with no users, in such a case it would be useful to have a special user that can be resolved, but doesn't actually add the user. This would allow a group structure to be built, even if not all the groups have users yet. I made a suggestion in slack that the user subject_id could be "null" and the subject_source_id could be "g:isa"
