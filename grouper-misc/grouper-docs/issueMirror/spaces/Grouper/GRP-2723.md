# GRP-2723  add grace periods to grouper

Add the grace marker attribute to a group, then assign name value pairs: days (integer), and group_name (full path of group).  The loader will create the group named "group_name" which will be populated with people who are not in the group, but were less than "days" days ago.  There is a change log consumer that will do real time updates or call a full sync of the loader job if too many records change or if attributes change.
