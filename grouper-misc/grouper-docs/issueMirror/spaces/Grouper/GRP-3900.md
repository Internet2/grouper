# GRP-3900  Allow an enabled/disabled date when adding a memberships from import screen

See GRP-2238 for background.   See [GRP-619|https://todos.internet2.edu/browse/GRP-619] for background

Allow an enabled/disabled date when adding a memberships, and dont add the membership then disabled right after.  maybe sure the membership is added as disabled if it is disabled. 

Add time component to enabled/disabled dates
Have a couple formats that are acceptable

2011-07-18T10:00+02:00
2011/07/18 15:24   (use timezone of container)
2011/07/18 3:24 PM    (display as this) (use timezone of server)

 

I think we should require time component...  and not allow midnight... since its confusing... midnight the night before or night after?

i.e. 2021/04/05 is no longer a valid disabled time from UI
