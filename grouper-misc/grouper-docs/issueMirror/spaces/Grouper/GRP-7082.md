# GRP-7082  Global ABAC follow-up: deterministic abacGlobal value query and configurable cache duration

Two small follow-ups to the ABAC global variables work (globalAttributeValue):
 # Added "order by gdfa.internal_id" to GrouperDataFieldAssignDao.selectDataFieldAssignValuesByMemberInternalId so that, if a data field is somehow assigned more than once to the etc:abacGlobal member, the value kept (last row wins) is deterministic across runs. Matches the ordering already used by the sibling by-ids query.
 # Made the abacGlobal value cache duration configurable instead of a hardcoded 2 minutes. New config key grouper.abac.globalAttributeValuesCacheMinutes (default 2), and the cache is now built lazily via a method so the configured value is read at runtime rather than at class load.

No behavior change for the normal single-value case; default cache duration stays at 2 minutes.
