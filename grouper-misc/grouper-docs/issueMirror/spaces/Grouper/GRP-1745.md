# GRP-1745  Implement help page in new UI

The Help document currently is reachable in the Admin UI. If the Admin UI goes away, the Help page needs to be accessible by the new UI. It may be good to have a logged in version as well as an anonymous one, so that the breadcrumbs and menus are there for navigation.

 

For translation versions, there is too much text to be practical in a property. Instead, one option is to add language-specific versions in the grouperText directory for the page to include.
