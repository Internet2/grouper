# GRP-7070  v6 loaders using display extension as display name gives error: "How can a group have a blank folder display name"

In v4, if you had a loader and wanted to set the display extension for a new group without touching the parent folder names, you could have the desired display extension as the GROUP_DISPLAY_NAME and it worked. In v6 this no longer works, and it returns error "How can a group have a blank folder display name?"

If the parent folder is based on the department name but is created by another loader, I would rather leave it alone and not need to calculate the name to match exactly so it doesn't change it. 

There is an option for Sync display names configuration, but neither of those is satisfactory. Either choice - sync after base folder name, or levels from group - require at least one folder level.
