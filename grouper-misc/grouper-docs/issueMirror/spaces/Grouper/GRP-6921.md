# GRP-6921  XmlExportGshScript support for multiple stems

XmlExportGshScript currently only supports exporting a single stem or a set of individual objects. Add support for specifying multiple stems so that all objects under each stem are included in a single export, without requiring callers to use XmlExportMain directly.

it's already feasible because the driving class XmlExportMain supports it. It's just the XmlExportGshScript class that's missing a method to add multiple stems.
