# GRP-535  grouper client xmpp listener will not respond to messages from groups that are not hardcoded in the config file to listen for

This is generally ok, but for atlassian, we are listening for any group in a stem, not specific individual groups.  so there is now a switch in the grouper.client.properties where you can ignore the groups to listen for:

e.g.

grouperClient.xmpp.job.atlassian.allowIncrementalNotInGroupNamesList = true
