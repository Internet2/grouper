# GRP-422  make ldappcng its own project

Make ldappcng its own project: ldappcng/ldappcng, so that Grouper doesnt need 40 jars of 40 megs.  You should be able to do:

ant dist

in the ldappc project, and 

ant ldappcng

in grouper, then run gsh -ldappcng as normal...
