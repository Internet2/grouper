# GRP-7532  Fix misspelled OAuth config key grouper.oauth.redrectUri (should be redirectUri), with upgrade task for database configs

The OAuth redirect URI allowlist config key is misspelled: grouper.oauth.redrectUri.<configId>.regex (redrect instead of redirect). It is in grouper.base.properties (MCP / OAuth section), GrouperOAuthStore (the config key pattern and the error message), and GrouperOAuthServlet javadoc.

Fix:
- Rename the key to grouper.oauth.redirectUri.<configId>.regex, and keep reading the old redrectUri spelling for backward compatibility (deprecated, log a warning)
- Add an upgrade task that renames existing grouper.oauth.redrectUri.* database configs (grouper_config) to grouper.oauth.redirectUri.*
- Update the base properties documentation and the MCP wiki, with an instruction for people who set it in a properties file to correct the spelling
- The GTE sets it in base/container_files/grouper/conf/grouper.properties, so update that too

Found in the TechEx 2026 Grouper MCP/AI training, where the lesson has to point out the misspelling.
