# GRP-1165  Provide "progress bars" as part of artifact downloads and install

Allow the grouper installer to demonstrate progress when it's downloading artifacts. This does not necessarily have to calculate the max; it could simply show progress in a fuzzy ". . . . . . . " mode. Or provide a status update every 5 seconds or so etc. 

## Comments

### mchyzer - 2015-07-20T01:29:11.495+0000

To use this, change the underlying method to a helper method, encapsulate in a Runnable, and pass to progress method (also use final variables).  Here is an example:

    final File[] result = new File[1];
    
    Runnable runnable = new Runnable() {

      public void run() {
        result[0] = untarHelper(fileName, autorunPropertiesKeyIfFileExistsUseLocal);
      }
    };

    GrouperInstallerUtils.threadRunWithStatusDots(runnable, true);

    return result[0];
