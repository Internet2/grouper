# GRP-7433  AssetSonar provisioner: use a WsBearerToken external system instead of a custom AssetSonar one

The custom AssetSonar external system (GRP-7420) stored its REST token under apiToken, whose name lacks pass, secret or private, so GrouperConfigHibernate.containsPasswordRelatedWords did not treat it as a secret. Its only other credential, the SCIM connector key, was used just by the connection test and is not needed.

Remove AssetSonarExternalSystem and use the generic WsBearerToken external system: endpoint = tenant url, accessTokenPassword = REST token (encrypted and masked), httpHeader = token, prependBearerTokenPrefix = false, test button testUrlSuffix = /members.api with testUrlResponseBodyRegex = ^.*status.*$. This also brings proxy support and delayAfterEachCallInMs. The tenant role ids move to the provisioner (assetSonarStaffUserRoleId, assetSonarAgentRoleId, assetSonarAdministratorRoleId). MCP admin_external_system_get needs externalSystemType = assetSonar.
