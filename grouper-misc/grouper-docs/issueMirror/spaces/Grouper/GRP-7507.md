# GRP-7507  Alphabetize the links on the UI Miscellaneous page

The links on the UI Miscellaneous page were not in alphabetical order. Newer links (Model Context Protocol (MCP), AI assistant, MCP recipes) had been added after Forms instead of in their alphabetical position, and AI assistant usage was listed after Authentication in the Administration section.

Reordered the links in grouper-ui/webapp/WEB-INF/grouperUi2/index/miscellaneous.jsp so both the main list and the Administration section are alphabetical. No links were added or removed, and the conditions that decide who sees each link are unchanged.
