# GRP-7197  Provisioner view details (the hyperlink) should have action menu consistent with the rest of the provisioner pages

On the provisioner listing, users like to click on the hyperlinked name of the provisioner because it looks obvious and because it’s easier than following a row from the far left of the screen to the far right. Then they are confused because the actions menu doesn’t have links to the full and incremental sync daemons. It sounds trivial, but it is a point of frustration for nearly everyone I work with. I tell people not to use the hyperlink since the actions list is incomplete (plus it’s a dump of technical data that’s not usually what the users are looking for).
