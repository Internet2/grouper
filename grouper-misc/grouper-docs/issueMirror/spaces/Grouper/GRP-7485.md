# GRP-7485  Add Smartsheet provisioner

New Grouper provisioner for Smartsheet (Smartsheet API 2.0) using a WsBearerToken external system. Provisions Grouper groups to Smartsheet groups, group memberships to Smartsheet group members, and manages Smartsheet organization users (add user, deactivate user).

Membership type is membershipObjects. Groups match on the cached Smartsheet group id with name for the initial match. Users match on email. Grouper only deletes groups it created, like other provisioners. Includes a mock service handler, tests, base properties, externalized text, and documentation.
