# GRP-2214  PSPNG - FullSyncing group not selected for provisioning

When a provisioning-selected group is changed, *persistent* full-sync queue items can be created. These queue items remain even when the group is later deselected.

 

PSPNG should drop full-sync queued items that reference groups that are not selected for provisioning.
