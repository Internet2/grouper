# GRP-6919  "gsh -registry -check -runscript -noprompt" does not exit

Using `./bin/gsh.sh -registry -check -runscript -noprompt` in V6 does create the tables and runs the upgrade tasks, but is frozen and never exits. This makes it unusable for automated deployments.

Unclear yet on what is stuck. It might be the Felix framework which has all of its stop functionality commented out. But that change was made in 2022 and this seems to be a more recent problem.

The workaround so far seems to be `./bin/gsh.sh /dev/null` which exits fine with a code 0, meaning success. Since gsh itself works but not with the -registry flags, it may be something related to that.
