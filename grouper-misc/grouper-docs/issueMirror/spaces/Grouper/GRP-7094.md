# GRP-7094  Accessibility: Focusable modal close links are hidden from assistive tech. 

Several modals render the close control as <a ... aria-hidden="true" class="close">x</a>, so keyboard focus can land on a control that screen readers are told to ignore. Change to button, remove href, remove aria-hidden, 
{code:java}
<div class="modal-header"><a href="#" data-dismiss="modal" aria-hidden="true" class="close">x</a>

change to be something like:
<button type="button" class="close" data-dismiss="modal" aria-label="Close">
    <span aria-hidden="true">&times;</span>
  </button>{code}
