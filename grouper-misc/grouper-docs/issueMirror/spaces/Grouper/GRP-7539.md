# GRP-7539  Freshservice agent provisioner (contributed by NDSU)

Add a Freshservice agent provisioner (edu.internet2.middleware.grouper.app.freshServiceAgent.FreshAgentProvisioner) that provisions Grouper groups to Freshservice agent groups, and members to Freshservice agents.

Contributed by North Dakota State University (danygard, https://github.com/DanNDSU/grouper_v6). The code was rebuilt from the v7 Freshservice requester provisioner so it is consistent with it (same structure, update style, sync-back to the generic provisioning tables, progress labels, mock service, and tests).

Differences from the requester provisioner, due to the Freshservice agent API: agent group memberships are the members array on the group (no member endpoints), so add/remove is a read and PUT of that array. Freshservice requires a role to create an agent, so there is a defaultAgentRoleId (and defaultAgentRoleAssignmentScope) config. A requester with the email of a new agent is converted with convert_to_agent. Freshservice reactivates and converts agents as occasional, so reactivateAsFullTime (default true) sets them back to full-time. Agents have an occasional attribute.

Includes base config, UI text, the start-with list entry, a mock service handler (mockServices/freshAgent), and unit tests (AllFreshAgentProvisionerTests).
