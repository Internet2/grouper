# GRP-7309  UI accessibility: loading spinner needs a status message (role=status)

The only loading indicator during ajax is the blockUI overlay spinner (commonBottom.jsp sets blockUI defaults message to busy.gif). It was an img with alt=busy, which gives screen reader users no meaningful loading status (SC 1.1.1, 4.1.3).

Fix: wrap the spinner in a role=status live region with a visually-hidden Loading message so screen readers announce the loading state when the overlay appears, and make the spinner image decorative (empty alt) so it is not read as busy. Added text key guiLoading=Loading. Note: text is JVM-cached, so a Tomcat bounce is needed to load the new key (the markup change - role=status + decorative img - is live already). fr.fr falls back to English until a French string is added.
