# GRP-5560  When appending debug log to loader log, put a newline and after before it

When a daemon log has debugLog appended, it bleeds into the lines before and after it. It's harder to read, and it takes guessing to know when it starts and ends

 

E.g.
{code}... lastSequenceProcessed: 2028, tookMillis: 0, eventsSkipped: 6Did not get all the way through the batch! 2028 != 2034
{code}
