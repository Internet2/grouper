# GRP-2884  Configuration UI unable to change "Expression Language Scriptlet" indicator

Using configuration UI, modifying existing values, if you set a value as a literal string. then pasted in an expression scriptlet and switched the "Expression Language Scriptlet" from "No" to "Yes", it saves the scriptlet text as a literal string value. It does not save the scriptlet setting. Consequently, it does not show as an "EL script" in the set value.
