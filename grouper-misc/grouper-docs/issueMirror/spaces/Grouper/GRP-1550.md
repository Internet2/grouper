# GRP-1550  PSPNG - Delete empty (bushy) OUs

PSPNG should delete empty OUs when they were created as part of a bushy provisioning destination.

For example:
group a:b:c:group1 gets created and provisioning, creating ou=a, ou=b and ou=c as a side effect.

If group1 was the only group provisioned into c and group1 was deleted, ou=c should be deleted along with ou=b and ou=a if they were to also become empty.
