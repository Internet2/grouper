# GRP-112  UI bugs when using browser back button

There appear to be multiple bugs when a user uses the browser back button.

Example 1:

1.  Go down a stem hierarchy with a few mouse clicks, hit the back button a couple of times, then click on a "Create Group" button.  
2.  The UI will want to create the group in the stem the user was in prior to hitting the back button.


Example 2:

1.  Go to the group summary of a group.
2.  Click on "View entity details".
3.  Hit back on the browser.
4.  Click "Delete" to delete the group.
5.  The user gets an error.
