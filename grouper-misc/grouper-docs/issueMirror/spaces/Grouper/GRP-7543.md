# GRP-7543  Scripted groups: refuse a script that refers to its own group, is too long, can't be parsed, or is for a composite group

h2. Overview

Saving a scripted (JEXL) group accepted some scripts that can't work. Each one either broke later, in the sync, or failed with an unhelpful error. Each is now refused when the script is saved, with a message saying why.

h2. Problems fixed

* A script could refer to its own group, for example entity.memberOf('this:group'). On its own that does nothing. With an or, the group only ever grows, because its members keep themselves in. With a not, its members flip on every sync.
* A long script could fail with a database error on save, because the value doesn't fit in its column: on Oracle over 4000 bytes, on Postgres over 4000 characters. MySQL's column holds more.
* A script that couldn't be parsed made the save fail with a generic error, and the parse error went only to the log.
* A composite group could be made a scripted group. A composite's members come from its factors, and the sync adds and removes members directly, which Grouper refuses for a composite ("cannot add member to composite membership"). So every sync failed on that group.

h2. Change

GrouperAbacScriptedGroup.checkScriptForSave, which the UI's loader screen uses, refuses each of these:

* a script longer than 4000 bytes, counted in UTF-8 bytes as Oracle counts them: "JEXL script is too long, it can be at most 4000 bytes";
* a group that is a composite: "A composite group cannot be a scripted group.  Remove the composite first";
* a script that can't be parsed: "JEXL script is invalid", followed by the parser's description of the problem, for example "parsing error in '('". The place in Grouper's code where the parser was called, which JEXL puts at the start of its message, is left out;
* a script that uses its own group by memberOf, memberOfAny, recentMemberOf or a bare group name: "A scripted group's script cannot refer to the group itself". This is checked straight after parsing, before the analysis runs its count queries.

New text keys: grouperLoaderEditJexlScriptTooLong, grouperLoaderEditJexlScriptComposite and grouperLoaderEditJexlScriptRefersToItself. The parse error uses the existing grouperLoaderEditJexlScriptInvalid.
