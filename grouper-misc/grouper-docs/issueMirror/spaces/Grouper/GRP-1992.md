# GRP-1992  PSPNG attempts to process a deleted group

as discussed on core list - PSPNG will attempt to process any deleted group, even if never PSPNG provisioned.  This really slows down PSPNG provisioning especially for large deleted groups.  If attributes of a group were stored in PIT then PSPNG could check to see if it needed to process the group or skip it.  Of course, a deleted group would need to resolve the pspng related attributes up the grouper tree and store that result in PIT.
