# GRP-6848  Tomcat access logs never going to container stdout

In V5+, property GROUPER_TOMCAT_LOG_ACCESS_DIRECTORY says where to save tomcat access logs to. If you don't set it, it goes to /opt/grouper/logs. There is no option to set environment variables to have it go to container output.

{code:xml}
<Valve className="org.apache.catalina.valves.AccessLogValve" requestAttributesEnabled="$GROUPER_TOMCAT_REMOTE_IP_VALVE" directory="$GROUPER_TOMCAT_LOG_ACCESS_DIRECTORY" prefix="tomcat_access_log" rotatable="false" pattern="%h %l %u %t &quot;%r&quot; %s %b" /> {code}

Up until 5.7.0 this was going to /tmp/tomcat_access_log. In V4 this was set up as a formatted pipe to stdout. But in V5 the pipes went away, so it was just a file in /tmp that sat there and accumulated, but most admins were unaware of. In V7 the /tmp part was changed to be configurable. But the file part is still tomcat_access_log.

The internet thinks if your directory is /dev and your file is stdout, and there is no file rotation, this should work. It doesn't work, at least as the tomcat user this runs as.

Adding a custom startup hook to create the access log file as a fifo pipe does work. Maybe there should be an environment variable for this?

{code}
#!/bin/sh

# called after the setupFiles functions is called, almost before the process starts
grouperScriptHooks_setupFilesPostChown() {
  echo "grouperContainer; INFO: (grouperScriptHooks.sh-setupFilesPostChown) Running startup hooks"
  if [ "$GROUPER_TOMCAT_LOG_ACCESS" == "true" ]; then
    if [ "$GROUPER_TOMCAT_LOG_ACCESS_DIRECTORY" != "" ]; then
      rm -f $GROUPER_TOMCAT_LOG_ACCESS_DIRECTORY/tomcat_access_log
      mkfifo -m 666 $GROUPER_TOMCAT_LOG_ACCESS_DIRECTORY/tomcat_access_log
      cat <> $GROUPER_TOMCAT_LOG_ACCESS_DIRECTORY/tomcat_access_log &
      echo "grouperContainer; INFO: (grouperScriptHooks.sh-setupFilesPostChown) created pipe for $GROUPER_TOMCAT_LOG_ACCESS_DIRECTORY/tomcat_access_log"
      ls -al $GROUPER_TOMCAT_LOG_ACCESS_DIRECTORY
    else
      echo "GROUPER_TOMCAT_LOG_ACCESS is defined but GROUPER_TOMCAT_LOG_ACCESS_DIRECTORY is not ('$GROUPER_TOMCAT_LOG_ACCESS_DIRECTORY') -- not creating pipe"
    fi
  fi
}
{code}
