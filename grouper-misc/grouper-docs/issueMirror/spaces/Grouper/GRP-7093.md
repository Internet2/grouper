# GRP-7093  Accessibility: Header and Nav color contrast

!image-2026-07-01-16-11-06-791.png!

Breadcrumbs active: change to white and bold

Button: change background color from #faa732 to #ffc107 and text color to black

Change logged in text from #777777 to #333333

Change logged out color to the link color

## Comments

### Chris Hyzer - 2026-07-01T20:42:12.020+0000

Implemented the four header/nav contrast fixes. All done as override rules appended to {{grouperUi2.css}} (which loads after {{{}bootstrap.css{}}}), following the same pattern as GRP-7091/7092 - no edits to vendored bootstrap. Cache-buster on the CSS link bumped in {{{}commonHead.jsp{}}}.

*1. Breadcrumbs* - the current/active crumb was {{#999999}} on the teal {{#1c6070}} bar (failed AA). Recolored to white. Emphasis convention: clickable crumbs are bold to signal they are navigable, the current (non-clickable) crumb is normal weight.

*2. Buttons* - {{.btn-primary}} and {{.btn-warning}} (both use the orange {{#faa732}} gradient with white text). Flattened to a solid {{#ffc107}} amber with black text, covering hover/focus/active/disabled so they do not revert. Applies to both button styles app-wide.

*3. Logged-in text* - the "Logged in as ..." line ({{{}.navbar-text{}}}) changed from {{#777777}} to {{{}#333333{}}}.

*4. Log out link* - the "Log out" link ({{{}.navbar-link{}}}) was gray {{{}#777777{}}}, unlike the adjacent Help link. Now uses the standard link color {{#0076a5}} (hover {{{}#003f59{}}}) so it looks like a link.
