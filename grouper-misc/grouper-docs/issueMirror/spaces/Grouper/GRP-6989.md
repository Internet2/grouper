# GRP-6989  Fix URI is not defined error in folder menu when URI.js library removed

* {{grouper-ui/webapp/grouperExternal/public/assets/js/URI.js}} was removed in {{{}GRP-6537: remove uri.js{}}}, but {{grouperUi.js}} still calls {{new URI(location.href)}} in {{dojoInitMenu}} (folder/group jstree auto-select path).
 * {{commonHead.jsp}} also still includes {{{}<script src=".../URI.js">{}}}, which now 404s.
 * Clicking the folder-menu button on {{UiV2Main.index}} throws {{Uncaught ReferenceError: URI is not defined}} at {{grouperUi.js:756}} and the menu fails to open.
 * Bug is present in {{GROUPER_RELEASE_7.1.0}} (tag has the call site but no {{URI.js}} file).
 * Fix: rewrite the call to use {{URLSearchParams(location.search)}} to build the query-param object, remove the dead {{<script>}} include from {{{}commonHead.jsp{}}}, and bump the {{grouperUi.js}} cache-buster in {{commonBottom.jsp}} so browsers pick up the fix.
