# GRP-7123  normalize data types in GcTableSync for compares

_(no description)_

## Comments

### Chris Hyzer - 2026-07-12T04:13:11.835+0000

when someone does a GcTableSync programmatically, it shouldnt matter if the value is an Integer, or Long, or BigDecimal, or whatever, it should normalize, and without too much overhead.  Same with date, timestamps, Floats, Doubles, etc.
