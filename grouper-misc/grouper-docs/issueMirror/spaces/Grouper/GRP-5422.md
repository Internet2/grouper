# GRP-5422  UI hyperlinked things should work when opening in new tabs

Various things in the new UI have hyperlinks, but those hyperlinks aren't functional independent of the way the UI implements ajax. This means you can't bookmark things, and can't open things in new tabs. It would be useful to have this work, so people can open new tabs with the specific item they want.
