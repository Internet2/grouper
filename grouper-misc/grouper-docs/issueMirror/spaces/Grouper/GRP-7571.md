# GRP-7571  Upgrade Tomcat to 9.0.124 for security

Bump the Grouper container from Apache Tomcat 9.0.122 to 9.0.124, which clears the open CVEs fixed in Tomcat 9.0.123 and 9.0.124 (see https://tomcat.apache.org/security-9.html). The stock conf/server.xml is byte-identical between 9.0.122 and 9.0.124, so the container's server.xml.grouper.patch still applies cleanly (no regeneration). The apache-tomcat-9.0.124.tar.gz tarball must be present on the Internet2 software mirror (software.internet2.edu/grouper/downloads/tools/) before the container build.
