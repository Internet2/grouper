# GRP-413  Flattened memberships

For 1.6, we're creating a flattened membership table that will be populated from the change log job running out of the Grouper Loader.  This will later be used to improve read performance, auditing, replication, etc...

## Comments

### shilen - 2010-06-18T14:36:18.584+0000

For 1.6, the flattened membership table is used for notifications using the change log.  The change log will record events for membership adds and deletes only if the subject is not a member of the group in any other way.  You can optionally configure the change log to include all immediate memberships.
