### mchyzer - 2015-02-23T12:47:53.949+0000

There were also issues with buttons and controls showing when they shouldnt.  i.e. the add member button should not show if the user doesnt have UPDATE.  The delete member controls should not sure if the user does not have UPDATE.  If a user cant VIEW a group which is a member of another group, should show a more descriptive label for group (see attachment).  Users should be able to UPDATE but not READ a group.  Context menus should more precisely show what the user is allowed to do.  You should be able to trace a list membership if you have READ on the group
