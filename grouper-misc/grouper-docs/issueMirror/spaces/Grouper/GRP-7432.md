# GRP-7432  grouper-ws fails to start: jackson-annotations 2.18.2 mismatched with jackson-databind 2.22.1, manage Jackson via jackson-bom

grouper-ws fails to start with NoClassDefFoundError: com/fasterxml/jackson/annotation/JsonSerializeAs (from JacksonAnnotationIntrospector, via ObjectMapper in GrouperUtil static init). The WS webapp ends up with jackson-databind and jackson-core 2.22.1 but jackson-annotations 2.18.2.

Cause: GRP-7158 bumped jackson.version to 2.22.1 in grouper-parent, but the parent only manages databind and the jaxrs artifacts, not jackson-annotations. The grouper-ws pom hardcodes jackson-datatype-jsr310 at 2.18.2, which transitively pulls jackson-annotations 2.18.2, and that is the nearest path since jersey-media-json-jackson excludes jackson-annotations. The UI does not have this dependency so it gets annotations 2.22.

Fix: import com.fasterxml.jackson:jackson-bom at jackson.version in the grouper-parent dependencyManagement so all Jackson modules stay aligned (the bom also maps jackson-annotations to its no-patch version 2.22), drop the individual Jackson version entries, and remove the hardcoded jsr310 version from the grouper-ws pom.
