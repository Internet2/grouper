# GRP-6895  provisioners with "pass" in the config id will store all properties as if they were passwords

I've seen this behavior in v4 and v5.  Was curious about it so dug into it a little bit.  In GrouperConfigHibernate.isPasswordHelper() at line 734-739 the full key is checked for certain words:



  // look for a key with certain words inside                                                                              

  if (key != null) {                                                                                                       

    String lowerKey = key.toLowerCase();                                                                                   

    if (lowerKey.contains("pass") || lowerKey.contains("secret") || lowerKey.contains("private")) {                        

      return true;                                                                                                         

    }      


So if the configId of the provisioner has "pass", "secret" or "private" in it, then the properties are treated like passwords when they are stored in the db.  This makes exporting the provisioner challenging.
