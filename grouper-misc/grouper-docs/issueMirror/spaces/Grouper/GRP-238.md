# GRP-238  Add configuration option to restrict users that can rename stems

Stem renames only require a user to have STEM access on the stem being renamed.  The user may or may not have write (or even read) access to any subgroups of the stem.  

We're adding an option in the API to restrict the users that can rename a stem based on an optional group.
