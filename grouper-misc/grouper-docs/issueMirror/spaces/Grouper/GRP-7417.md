# GRP-7417  Postgres: change grouper_file.file_contents_clob from VARCHAR(10000000) to TEXT

In postgres, grouper_file.file_contents_clob is VARCHAR(10000000), which caps file contents at about 10MB (postgres varchar max is 10485760). Change it to TEXT so larger files can be stored.

SQL: ALTER TABLE grouper_file ALTER COLUMN file_contents_clob TYPE text;

Update the postgres install SQL, add a DDL version change for database compares, and an upgrade task to alter existing installs. Oracle (CLOB) and mysql (MEDIUMTEXT) are unchanged.
