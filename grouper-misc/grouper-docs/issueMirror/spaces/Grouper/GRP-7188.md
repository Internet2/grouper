# GRP-7188  v2 UI modal close (X) button fails WCAG contrast and target-size

The modal close button (the X, bootstrap .close) in the v2 UI is accessible in name and keyboard behavior (real button, aria-label Close, glyph in an aria-hidden span), but its default bootstrap styling fails two WCAG checks.

1. Contrast (SC 1.4.11): the glyph is black at opacity 0.2, which renders about 1.6:1 on the white modal header (hover is about 2.3:1). Non-text UI components require 3:1.

2. Target size (WCAG 2.2 SC 2.5.8): the button hit area is about 12x18 CSS px, below the 24x24 minimum, with no compensating spacing exception.

Fix: add a grouperUi2.css override for .close that raises the glyph contrast to clear 3:1 and pads the button to a 24x24 target. grouperUi2.css loads after bootstrap.css so the override wins. This affects every modal X across the v2 UI.
