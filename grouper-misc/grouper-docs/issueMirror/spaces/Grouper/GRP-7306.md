# GRP-7306  UI accessibility: convert fake-button anchors to native buttons

Many in-page-action controls are coded as fake-button anchors (a href=# or href=javascript:void(0) with an onclick), so assistive tech announces them as links, not buttons (SC 4.1.2, 2.4.4). Per the accessibility action plan item 5, controls that perform an in-page action should be native button type=button; a-tags stay only for real navigation, and jstree tree entries are handled separately since the library needs href=#.

A reusable class grouper-linkbutton (in grouperUi2.css) renders a native button as an inline text link (chrome stripped, standard link blue #0076a5 at 5.08:1) so the conversion is visually neutral for link-styled controls. Rollout is family by family (shared shell first, then group/folder/subject/config screens) with live verification of role, keyboard, and behavior at each step. Started with the shared shell: the Hide/Show side panel toggles in header.jsp.
