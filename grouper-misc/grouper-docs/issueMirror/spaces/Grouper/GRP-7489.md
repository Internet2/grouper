# GRP-7489  Smartsheet provisioner: sync-back

Add sync-back to the Smartsheet provisioner (v7 and later): capture users, groups and memberships into the generic provisioning tables, and support fullSyncUsersFromSyncBack, fullSyncGroupsFromSyncBack and fullSyncMembershipsFromSyncBack so full syncs can skip the per-group member reads.
