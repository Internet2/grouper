# GRP-335  integration with vt-ldap 3.2

Replace use of LdapContext with vt-ldap 3.2 to provide improved SSL/TLS support, automatic connection retry, logging, Active Directory "range" support, etc., possibly connection pooling.

## Comments

### tzeller@example.com - 2009-10-30T05:21:40.834+0000

The <ldap ...> configuration element is no longer allowed. Configuration for vt-ldap is done via ldappc.properties.

The 

edu.internet2.middleware.ldappc.useRangeSearchResultHandler=true

parameter supports groups with a large (>1500) number of members.

See

http://code.google.com/p/vt-middleware/wiki/vtldapAD#Range_Attributes
