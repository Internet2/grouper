# GRP-4881  Google provisioner should batch fetch users, not individually

When debug logging Google provisioning, the entity fetches look like it's getting every user in a page size of 1, which ends up being very slow. It doesn't seem to make a difference whether "{*}Select all entities at once during full sync"{*} and "{*}Select all groups at once during full sync"{*} are false vs. true either.

Also, the second full sync run, it doesn't seem to be using the cache, and re-fetches everyone again.

## Comments

### Chad Redman - 2023-08-15T19:49:35.705+0000

I see most of this is improved in 4.1.7. However, it is necessary for both select all entities at once and select all groups to be false, otherwise it will still trigger retrieveAllData.

Note that there was no Jira associated with the fix, so it does not show up in release notes!
