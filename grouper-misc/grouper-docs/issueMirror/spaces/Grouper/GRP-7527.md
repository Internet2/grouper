# GRP-7527  Report config screen: choose GSH script or compiled GSH report template

The report config add/edit screen required the GSH script textarea for GSH reports even when a compiled GSH report template config id (GRP-7031) was set. Users pasted the Java source into the script field to satisfy it, and the save failed with a DataException because the attribute value was over 4000 characters.

Added a GSH source dropdown (GSH script entered here, or compiled GSH report template), like the script daemon config. Only the chosen field shows, is required, and is saved; the other is cleared.

Validation: the compiled template config id must exist with templateType=report and templateMode=compiled in grouper.properties, and a script over 4000 characters gets a clear error instead of a database error.

The source type is derived from whether a template config id is set, so existing report configs need no upgrade task.

Files: UiV2GrouperReport.java, reportConfigObjectAddHelper.jsp, reportConfigObjectEditHelper.jsp, GrouperReportConfigurationBean.java, grouper.textNg.en.us.base.properties
