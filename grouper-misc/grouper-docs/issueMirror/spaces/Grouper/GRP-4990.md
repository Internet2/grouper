# GRP-4990  Allow to add membership notes when adding a membership

Similar to adding a start/end date on a new membership, have fields for membership attributes that can be added. The configuration can be similar to the [Group editor page|https://spaces.at.internet2.edu/display/Grouper/Grouper+attribute+framework+attributes+editable+in+group+edit+screen] where you can configure which attributes show up.
