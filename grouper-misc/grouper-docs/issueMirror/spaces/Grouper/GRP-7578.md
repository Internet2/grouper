# GRP-7578  Security: MCP scope checks

Security fixes from the 2026 Grouper security review, category G. Each line is one fix, its severity, and the public advisory it belongs to:

- MCP attribute assignment scope checks use the real owner (medium, advisory MCP)
- MCP subject scope checks the subject source (medium, advisory MCP)
- MCP institutional tools check the owner against scope (medium, advisory MCP)
- MCP scope checks use the object's current name (medium, advisory MCP)
- MCP replace-all membership checks subject scope (medium, advisory MCP)
- Also includes GRP-7540 (MCP institutional_tools: an input given under both its full and short name could bypass the read-write data scope), ported from GROUPER_7_BRANCH to 7.9.

Fixed in 7.9.1 (GROUPER_7_9_0-branch). The same fixes were provided as security patches for earlier releases. See the security announcement for details and required steps.
