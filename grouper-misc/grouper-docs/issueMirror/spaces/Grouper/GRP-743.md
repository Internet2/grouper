# GRP-743  Bad membership finder updates

1.  Update bad membership finder so that composites are not deleted/recreated if there's a problem.
2.  Bad membership finder should handle the case when 
      a.  group sets are created for composites.
      b.  immediate memberships are added to composite groups.
      c.  composite memberships exist for groups that are not composites.
      d.  group sets have the wrong type (composite vs immediate)
      e.  there are missing effective group sets
