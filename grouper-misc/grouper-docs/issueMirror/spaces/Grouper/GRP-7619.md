# GRP-7619  Upgrade postgresql to 42.7.15 for security

The 7.10.0 image ships postgresql (pgjdbc) 42.7.13, which image scanners flag for these CVEs, all fixed in 42.7.15:

CVE-2026-134841, CVE-2026-134842, CVE-2026-134843, CVE-2026-134844, CVE-2026-134845, CVE-2026-134846, CVE-2026-134847, CVE-2026-134848, CVE-2026-107314, CVE-2026-107315

Change: postgresql.version 42.7.13 to 42.7.15 in grouper-parent/pom.xml (postgresql is a direct dependency of grouper and grouper-ui).
