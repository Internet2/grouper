# GRP-343  Ldappc should have option to ignore elements in LDAP that are outside of some name space

Per suggestion from Michael Gettes, it should be possible for groups, memberships, and permissions, to specify namespaces, and instead of deleting existing groups, memberships and/or permissions that are outside of that namespace, Ldappc will simply ignore them. Elements that are not present in Grouper/Signet that *are* in the specified namespace would be deleted.

This would allow multiple Grouper/Signet instances to provision the same LDAP in the same branches from different data without colliding.
