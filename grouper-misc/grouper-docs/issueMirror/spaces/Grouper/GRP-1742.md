# GRP-1742  grouper-el.tld invalid markup

Tag definitions in grouper-el.tld sometimes use <tag-class> and sometimes <tagclass>, and sometimes <description> and sometimes <info>. Per the schema referenced in the file, only tag-class and description are valid attributes. It doesn't seem to cause issues in Tomcat, but in other containers (at least in JBoss EAP 7) it does validate the file so the current syntax causes issues.
