# GRP-2267  Switch Maven license check to Checkstyle

There is currently a mandatory task in the maven build to check for a license header in every file, unless specifically put into a whitelist. It's not very targeted, and outputs warning for a lot of text files that adds uninteresting information every time Maven runs. You can avoid it by adding `-Dlicense.skip=true` every time you run Maven, but it's easy to forget. Plus, if you need to add a flag 100% of the time to avoid something, it raises the question of whether we really need it.

There is an alternative called checkstyle, which not only checks headers (including regular expressions), but a lot of other Java style rules like tab spacing and line length. And it can integrate with IntelliJ and Eclipse, to automatically apply check while editing the file. That way we can catch issues before committing. I've seen it used in other projects, so there are good examples to copy from.

## Comments

### Chad Redman  (unc.edu) - 2019-09-25T02:43:54.047+0000

I updated the grouper-parent to comment out the maven-license-check, and added the checkstyle plugin. I did not add it to reporting, since that would end up in the html site that everyone would see. Instead, you can run `mvn checkstyle:checkstyle`, which would do a scan on the current directory.

The typical checkstyle settings check a lot of items, and it results in a lot of warnings for older files that vary a lot in code style. So I created two separate checkstyle configurations. One is checkstyle-legacy.xml, and it just checks the licenses and a few very basic style checks which don't return too many warnings on older files. This is the default style set that is active when you run `mvn checkstyle:checkstyle`. Then there is another file that checks a lot more things too, and should be used for newly created files. You could use this in maven with `mvn checkstyle:checkstyle -Dcheckstyle.config.location=src/checkstyle/checkstyle.xml`, but it would scan every file, even older ones. Better would be to add the checkstyle plugin to either Eclipse or IntelliJ, where it can scan specific java files either on command or in the background.
