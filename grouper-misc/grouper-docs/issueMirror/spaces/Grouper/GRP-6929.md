# GRP-6929  Add unit test for composite membership flow into grouper_sql_cache_mship

* New SqlCacheMembershipTest.testCacheCompositeMembershipsFlattened.
 * Sets up compositeGroup = leftGroup MINUS rightGroup (COMPLEMENT), adds SUBJ0 to leftGroup.
 * Asserts that after the standard async chain (changeLogTempToChangeLog → compositeMemberships consumer → changeLogTempToChangeLog), grouper_sql_cache_mship contains the composite-derived membership for compositeGroup.
 * Documents the prelude needed in tests: the compositeMemberships changelog consumer must be invoked once before the action under test so its sequence baseline is set; otherwise its first run treats the current sequence as already-processed and skips the events.
 * Also fixes a long-standing typo in this test class and SqlCacheGroupTest: runRullSync → runFullSync (private helper, all callers updated).
