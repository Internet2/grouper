# GRP-7035  GSH Java template compilation — base-class validation on save in the GSH template config UI

* Phase 5. Builds on GRP-7033 (compile-on-save) and GRP-7006/7010/7011. Design doc {{grouper/temp/trash/gshCompileImprovement.html}}, section "Compile on save" (type-specific validation: correct framework base).
 * GRP-7033 added compile-on-save but only checked that the Java compiles. This adds the second half: validate at save that a compiled template's class extends the framework base class its {{templateType}} requires, blocking the save with an inline error instead of letting a wrong base surface only at dispatch time.
 * In {{{}GshTemplateConfiguration.validatePreSave{}}}, after the compile check passes for a {{templateMode=compiled}} template, call {{{}baseClassErrorOrNull(source, templateType){}}}: recompile to bytecode, define the class in a throwaway {{{}ByteArrayClassLoader{}}}, and check {{isAssignableFrom}} against the expected base(s). On mismatch, put an inline error on the source field and block save.
 * Expected base per type: gsh/abac → {{{}GshTemplateV2{}}}; provisioner → {{{}GshTemplateProvisionerBase{}}}; daemon → {{{}GrouperTemplateDaemon{}}}; daemonChangeLog → {{{}GrouperTemplateDaemonChangeLog{}}}; report → {{{}GrouperTemplateReport{}}}; hook → any of the existing hook base classes (via {{{}GrouperHookType.getBaseClass(){}}}); customUi → {{{}GrouperTemplateCustomUi{}}}; library → no required base.
 * The customUi base lives in grouper-ui, unreachable at compile time from this grouper-module validator, so it is resolved by name at runtime ({{{}Class.forName{}}}). When the expected base is not on the JVM's classpath (a non-UI save context) or the compiled class can't be loaded, validation is skipped (returns null) and the dispatcher's runtime {{asSubclass}} still enforces the base — never a false failure.
 * Externalized text for the new error in {{grouper.textNg.en.us.base.properties}} only.
 * Tests: a class extending the correct base passes; the wrong base is rejected and the error names the required base; library templates have no requirement.
