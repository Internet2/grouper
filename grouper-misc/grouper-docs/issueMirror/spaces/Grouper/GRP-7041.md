### Chris Hyzer - 2026-06-21T05:53:32.405+0000

MySQL/MariaDB rejects a table alias in single-table DELETE FROM. Correlate
the not-exists subqueries with the full table name so the SQL is portable
across Oracle, Postgres, and MySQL.
