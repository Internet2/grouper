# GRP-3674  keep the oidc library in sync with pac4j

Axel Stohn Today at 3:04 PM
Hi @mchyzer here are the details around Unicon’s testing of Grouper-authentication for Grouper 2.5 and 2.6:
Tested protocol’s CAS, SAML and OIDC
Loaded each protocol via “Import config file” and verified can log into Grouper
Results:
For Grouper 2.5:
SAML - Passed
CAS - Passed
OIDC - Passed
For Grouper 2.6:
SAML - Passed
CAS - Passed
OIDC - Failed
Reason: Version issue with Nimbus lib. Grouper-parent references com.nimbusds v9.15, while Grouper-authentication uses Pac4J v4.5, which requires v8.22 of Nimbus. Pac4j cannot be upgraded since v4.5 is the last of the Pac4j versions that supports Java 8, Pac4j v5.x uses Java 11. Can the version used by Grouper-parent be downgraded?
