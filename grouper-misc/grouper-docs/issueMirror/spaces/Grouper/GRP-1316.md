# GRP-1316  PSPNG: Support disabling of LDAP Paging

PSPNG 2.3.0 was created with LDAP paging always enabled. 

PSPNG should respect an ldaptive option if one exists or should create a property for grouper-loader.properties ldap paragraphs that disables paging. 

## Comments

### bert - 2018-09-04T07:42:50.675+0000

Since 2.3 PSPNG Patch #0, the following properties can be used to control LDAP paging:

org.ldaptive.searchResultPagingEnabled

org.ldaptive.searchResultPagingSize
