### Harry Hyzer - 2024-06-04T17:52:36.038+0000

If you are calling findStems non-lite, you can pass in multiple lookups, so the javadoc says that if any of them are not found it is still a 200 since it is a search rather than a lookup. You will see no stems in the result. Ill test later if the lite method searching for one stem returns a 404.
