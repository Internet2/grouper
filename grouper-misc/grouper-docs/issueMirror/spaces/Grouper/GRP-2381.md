# GRP-2381  dont set cookies in WS container.  if path is different some clients give superfluous warnings

/opt/tomcat/conf/Catalina/localhost/grouper-ws.xml

add in cookies="false" attribute to the Context element

<Context ... cookies="false" >

note you can test this by doing a grouper client WS call and look in headers in response, you should not see a cookie set for JSESSIONID
