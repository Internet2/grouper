# GRP-4674  Provisioning - issue when sync'ing subject ids as memberships

Apparently the UI option for "Entity cache location for memberships" maps to the config groupMembershipAttributeValue.  The UI allows you to select cache buckets 0-3, which I assume is useful if you're doing entity linking.  But if you want to just provision subject ids in the membership attribute, I believe you need the property to be set as subjectId.
