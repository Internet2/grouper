This may be of limited impact since it affects OpenShift deployments of Grouper. It looks like an extra option added to the copy (cp) command in /usr/local/bin/librarySetupFilesForComponent.sh in versions 2.6.10 through 2.6.15.1 causes deployments to fail with CrashLoop errors. The startup scripts rely on the status of the cp command, but in OpenShift, because the command is run as an arbitrary user, the status code of the result is 1, resulting in exiting the script and ultimately crashing the deployment.
$ diff librarySetupFilesForComponent.sh.2.6.8_and_older librarySetupFilesForComponent.sh.2.6.10_and_newer
8c8
<        cp -r /opt/grouper/grouperWebapp/WEB-INF/libWs/* /opt/grouper/grouperWebapp/WEB-INF/lib/
---
>        cp -ra /opt/grouper/grouperWebapp/WEB-INF/libWs/* /opt/grouper/grouperWebapp/WEB-INF/lib/
20c20
<        cp -r /opt/grouper/grouperWebapp/WEB-INF/libScim/* /opt/grouper/grouperWebapp/WEB-INF/lib/
---
>        cp -ra /opt/grouper/grouperWebapp/WEB-INF/libScim/* /opt/grouper/grouperWebapp/WEB-INF/lib/
32c32
<        cp -r /opt/grouper/grouperWebapp/WEB-INF/libUiAndDaemon/* /opt/grouper/grouperWebapp/WEB-INF/lib/
---
>        cp -ra /opt/grouper/grouperWebapp/WEB-INF/libUiAndDaemon/* /opt/grouper/grouperWebapp/WEB-INF/lib/
In OpenShift environments:
sh-4.2$ cd /usr/local/bin/
sh-4.2$ cp -ra /opt/grouper/grouperWebapp/WEB-INF/libUiAndDaemon/* /opt/grouper/grouperWebapp/WEB-INF/lib/
cp: preserving times for '/opt/grouper/grouperWebapp/WEB-INF/lib/slf4j-api-1.7.32.jar': Operation not permitted
sh-4.2$ echo $?
1
sh-4.2$
sh-4.2$
sh-4.2$ cp -r /opt/grouper/grouperWebapp/WEB-INF/libUiAndDaemon/* /opt/grouper/grouperWebapp/WEB-INF/lib/
sh-4.2$ echo $?
0

which results in the following errors at startup:
cp: preserving times for '/opt/grouper/grouperWebapp/WEB-INF/lib/slf4j-api-1.7.32.jar': Operation not permitted
grouperContainer; INFO: (librarySetupFilesForComponent.sh-setupFilesForComponent_ui) cp -r /opt/grouper/grouperWebapp/WEB-INF/libUiAndDaemon/* /opt/grouper/grouperWebapp/WEB-INF/lib/ , result: 1
It's not an issue in docker deployments:
[tomcat@0c4a4596d8dd bin]$ cp -ra /opt/grouper/grouperWebapp/WEB-INF/libUiAndDaemon/* /opt/grouper/grouperWebapp/WEB-INF/lib/
[tomcat@0c4a4596d8dd bin]$ echo $?
0
