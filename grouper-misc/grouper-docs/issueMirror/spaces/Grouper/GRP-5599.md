# GRP-5599  Script daemon output remove info about script type and source code

Minor suggestion. This is what output from a script daemon currently looks like

 
{code}...
(end of actual log output)...policyGroups: 2, courses: 1, sections: 1, members: 11

scriptType: gsh
scriptSource: import edu.internet2.middleware.grouper.app.externalSystem.WsBearerTokenExternalSystem
import edu.internet2.middleware.grouper.app.grouperTypes.GrouperObjectTypesAttributeNames
import edu.internet2...

null
{code}
It doesn't add much to output this final information. You're in the job view, you can look at the settings if you want to know what they are. It makes the actual output harder to find with this tacked on. Also, the final "null" is just there as a mystery for people to wonder about.
