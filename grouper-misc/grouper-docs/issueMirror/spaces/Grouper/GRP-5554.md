# GRP-5554  allow gsh template to download a file

From the UI, running a GSH template... is there a way to end the GSH template by triggering a download of a file?
I am thinking about several uses for this general idea.
download a CSV file to "snapshot" a group's memberships (That later could be used to restore the group. Or compare with it after importing to a different group
trigger the download of a JWT cert for a user.
export a zip file of reports
export loader jobs to a GSH template ( I have code that almost does that, but it emails the file instead of downloading it. )
....
And I bet there are others too.
