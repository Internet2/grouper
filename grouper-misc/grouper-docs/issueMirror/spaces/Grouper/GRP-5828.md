# GRP-5828  UI subject source give more details on searchAttributeN and sortAttributeN

The subject source editor sections for Search attributes and Sort attributes let you specify more than 1 attribute, but there is no explanation what that means. Many people assume these are additional fields to search on and secondary sorts. Then they get confused why users aren't found by those attributes. It should be clearer with a text description, that additional search/sort attributes are for privacy levels, and the only one that needs to be set is attribute 0.
