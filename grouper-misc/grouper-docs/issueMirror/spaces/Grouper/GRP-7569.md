# GRP-7569  Move group: Set alternate names checkbox should not be checked by default

When moving a group in the UI (Group actions, Move group), the checkbox "Set alternate names for groups?" is checked by default. It should be unchecked by default. Seen in the latest v7.

If it is left checked, every moved group gets its old ID path set as an alternate ID path, which most people do not want and do not notice.

Code: grouper-ui/webapp/WEB-INF/grouperUi2/group/groupMove.jsp line 48, the moveChangeAlternateNames checkbox has checked="checked". Remove that so it defaults to unchecked.

Note: the folder move screen (stem/stemMove.jsp line 49) has the same checked="checked" on moveChangeAlternateNames. Consider unchecking that by default too.
