# GRP-7447  GSH templates only show and require runAsType/securityRunType for gsh and abac types

runAsType and securityRunType only take effect for gsh and abac templates, which run through GshTemplateExec. The other compiled types (daemonChangeLog, report, customUi, hook, library) are loaded by their own callers and ignore both settings, but the UI still requires them, which is misleading (e.g. customUi always runs as root regardless of runAsType).

Change: the UI shows these fields only for gsh and abac, and GshTemplateConfig only requires them for those types. Other types run as GrouperSystem with wheel security in the config object (provisioner and daemon already did, GRP-7407). No config keys are renamed; existing values are ignored for the other types and dropped on the next UI save.

Where each type actually runs: daemon, daemonChangeLog, report, customUi, provisioner run as root; hook and library run in the caller's session.
