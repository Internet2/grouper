# GRP-7416  Generic provisioner add option for external system

If your generic provisioner needs to access an external system, you need to hard code it in Java or use a custom config parameter. If you set provisioner.myProvisioner.someExternalSystemConfigId, it gets deleted every time you save the provisioner. You need to keep restoring from the config history.

If there was an option, something like provisioner.GrouperGenericProvisioner.genericExternalSystemConfigId, which lists all the external systems, that would help. It wouldn’t be required. Another option is to just not delete unrecognized options from the generic provisioner config.
