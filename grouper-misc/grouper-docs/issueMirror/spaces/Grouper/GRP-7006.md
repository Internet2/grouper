# GRP-7006  GSH Java template compilation — in-process Java compiler wrapper

* Phase 2 of the GSH Java template compilation effort; design doc at {{grouper/temp/trash/gshCompileImprovement.html}}
 * New class {{GshTemplateJavaCompiler}} wrapping {{javax.tools.ToolProvider.getSystemJavaCompiler()}}
 * In-memory {{JavaFileObject}} for source input; in-memory {{JavaFileManager}} for bytecode output
 * Compile against the running JVM classpath so Grouper API resolves at compile time
 * {{DiagnosticCollector}} translated to a Grouper-friendly error format (line, column, severity, message)
 * JUnit tests: compile success, syntax error, unresolved import, type error, unresolved Grouper API call, valid {{GshTemplateV2}} subclass
 * Standalone — no integration with existing GSH execution path in this commit
 * Future commits will add the per-template classloader registry, dispatcher integration, UI compile-on-save, etc., each as its own JIRA
