# GRP-2097  visualization: option to include groups in counts

There should be an option which defaults to not including groups in counts.  but maybe you could turn that on...  would the legend auto reflect that?

 

ie. if a group has 5 (non group) members, and it is in another group with no other members.  Both should show a count of "5 members"

noticed that the member counts for non-composite groups include both subjects (ppl) and group members (e.g. ref groups). i think we probably want to default to only show subject (ppl) memberships? or maybe display more than one count if that is possible?

basically as an iam analyst you want to be able to make sense of the visualization counts. when they include group members all the math is off. you would normally just want to see subject (i.e. ppl) membership counts (direct and indirect).
