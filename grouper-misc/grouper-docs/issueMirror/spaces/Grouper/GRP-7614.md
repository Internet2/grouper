# GRP-7614  Tests: replace internal tracking ids in test data names and javadocs with descriptive names

Several test classes use internal tracking numbers in test data names and javadocs instead of names that say what is being tested, for example folder and template ids like test:secPatch145 or secPatch145 (GshTemplateUploadCleanupHttpTest), "issue NN" references in about 26 test javadocs, and secpatchNN table names in some tests.

Change: rename the test data to descriptive names (for example test:uploadCleanup and uploadCleanupTemplate), and reword the javadocs to describe the behavior being tested, with the GRP issue where there is one. No behavior change.
