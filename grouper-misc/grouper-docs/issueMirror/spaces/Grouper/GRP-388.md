# GRP-388  import export should not be on by default in admin ui

_(no description)_

## Comments

### mchyzer - 2010-03-11T21:59:24.089+0000

In 1.5.0 and 1.5.1 the admin ui had import/export on by default.  This doesnt work correctly if you have a custom source, so lets go back to default to off.  If you want it on, do this in media.properties:

### membership-export.config=resources/grouper/membership-export.xml
### membership-import.config=resources/grouper/membership-import.xml
