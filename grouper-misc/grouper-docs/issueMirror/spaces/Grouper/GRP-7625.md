# GRP-7625  Group screen: while the add members panel is open, the Add members button becomes a secondary Hide add members button so the panel's submit is clear

On the group screen the Add members button (groupMoreActionsButtonContents.jsp) opens the add members panel (add-block-container in groupHeader.jsp). Both the toggle and the panel's submit button are blue primary buttons, and the submit just says Add, so users click Add members again expecting it to submit the form, and it closes the panel instead.

While the panel is open, the toggle should read Hide add members (new externalized text key) and be a plain btn, not btn-primary, so the panel's submit is the only primary button. When the panel is closed it goes back to the primary Add members button. Do this in showHideMemberAddBlock() in grouperUi.js, and bump the grouperUi.js cache buster in commonBottom.jsp.

Rename the panel's submit button text from Add to Add members (groupViewAddMemberLink). Check the other places that key is used, e.g. the custom UI group page (customUiGroup.jsp), and add a new key if the text should not change there.

Accessibility: put aria-expanded and aria-controls=add-block-container on the toggle button itself. Today showHideMemberAddBlock() sets aria-expanded on add-member-control-group inside the panel, which is the wrong element, and adds role=alert, which should be dropped.
