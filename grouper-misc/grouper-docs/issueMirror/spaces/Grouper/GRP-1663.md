# GRP-1663  inherited privileges should revoke those privileges to subobjects

Note, dont revoke the privileges if there is another inherited rule in one of their ancestor folders.

This is performed in a thread so the page doesnt hang on large operations.

{code}
    int changes = RuleApi.removePrivilegesIfNotAssignedByRule(true, stem2, Scope.SUB, groupA.toSubject(), Privilege.getInstances("read, update"), null);
{code}

## Comments

### mchyzer - 2018-01-24T09:07:44.942+0000

set this to false in grouper-ui.properties if you dont want this:

{code}
uiV2.grouperRule.removeInheritedPrivileges.whenUnassigned = false
{code}

it will revoke privileges in sub objects as root, if you want it to act as the current logged in subject, do this in grouper-ui.properties:

{code}
uiV2.grouperRule.removeInheritedPrivileges.asRoot = false
{code}
