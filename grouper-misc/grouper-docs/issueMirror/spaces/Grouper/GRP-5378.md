### Chad Redman - 2024-07-25T04:25:47.263+0000

Works with builtin auth, but who is using that in production?

Pac4j is a problem because it protects all of /grouper/*. Tomcat doesn't support internal forwards like Apache does, so it's harder to get a different context to function, without copying parts of Grouper to a new directory. The status_grouper could potentially point to the same docBase, except that it might expose other files without SSO protection.
h2. Option 1 - copy grouper libs and classes to a new context; only expose the status servlet

h2. Option 2 - use urlrewritefilter library along with crossContext

[https://tuckey.org/urlrewrite/manual/4.0/index.html]

/opt/tomcat/conf/Catalina/localhost/grouper.xml
{code}<Context docBase="/opt/grouper/grouperWebapp/" path="/grouper" reloadable="false" cookies="true" crossContext="true" > 
  <Resources allowLinking="true" />
</Context>
{code}
/opt/tomcat/conf/Catalina/localhost/status_grouper.xml
{code}<Context docBase="/opt/grouper/grouperStatusWebapp/" path="/status_grouper" reloadable="false" crossContext="true" /> 
{code}
/opt/grouper/grouperStatusWebapp/WEB-INF/web.xml
{code}<?xml version="1.0" encoding="UTF-8"?>
<web-app xmlns:j2ee="http://java.sun.com/xml/ns/j2ee" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
  xsi:schemaLocation="http://java.sun.com/xml/ns/j2ee http://java.sun.com/xml/ns/j2ee/web-app_2_4.xsd"
  version="3.0">

    <filter>
        <filter-name>UrlRewriteFilter</filter-name>
        <filter-class>org.tuckey.web.filters.urlrewrite.UrlRewriteFilter</filter-class>
    </filter>
    <filter-mapping>
        <filter-name>UrlRewriteFilter</filter-name>
        <url-pattern>/status</url-pattern>
        <dispatcher>REQUEST</dispatcher>
        <dispatcher>FORWARD</dispatcher>
    </filter-mapping>
</web-app>
{code}
/opt/grouper/grouperStatusWebapp/WEB-INF/lib/urlrewritefilter-4.0.4.jar
 - from [https://repo1.maven.org/maven2/org/tuckey/urlrewritefilter/4.0.4/urlrewritefilter-4.0.4.jar]
 - the latest version 5.1.3 only works with Tomcat 11

/opt/grouper/grouperStatusWebapp/WEB-INF/urlrewrite.xml
{code}<?xml version="1.0" encoding="utf-8"?>
<!DOCTYPE urlrewrite
    PUBLIC "-//tuckey.org//DTD UrlRewrite 4.0//EN"
    "http://www.tuckey.org/res/dtds/urlrewrite4.0.dtd">

<urlrewrite>
    <rule>
        <from>^/status$</from>
        <to type="forward" context="grouper">/status</to>
    </rule>
</urlrewrite>
{code}
