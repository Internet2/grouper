# GRP-581  Inconsistency in web-services options related to getting subject details

When making REST WS requests and asking the WS for full subject details, most methods want you to set includeSubjectDetail=T.  However, 4 methods: WsRestGetMembershipsLiteRequest, WsRestGetMembersLiteRequest, WsRestGetSubjectsLiteRequest, WsRestMemberChangeSubjectLiteRequest instead use the field retriveSubjectDetail.  Can this be fixed to be consistent, I don't care include vs retrieve, just that it's the same throughout the entire API.
