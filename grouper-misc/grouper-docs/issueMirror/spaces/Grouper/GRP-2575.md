# GRP-2575  UI (maybe WS too?) ability to bulk add list of Groups to a folder from a "CSV"/"copy and paste" inputs

Much like the ability to add a list of members to a group in bulk. There are times when a "set of groups" or a "set of folders" need to be created too.

It would be helpful ( to some users ) to be able to do these operations in "one action" from "a list".
