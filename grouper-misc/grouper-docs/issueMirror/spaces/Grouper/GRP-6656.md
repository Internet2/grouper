# GRP-6656  Startup error "Config file line invalid" should be warn not error

There was a bug in a config in 5.22.1. When deployers do an upgrade to V5, they get this error and if there is a startup problem they think this is the cause.

 {code}ERROR ConfigFileMetadata.generateMetadataForConfigFile(301) - Config file line invalid, GROUPER_PROPERTIES, line: 1550 should be a comment with one hash: '## docker / podman command'{code}
