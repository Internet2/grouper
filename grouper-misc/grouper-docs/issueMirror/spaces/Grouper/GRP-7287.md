# GRP-7287  Add a test script for the old-wiki to Cloud docs redirects

Follow-on to GRP-7201, which built the Apache rewrite map that redirects the frozen on-prem wiki (spaces.at.internet2.edu) Grouper space to the Cloud docs site. The map and conf were handed to the Internet2 infra team to deploy, but there was no way to check the deployed result other than clicking URLs by hand.

Add grouper-misc/grouper-docs/redirects/test_redirects.sh, which runs one representative case for every rule in grouper_redirects.conf and prints PASS/FAIL with the expected versus actual first hop. It takes the host as an argument so it can be pointed at the dev host or prod, and it is read-only (HEAD/GET only). It sends a browser User-Agent because the ELB/WAF in front of these hosts answers 403 to bare curl, and it prints a reminder that a green run still does not prove Googlebot can reach the 301s.

Only the first hop is checked on purpose: a correct config 301s straight to docs.grouper.internet2.edu, so any 302 that stays on the source host is Confluence answering instead of the rewrite rule, and that is a failure.
