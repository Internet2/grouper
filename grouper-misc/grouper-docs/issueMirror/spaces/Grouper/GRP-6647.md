# GRP-6647  "finalLog: true" should be surfaced in the Daemon logs UI as a column. To make it far easier to know if an "Error" status was a completed job or a failed partial job.

Please add an independent column in the job report that identifies "finalLog: true"  vs "finalLog: false" for all jobs.

This could also be added to the 'Filter status' options, or a check box like the "Show subjobs" to allow the user to find only jobs that did not complete.
