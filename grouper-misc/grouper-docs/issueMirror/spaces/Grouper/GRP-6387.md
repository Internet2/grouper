# GRP-6387  Grouper report can't be edited from the daemon job screen

Grouper reports created on a folder or group show up in the daemon job list similarly to loader jobs, with names like grouper_report_<objectId>_<attributemarker>. There is special logic for loader jobs, so that they go to the group's loader edit screen instead of the normal daemon edit screen. It's not as easy to add similar logic to go to the report edit screen, since you can't tell from the job name whether it's for a group or for a folder.

 

Option 1: Remove the edit daemon option from the job actions

Option 2: When building the daemon list and daemon detail screen, parse the group or folder id from the job name, do a query to determine whether it's a group or folder, and build the correct link so it goes to the right report editor screen
