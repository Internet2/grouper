# GRP-7056  Accessibility: add aria-label and role=search to main page search box

WAVE flags a "Missing form label" error on the search input in the main page top navbar. A {{placeholder}} is not an accessible name, so screen readers announce the field as unlabeled.

Changes in {{grouper-ui/webapp/WEB-INF/grouperUi2/index/index.jsp}}:
 * Added {{aria-label}} to the {{#mainPageSearchInput}} input, reusing the existing {{ariaLabelGuiSearch}} text key (already localized in en and fr, already used by the adjacent search button).
 * Added {{role="search"}} to the surrounding {{<form class="navbar-search">}} so the search box is exposed as a search landmark.
 * Same edits applied to the commented-out POST variant from GRP-2677 to keep both forms in parity.

No styling or behavior change.

*Acceptance*
 * WAVE shows no "Missing form label" error on the main page search input.
 * VoiceOver / NVDA announce the input as "Search, edit text".
 * Search still submits as before.
