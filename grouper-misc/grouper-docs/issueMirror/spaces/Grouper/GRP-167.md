# GRP-167  centralize utilties in gsh

It seems desireable for utilities (e.g. the unresovable subject deletion utility and fix bad memberships, perhaps grouper-loader) to be runnable from within gsh as well as from external scripts (e.g. .sh and .bat). The number of external scripts could be reduced to one, gsh.sh, and possibly the UI and WS could have access to utility functions.
