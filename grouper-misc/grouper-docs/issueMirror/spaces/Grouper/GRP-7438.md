# GRP-7438  GSH templates can return a file for the user to download

GSH templates (including compiled Java templates) should be able to hand the user a file to download after the template runs, e.g. a daily CSV report.

The template saves text contents to grouper_file (system_name gshTemplateDownload, file_path /gshTemplateDownload/<templateConfigId>/<yyyy-MM-dd>/<fileName>, unencrypted) or points at an existing grouper_file row. A template can look up whether the file for a date already exists and reuse it instead of recomputing.

UI: any ajax action can start a download. The file id goes in the HTTP session under a random token, and a screen action sets location.href to a plain GET download action, which only serves tokens in the current session and streams the file with Content-Disposition attachment (gzip when the browser accepts it).

Rows the template creates are deleted after a configurable retention period. Pointing at an existing row never deletes it.

Design change: no central cleanup or retention config. Each template deletes its own old download files with gsh_builtin_gshTemplateOutput.deleteExpiredDownloadFiles(retentionDays), which only affects that template's paths.
