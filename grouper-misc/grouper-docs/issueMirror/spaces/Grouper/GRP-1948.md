# GRP-1948  Upgrade dependent jars to latest version possible

In the API and UI, the majority of dependent jar files included with the 2.4 distribution have been upgraded to the latest version possible. Those remaining had some issues, such as method changes that required significant changes in Grouper code. In addition, the WS jars were mostly left as is, as many were already fairly recent.
