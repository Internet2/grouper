# GRP-2677  Have searchQuery submit query by URL

If you search by using the search-query in the upper right of the page, the query is sent via URL and the results are displayed as expected.  Any subsequent queries using the searchQuery field above the results does not use the URL to send the queries.

 

The results in an experience disruption when a user performs a second query using the more prominent searchQuery, clicks on a link from the results, then use the back button to return to the results.  What's returned are the results from the initial query made from search-query, which may not be what the user wants or expects.
