### mchyzer - 2010-03-16T17:55:18.281+0000

One thing I can do is when there is an error, to make sure to send back valid XML so the control will display that there was an error.  Right now maybe when there is an error, it throws the error, and the combobox control is confused.

In addition, the sort column is correct when not having to join to the security tables, but when joining, it is wrong.  If I change SimpleMembershipUpdateFilter.java line 83:

FROM:
        queryOptions = new QueryOptions().paging(TagUtils.mediaResourceInt("simpleMembershipUpdate.groupComboboxResultSize", 200), 1, true).sortAsc("displayNameDb");

TO:
        queryOptions = new QueryOptions().paging(TagUtils.mediaResourceInt("simpleMembershipUpdate.groupComboboxResultSize", 200), 1, true).sortAsc("theGroup.displayNameDb");


Then it works.

This is in the 1.5 branch, and will be in 1.5.3.

Hi,

Just been testing out the new lite UI, and have came across a minor issue when using the find a group function. 

If a user is logged into the lite Ui to manage their group, for example nclgroup, and they go to use the "find a group" search function to look for another group that they manage, eg nclgroup_admins, an xml error is returned (the user has admin privileges on both the groups). The error appears when beginning to type in the search text, after a few characters a warning box pops up displaying the below;

Error type: LoadXML
Description: Incorrect XML

If you click ok, and try and search again the search returns no values.

To try and pinpoint the problem, i added the user to the wheel group, you are then able to successfully search for other groups. It appears that the issue only exists if the user is not a member of the wheel group. 

I'm not sure if this is the way the Ui has been designed, where it is only the root like users who can find groups with this function? or if its a little bug in the Ui.

Not sure if anyone else has came across the same error or if it is just something which is specific to our install. This is using grouper 1.5.1.
