# GRP-7506  AI agent config docs: note that the bearer token external system goes in grouper-loader.properties, not grouper.properties

The AI agent in the UI section of grouper.base.properties says the provider endpoint and API key come from a web service bearer token external system (grouper.wsBearerToken.<configId>.*), but does not say which config file that goes in.

It is easy to put the external system in grouper.properties next to the grouper.ai.agent.* settings. Then the assistant only shows: The AI assistant is not set up correctly. Contact your Grouper administrator. The log says grouper.wsBearerToken.<configId>.endpoint is not set in grouper-loader.properties.

Add a note to the section header: the external system goes in grouper-loader.properties (or add it in the UI under external systems), while the grouper.ai.agent.* settings go in grouper.properties.
