# GRP-7011  GSH Java template compilation — templateMode config, template-type framework, base classes, registry typing

Phase 1+3 of the GSH Java template compilation effort; design doc at {{grouper/temp/trash/gshCompileImprovement.html}}. Builds on the compiler wrapper (GRP-7006) and the per-template classloader registry (GRP-7010).

*Config additions (no new DB table):*
 * Add new property {{grouperGshTemplate.\{id}.templateMode}} with values {{interpreted}} (default, legacy — Groovy or Java syntax run through the legacy Groovy engine) or {{compiled}} (Java compiled to bytecode at runtime via the new registry)
 * New enum {{GshTemplateMode \{ interpreted, compiled }}} with {{valueOfIgnoreCase}} helper matching the existing convention
 * Add {{gshTemplateMode}} field + getter/setter to {{{}GshTemplateConfig{}}}; read with default {{interpreted}} in the existing config-load block
 * Add 6 new values to the existing {{GshTemplateType}} enum: {{{}daemon{}}}, {{{}daemonChangeLog{}}}, {{{}report{}}}, {{{}customUi{}}}, {{{}hook{}}}, {{{}library{}}}. Existing {{{}gsh{}}}, {{{}abac{}}}, {{provisioner}} unchanged
 * Existing rows untouched and default to {{templateMode=interpreted}} + current {{templateType}}
 * Externalized text in {{grouper.textNg.en.us.base.properties}} (only) for {{{}templateMode{}}}'s label/tooltip and for the 6 new enum values

*New base classes (in {{{}edu.internet2.middleware.grouper.app.gsh.template{}}}, grouper module):*
 * {{GrouperTemplateDaemon}} — abstract; {{public abstract void runDaemon(OtherJobTemplateInput otherJobTemplateInput)}}
 * {{GrouperTemplateDaemonChangeLog}} — abstract; {{public abstract long processRecords(EsbPublisherChangeLogScript esbPublisherChangeLogScript)}} (returns last-processed sequence number; -1 = no advance)
 * {{GrouperTemplateReport}} — abstract; {{public abstract void runReport(GshReportRuntime gshReportRuntime)}}

*New base class (in grouper-ui module, package {{{}edu.internet2.middleware.grouper.grouperUi.beans.ui{}}}):*
 * {{GrouperTemplateCustomUi}} — abstract; {{public void runOnJoin(CustomUiTemplateInput customUiTemplateInput)}} and {{{}public void runOnLeave(CustomUiTemplateInput customUiTemplateInput){}}}. Both default-throw {{UnsupportedOperationException}} so a misconfigured template surfaces loudly. New hook-point methods can be added here in the future with the same throws-default pattern.

*New input beans:*
 * {{OtherJobTemplateInput extends OtherJobInput}} (in {{{}edu.internet2.middleware.grouper.app.loader{}}}, next to {{{}OtherJobInput{}}}) — adds {{gshTemplateConfigId}} and {{gshTemplateConfig}} fields. Override {{copyFieldsTo}} to also copy these
 * {{CustomUiTemplateInput}} (in {{{}edu.internet2.middleware.grouper.grouperUi.beans.ui{}}}, grouper-ui module) — POJO bundling {{{}customUiContainer{}}}, {{{}group{}}}, {{{}subject{}}}, {{{}subjectLoggedIn{}}}, {{{}gshTemplateConfigId{}}}, {{gshTemplateConfig}}

*Registry typing tweak (Phase 4a follow-up):*
 * {{{}GshTemplateClassLoaderRegistry.GshTemplateCachedClass.templateClass{}}}: type broadened from {{Class<? extends GshTemplateV2>}} to {{Class<?>}}
 * {{{}GshTemplateResolveResult.getTemplateClass(){}}}: same broadening
 * Drop the {{GshTemplateV2.class.isAssignableFrom(...)}} check from {{resolve()}} — each type's Phase 7 dispatcher does its own {{asSubclass()}} to the appropriate base
 * Update existing {{GshTemplateClassLoaderRegistryTest}} cases to match the broadened return type

*Out of scope for this JIRA (deferred to Phase 7 sub-tasks):*
 * The save-time validation mapping {{templateType}} → expected base class (each Phase 7 dispatcher does the cast and surfaces errors at runtime; UI-side validation lands when Phase 5 wires the inventory screen)
 * Bridge wiring ({{{}OtherJobScript{}}}, {{{}EsbPublisherChangeLogScript{}}}, {{{}ReportConfigType.GSH{}}}, {{{}CustomUiContainer{}}}, hooks framework) — each its own Phase 7 sub-task
 * {{hook}} templateType has no new base class (templates extend one of the 17 existing hook classes directly); validation is the framework's existing hook-discovery code, gated by {{templateMode=compiled}}
 * {{provisioner}} templateType reuses existing {{{}GshTemplateProvisionerBase{}}}; no new class
 * {{library}} templateType has no required base class

*Tests:*
 * {{GshTemplateConfig}} test: existing rows without {{templateMode}} default to {{{}interpreted{}}}; {{templateMode=compiled}} reads back as {{{}compiled{}}}; new {{GshTemplateType}} enum values accepted by {{valueOfIgnoreCase}}
 * Each new {{GrouperTemplate*}} base class: trivial instantiation test confirming a concrete subclass can be defined and the method invoked
 * {{{}OtherJobTemplateInput.copyFieldsTo{}}}: confirms parent fields + subclass fields both copied via setters
 * Registry typing tweak: update {{GshTemplateClassLoaderRegistryTest}} to confirm a non-{{{}GshTemplateV2{}}} compiled class (e.g. one extending {{Object}} or {{{}OtherJobBase{}}}) is now resolvable via the registry (the test previously asserted it must be a {{GshTemplateV2}} subclass — that assertion gets dropped/inverted)
