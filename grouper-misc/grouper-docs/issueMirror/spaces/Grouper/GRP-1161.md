# GRP-1161  Ensure Grouper builds have the right Java ver installed

Modify the build system to make sure the build is using Java 6, and nothing else. This prevents a ton of problems later on with database drivers, etc.

Put out a huge warning and disclaimer out into the console that: 

MAKE SURE YOU ARE RUNNING JAVA 6.
IF YOU ARE NOT, YOU ARE VYING FOR A WORLD OF PAIN.
MAKE SURE ALL JARS SUCH AS DB DRIVERS ARE COMPATIBLE WITH JAVA 6.

etc.

### mmoayyed - 2015-07-20T15:56:26.351+0000

The issue that we ran into during an install session was that the platform had JDK8 installed and while most modules were built using 1.6 via ant, WS did not. We took care of that problem in a separate JIRA, but the next issue we ran into was that some of the other JARs that we included in the build for DB drivers and what not were incompatible with JDK8 which forced us to find the right driver version and then do a bit of back and forth to finally get JDK6 on the machine. While none of that is an actual problem per se, I think it makes sense to put a big warning in the grouper installer and simply reject the build entirely if the JDK platform is anything > 6, just to avoid all that unnecessary struggle.
