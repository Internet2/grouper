# GRP-7382  grouper-release skill: user creates the container release branch; bump both version ARGs in the Dockerfile

The container repo has one branch per release (7.4.0, 7.5.0, 7.5.1), each cut from the previous release branch. Document that the human creates that branch, and the AI assistant only verifies the current branch and edits files on it; the human commits and pushes.

Also document that GROUPER_CONTAINER_VERSION and GROUPER_VERSION both get bumped, that the Dockerfile is the only file carrying the version, and to confirm with git grep for the previous version. Found while cutting 7.5.1.
