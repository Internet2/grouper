# GRP-7516  Google provisioner - add whoCanDiscoverGroup (who can see group) and ALL_OWNERS_CAN_VIEW

In the Google Groups Settings API, whoCanViewGroup means permission to view group messages, which the Google Groups UI shows as 'who can view conversations'. The UI setting 'who can see group' is a different API field, whoCanDiscoverGroup (ANYONE_CAN_DISCOVER, ALL_IN_DOMAIN_CAN_DISCOVER, ALL_MEMBERS_CAN_DISCOVER). It replaced the deprecated showInGroupDirectory, and the Grouper Google provisioner did not support it. UMN reported this on Slack: whoCanViewGroup was set correctly, but 'who can see group' stayed at the Google default.

Changes:
- Add whoCanDiscoverGroup as a Google target group attribute and optional group metadata (provisioner.myGoogleProvisioner.whoCanDiscoverGroup, and provisionerStartWith.googleCommon.hasMetadataForWhoCanDiscoverGroup). The default is false, so existing provisioners are unchanged.
- Add ALL_OWNERS_CAN_VIEW to the whoCanViewGroup metadata dropdown. Google allows this value, but Grouper did not offer it.
- Relabel the whoCanViewGroup metadata 'Who can view conversations' to match the Google UI.

Reference: https://developers.google.com/workspace/admin/groups-settings/v1/reference/groups
