# GRP-5085  Provisioner External entity attributes set Dn as a potential attribute

When using External entity attributes configuration, you can't set set `entityResolver.attributes=dn` and then retrieve the Dn as entityAttributeResolverLdap__dn because the dn is a special field and not an attribute.

## Comments

### Chad Redman - 2023-10-25T23:20:03.890+0000

Solved! The value is entryDN, or entrydn since Grouper converts it to lowercase.

 
{code}
provisioner.abc.entityResolver.attributes = entryDN
provisioner.abc.targetEntityAttribute.0.translateExpression = ${grouperProvisioningEntity.retrieveAttributeValueString('entityAttributeResolverLdap__entrydn')}
{code}
