# GRP-1643  Allow values on individual attributes to be excluded from audit/changelog and use with attestation by default

There is functionality that already exists to allow values on all attributes within an attribute definition to be excluded from audits and change log.  This Jira is about adding the same functionality to individual attributes rather than all attributes of an attribute definition.
