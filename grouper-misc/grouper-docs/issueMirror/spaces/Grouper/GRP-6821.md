# GRP-6821  Log "Cannot invite: inviteExternalMembers.enableInvitation is false" when not doing invites

When LiteUI classes were migrated in v6.0.0, canInviteExternalUsers added an error log if property inviteExternalMembers is false. It shouldn't log this because it's just checking the privilege, not actually trying to invite. It logs this even when users are doing normal UI activities unrelated to invites.

A better refactor is to only check the privilege when doing an invite.
