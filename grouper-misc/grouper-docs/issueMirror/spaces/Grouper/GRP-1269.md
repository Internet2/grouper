# GRP-1269  Grouper Provisioning, The Next Generation (PSPNG)

PSPNG will be a new Provisioning infrastructure that:
* Performs changes much faster than PSP
* Is easier to configure, particularly by using good defaults, property overlays and JEXL expressions
* Is probably less flexible (is not all things to all people)
* Can implement changes into LDAP systems: 
# Active Directory Groups
# GroupOfNames or GroupOfUniqueNames
# PosixGroups
# Attributes of User objects (eg, entitlements)

Generally, PSPNG's goals are described in the Grouper Wiki [https://spaces.internet2.edu/display/Grouper/Post+PSP+Provisioning]

PSPNG page is here https://spaces.internet2.edu/display/Grouper/Grouper+Provisioning%3A+PSPNG
