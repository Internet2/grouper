# GRP-2840  "recent memberships" should work across group renames

Note: I cannot reproduce this, so it might be ok right now, but there is a tweak to improve it.  Note: if you rename a group the history will still be there.  If you delete and recreate group, you will not have the same "recent memberships" list since it is now being controlled by the group uuid

## Comments

### Chris Hyzer - 2020-06-07T19:08:18.796+0000

You can fix this before 2.5.30 by changing the query in the recent memberships loader:

FROM:

and gaaagv_groupName.group_name = gpg.name

TO:

and gaaagv_groupName.group_id = gpg.source_id
