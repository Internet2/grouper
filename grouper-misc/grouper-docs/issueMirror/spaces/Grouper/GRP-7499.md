# GRP-7499  Group edit page fails for user lifecycle policies without an index (regression from GRP-7174)

After upgrading to 6.4.1, the Edit group screen fails with: java.lang.RuntimeException: Cant find property: grouperUserLifecyclePolicy.<configId>.index in properties file: grouper.properties, it is required

GRP-7174 added an index setting to user lifecycle policies to order the radio buttons on the group edit page, and GuiUserLifecyclePolicy reads it as required. Policies configured before that change have no index, so the group edit page throws for every group as soon as one such policy exists.

Fix: read the index as optional. Policies without an index sort to the bottom of the list (GroupContainer already treats a null index as last). New policies still prompt for an index in the config form.

Workaround: add grouperUserLifecyclePolicy.<configId>.index to each lifecycle policy.
