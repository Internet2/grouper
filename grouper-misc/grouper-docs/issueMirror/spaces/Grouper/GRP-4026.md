# GRP-4026  ability for container to add ssl anchor cert for OS/java

https://spaces.at.internet2.edu/display/Grouper/Grouper+v2.5+container+client+SSL+certificates

## Comments

### Chris Hyzer - 2022-05-05T18:01:30.224+0000

Note, if you have files in the Grouper anchor dir:
{code:java}
 /opt/grouper/certs/anchors{code}
then this command will be run: /bin/update-ca-trust (if container user is root), if not, then you need to run that in the subimage Dockerfile

This is included by default in the java startup for tomee or gsh, so if you have this in your override, you should remove it:
{code:java}
 -Djavax.net.ssl.trustStore=/etc/pki/java/cacerts{code}
