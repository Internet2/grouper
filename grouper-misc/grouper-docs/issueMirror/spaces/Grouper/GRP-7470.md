# GRP-7470  Upgrade RabbitMQ amqp-client to 5.37.0 for security

amqp-client 5.35.0 has GHSA-7822-rcf6-97fx (moderate, malformed UTF-8 in shortstr properties permanently disables RPC consumers, fixed in 5.36.0) and GHSA-cqgh-8p3p-mx4m (moderate, JSONReader in the default JSON-RPC mapper never terminates on truncated input, advisory says fixed in 5.36.1, which is not published to Maven Central). 5.37.0 has no open advisories. Only affects sites using RabbitMQ messaging.

Fix: amqp-client.version 5.35.0 -> 5.37.0 in grouper-parent.
