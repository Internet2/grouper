# GRP-7083  Convert mock services to Javalin

Mock services are low-level string parsing of REST urls. This makes the implementations harder to read, potentially flawed, and slower to implement.

Javalin is a framework for easily implementing REST servers. The syntax is similar to Flask for python. It requires only a single dependency, so should not add extra cruft to the project.
