# GRP-5990  Add RuleUtil method membershipDisabledDateDays()

A client wants to create a rule to set a disabled date on a user who loses employee status, but only if it doesn't extend the disabled date. There is no easy way to do this now - the rule EL variable map only has the group name of the group they lost the membership in, not the one the rule is on to set their disabled date. If there were a jexl method in the If condition to get the current number of days for their membership disabled date, it could check and only proceed if the target value is less than the current value.
