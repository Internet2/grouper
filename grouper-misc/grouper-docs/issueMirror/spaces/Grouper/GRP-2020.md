# GRP-2020  attestation should support a "Email group Managers" option of "Other group" to point at a Grouper Group to get Members

The current options for attestation, "Email group Managers" are:
 * Group Admins
 * custom CSV list of email addresses

A third option to point at a grouper group to be able to reuse a "custom list" (members of the selected group) and to allow other's to admin the list to notify for one or more groups without giving them privileges on all of the groups using the list. ( Think "Access Management team" vs "Audit/certification teams" )

If the UI had the ability to also "Search for groups" when this option was selected that would be amazing too. :)
