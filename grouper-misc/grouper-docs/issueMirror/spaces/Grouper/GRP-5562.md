# GRP-5562  Provisioner view assignments should show provisionable yes/no values

The Provisioner view assignments page shows all the groups and folders with direct provisioning set. However an object could be set to provisionable = false and still show up here. Users might expect that the list is all provisionable objects when that may not be true. There should be another column to show provisionable yes/no
