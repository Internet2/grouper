# GRP-399  make exceptions runtime, finders intuitive

Make the exceptions in the subject API runtime.

Thus, it is confusing if a find method which is to return 1 or 0 results throws a runtime exception on 0, so deprecated those methods, and overload with a boolean param exceptionIfNull

Also, format the code, remove eclipse warnings.
