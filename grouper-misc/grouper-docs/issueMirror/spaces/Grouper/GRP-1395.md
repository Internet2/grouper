# GRP-1395  Change log improvements

1.  Fix issue where the cached next sequence number needs to be reset on each run since the daemon can now run on multiple servers.
2.  Allow the batch size for change log consumers to be configurable.  Change default from 100 to 1000.
3.  Grouper diagnostics shouldn't error out if a change log consumer hasn't had a success but is running and making progress.  Configurable so you can revert to the old behavior.
