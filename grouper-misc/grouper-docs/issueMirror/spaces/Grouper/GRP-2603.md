# GRP-2603  Messaging Listener for RabbitMQ RealTime Loader losing messages

Worked with Shilen to demonstrate the rabbitmq message listener consumes messages from rabbitmq but usually loses the message and doesn't update the realTime table.  Shilen confirmed the configuration used and we turned up debug messaging.  On a restart of loader with a disabled listener and message in queue - then enabling the listener shows messages received and entries in the table created for the first 2 or so messages.  Further runs of the listener would read/empty the queue but nothing gets deposited in the table and no useful errors generated.
The rest of the realtime loader appears to work well once entries are created in the realtime loader table.
