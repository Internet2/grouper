# GRP-7494  CSV report daemon: add csvReport.minRows failsafe

GrouperCsvReportJob (CSV report daemon) has no failsafe. If the query returns a bad result, e.g. a source table was truncated or a reference group was emptied, the file is still written and sftp'd, and the target system may remove or disable everyone missing from it.

Add an optional config otherJob.<jobId>.csvReport.minRows in grouper-loader.properties. If the query returns fewer rows than this, the job errors and the file is not created or sent. Blank or 0 means no minimum.

Added to grouper-loader.base.properties and the daemon config UI text (en and fr).
