This is similar to the subject picker.  This will be useful for the Kuali Workflow integration where you want a screen for permission assignments, and a picker to select which permissions to assign.  e.g. here is a demo

https://spaces.internet2.edu/download/attachments/11075978/kualiPermissions.wmv

Here is the wiki

https://spaces.internet2.edu/display/GrouperWG/Grouper+resource+or+permission+picker

The Grouper attributeDefName resource picker is a lightweight embeddable UI component which can help external applications (or Grouper itself) to find attributes, resources, or permissions to put into textfields or hidden fields or drop downs or whatever.  This is available for Grouper 1.6+.
