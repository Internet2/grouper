# GRP-2695  add env var to switch to tomcat ws authn

In a future version we would like an env var to switch to tomcat ws authn so people do not need to overlay and so we can control the configuration internally on upgrades.

So if people pass in

GROUPER_WS_TOMCAT_AUTHN=true

Then copy 

/opt/grouper/grouperWebapp/WEB-INF/web.wsTomcatAuthn.xml

to

/opt/grouper/grouperWebapp/WEB-INF/web.xml

 

And copy

 

/opt/grouper/grouperWebapp/WEB-INF/server.wsTomcatAuthn.xml

to

/opt/tomee/conf/server.xml
