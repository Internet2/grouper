# GRP-2297  Public method to create pspng attributes

Method pspng.Provisioner.checkAttributeDefinitions() creates the stem, attributeDefs, and attributeDefNames for pspng provision_to and do_not_provision_to attributes. Sadly, it a private method, which only gets called when invoking an actual Provisioner object.

Any way this can be made public, so it can be called by gsh?
