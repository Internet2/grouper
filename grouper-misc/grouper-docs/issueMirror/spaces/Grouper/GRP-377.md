# GRP-377  grouper ui access control lists

_(no description)_

## Comments

### mchyzer - 2010-02-18T14:56:23.912+0000

There are now three access control lists for the grouper ui configured in the media.properties.  These default to blank which means all allowed.

#users must be in this group to be able to login to the UI
require.group.for.logins=

#users must be in this group to be able to login to the lite membership update UI
require.group.for.membershipUpdateLite.logins=

#users must be in this group to be able to login to the subjectPicker UI
require.group.for.subjectPicker.logins=

Note that if you are allowed in the admin UI (first group), you are allowed in the other two.  If you are allowed in the memebershipUpdateLite (lite UI), then you are allowed in the subjectPicker.
