# GRP-7165  Widen grouper_sync_member.subject_identifier to varchar(1024) for parity with grouper_members.subject_identifier0 (GRP-7076)

GRP-7076 widened grouper_members.subject_identifier0/1/2, grouper_pit_members.subject_identifier0, and grouper_stems.name/display_name/alternate_name from varchar(255) to varchar(1024) so group and folder names of 256-1024 chars can be saved and used as subjects. grouper_sync_member.subject_identifier was not part of that change and is still varchar(255).

When a group whose name exceeds 255 chars is provisioned as a subject, its identifier is cached in grouper_sync_member.subject_identifier, which at varchar(255) would truncate or error. Propose widening grouper_sync_member.subject_identifier to varchar(1024) for parity. Note it has a dependent database view (grouper_sync_membership_v) that must be dropped and recreated around the alter; mysql index prefixes stay at 255.
