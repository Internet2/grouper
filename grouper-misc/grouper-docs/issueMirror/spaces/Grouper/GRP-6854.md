# GRP-6854  Move data field/row history cleanup to cleanLogs daemon

Moved data field/row PIT history cleanup out of each data provider full sync into the OTHER_JOB_cleanLogs daemon (GrouperDaemonDeleteOldRecords), so it runs once daily instead of redundantly in every provider full sync. The method is now public static on GrouperDataProviderLogic and called from the cleanup daemon.
