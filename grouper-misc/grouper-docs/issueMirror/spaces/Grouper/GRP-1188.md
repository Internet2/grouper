# GRP-1188  print an error if Grouper is used with invalid version of Java

Grouper can have problems if used with Java8.   Print an error if invalid Java is used.

## Comments

### mchyzer - 2015-08-30T19:35:56.000+0000

Fixed in API patch 25 in 2.2.1

2015-08-30 15:31:48,676: [main] ERROR GrouperStartup.startup(219) -  - Error: Java should be version 6 or 7 (1.6 or 1.7), but is detected as: 1.8.0_60

configure this in grouper.properties to not check:

configuration.checkJavaVersion = false


### mchyzer - 2015-08-30T21:24:35.803+0000

The installer will display this:

Error: Java should be version 6 or 7 (1.6 or 1.7), but is detected as: 1.8.0_60
Press <enter> to continue...

You can turn this off with in grouper.installer.properties

# if should check java version and make sure ok
grouperInstaller.checkJavaVersion = true


Or autofill by uncommenting this:

# autorun, Error: Java should be version 6 or 7 (1.6 or 1.7), but is detected as: (you can just uncomment, doesnt need a value)
# grouperInstaller.autorun.wrongJavaContinue =
