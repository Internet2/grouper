# GRP-7610  SCIM: support PATCH /Groups/{id} to add and remove members

The SCIM Groups endpoint supports POST, PUT and DELETE but not PATCH. In standard SCIM (RFC 7644 section 3.5.2) a client adds or removes group members with PATCH /Groups/{id} using add and remove operations on the members attribute. Today the only way to add or remove a single member is the Grouper specific /Memberships endpoint, or a PUT of the whole group.

Change: support PATCH /Groups/{id} with add and remove operations on members (add: value is the member id; remove: path members[value eq "..."]), with the same privilege checks as /Memberships. Other attributes can be added later.

Also: unit tests, and update the SCIM documentation.

Related: GRP-7609 (Group responses do not embed members unless a setting is on), GRP-7611 (paged GET /Users filtered by group), GRP-7612 (deprecate /Memberships, needs this one first).
