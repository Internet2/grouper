# GRP-6873  TrueFoundry provisioner should always set group name since it is required for team API calls

The TrueFoundry provisioner was conditionally setting the group name only when "name" was in the fieldNamesToSet. However, the name field is required for TrueFoundry team API calls (similar to how id is always set). This could cause API failures when name was not in the fields to set. The fix always sets the name field regardless of fieldNamesToSet.
