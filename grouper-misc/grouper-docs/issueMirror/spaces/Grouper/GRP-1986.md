# GRP-1986  UI/WS upgrade reverts some patching

Happens during an upgrade of the UI from 2.3 to 2.4. The process now is:
 # revert all 2.3 patches to base 2,3
 # Upgrade API libs and conf in UI directory
 # Patch UI with api patches
 # Build base 2.4 ui from tarball
 # Compare base 2.4 against ui install and "upgrade" lib files that don't match

This means that the domj and ldaptive are upgraded in step 3, but reverted in step 5.

There are few ways to fix this, maybe just by changing the order.
