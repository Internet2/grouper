# GRP-7402  MCP scope tests still pass the old ownerSubjectId argument so subject owner checks are never exercised

GRP-6775 renamed the attribute_assignment_save argument ownerSubjectId to ownerSubjectIdOrIdentifier, but three tests in GrouperMcpScopeTest still passed ownerSubjectId. The tool ignored it and never saw a subject owner, so the subject scope checks were never run: testAssignAttributes_invalidSubjectScope and testAssignAttributes_subjectOwner_deniedWhenGroupFolderScopeOnly failed, and a third test passed only because the subject was ignored.

Fix: the tests now pass ownerSubjectIdOrIdentifier. Test-only change, no change to the tool.
