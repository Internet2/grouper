# GRP-4011  Grouper UI queries root folder twice

Regardless of whether the UI root (i.e. in the browse folders section) is configured to be the actual root or another stem, the Grouper UI will query that node twice.  The query involves figuring out the child folders that the user can see.  Since it can be an expensive query, when it's done an additional unnecessary time, it can be noticeable.
