# GRP-1140  Virtual attributes for subject name and description

Support virtual attributes for the subject name and description.

## Comments

### shilen - 2015-06-19T16:22:18.879+0000

Can be used like this in sources.xml:

    <init-param>
      <param-name>Name_AttributeType</param-name>
      <param-value>customName</param-value>
    </init-param>
    <init-param>
      <param-name>Description_AttributeType</param-name>
      <param-value>customDescription</param-value>
    </init-param>

    <init-param>
      <param-name>subjectVirtualAttribute_1_customName</param-name>
      <param-value>${subjectUtils.defaultIfBlank(subject.getAttributeValue('displayName'), subject.getAttributeValue('givenName') + " " + subject.getAttributeValue('sn'))}</param-value>
    </init-param>
    <init-param>
      <param-name>subjectVirtualAttribute_2_customDescription</param-name>
      <param-value>${subjectUtils.defaultIfBlank(subject.getAttributeValue('description'), subject.getAttributeValue('givenName') + " " + subject.getAttributeValue('sn'))}</param-value>
    </init-param>
