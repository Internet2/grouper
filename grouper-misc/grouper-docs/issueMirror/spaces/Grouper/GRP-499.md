# GRP-499  ldappc-ng's optional -lastModifyTime option incorrectly deletes groups

Ldappcng's optional -lastModifyTime option incorrectly deletes groups which were not modified after the given lastModifyTime.

I rushed this implementation, the bug is serious and results in data loss on provisioned targets.

## Comments

### tzeller@example.com - 2010-10-14T02:42:09.560+0000

Fixed.

During the PSP's execution of BulkDiff requests, the identifiers of objects changed since the specified lastModifyTime are diff'ed, followed by a reconciliation of the identifiers of all objects whereby provisioned objects that no longer exist in sources are deleted.
