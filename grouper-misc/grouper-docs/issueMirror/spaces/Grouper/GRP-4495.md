# GRP-4495  Ability to use different regex for validation of groups/stems/etc per folder

I am seeking the ability to apply different regex validation rules for group/stem/etc names.  Would like to be able to apply these via the UI.

I'd like to preserve the default regex validation for all of grouper and have these just be exceptions.

I am happy to have one regex to apply for all objects in the folder.

### Chris Hyzer - 2022-11-17T06:28:05.018+0000

Use a fancy regex (grouper.properties)

example that allows the test folder to have any chars, and other folders must be alphanumeric underscore or dash (default)


{code:java}group.validateExtensionByDefault = false
stem.validateExtensionByDefault = false
group.attribute.validator.attributeName.0=name
group.attribute.validator.regex.0=^((test:.*)|([\\p{L}:0-9_-]+))$
group.attribute.validator.vetoMessage.0=The group ID can only contain letters, numbers, underscore, or dash
stem.attribute.validator.attributeName.0=name
stem.attribute.validator.regex.0=^((test:.*)|([\\p{L}:0-9_-]+))$
stem.attribute.validator.vetoMessage.0=The folder ID can only contain letters, numbers, underscore, or dash {code}

### Chris Hyzer - 2022-11-17T06:28:35.696+0000

Note: there is no fix for this, it is just an example which works in any supported Grouper version
