# GRP-2308  Web UI - allow for hiding left hand navigate elements

as discussed in slack:
would you consider a UI element to completely collapse/remove the quick links/browse folders so we can actually get a full screen of info instead of the left-right scrolling?
maybe something in the very top bar which is largely empty could be used to allow me to select to have the left hand stuff removed?
this config stuff, the graphing and even just viewing some groups could all benefit from better use of screen real estate.
The idea would be i could click on something and the left hand side disappears and we are now making full screen width use of the main group view (for config view and so on).  I should then be able to click on something again and the left hand nav aid comes back and we are back to the "traditional" view.
