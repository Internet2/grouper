# GRP-7483  GSH template displayErrorOutput renders the exception stack trace in the UI without HTML escaping

UiV2Template.java builds the error output for a failed GSH template run when displayErrorOutput is true. The script output is HTML-escaped, but the exception stack trace (ExceptionUtils.getStackTrace) is put inside a pre tag as raw HTML. Anything in the exception message that looks like a tag disappears, for example an email in angle brackets or a Java generic type. Text from user input, other users’ group or folder names, or remote API responses can also inject markup or script (XSS). The fix is to escape it with GrouperUtil.escapeHtml(exceptionMessage, true), matching the script output.
