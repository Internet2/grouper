# GRP-2541  Miscellaneous >> All daemon jobs "Apply filter" button does not honor URL parameter value ( Example: daemonJobsFilter=usduDaemon )

Starting from the Miscellaneous >> Subject resolution  >> Subject resolution stats  page.

click the "More Actions" > "view daemon logs"

The user is routed to a URL like: ..../grouper_v2_4/grouperUi/app/UiV2Main.index?operation=UiV2Admin.daemonJobs&daemonJobsFilter=usduDaemon

 

And the page only shows one item (the usduDaemon job) in the list.

If the user pushes the "Apply filter" button then the list is refreshed to the full list.
If the user refreshes their browser window it goes back to only showing the usduDaemon job.

 

I think it would be better if the filter value was passed into the field "Filter for:" field so that the "Apply filter" button behavior would not change the state of the data being displayed.
