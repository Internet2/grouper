2. tooltips.  Add a way to have tooltips in grouper so that users will be able to get instance hints on what things mean
3. infodots. Have unobtrusive help blubs peppered around the screens so users can get specific help on screen sections
4. layout updates.  Make small but important improvements to the UI design in general
