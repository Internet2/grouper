# GRP-1141  PSP distribution files are not Java 8 compatible.

PSP example files contain some scripted attributes which are not compatible with Java 8's JS engine.  The fix is to follow the guidlines at:

https://wiki.shibboleth.net/confluence/display/SHIB2/IdPJava1.8



## Comments

### langedb - 2015-06-17T16:48:54.817+0000

Consensus from the Grouper Call on June 17, 2015 is that we will update the PSP to warn if you try to run the PSP with Java 8.  We will also trap the exception that gets thrown for the bad scripts & log at WARN that the PSP requires Java 7.
