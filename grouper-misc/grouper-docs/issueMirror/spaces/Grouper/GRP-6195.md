# GRP-6195  Import Member Functionality is not executing

When a user goes to import users into a group, users can select users via the form(single user, list, csv file), but when they go to import, the form throws an error in the console and the form is not submitted.  This results in bulk imports not working for any users.

Steps to recreate:

Go to a group, click on Group actions -> Import members

add users via any of the available options and click submit

Observe that nothing happens.
