# GRP-3058  add provisioning error code to tables

This will add the error_code column to sync groups, members and memberships.  Also to the sync membership view, and the three error indexes.

3 categories, ERR (provisioning error), INV/LEN/REQ (invalid data by script, max length, and required field/attribute), and DNE (does not exist in target and not creating)
