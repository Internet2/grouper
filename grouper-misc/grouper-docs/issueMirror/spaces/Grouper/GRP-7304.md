# GRP-7304  UI accessibility: home page heading hierarchy skipped a level (h1 to h3)

The home page (indexMain) already has a meaningful h1 (app name + institution), but its outline jumps h1 -> h3 (Recent activity) -> h4 (dashboard panels), skipping h2 (SC 1.3.1, 2.4.6).

Fix: bump the section/panel headings one level so the outline is h1 -> h2 -> h3 with no gap - Recent activity h3 to h2 (indexMain.jsp), and the dashboard panel titles h4 to h3 (indexMyFavorites, indexGroupsImanage, indexMyServices, indexMyMemberships, indexRecentlyUsed, indexStemsImanage). Two size-preserving classes in grouperUi2.css keep the original bootstrap visual size after the bump (h2 shown at h3 size = 22.75px; h3 shown at h4 size = 16.25px with line-height 18px), so the page looks unchanged while the semantics become correct.
