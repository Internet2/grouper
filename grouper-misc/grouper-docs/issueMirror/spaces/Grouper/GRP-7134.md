# GRP-7134  Grouper wiki: migrate GrIntDev to cloud, fix on-prem links across both spaces, add a git markdown mirror for AI/RAG

h2. Background

The Grouper wiki moved from the on-prem Internet2 wiki (spaces.at.internet2.edu) to Confluence Cloud (grouper.atlassian.net). Many migrated pages still linked back to the on-prem wiki, the internal-development space needed a cloud home, and we want a version-controlled Markdown copy of the wiki for AI question-answering and change tracking.
h2. What was done

*1. GrIntDev migration and access*
 * Imported the Grouper Internal Development (GrIntDev) space into grouper.atlassian.net as its own space (via edited XML export, working around CCMA user conflicts).
 * Restricted it to logged-in users so internal-dev content stays out of the public wiki search — public/non-secret, just not indexed with the main wiki.
 * Fixed the on-prem "this documentation has moved" banner and repaired the every-page navigation include.

*2. On-prem link sweep (both spaces, ~4,000 links, 0 errors)*
 * Rewrote *~3,370* links that pointed back to the on-prem wiki into native cloud links (pageId-stable, survive rename/move).
 * Un-hyperlinked *~570* links to pages that were deleted on-prem (link text preserved).
 * Un-hyperlinked ~600 personal-space author links, removed createpage/broken links; left links to non-migrated spaces and attachments (they still resolve while on-prem is up).

*3. Page-structure repairs*
 * Converted *136* broken page-include macros (old server {{{}spaceKey{}}}/{{{}pageTitle{}}} format) to the working cloud format; added the nav include to *223* pages that were missing it.
 * Moved public-facing dev content (WG presentations, dev-environment setup guides) into the public Grouper space and created a "Setting up a Grouper development environment" landing page.

*4. Markdown mirror in git (for AI/RAG and change tracking)*
 * Added a self-maintaining Markdown export of the whole wiki at {{grouper-misc/grouper-docs/wikiMirror/}} (1,362 pages, ~14 MB).
 * One file per page, hierarchical, with YAML frontmatter (title/space/pageId/version/lastUpdated/absolute URL); internal links resolved to absolute cloud URLs; images, attachments, and navigation stripped (content only).
 * Incremental (only re-fetches changed pages), {{git mv}} on rename, {{git rm}} on delete, and fails on filename collisions so they get fixed upstream.
 * Committed a reference converter ({{{}wikiToMarkdown.py{}}}) plus AI instructions ({{{}convertToMarkdownAiInstructions.md{}}}) so any AI can refresh the mirror per release.

h2. Follow-ups
 * When the on-prem wiki is retired, run a final pass to un-hyperlink links that then go dead (non-migrated spaces, attachments).
