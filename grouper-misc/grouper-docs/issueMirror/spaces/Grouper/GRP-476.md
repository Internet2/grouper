# GRP-476  Don't flush on every row received in query

In 1.6.0, when a query is made that retrieves X rows, Hibernate flush() is called X times.  In my testing, flush() takes about 100 to 200 milliseconds so if X is 100,000 (because you're getting all members of a large group for instance), then it's clear that there's a performance issue.

The fix will be to call flush() just once.
