# GRP-154  Allow multiple messages, including warning messages

Chris requested the ability to display multiple messages to the user and to add warning messages

## Comments

### Gary Brown - 2008-08-05T16:24:56.586+0000

Added Message.setWarning(boolean) and LowLevelGrouperCapableAction has a method addMessage(Message,HttpServletRequest).

The existing mechanism of setting a request attribute called "message" still works. If it has been called prior to any addMessage invocation the message will be placed at the start of the List. If the existing method is used after addMessage has been called the message will be ignored.

The error page for unhandled errors is unaffected.

Chris: you might want to change the color (brown) I used for warning messages. For testing I modified the Save Group Action:

request.setAttribute("message", new Message(
				"groups.message.group-saved", (String) groupForm
						.get("groupDisplayName")));
		addMessage(new Message(
				"groups.message.group-saved", (String) groupForm
				.get("groupDisplayName"),true), request);
		Message m = new Message(
				"groups.message.group-saved", (String) groupForm
				.get("groupDisplayName"));
		m.setWarning(true);
		addMessage(m,request);
