# GRP-1084  Blank Descriptions Causes psp LDAP Provisioning Error

Greetings,

It looks like that using the default configuration examples in the psp.xml file, I'm seeing errors when trying to create an LDAP group if that group has no description set:
LDAP: error code 21 - description: value #0 invalid per syntax

It looks like it's trying to create a group with a blank description attribute as opposed to not trying to set the description attribute at all. It seems like the code should detect a blank attribute and keep it from trying to be set on the LDAP layer. As long as the group has a description, the psp provisions fine.
