# GRP-5999  Rule pattern "Veto if not eligible due to group" does not run in daemon

The v5 rule pattern "Veto if not eligible due to group" sets up a rule with:

- Check type: membershipAdd
- If condition: groupHasNoEnabledMembership
- Then action: veto

Works in UI to veto adding a member. But it does not work in the daemon. The method canRunDeamon() for the membershipAdd type only works for IfConditions:
- groupHasNoImmediateEnabledMembership
- noGroupInFolderHasImmediateEnabledMembership

It does not run for the groupHasNoEnabledMembership type.
