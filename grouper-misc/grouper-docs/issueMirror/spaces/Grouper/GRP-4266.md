# GRP-4266  add provisioning membership delete setting to only delete memberships that grouper has tracked

For instance in Duo, if you make Duo authoritative, it will delete all memberships from all groups (that Grouper has never tracked)

## Comments

### Chris Hyzer - 2022-08-27T18:44:18.843+0000

ie the memberships need to be in a group in the grouper sync group table

### Chris Hyzer - 2022-10-20T15:11:13.046+0000

Create a setting.

Show only if delete memberships "delete if not exist in grouper" is selected

Label: Delete memberships only in tracked groups

Default: true

If this is false, then do the existing behavior

If this is true, then only delete memberships if:
 * the group is being deleted
 * (or) if the group is or was provisionable (has a grouper sync group record and provisionable is true or provisionable_end is not null)
