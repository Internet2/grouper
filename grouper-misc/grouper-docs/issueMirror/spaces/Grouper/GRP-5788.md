# GRP-5788  Swagger URLS contain zero-width characters and can't be used directly

The URLs generated on the swagger documentation look like this:

BAD (Swagger URL) ​/grouper-ws_v4​/servicesRest​/v4_0_450​/groups

 

It looks like a normal URL, but if you move the cursor through the string, you can see there are zero-width characters in the URL before the slashes. This means you can't copy the URLs from the swagger page and paste them in. You get the following 400 error:
{quote}*Type* Exception Report

*Message* Invalid character found in the request target [/grouper/servicesRest0xe20x800x8b/v4_0_4500xe20x800x8b/groups ]. The valid characters are defined in RFC 7230 and RFC 3986

*Description* The server cannot or will not process the request due to something that is perceived to be a client error (e.g., malformed request syntax, invalid request message framing, or deceptive request routing).

 
{quote}
The following URL below looks the same, but it is not. It was typed in manually, and has normal slashes with no invisible characters. WS responds to this URL normally.

GOOD (type in by hand) /grouper-ws_v4/servicesRest/v4_0_450/groups
