# GRP-1901  Real time loader SQL jobs - allow separate database for incremental table

The real time loader currently assumes that the "warehouse" database is the same as the one that has the incremental table since the assumption was that you'd put triggers on your source tables to populate the incremental table.  There's a request to separate that now.
