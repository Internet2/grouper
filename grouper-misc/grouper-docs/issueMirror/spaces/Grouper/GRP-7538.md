# GRP-7538  group list loader with like string doesn't trigger failsafe for groups removed

A group list loader (SQL or LDAP) with a groups-like string and failsafe enabled does not trigger the failsafe when the source returns no groups. This happens when the groups matching the like string have no loaderMetadata for that loader.

Steps to reproduce

# Configure a group list loader with a groups-like string.
# Enable the failsafe: grouperLoaderFailsafeUse is true, or loader.failsafe.use is true. Set grouperLoaderMaxOverallPercentGroupsRemove, for example to 30.
# Run the loader to create groups and populate memberships
# Make the source return no groups, then run the loader.

Expected

The loader sees that it is about to clear 100% of the populated managed groups. It stops with ERROR_FAILSAFE.

Actual

The failsafe is not triggered.
