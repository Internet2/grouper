# GRP-2402  Morph.decryptIfFile should accept slashes in passwords

Morph.decryptIfFile

file if starts file: and the file path, or if it is a file that can be resolved

## Comments

### Chris Hyzer - 2019-11-01T11:01:25.385+0000

Accepted inputs:

abcdef123    (password)

nr/3jdfo9=   (encrypted password)

/some/file.txt   (file name (if its a file?) with password inside or an encrypted password inside)

file:/some/file.txt   (must be filename with password inside or an encrypted password inside)

 

 If the string can be decrypted, decrypt it and return it.

If it starts with "file:", then strip that off and read from file.  If file doesnt exist, that is an error.

If the contents of the file can be decrypted, decrypt them.  Else just return.
