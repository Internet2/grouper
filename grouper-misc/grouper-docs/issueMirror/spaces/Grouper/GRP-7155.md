# GRP-7155  config editor: dropdown of compiled daemon template config ids for gshTemplateConfigId

When configuring a compiledJava daemon in the config editor, the gshTemplateConfigId field is a free-text input. It should be a dropdown of eligible GSH template config ids so the admin picks a valid template instead of typing a raw id.

For an otherJob script daemon (scriptType=compiledJava), populate the dropdown from templates with templateType=daemon. For a change-log consumer daemon (changeLogScriptType=compiledJava), populate it from templates with templateType=daemonChangeLog. Both daemon template types are always compiled, so no templateMode filter is needed.

Implemented with two OptionValueDriver classes (GshTemplateDaemonConfigIds and GshTemplateDaemonChangeLogConfigIds), modeled on the existing GshTemplateProvisionerConfigIds, wired via formElement=dropdown and optionValuesFromClass on the gshTemplateConfigId metadata in grouper-loader.base.properties. The existing showEl conditions still gate visibility to the compiledJava case.
