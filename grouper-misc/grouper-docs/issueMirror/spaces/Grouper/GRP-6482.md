# GRP-6482  ws request and response logging should not need log4j change

## Comments

### Chris Hyzer - 2025-12-18T06:39:36.957+0000

The log level does not affect the logging. You need to set the grouper-ws.properties settings
{code:java}
# If set to true, this will log all rest requests (maybe for certain users or source IP networks, if configured)
# note: you do NOT need to set log4j edu.internet2.middleware.grouper.ws.j2ee.ServletFilterLogger to debug level, 
# this setting will always log at whatever level is available
# {valueType: "boolean", defaultValue: "false"}
ws.ServletFilterLogger.logRequests = false

# Comma separated source IP cidr's where the requests will be logged if ws.ServletFilterLogger.logRequests is true
# this is or'ed with logForSubjects.  e.g. 1.2.3.4/32, 2.3.4.5/24.  This is for ipv4 only for now.
# {valueType: "string", multiple: true}
ws.ServletFilterLogger.logForSourceIpCidrs = 

 {code}

By default the logger on the class is now DEBUG but that just helps identify the logs in the log file.
