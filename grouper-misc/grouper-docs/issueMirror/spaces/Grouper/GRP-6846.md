# GRP-6846  TrueFoundry provisioner: add team manager group metadata

Added support for specifying a managers group on a per-team basis, following the same pattern as the Datadog provisioner. A new group-level metadata attribute {{md_trueFoundryManagerGroupName}} (configurable via {{{}trueFoundryManagerGroupMetadataName{}}}, defaulting to {{{}md_trueFoundryManagerGroupName{}}}) is set on a team group to point to the Grouper group whose members should be team managers. Added {{TrueFoundryProvisioningTranslator}} which reads this metadata and populates the {{managers}} attribute on the target group using the named group's members. Added the metadata item to {{TrueFoundrySyncObjectMetadata}} with {{{}showForGroup = true{}}}. Requires {{{}trueFoundryAddTeamManagerMetadata = true{}}}. Documentation and i18n text updated.
