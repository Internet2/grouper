# GRP-6390  csv reports with doublequotes have doublequotes in the csv file and double double quotes

if you want the previous behavior with doublequotes in column headers, set this in grouper-loader.properties
{code:java}keepDoublequotesInColumnHeadersDefault = true {code}
There is a new setting on CSV sftp jobs that can control this different from that default (which if you do not change will default to false)

To see if you have any such jobs, look in your grouper-loader.properties for: csvReport.query
Look for double quotes in the column names of the query.
