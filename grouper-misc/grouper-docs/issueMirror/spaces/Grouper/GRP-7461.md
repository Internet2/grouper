# GRP-7461  MCP tool descriptions use Penn-specific 'pennkey' as an example subject identifier

* Six MCP tool descriptions give "pennkey" as an example of a subject identifier, e.g. "(e.g., login ID, pennkey, eppn, or subject ID)": `entity_get`, `entity_get_groups`, `privilege_assign`, `privilege_get`, `attribute_assignment_save`, and the shared subject property in `GrouperMcpSubjectUtils` that other tools use.

* Models repeat it back to users at other institutions, for example asking someone for their "pennkey" when it needs to know who they are.

* **Fix:** "pennkey" is replaced with the generic "netid" in all six. Text only, no behaviour change. MCP clients see the new descriptions in their next tool list.
