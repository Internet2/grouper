# GRP-7443  GcDbAccess binary (byte[] / blob) column support

GcDbAccess cannot read binary columns today: retrieveObjectFromResultSetByIndex throws Not expecting column type for BINARY, VARBINARY, LONGVARBINARY and BLOB, so select(byte[].class), selectList, and hydrating a GcPersistableClass bean with a byte[] field all fail. Add read support (getBytes for BINARY / VARBINARY / LONGVARBINARY, getBlob for BLOB) covering postgres bytea, mysql longblob and oracle blob.

Writes: storing a persistable bean with a null byte[] field should bind a typed null (setNull with a binary type) instead of setObject(index, null), which oracle can reject for a BLOB column. Document size limits (oracle setBytes into BLOB, mysql max_allowed_packet).

Backward compatible: nothing that works today changes. Prerequisite for a file_contents_blob column on grouper_file (persisted with GcDbAccess since GRP-7440). Unit tests in GcDbAccessBinaryTest.
