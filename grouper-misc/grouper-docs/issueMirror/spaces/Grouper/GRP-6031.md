# GRP-6031  non admins should be able to edit loaders for abac

I think users who can see the loader screen should be able to edit the loader.  When they go to edit it, they should only be able to do abac (have an optional abac users group), and recent memberships (have an optional recent memberships users group).  make sure they can only edit or view what that should be able to do.  Make a confluence page for each of these.  If the group is loaded by SQL or LDAP they should not be allowed to edit it.
