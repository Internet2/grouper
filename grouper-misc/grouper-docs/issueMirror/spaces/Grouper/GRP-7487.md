# GRP-7487  Smartsheet provisioner: seat types and account flag groups

Configure Grouper group names that drive Smartsheet seat types (member, contributor, guest) and account flags (admin, groupAdmin, licensedSheetCreator, resourceViewer). Groups do not need to be provisionable; the translator uses isInGroup so membership changes reach incremental provisioning. A blank group name means Grouper does not manage that seat or flag.

Highest seat wins (MEMBER over GUEST over CONTRIBUTOR). Optional smartsheetSeatTypeDefault for provisioned users in no seat group (blank by default). smartsheetDowngradeProvisionalMembers (default false). smartsheetPlanId is required when seat types are used. Seats change via the upgrade and downgrade endpoints.
