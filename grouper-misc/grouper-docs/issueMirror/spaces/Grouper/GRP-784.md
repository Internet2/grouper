# GRP-784  grouper ws login cache is too long

_(no description)_

## Comments

### mchyzer - 2012-05-09T20:50:57.582+0000

The cache was 30 minutes.  but this is too long since if an app hits the WS, gets an error, then is authorized, it wont check for 30 minutes.  Likewise if you revoke, that ID still has 30 minutes of access.  This was changed to 5 minutes which is still acceptable for performance.
