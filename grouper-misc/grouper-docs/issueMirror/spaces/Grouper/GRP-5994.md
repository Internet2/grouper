# GRP-5994  Add property rules.membershipDisabledDateDoNotExtend

I haven't tested this yet, but if there are two rules that set different disabled dates on a membership based on losing membership on different groups, will it consistently set the date to the shorter period? Or will it be random.

If there is a property rules.membershipDisabledDateDoNotExtend, it can consistently set the date to the shorter value, by not setting a longer date if one was already present.
