# GRP-5789  Javadoc and swagger reference FIND_BY_ATTRIBUTE, should be FIND_BY_EXACT_ATTRIBUTE

The WsQueryFilterType enum value is FIND_BY_EXACT_ATTRIBUTE, but all the docs refer to it as FIND_BY_ATTRIBUTE which returns an error when you specify that value.
