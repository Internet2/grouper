# GRP-1318  PSPNG-Creation and Location of provision_to and do_not_provision_to

Grouper PSPNG's default group-selection in 2.3.0 makes use of two attributes that deployers need to create: etc:attribute:userData:provision_to and etc:attribute:userData:do_not_provision_to.

There are two problems with this:
# The deployer had to create the attribute definitions and names, not the best process
# Attributes used by the system do not belong in userData.

This issue is to move the attributes and automatically create them: etc:pspng:provision_to and etc:pspng_do_not_provision_to.
