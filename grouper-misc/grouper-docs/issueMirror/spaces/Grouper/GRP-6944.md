# GRP-6944  Add native-target reporting infrastructure: beans, config, LDAP DAO wiring (WIP)

* Add three native-target beans for strict-native reporting: {{{}GrouperProvisioningTargetNativeUser{}}}, {{{}…NativeGroup{}}}, {{…NativeMembership}} (POJOs with {{targetId}} + optional Grouper-side FK + attributes map)
 * Add three lists on {{{}GrouperProvisioningData{}}}: {{targetNativeUsers}} / {{targetNativeGroups}} / {{targetNativeMemberships}} with getters/setters
 * Add target-id-keyed Maps on {{GrouperProvisioningDataIndex}} ({{{}targetUserIdToNativeUser{}}}, {{{}targetGroupIdToNativeGroup{}}}) plus {{buildNativeIndexes(debugMap)}} failsafe builder that records dup counts and sample examples in the debug map under {{nativeUserTargetIdDupCount}} / {{nativeUserTargetIdDupExamples}} / {{nativeGroupTargetIdDupCount}} / {{nativeGroupTargetIdDupExamples}}
 * Add new bean {{GrouperProvisioningNativeAttributeConfig}} (name/path/type) plus static {{parseAndValidate(String, String)}} to read the JSON-textarea config; throws on bad JSON so the daemon fails fast
 * Add two textarea config keys {{nativeAttributesJsonEntities}} / {{nativeAttributesJsonGroups}} to {{{}grouper-loader.base.properties{}}}, gated on {{${loadEntitiesToGenericGrouperTable}}} / {{${loadGroupsToGenericGrouperTable}}} respectively
 * Add labels and descriptions in {{grouper.textNg.en.us.base.properties}}
 * Add JSON validation hook in {{GrouperProvisioningConfigurationValidation.validateNativeAttributesJson()}} that surfaces parse errors via {{ProvisioningValidationIssue.assignJqueryHandle(suffix)}} so the UI can highlight the bad field
 * Wire parse + cache into {{GrouperProvisioningConfiguration.configureProvisioner}} with two new fields (raw JSON string + parsed {{{}List<GrouperProvisioningNativeAttributeConfig>{}}}) and getters
 * Refactor {{GrouperProvisioningLogic.loadDataToGenericProvisionerTables}} and the incremental counterpart to read from the new native lists instead of walking wrappers; drop the wrapper-based fallback helpers
 * Add {{LdapProvisioningTargetNativeBuilder}} (LDAP-side helper) with {{{}widenLdapAttributeNamesForGroups/Entities{}}}, {{{}buildNativeGroup/User{}}}, and {{appendNativeMembershipsFromGroupEntry/EntityEntry}}
 * Wire the four LDAP DAO select methods ({{{}retrieveAllGroups{}}}, {{{}retrieveGroups{}}}, {{{}retrieveAllEntities{}}}, {{{}retrieveEntities{}}}) to widen attribute requests with native-attribute paths and populate the native lists at parse time, gated on the corresponding load flags
 * Add non-unique single-column indexes {{grouper_prov_user_idx2}} on {{target_user_id}} and {{grouper_prov_grp_idx2}} on {{target_group_id}} across postgres / oracle / mysql install + V41 + GrouperDdl7_2_0 + aiGsh schema reference
 * Widen {{target_user_id}} and {{target_group_id}} from {{VARCHAR(256)}} to {{VARCHAR(1000)}} to accommodate LDAP DNs and other long target identifiers
 * Add {{LdapProvisionerGenericTableTest}} with two test methods (group side and entity side) — currently failing; tests will be tightened in a follow-up commit once the strict-native two-pass behavior is fully validated against the LDAP test container
