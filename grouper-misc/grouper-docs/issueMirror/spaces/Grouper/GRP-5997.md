# GRP-5997  HookVeto reasonKeys don't get replaced with text in the UI

Veto exceptions for hooks and rules have a reason with a free text string. It also has a reasonKey which is supposed to be a key from text.properties based on code comments and UI descriptions, but I don't see it actually doing the replacement. The raw value becomes part of the error message, i.e., theReasonKey + ": " + theReason. This looks ugly in the UI. It's required since it's doing a string append in the message.
