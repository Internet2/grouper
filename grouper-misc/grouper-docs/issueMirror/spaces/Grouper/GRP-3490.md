### Chris Hyzer - 2021-06-01T17:24:18.387+0000

Looks like we identified the problem.The issue is in 2.4 we have this property set to: (in grouper-loader.properties)
changeLog.consumer.pspng_LdapAttributeProvisioner.attributesUsedInGroupSelectionExpression = etc:pspng:provision_to
But looks like it should be set to this in 2.5:
changeLog.consumer.pspng_LdapAttributeProvisioner.attributesUsedInGroupSelectionExpression = etc:pspng:provision_to,etc:pspng:do_not_provision_to
