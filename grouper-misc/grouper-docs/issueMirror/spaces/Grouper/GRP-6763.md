# GRP-6763  MCP doc_search tool - RAG full-text search over documentation

Added a new {{doc_search}} MCP tool that provides Retrieval Augmented Generation (RAG) full-text search over institutional documentation using Apache Lucene.

*Features:*
 * In-memory Lucene index with automatic chunking (~3200 char chunks with ~400 char overlap at paragraph boundaries)
 * Four actions: {{query}} (full-text search), {{retrieveChunk}} (fetch specific chunks by name/url), {{listSourceConfigIds}} (list available sources with descriptions), {{listNames}} (list document names for a source, max 1000)
 * SQL-based content sources configured via {{grouper.base.properties}} — point any external system query at a table/view with name, url, and content columns
 * Built-in {{grouperDataDictionary}} source that automatically indexes data field and data row configurations (descriptions, examples, aliases, types) with HTML-to-markdown conversion
 * Privacy realm filtering: data dictionary results are filtered per-user based on privacy realm viewer/reader/updater group membership; public realms accessible to all
 * Tool is only advertised to users who have access to at least one source (SQL-based or privacy realm)
 * Index rebuilds automatically with configurable TTL; zero-downtime rebuild via atomic swap
 * Data dictionary indexing can be disabled via {{grouper.mcp.docSearch.dataDictionary.enable}}

*Files changed:*
 * {{GrouperMcpDocSearchIndex.java}} (grouper core) — Lucene index manager singleton with chunking, indexing, search, privacy filtering
 * {{GrouperMcpDocSearch.java}} (grouper-ws) — MCP tool handler with action dispatch
 * {{GrouperMcpServlet.java}} (grouper-ws) — tool advertisement filtered by subject access
 * {{GrouperMcpToolLog.java}} (grouper core) — doc_search categorized as read-only
 * {{grouper.base.properties}} — new configuration properties for doc search sources and data dictionary enable
 * {{GrouperMcpDocSearchTest.java}} — unit tests including chunking, search, retrieve, source filtering, data dictionary with privacy realm authorization
 * Lucene 9.12.1 dependencies added to pom.xml (lucene-core, lucene-analysis-common, lucene-queryparser)
 * Wiki documentation updated (user guide and admin guide)
