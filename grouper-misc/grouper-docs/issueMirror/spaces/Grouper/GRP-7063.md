# GRP-7063  UI daemon loader jobs list filter on error should act on last status, not overall

The filter by error status in the loader job page doesn't work the same as it does in the daemon job list. Filtering for any error in the loader job list only shows disabled jobs. Likely it's only looking at overall status and not last run status. The latter is more useful to see which are the actual failures. Also, there should be a column for last run status like the daemon list has. The status column probably means overall status over a period of time.
