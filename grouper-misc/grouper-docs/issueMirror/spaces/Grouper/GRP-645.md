### Gary Brown - 2012-01-04T16:39:22.651+0000

Problem was due to the current browse node being set to a group when a stem is expected. The browsing code handles this by getting the parent of such a group. I've now added code to set the parent as the current node. Gets rid of the error though browsing point may not always be what is expected
