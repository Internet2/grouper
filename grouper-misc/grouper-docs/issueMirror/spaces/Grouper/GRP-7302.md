# GRP-7302  UI accessibility: form-field border contrast and keyboard focus indicator contrast

Two shared non-text-contrast fixes in grouperUi2.css (accessibility items 7 and 2), both overriding bootstrap defaults. grouperUi2.css loads after bootstrap.css so equal-or-higher-specificity rules win.

Item 7 (SC 1.4.11): form controls use bootstrap border 1px solid #cccccc, which is about 1.61:1 on white and fails the 3:1 non-text-contrast requirement. Darken the resting border of inputs, textareas and selects to #767676 (about 4.54:1). Affected controls include the header search, folder-name filter, and the my-folders filter.

Item 2 (SC 2.4.11 / 1.4.11): the authored link focus outline (bootstrap thin dotted #333) is about 1.78:1 on the teal #1c6070 breadcrumb bar, effectively invisible there. Replace it with a robust focus-visible indicator: a teal #1c6070 outline plus a two-layer white+teal ring (box-shadow), so focus is at least 3:1 on both white content and the teal bar (white-on-teal and teal-on-white are each about 7.1:1). The outline is kept so Windows High Contrast Mode still shows an indicator.
