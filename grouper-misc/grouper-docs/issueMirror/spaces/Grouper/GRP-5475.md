# GRP-5475  Upgrade bootstrap version

The bootstrap version in Grouper is 2.2.2 which is from 2012. It still works, but the dropdown syntax is slightly incompatible with jquery 1.12+, and we want to upgrade jquery. We would need to modify all the dropdowns either way, so maybe it's a good time to upgrade?
