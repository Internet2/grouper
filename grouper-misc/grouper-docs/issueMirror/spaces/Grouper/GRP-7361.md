# GRP-7361  Add scripted group methods for entity recent attribute

{noformat}# some ideas
entity.hasRecentAttribute('is_active', true, '7 days')
OR
entity.hasRecentAttribute('primary_dept =~ ['ITS', CAS']', '7 days')
OR (includeCurrent flag for whether to include currently having it)
entity.hasRecentAttribute('primary_dept =~ ['ITS', CAS']', '7 days', false)
OR (had implies no longer has it)
entity.hadRecentAttribute('primary_dept =~ ['ITS', CAS']', '7 days')
{noformat}

Without this, you still need an intermediate group of people who currently have the attribute, and then set up a grace period group to capture those who leave the group. With this jexl, you could skip those intermediate groups.

Carey had a suggestion to add a flag for requireAllValues. If there is a parallel with memberOf methods then ok. Otherwise just have multiple expressions.
