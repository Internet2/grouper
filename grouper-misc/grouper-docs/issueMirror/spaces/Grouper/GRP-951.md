# GRP-951  PSP needs a MembershipDataConnector

Rice and others are trying to put attributes on memberships and have those be applied to LDAP entries.  There is not membership data connector though so we need to create one.

## Comments

### langedb - 2014-05-01T23:58:59.914+0000

This seems to be a huge issue now regarding deleting of attributes off users - need to get this fixed sooner than later.  The issue is adding a member to a group puts the member into the group with the attributes & everything is fine.  Unfortunately, when a user is deleted from the group or if an attribute is removed from that user, it's a Membership object & that causes us to skip it as we don't process membership items.
