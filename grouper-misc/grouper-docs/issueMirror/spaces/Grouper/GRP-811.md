# GRP-811  PSP message " Unable to calculate provisioned object" for unmannaged PSP groups show on Error log

The PSP message " Unable to calculate provisioned object" if logged at the error level when the PSP tries to calculate for a newly created group that is outside of PSP's managed stem.

Use case :
1- PSP is provisionning everything under stem udem:
2- Create a group test:NewGroup
3- Log will show multiple " Unable to calculate provisioned object" calc response
