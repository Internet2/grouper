# GRP-7349  Add YourKit open source profiler acknowledgment to README

YourKit GmbH provides free open source licenses for the YourKit Java Profiler to the Grouper development team. In exchange they ask for a public acknowledgment on the project site that includes the YourKit logo and a hyperlink to yourkit.com.

Add a Profiling section at the bottom of README.md in the GitHub repo stating that the Grouper development team uses the YourKit Java Profiler, with the YourKit logo and links to the YourKit Java Profiler, YourKit .NET Profiler, and YourKit YouMonitor pages.
