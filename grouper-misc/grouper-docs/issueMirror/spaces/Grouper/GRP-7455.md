# GRP-7455  Do not publish -tests.jar artifacts to Maven Central to reduce release size

Maven Central now enforces a monthly Release Size limit (80 MB/month for Internet2). The -tests.jar artifacts add about 7 MB per release (grouper-tests 6.3 MB, grouper-ws-tests 0.8 MB, others small). Nobody consumes them from Central: Eclipse uses source, and CI/release builds use the tests jars built locally in the reactor.

Change: the modules that depend on another module's tests jar (grouper, grouper-ui, grouper-ws, grouper-ws-test, grouper-authentication-logic) now declare those test-jar dependencies in a profile that is active unless -Dmaven.test.skip=true. The Maven Central release build should run with -Prelease -Dmaven.test.skip=true, which skips test compilation, skips building the tests jars (maven-jar-plugin test-jar honors maven.test.skip), and skips resolving the test-jar dependencies, so no tests jars are published. Normal builds are unchanged.
