# GRP-7467  Upgrade jackson to 2.22.3 for security

jackson-core and jackson-databind 2.22.1 have open advisories, fixed in 2.22.3: GHSA-7hhh-6rmp-j9qf (high), GHSA-p6pp-m3f8-5c89 (high, ReDoS in NumberInput), GHSA-cxp5-3px4-pw24 (high), GHSA-wv8q-qhhj-9h54 (high), GHSA-q4xh-88c3-wmh7 (high), GHSA-gx83-3vf8-gh7j (moderate), GHSA-wjgm-6hv5-3cvf (moderate). Mostly denial of service on parsing untrusted JSON.

Fix: jackson.version 2.22.1 -> 2.22.3 in grouper-parent. All Jackson modules follow via the jackson-bom import (GRP-7432). The container poms do not inherit grouper-parent (GRP-7453), so verify the image with: docker run --rm i2incommon/grouper:<version> bash -c "ls /opt/grouper/grouperWebapp/WEB-INF/lib | grep -i jackson"
