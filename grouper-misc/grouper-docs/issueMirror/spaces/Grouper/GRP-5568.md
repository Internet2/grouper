# GRP-5568  Using provisioner ACLs, add configuration property so only group admins can set provisioning, not readers

Currently, if you have a group of members who can admin provisioning, they only need read access on the group to set provisioning. Some customers would rather require to be a group admin PLUS be in the control list of provisioner admins.
