# GRP-1010  Changes to Browse Folders pane not automatically refreshing

per the email below - i suggest just adding a refresh button on the folders pane as Chris suggests.

We don't have the distinction of admin vs user in the new UI...  I don't think that exists in the API, it was just built in the Admin UI code which is going away.  The new UI uses the API as much as possible, so if we want this functionality back we need to add this to the API...  if you need this please add a jira.

The folders don't get updated when objects add/delete/change, you need to refresh your browser.  One thing I have been considering is if you add/change/delete an object that folders pane would just refresh and everything would be collapsed...  it's a difficult problem with ajax and not refreshing the page...  you can enter a jira for that too if you like :)  I can also add a refresh button to the folders pane to just reload that pane...

Thanks,
Chris
