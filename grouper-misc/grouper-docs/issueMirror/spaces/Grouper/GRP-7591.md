# GRP-7591  Entity data provider query: subject id type should be required

In the entity data provider query config (grouperDataProviderQuery.<configId>.providerQuerySubjectIdType), the subject id type (subjectId or subjectIdentifier) is not marked required in the UI, so a provider query can be saved without it.

Fix: add required: true to the config metadata for providerQuerySubjectIdType in grouper.base.properties so the UI enforces selecting a value.
