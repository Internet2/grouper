# GRP-1346  PSPNG-Group-DN updates

From [grouper-users, July 2016|https://lists.internet2.edu/sympa/arc/grouper-users/2016-07/msg00036.html].

The DNs of LDAP Groups are correctly defined when groups are created, but are not updated when data is changed in Grouper. For example, when the Group's name is mapped to CN which is then used as the RDN, the CN&DN should be updated when the group's name is changed in grouper. 

bq. changeLog.consumer.pspng_groupOfNames.groupCreationLdifTemplate = dn: ${utils.bushyDn(group.name, "cn", "ou")}||objectclass: groupOfNames||description: ${group.description}


Note, this ticket is limited to mirroring changes of the LDAP DN. Problems updating other attributes of Groups are scoped in GRP-1345.
