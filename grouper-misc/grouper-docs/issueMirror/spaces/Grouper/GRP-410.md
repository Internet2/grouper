# GRP-410  license and copyright procedures

The suggestion is to follow shibboleth's example and use an Eclipse template to automatically add the Apache License header to each newly created java source file. Of course, existing files will need to be handled manually, one time.

We would need to add another template to the "org.eclipse.jdt.ui.text.custom_code_templates"  property of .settings/org.eclipse.jdt.ui.prefs.
