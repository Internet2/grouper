### bert - 2018-09-17T06:32:01.661+0000

In regards to the lack of information present in the logs about which provisioner is having problems.... The following log4j formatter may help add a lot of contextual information. In particular, the %X items annotate the lines you're seeing.

log4j.appender.grouper_error.layout.ConversionPattern  = %d\{ISO8601}: [%t] %-5p [%c\{1}] %X\{why}%X\{who}%X\{what}%X\{step} - %x - %m%n

 

In regards to the actual problem:

PSPNG Patch 0 has reorganized the method that failed in your log, and the new version does handle NULLs specifically.

Please do try Patch 0 once it is packaged, or here is a Dockerfile that will patch your image. (This one inherits from an intermediate container, but this should could be changed to inherit from any 2.4 image):

[Patched Image Github Folder|https://github.com/Internet2/grouper/tree/master/grouper-misc/grouper-pspng/pspng-docker-tests/docker-compose/grouper-pspng-testpatched]
