# GRP-5314  Convert enabledDisabled MAINTENANCE job to OTHER_JOB

_(no description)_

## Comments

### Shilen Patel - 2024-02-21T17:10:19.814+0000

Upgrade step needed for users who have overwritten configuration for {*}changeLog.enabledDisabled.queryIntervalInSeconds{*}. 

The new property name is {*}otherJob.enabledDisabled.queryIntervalInSeconds{*}.

The default value is still 3600.  So if you have the old property configured as something else, you probably want to set that value on the new property.  This property is in grouper-loader.properties and can also be edited using the Daemon UI screen.
