# GRP-7451  Container: Tomcat error pages do not show stack traces or the Tomcat version

Tomcat's default ErrorReportValve shows the exception stack trace and the Tomcat version on its error pages (e.g. an Error thrown before the Grouper app handles it, or a sendError 500). Security scanners flag this (CWE-209, CWE-200).

The container server.xml patch now adds <Valve className=org.apache.catalina.valves.ErrorReportValve showReport=false showServerInfo=false /> to the Host, so Tomcat error pages show only the status.
