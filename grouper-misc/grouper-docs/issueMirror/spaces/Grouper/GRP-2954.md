# GRP-2954  add param for mod_remoteip

Are you the only one who would add ENV's to the containers?
  
 !https://ca.slack-edge.com/T073A2Z0D-U2CFLGARY-g75844fcd810-24! Scott Koranda
 I have looked at images i2incommon/grouper:2.5.29 and i2incommon/grouper:2.5.33 and I do not see that the Apache HTTP Server mod_remoteip ([https://httpd.apache.org/docs/2.4/mod/mod_remoteip.html]) is being configured. Could that be added in the future? Perhaps it could be “off” by default but configured/enabled when either (or both) of the environment variables GROUPER_APACHE_REMOTE_IP_HEADER and GROUPER_APACHE_REMOTE_IP_TRUSTED_PROXY are defined with values for the configuration options RemoteIPHeader and RemoteIPTrustedProxy respectively.
