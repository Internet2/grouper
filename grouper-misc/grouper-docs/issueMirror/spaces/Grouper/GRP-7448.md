# GRP-7448  Compiled GSH templates are treated as V1 unless templateVersion is set to V2

A compiled GSH template (templateMode=compiled) always extends GshTemplateV2, but several places still check templateVersion == V2 instead of also checking compiled mode. templateVersion defaults to V1, so a new compiled template that does not explicitly set V2 silently skips decorateForUi in validation and in the UI, and the template test runner says only V2 templates can be tested.

Fix: treat compiled templates as V2 wherever the version is checked, and hide templateVersion in the UI for compiled templates since it only applies to interpreted (Groovy) templates. No config keys change; existing compiled templates with templateVersion=V2 keep working.
