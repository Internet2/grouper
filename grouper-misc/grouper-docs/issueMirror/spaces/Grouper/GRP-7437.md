# GRP-7437  Provisioner failsafe does not cover entity deletes (entity-only provisioners have no failsafe)

Provisioner failsafes only count groups and memberships (failsafeMaxPercentRemove, failsafeMaxOverallPercentGroupsRemove, failsafeMaxOverallPercentMembershipsRemove, failsafeMinOverallNumberOfMembers). GrouperProvisioningFailsafe has no entity checks, so for an entity-only provisioner (operateOnGrouperGroups=false, operateOnGrouperMemberships=false, e.g. AssetSonar) every threshold sees zero and nothing trips, even if a bad run would delete or deactivate most accounts in the target. Turning on showFailsafe looks like a brake with nothing attached.

Add two provisioner failsafe settings that work like the membership ones: failsafeMaxOverallPercentEntitiesRemove (trip if more than this percent of the entities in the target would be deleted in one run) and failsafeMinOverallNumberOfEntities (trip if the target would be left with fewer entities than this). The current count is the larger of the entities this provisioner has in the target (grouper_sync_member in_target) and the target entities read this run (so a full sync that selects all entities also counts entities Grouper never created). Blank or -1 means off, no global default, so nothing changes on upgrade. Approve and email work as for the other failsafes.

Added two provisioner failsafe settings that count entity deletes: failsafeMaxOverallPercentEntitiesRemove (trip if a run would delete more than this percent of the entities in the target) and failsafeMinOverallNumberOfEntities (trip if a run would leave fewer than this). Blank or -1 means off, no global default, so nothing changes on upgrade. Approval, email and ERROR_FAILSAFE work as for the other failsafes.

The entity count is the larger of the entities this provisioner has in the target (grouper_sync_member in_target) and the target entities read this run, so a full sync that selects all entities also counts accounts Grouper never created. The count query only runs when there are entity deletes. The failsafe summary in the job log shows the entity count and deletes.
