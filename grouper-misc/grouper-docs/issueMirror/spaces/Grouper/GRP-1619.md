# GRP-1619  Use an installer property to limit the type of patch applied

It would be great if the Grouper Installer's automated install config/properties file could be used to limit the type of patches applied to a given installation. A user could specify bugs vs enhancements.

The biggest problem I see with this requests is I'm not sure how the team could effectively patch a baseline bug that may or may not have included changes to an enhancement. Dependency patch management might get complicated.
