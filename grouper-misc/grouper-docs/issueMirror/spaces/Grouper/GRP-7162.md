# GRP-7162  daemon jobs list/search should include unscheduled (config-only) jobs, with a Schedule action

The Miscellaneous -> Daemon jobs list (UiV2Admin.daemonJobs) only shows jobs currently registered with the Quartz scheduler. A daemon that has been configured but not yet scheduled -- for example an otherJob added via the config editor or config import that has not gone through a reschedule -- does not appear in the list, and searching for it by job name returns no results. This is confusing: the config clearly exists, but the daemon screen says there is nothing there.

Improvement 1: the daemon jobs list and its job-name search should also return unscheduled config-only jobs (jobs that have an otherJob/changeLog/loader config but no live Quartz schedule), clearly marked as unscheduled, so an admin can see everything that is configured, not just what is currently scheduled.

Improvement 2: for such an unscheduled job, the per-job actions menu should offer a Schedule action that registers it with the scheduler (using its configured quartzCron), so the admin can schedule it from the list without restarting or waiting for a reschedule cycle.

Found while testing GRP-7155: a compiledJava otherJob daemon that was configured but not scheduled was invisible in the daemon jobs list and unfindable by search.
