# GRP-6900  tomcat access log pattern should be configurable

The log pattern for tomcat access log is hardcoded in librarySetupFilesTomcat.sh. There should be a variable that makes it easier to customize.



## Comments

### Chad Redman - 2026-05-15T15:22:03.480+0000

From testing, using request attribute "grouperRemoteUser" (pattern %\{grouperRemoteUser}r) is reliable for both built-in auth and for pac4j. If you have an external sidecar doing auth, it's probably injecting the REMOTE_USER header, so in that case it should just be %u.

This is what I have for the default pattern, which is close to what it was in v4. It's not easy to add in the environment and component, but I added the "catalina.out" so it can be discerned in the logs.

 

GROUPER_TOMCAT_LOG_ACCESS_PATTERN=catalina.out;%h %l %\{grouperRemoteUser}r %t \"%r\" %s %b
