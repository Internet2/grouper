# GRP-7492  Review or create a Grouper UI accessibility standards wiki page for developers

Check whether the Grouper wiki already has an accessibility standards page for developers. If it does, review and update it. If not, create one. The goal is one page that UI contributors (core team and community PRs) read before changing JSPs, JS, or CSS, so new work does not reintroduce issues that were already fixed.

Background: accessibility fixes have been made in several waves (GRP-1380 to GRP-1546 in 2016-2017, GRP-4877 in 2023, GRP-7056 to GRP-7463 in 2026) without a written standard, and a number of old accessibility tickets stayed open for years after they were fixed. Institutions are also starting to audit Grouper against WCAG (for example the session timeout and 2.2.1 Timing Adjustable).

Suggested contents:

* Target standard: WCAG 2.2 level AA for the Grouper UI.
* Use native elements: button for actions (no anchors that only run ajax), a for navigation only, real form labels tied to inputs by id.
* ARIA: unique ids, aria-controls / aria-expanded on disclosures and menus, aria-hidden on decorative icons, aria-label on icon-only buttons, no HTML markup in title attributes.
* Dynamic content: role=status for loading/progress, role=alert or a live region for success and error messages, focus management after ajax redraws (focus the changed field or the new content).
* Page structure: unique page title, one h1 per screen, main landmark and skip link, breadcrumb as a labeled nav.
* Visual: text and UI component contrast (4.5:1 and 3:1), visible keyboard focus indicator, 24x24 minimum target size for icon-only controls.
* Keyboard: every action reachable and operable by keyboard, logical tab order, dropdowns and modals keyboard-operable with focus returned on close.
* Time limits: session timeout behavior and the plan for a warning / extend dialog (WCAG 2.2.1).
* Testing checklist for PRs: WAVE or axe pass, keyboard-only walkthrough, a quick screen reader check (NVDA or VoiceOver), contrast check of any new colors.
* Where styles live (grouperUi2.css) and reusable patterns / snippets for buttons, menus, tooltips and modals, with links to the GRP tickets that established them.

Done when: the page exists (or is updated) on the Grouper wiki, is linked from the developer / contributing docs, and the PR process mentions the accessibility checklist.
