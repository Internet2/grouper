# GRP-1060  add aws sns / sqs support to the esb change log consumer

## Comments

### mchyzer - 2014-10-15T14:42:33.800+0000

This is done:

https://github.com/Internet2/grouper/commit/b0289d5f88c511128af0785e3414cf96aa06c0dc

You need to configure an SNS topic, a user who can publish to the topic, an SQS queue subscribed to the topic, and the same user or a different user who can receive/delete from the queue.  I would also set the delivery option on the SQS so it doesnt include the SNS wrapper.  Configure in the grouper-loader.properties:

changeLog.consumer.awsJira.quartzCron = 
changeLog.consumer.awsJira.class = edu.internet2.middleware.grouper.changeLog.esb.consumer.EsbConsumer
changeLog.consumer.awsJira.elfilter = (event.eventType eq 'MEMBERSHIP_ADD' || event.eventType eq 'MEMBERSHIP_DELETE') && event.groupName != null && event.groupName.startsWith('some:stem')
changeLog.consumer.awsJira.publisher.class = edu.internet2.middleware.grouperAwsChangelog.GrouperAwsEsbPublisher
changeLog.consumer.awsJira.publisher.awsAccessKey = 789xyz
changeLog.consumer.awsJira.publisher.awsSecretKey = abc123
changeLog.consumer.awsJira.publisher.awsRegion = US_EAST_1
changeLog.consumer.awsJira.publisher.awsSnsTopicArn = arn:aws:sns:us-east-1:1234567:topicName

Note, you need to add the jars from the project grouper-misc/grouper-aws-changelog: dist/grouperAws.jar, and everything in the lib/*.jar.  There is a class GrouperAwsSqsListener which will pop events off the SQS.

Just set this in the grouper.client.properties:

grouperClient.awsAccessKey = xyz789
grouperClient.awsSecretKey = abc123
grouperClient.awsSqsQueueUrl = https://sqs.us-east-1.amazonaws.com/1234/queue_name
